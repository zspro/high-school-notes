# Readme

欢迎来到 **An Awesome Note** ！

这是一个基于中国普通高中教科书（人教版）的笔记项目，覆盖数学、物理、化学三科。

目前还在持续更新并搭建中。

## 收录内容

| 学科 | 必修 | 选择性必修 |
|:---:|:---|:---|
| [数学](/数学/) | 必修一、必修二 | 选择性必修一、二、三 |
| [物理](/物理/) | 必修一、必修二、必修三 | 选择性必修一、二、三 |
| [化学](/化学/) | 必修一、必修二 | 选择性必修一、二、三 |

每章笔记大致包含：来龙去脉、基础精讲、深度理解、知识串联、隐性考点、易错警示、思想方法。标注"超出教材要求"的内容仅供拓展。

## 如何使用？

左侧有目录（移动设备是顶上有一个 Menu 可以展开），可以打开对应章节来查看。

顶部导航栏可以按学科、按册跳转；顶部的搜索栏可以根据关键词搜索内容。
