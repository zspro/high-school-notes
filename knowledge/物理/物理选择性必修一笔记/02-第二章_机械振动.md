# 第二章 机械振动
---

## 一、来龙去脉：振动现象的历史研究

### 1.1 人类对周期性运动的早期观察

机械振动是自然界中最普遍的运动形式之一。从古代起，人类就注意到了物体的往复运动：树枝在风中摇曳、琴弦发出声响、水面波浪的起伏。然而，对这些现象进行定量的科学分析，则始于17世纪的科学革命。

### 1.2 伽利略与摆的等时性

1583年，伽利略（Galileo Galilei）在比萨大教堂观察到吊灯的摆动。他用自己的脉搏测量发现，无论摆幅大小如何，吊灯完成一次摆动的时间几乎是相同的。这一观察导致了摆的等时性原理的发现：在小幅摆动条件下，单摆的周期与振幅无关。

伽利略晚年对摆进行了系统研究，提出了利用摆来制造更精确计时装置的设想。他认识到，摆的周期只取决于摆长，这一性质为后来精密计时仪器的研制奠定了物理基础。

### 1.3 惠更斯与摆钟的发明

1656年，荷兰物理学家惠更斯（Christiaan Huygens）基于伽利略的发现，成功制造出第一台实用的摆钟。惠更斯在《摆钟论》（*Horologium Oscillatorium*, 1673）中给出了单摆周期的数学表达式：

$$T = 2\pi\sqrt{\frac{l}{g}}$$

惠更斯还研究了复摆的等时性问题，提出了摆动中心的概念，为刚体转动动力学的发展作出了重要贡献。摆钟的发明使时间测量的精度从原来的每日误差约15分钟提高到每日误差不超过几秒钟，极大地推动了天文学、航海学和物理学的发展。

### 1.4 胡克定律与弹性回复力

1678年，英国科学家胡克（Robert Hooke）发表了弹性定律：在弹性限度内，弹簧的伸长量与所受外力成正比。其数学表述为：

$$F = kx$$

其中 $k$ 为弹簧的劲度系数，$x$ 为形变量。胡克定律揭示了弹性体恢复原状的内在机制——当物体偏离平衡位置时，会产生一个指向平衡位置的力，其大小与偏离量成正比。这一发现为建立简谐运动的力学模型提供了核心基础。

### 1.5 简谐运动作为理想模型的意义

简谐运动是最基本、最重要的振动形式。任何复杂的周期性运动都可以分解为若干个简谐运动的叠加（傅里叶分析），这使得简谐运动成为研究一切振动现象的出发点。

将实际的振动系统抽象为简谐运动模型，需要引入以下理想化条件：

| 理想化条件 | 物理含义 | 实际系统的偏差 |
|:---|:---|:---|
| 无阻尼 | 系统运动过程中无能量耗散 | 存在空气阻力、摩擦等耗散因素 |
| 小角度/小位移 | 回复力与位移严格成正比 | 大位移时非线性效应显著 |
| 理想弹性体 | 服从胡克定律，无塑性形变 | 弹簧存在质量，大形变时偏离线性 |
| 质点模型 | 振动物体视为质点 | 实际物体有大小和形状，涉及转动 |

这种理想模型法的核心思想是：首先研究最简化的模型，掌握其基本规律，再逐步引入实际因素，使理论更接近真实情况。这一方法论在物理学中具有普适性。

## 二、基础精讲

### 2.1 简谐运动

#### 2.1.1 弹簧振子模型

弹簧振子是研究简谐运动的典型模型。由一根质量可忽略的轻弹簧和一个可视为质点的物体（振子）组成。将振子从平衡位置拉开后释放，在弹性回复力的作用下，振子将在平衡位置附近做往复运动。

设弹簧的劲度系数为 $k$，振子质量为 $m$，以平衡位置为坐标原点，沿振动方向建立 $x$ 轴。当振子位移为 $x$ 时，根据胡克定律，回复力为：

$$F = -kx$$

负号表示回复力方向始终与位移方向相反，即始终指向平衡位置。

根据牛顿第二定律 $F = ma$，有：

$$m\frac{d^2x}{dt^2} = -kx$$

整理得：

$$\frac{d^2x}{dt^2} + \frac{k}{m}x = 0$$

令 $\omega^2 = \frac{k}{m}$，得到简谐运动的微分方程：

$$\frac{d^2x}{dt^2} + \omega^2 x = 0$$

#### 2.1.2 运动学方程的求解

上述微分方程为二阶常系数线性齐次微分方程。其特征方程为：

$$r^2 + \omega^2 = 0$$

解得特征根 $r = \pm i\omega$。因此方程的通解为：

$$x(t) = C_1\cos(\omega t) + C_2\sin(\omega t)$$

利用三角函数的和角公式，可将上式改写为：

$$x(t) = A\sin(\omega t + \varphi)$$

或等价地：

$$x(t) = A\cos(\omega t + \varphi')$$

其中 $A$、$\varphi$（或 $\varphi'$）为由初始条件确定的常数。上式即为简谐运动的运动学方程，表明简谐运动是时间的正弦（或余弦）函数。

#### 2.1.3 位移-时间图像

以横轴表示时间 $t$，纵轴表示位移 $x$，简谐运动的 $x-t$ 图像为正弦（或余弦）曲线。图像的特征包括：

| 图像特征 | 物理意义 |
|:---|:---|
| 曲线峰值/谷值的绝对值 | 振幅 $A$ |
| 相邻两个波峰（或波谷）之间的时间间隔 | 周期 $T$ |
| $t = 0$ 时的位移值 | 初相位 $\varphi$ 决定 |
| 曲线在某点的斜率 | 该时刻的瞬时速度 |
| 斜率变化的快慢程度 | 该时刻的加速度 |

由运动学方程 $x = A\sin(\omega t + \varphi)$，通过求导可得速度和加速度：

$$v = \frac{dx}{dt} = A\omega\cos(\omega t + \varphi)$$

$$a = \frac{d^2x}{dt^2} = -A\omega^2\sin(\omega t + \varphi) = -\omega^2 x$$

速度-时间曲线和加速度-时间曲线同样为正弦型曲线，但相位依次超前 $\frac{\pi}{2}$。

### 2.2 简谐运动的描述

#### 2.2.1 振幅 $A$

振幅 $A$ 是振动物体离开平衡位置的最大距离，是标量，恒取正值。振幅反映了振动的强弱，由系统的初始能量决定。对弹簧振子，若初始时刻 $t = 0$ 时位移为 $x_0$、速度为 $v_0$，则：

$$A = \sqrt{x_0^2 + \frac{v_0^2}{\omega^2}}$$

振幅的单位为米（m）。

#### 2.2.2 周期 $T$ 与频率 $f$

周期 $T$ 是物体完成一次全振动所需的时间，单位为秒（s）。频率 $f$ 是单位时间内完成全振动的次数，单位为赫兹（Hz）。二者互为倒数：

$$f = \frac{1}{T}$$

角频率 $\omega$（又称圆频率）表示单位时间内相位的变化量，单位为弧度每秒（rad/s）。三者关系为：

$$\omega = \frac{2\pi}{T} = 2\pi f$$

对弹簧振子，由 $\omega^2 = \frac{k}{m}$ 得：

$$T = 2\pi\sqrt{\frac{m}{k}}$$

#### 2.2.3 相位 $\varphi$ 与初相位

相位 $(\omega t + \varphi)$ 是决定简谐运动物体在任意时刻运动状态的物理量。初相位 $\varphi$ 是 $t = 0$ 时的相位，由初始条件确定：

$$\tan\varphi = \frac{x_0\omega}{v_0}$$

或

$$\varphi = \arctan\left(\frac{v_0}{\omega x_0}\right)$$

具体取值需结合 $x_0$ 和 $v_0$ 的正负确定象限。

#### 2.2.4 相位差的计算

两个同频率简谐运动 $x_1 = A_1\sin(\omega t + \varphi_1)$ 和 $x_2 = A_2\sin(\omega t + \varphi_2)$ 的相位差为：

$$\Delta\varphi = (\omega t + \varphi_2) - (\omega t + \varphi_1) = \varphi_2 - \varphi_1$$

| 相位差条件 | 运动关系 |
|:---|:---|
|$\Delta\varphi = 0$ | 同相：两振动物体同时达到最大位移和平衡位置 |
|$\Delta\varphi = \pi$ | 反相：一物体达正最大位移时另一物体达负最大位移 |
|$\Delta\varphi = \frac{\pi}{2}$ | 正交：一物体在最大位移处时另一物体在平衡位置 |

### 2.3 简谐运动的回复力和能量

#### 2.3.1 回复力的本质特征

简谐运动的动力学定义：如果物体所受的回复力与位移成正比且方向相反，即满足

$$F = -kx$$

则物体的运动为简谐运动。这是简谐运动的本质判据，也是判断是否做简谐运动的根本依据。

回复力不是一种新的性质的力，它是按力的效果命名的。它可以由某个单独的力提供（如水平弹簧振子的弹力），也可以由几个力的合力提供（如竖直弹簧振子的弹力与重力的合力），还可以由某个力的分力提供（如单摆的重力沿切向的分力）。

#### 2.3.2 竖直弹簧振子的回复力分析

将弹簧振子竖直悬挂时，平衡位置不再是弹簧的原长位置。设弹簧劲度系数为 $k$，振子质量为 $m$，弹簧在平衡位置时的伸长量为 $x_0$。由平衡条件：

$$kx_0 = mg$$

以平衡位置为坐标原点，向下为正方向。当振子向下偏离平衡位置位移 $x$ 时，弹簧总伸长量为 $x_0 + x$，弹力大小为 $k(x_0 + x)$，方向向上。此时回复力为：

$$F = mg - k(x_0 + x) = mg - kx_0 - kx = -kx$$

由此可见，以平衡位置为原点时，回复力仍然满足 $F = -kx$ 的形式。这说明竖直弹簧振子在平衡位置附近的小振动同样是简谐运动，但其平衡位置对应于弹簧的伸长状态而非原长状态。

#### 2.3.3 简谐运动的能量转化

弹簧振子的机械能包括动能和弹性势能（对竖直弹簧振子还需考虑重力势能，但通常以平衡位置为势能零点统一处理）。

动能：

$$E_k = \frac{1}{2}mv^2 = \frac{1}{2}m\omega^2 A^2\cos^2(\omega t + \varphi)$$

势能（以平衡位置为零势能点）：

$$E_p = \frac{1}{2}kx^2 = \frac{1}{2}kA^2\sin^2(\omega t + \varphi)$$

总机械能：

$$E = E_k + E_p = \frac{1}{2}kA^2 = \frac{1}{2}m\omega^2 A^2$$

| 位置 | 位移 | 速度 | 动能 | 势能 |
|:---|:---|:---|:---|:---|
| 平衡位置 | $x = 0$ | $v = \pm\omega A$（最大） | 最大 | 零 |
| 最大位移处 | $x = \pm A$ | $v = 0$ | 零 | 最大 |
| 任意位置 | $x$ | $v = \pm\omega\sqrt{A^2 - x^2}$ | $\frac{1}{2}k(A^2-x^2)$ | $\frac{1}{2}kx^2$ |

在简谐运动中，动能和势能相互转化，但总机械能保持不变（无阻尼条件下）。动能和势能的变化频率是位移变化频率的两倍，即：

$$E_k \propto \cos^2(\omega t + \varphi) = \frac{1 + \cos(2\omega t + 2\varphi)}{2}$$

$$E_p \propto \sin^2(\omega t + \varphi) = \frac{1 - \cos(2\omega t + 2\varphi)}{2}$$

### 2.4 单摆

#### 2.4.1 单摆模型

单摆是由一根不可伸长的轻绳（或轻杆）上端固定、下端悬挂一个可视为质点的小球构成的系统。当摆球从平衡位置拉开一个小角度后释放，在重力作用下，摆球在竖直平面内做往复运动。

#### 2.4.2 单摆的运动方程

设摆长为 $l$，摆球质量为 $m$，某时刻摆线与竖直方向的夹角为 $\theta$。以摆球为研究对象，摆球受到重力 $mg$ 和绳的拉力 $T$。将重力分解为沿绳方向的分量 $mg\cos\theta$ 和垂直于绳方向（沿切向）的分量 $mg\sin\theta$。

沿切向方向，根据牛顿第二定律：

$$-mg\sin\theta = ma_t = ml\frac{d^2\theta}{dt^2}$$

整理得单摆的运动微分方程：

$$\frac{d^2\theta}{dt^2} + \frac{g}{l}\sin\theta = 0$$

#### 2.4.3 小角度近似与简谐运动条件

上述方程中含有 $\sin\theta$，是非线性微分方程，一般没有初等解析解。当摆角很小（通常要求 $\theta \ll 1$ rad，即 $\theta < 5°$）时，利用泰勒展开：

$$\sin\theta = \theta - \frac{\theta^3}{3!} + \frac{\theta^5}{5!} - \cdots$$

当 $\theta$ 很小时，可忽略三次方及以上高阶项，取一级近似：

$$\sin\theta \approx \theta$$

代入运动方程得：

$$\frac{d^2\theta}{dt^2} + \frac{g}{l}\theta = 0$$

这是标准的简谐运动微分方程形式，其中 $\omega^2 = \frac{g}{l}$。因此，小角度条件下单摆做简谐运动。

#### 2.4.4 单摆周期公式的推导

由 $\omega^2 = \frac{g}{l}$，得角频率：

$$\omega = \sqrt{\frac{g}{l}}$$

周期为：

$$T = \frac{2\pi}{\omega} = 2\pi\sqrt{\frac{l}{g}}$$

这就是单摆的周期公式。需要特别指出：

1. 单摆周期只与摆长 $l$ 和重力加速度 $g$ 有关，与摆球质量 $m$ 和振幅（小角度范围内）无关。
2. 等时性是小角度近似下的结论，当摆角较大时周期会随振幅增大而增大。
3. 周期公式成立的条件：摆角 $\theta < 5°$（要求不高时可放宽至 $10°$）。

#### 2.4.5 大角度情况下的周期修正

当摆角较大时，需考虑非线性效应。大角度单摆的精确周期可用椭圆积分表示，其级数展开的一阶修正为：

$$T = T_0\left(1 + \frac{1}{4}\sin^2\frac{\theta_m}{2} + \cdots\right)$$

其中 $T_0 = 2\pi\sqrt{\frac{l}{g}}$ 为小角度极限下的周期，$\theta_m$ 为最大摆角。可见周期随振幅增大而增大，但偏离较慢。

#### 2.4.6 秒摆

周期恰为 $2$ 秒的摆称为秒摆（每次半周期为 $1$ 秒，便于计时）。由 $T = 2\pi\sqrt{\frac{l}{g}}$，当 $T = 2$ s 时：

$$l = \frac{gT^2}{4\pi^2} \approx \frac{9.8 \times 4}{4 \times 9.87} \approx 0.994 \text{ m}$$

即在地球表面，秒摆的摆长约为 $1$ m。

### 2.5 实验：用单摆测量重力加速度

#### 2.5.1 实验原理

由单摆周期公式 $T = 2\pi\sqrt{\frac{l}{g}}$，变形得：

$$g = \frac{4\pi^2 l}{T^2}$$

只要测出摆长 $l$ 和周期 $T$，即可计算出当地的重力加速度 $g$。

#### 2.5.2 实验器材

铁架台（带铁夹）、细线（长约 $1$ m）、小钢球（直径约 $1-2$ cm）、毫米刻度尺、游标卡尺、秒表。

#### 2.5.3 实验步骤

1. 取长约 $1$ m的细线，一端系住小球，另一端固定在铁架台上。
2. 用毫米刻度尺测量悬点到小球球心的距离作为摆长 $l$。其中悬点应清晰固定，球心位置需根据小球直径 $d$（用游标卡尺测量）和悬线长 $L$ 确定：$l = L + \frac{d}{2}$。
3. 将小球从平衡位置拉开一个小角度（不超过 $5°$），无初速度释放。
4. 待摆动稳定后，从摆球经过平衡位置的瞬间开始计时，用秒表测量完成 $n$ 次（通常取 $30-50$ 次）全振动的时间 $t$，则周期 $T = \frac{t}{n}$。
5. 改变摆长，重复测量多次。
6. 代入公式计算 $g$，取平均值。

#### 2.5.4 数据处理方法

**方法一：公式法**

对每个摆长对应的周期计算 $g_i = \frac{4\pi^2 l_i}{T_i^2}$，再求平均值 $\bar{g} = \frac{1}{n}\sum g_i$。

**方法二：图像法**

由 $T = 2\pi\sqrt{\frac{l}{g}}$ 得 $T^2 = \frac{4\pi^2}{g} \cdot l$。作 $T^2 - l$ 图像，应得到一条过原点的直线。直线的斜率 $k = \frac{4\pi^2}{g}$，因此：

$$g = \frac{4\pi^2}{k}$$

图像法可减小偶然误差，且便于发现异常数据。

#### 2.5.5 误差分析

| 误差来源 | 影响 | 结果 |
|:---|:---|:---|
| 摆长测量偏大（如漏加小球半径） | $l$ 测量值偏大 | $g$ 测量值偏大 |
| 摆长测量偏小（如悬点松动导致 $L$ 减小） | $l$ 测量值偏小 | $g$ 测量值偏小 |
| 周期测量偏大（如计时开始过晚） | $T$ 测量值偏大 | $g$ 测量值偏小 |
| 周期测量偏小（如多计振动次数） | $T$ 测量值偏小 | $g$ 测量值偏大 |
| 摆角过大（超过 $5°$） | 实际周期偏大 | $g$ 测量值偏小 |
| 形成圆锥摆 | 等效为单摆的水平分运动，周期偏小 | $g$ 测量值偏大 |

#### 2.5.6 注意事项

1. 细线应选用不可伸长、质量可忽略的材料。
2. 小球应选用密度大的材料，以减小空气阻力的影响。
3. 摆动的竖直平面应固定，避免形成圆锥摆。
4. 计时应从摆球经过平衡位置时开始，因为此时摆球速度最大，位置判断的计时误差最小。
5. 为减小偶然误差，应多次测量取平均值。

### 2.6 受迫振动与共振

#### 2.6.1 阻尼振动

实际的振动系统不可避免地受到阻力作用，阻力对振动做负功，使系统的机械能逐渐减小，振幅也逐渐减小。这种振幅随时间减小的振动称为阻尼振动。

当阻尼较小时（欠阻尼），振动的位移-时间曲线为振幅逐渐衰减的正弦曲线，可近似表示为：

$$x = A_0 e^{-\beta t}\sin(\omega' t + \varphi)$$

其中 $\beta$ 为阻尼系数，$A_0$ 为初始振幅，$\omega'$ 为阻尼振动的角频率，略小于固有角频率 $\omega_0$。

阻尼振动的三种状态：

| 状态 | 条件 | 运动特征 |
|:---|:---|:---|
| 欠阻尼 | $\beta < \omega_0$ | 振幅逐渐衰减的往复运动 |
| 临界阻尼 | $\beta = \omega_0$ | 不做往复运动，最快地回到平衡位置 |
| 过阻尼 | $\beta > \omega_0$ | 不做往复运动，缓慢回到平衡位置 |

#### 2.6.2 受迫振动

系统在周期性外力（驱动力）持续作用下的振动称为受迫振动。设驱动力为 $F = F_0\sin(\omega_d t)$，其中 $\omega_d$ 为驱动力的角频率。受迫振动的运动方程为：

$$m\frac{d^2x}{dt^2} + c\frac{dx}{dt} + kx = F_0\sin(\omega_d t)$$

其中 $c$ 为阻尼系数。方程的解包含两部分：暂态解（随时间衰减的阻尼振动）和稳态解。暂态解很快消失，稳态解为：

$$x = A\sin(\omega_d t + \varphi)$$

其中稳态振幅为：

$$A = \frac{F_0}{\sqrt{(k - m\omega_d^2)^2 + (c\omega_d)^2}}$$

或用固有角频率 $\omega_0 = \sqrt{\frac{k}{m}}$ 表示：

$$A = \frac{F_0/m}{\sqrt{(\omega_0^2 - \omega_d^2)^2 + (2\beta\omega_d)^2}}$$

稳态受迫振动的频率等于驱动力的频率 $\omega_d$，与系统的固有频率无关。振幅 $A$ 的大小与驱动力频率 $\omega_d$ 和固有频率 $\omega_0$ 的相对关系密切相关。

#### 2.6.3 共振

当驱动力的频率 $\omega_d$ 接近系统的固有频率 $\omega_0$ 时，受迫振动的振幅达到最大值，这种现象称为共振。

对振幅公式求极值，令 $\frac{dA}{d\omega_d} = 0$，可得共振角频率：

$$\omega_r = \sqrt{\omega_0^2 - 2\beta^2}$$

当阻尼很小时（$\beta \ll \omega_0$），共振频率近似等于固有频率：

$$\omega_r \approx \omega_0$$

此时最大振幅为：

$$A_{max} = \frac{F_0}{2m\beta\omega_0}$$

阻尼越小，共振时的振幅越大。

#### 2.6.4 共振曲线

振幅 $A$ 随驱动力频率 $\omega_d$ 变化的曲线称为共振曲线。共振曲线的特征：

1. 当 $\omega_d \ll \omega_0$ 时，$A \approx \frac{F_0}{k}$（准静态区）。
2. 当 $\omega_d = \omega_0$ 时（小阻尼），振幅达到最大值。
3. 当 $\omega_d \gg \omega_0$ 时，$A \approx \frac{F_0}{m\omega_d^2} \to 0$（惯性控制区）。
4. 阻尼越小，共振峰越尖锐，共振现象越显著。

#### 2.6.5 共振的应用与防护

| 应用领域 | 原理 |
|:---|:---|
| 乐器的共鸣箱 | 利用共振放大声音 |
| 核磁共振成像（MRI） | 原子核在交变磁场中的共振吸收 |
| 无线电调谐 | LC回路的电谐振选频 |
| 微波炉加热 | 水分子在微波频率（约2.45 GHz）的共振吸收 |

| 防护需求 | 措施 |
|:---|:---|
| 桥梁风致振动（塔科马大桥事故） | 改变结构固有频率或增大阻尼 |
| 机床振动 | 安装减振器或改变工作转速 |
| 建筑物抗震 | 设置隔震层，改变系统固有频率 |
| 士兵过桥不齐步走 | 避免步频与桥梁固有频率一致引发共振 |

## 三、深度理解

### 3.1 回复力与位移成正比是简谐运动本质特征的论证

简谐运动的动力学定义 $F = -kx$ 揭示了振动物体在平衡位置附近的受力特征。这一线性关系之所以成为简谐运动的本质特征，基于以下深层原因。

**第一，线性方程的可解性与通解结构。**

$F = -kx$ 对应的运动微分方程 $\frac{d^2x}{dt^2} + \omega^2 x = 0$ 是线性微分方程，其数学性质极为优越：满足叠加原理，通解为两个独立简谐函数的线性组合，且具有解析精确解。若回复力含有非线性项（如 $F = -kx - \alpha x^3$），方程一般没有初等函数形式的解，运动行为会变得极为复杂，出现混沌等不可预测现象。

**第二，任意势能函数极小值附近的普适性。**

设系统的势能函数为 $E_p(x)$，在稳定平衡点 $x_0$ 附近作泰勒展开：

$$E_p(x) = E_p(x_0) + \frac{dE_p}{dx}\bigg|_{x_0}(x - x_0) + \frac{1}{2}\frac{d^2E_p}{dx^2}\bigg|_{x_0}(x - x_0)^2 + \frac{1}{6}\frac{d^3E_p}{dx^3}\bigg|_{x_0}(x - x_0)^3 + \cdots$$

在稳定平衡位置，$\frac{dE_p}{dx}\big|_{x_0} = 0$（受力平衡），$\frac{d^2E_p}{dx^2}\big|_{x_0} > 0$（稳定条件）。令 $x' = x - x_0$，取势能零点 $E_p(x_0) = 0$，则：

$$E_p(x') \approx \frac{1}{2}\frac{d^2E_p}{dx^2}\bigg|_{x_0}x'^2 = \frac{1}{2}kx'^2$$

其中 $k = \frac{d^2E_p}{dx^2}\big|_{x_0} > 0$。对应的回复力为：

$$F = -\frac{dE_p}{dx'} = -kx'$$

这一结果表明：**任何系统在稳定平衡位置附近的微小振动，都近似为简谐运动**。简谐运动不仅是一种特殊运动，更是所有振动现象在平衡点附近的普适近似描述。这是简谐运动成为振动学基础的根本原因之一。

**第三，谐振子的完备性。**

简谐运动的解构成一组完备的正交函数基（傅里叶基）。任意满足一定条件的周期函数都可以展开为简谐函数的线性组合（傅里叶级数），任意满足一定条件的非周期函数也可以表示为简谐函数的积分（傅里叶变换）。这种数学上的完备性使得简谐运动成为分析和合成一切复杂振动的基础工具。

### 3.2 相位 $\varphi$ 的物理意义

相位 $(\omega t + \varphi)$ 是简谐运动中最具信息量的物理量，它全面地刻画了振动系统在任意时刻的运动状态。

**第一，相位与运动状态的对应关系。**

对简谐运动 $x = A\sin(\omega t + \varphi)$，相位 $\phi = \omega t + \varphi$ 在 $[0, 2\pi)$ 范围内的一个值唯一确定了系统的位移、速度、加速度和能量状态：

| 相位 $\phi$ | 位移 $x$ | 速度 $v$ | 加速度 $a$ |
|:---|:---|:---|:---|
|$0$ | $0$ | $A\omega$（正向最大） | $0$ |
|$\frac{\pi}{2}$ | $A$（正向最大） | $0$ | $-\omega^2 A$（负向最大） |
|$\pi$ | $0$ | $-A\omega$（负向最大） | $0$ |
|$\frac{3\pi}{2}$ | $-A$（负向最大） | $0$ | $\omega^2 A$（正向最大） |

可见，一个相位值对应一套完整的运动状态。两个简谐运动即使振幅和频率相同，只要相位不同，同一时刻的运动状态就不同。

**第二，初相位的物理意义。**

初相位 $\varphi$ 由初始条件 $x_0$ 和 $v_0$ 共同决定，它反映了振动系统在计时起点 $t = 0$ 时刻的运动状态：

- 若 $\varphi = 0$，则 $t = 0$ 时 $x_0 = 0$，$v_0 = A\omega > 0$，振子正经过平衡位置向正方向运动。
- 若 $\varphi = \frac{\pi}{2}$，则 $t = 0$ 时 $x_0 = A$，$v_0 = 0$，振子恰在正的最大位移处。
- 若 $\varphi = \pi$，则 $t = 0$ 时 $x_0 = 0$，$v_0 = -A\omega < 0$，振子正经过平衡位置向负方向运动。
- 若 $\varphi = \frac{3\pi}{2}$（或 $-\frac{\pi}{2}$），则 $t = 0$ 时 $x_0 = -A$，$v_0 = 0$，振子恰在负的最大位移处。

初相位是振动系统的"历史记录"，它将系统的初始信息编码进运动学方程中。

**第三，相位在振动合成与波动中的核心作用。**

当两个简谐运动叠加时，相位差决定合成结果：同相时振幅相加，反相时振幅相消。在波动中，相位描述了振动状态的传播。相位的概念也是量子力学波函数的基石，波函数的幅角即为相位，相位的变化直接关联概率流的分布。

### 3.3 小角度近似 $\sin\theta \approx \theta$ 的数学基础

单摆周期公式的推导依赖于小角度近似 $\sin\theta \approx \theta$（$\theta$ 以弧度为单位）。这一近似的数学本质是三角函数的泰勒展开。

对 $\sin\theta$ 在 $\theta = 0$ 处作泰勒展开：

$$\sin\theta = \theta - \frac{\theta^3}{3!} + \frac{\theta^5}{5!} - \frac{\theta^7}{7!} + \cdots$$

当 $\theta$ 很小时，$\theta^3$ 项及更高阶项远小于 $\theta$ 项，因此可近似为 $\sin\theta \approx \theta$。

近似的精度随角度变化：

| 角度 $\theta$ | $\sin\theta$ | 近似值 $\theta$（弧度） | 相对误差 |
|:---|:---|:---|:---|
|$1° \approx 0.0175$ rad | $0.017452$ | $0.017453$ | $0.005\%$ |
|$5° \approx 0.0873$ rad | $0.087156$ | $0.087266$ | $0.13\%$ |
|$10° \approx 0.1745$ rad | $0.173648$ | $0.174533$ | $0.51\%$ |
|$15° \approx 0.2618$ rad | $0.258819$ | $0.261799$ | $1.15\%$ |
|$30° \approx 0.5236$ rad | $0.500000$ | $0.523599$ | $4.72\%$ |

从表中可见，在 $5°$ 范围内相对误差小于 $0.2\%$，在 $10°$ 范围内误差约 $0.5\%$，而在 $30°$ 时误差已接近 $5\%$。因此物理实验中将小角度条件限定在 $5°$ 以内，以确保周期公式的精度。

### 3.4 共振的能量传递机制

共振现象的本质是驱动力与振动系统之间高效的能量交换。

在受迫振动的稳态中，驱动力对系统做功的功率为 $P = F \cdot v$。当驱动力频率等于系统固有频率时，驱动力与速度的相位关系使得驱动力始终对系统做正功（或做功的平均值最大）。具体而言：

在共振条件下，位移 $x$ 与驱动力 $F$ 同相，速度 $v = \frac{dx}{dt}$ 超前位移 $\frac{\pi}{2}$，恰好与驱动力同相。因此驱动力与速度同相，$F \cdot v > 0$，驱动力持续向系统输入能量。

若 $\omega_d \neq \omega_0$，驱动力与速度存在相位差，在一个周期内驱动力有时做正功、有时做负功，净能量输入减小。

从能量角度看，共振时系统在每周期内从驱动力获得最大能量，恰好补偿阻尼耗散的能量，因此维持最大振幅的稳态振动。阻尼越小，维持给定振幅所需的功率越小，共振峰越尖锐。

## 四、知识串联

### 4.1 简谐运动与匀速圆周运动的联系——参考圆方法

简谐运动可以看作匀速圆周运动在直径上的投影。设一质点在半径为 $A$ 的圆周上以角速度 $\omega$ 做匀速圆周运动，初始时刻半径与 $x$ 轴的夹角为 $\varphi$。则 $t$ 时刻质点在 $x$ 轴上的投影坐标为：

$$x = A\cos(\omega t + \varphi)$$

这正是简谐运动的运动学方程。因此，匀速圆周运动在任一方向的投影都是简谐运动。

**参考圆的对应关系：**

| 匀速圆周运动 | 简谐运动 |
|:---|:---|
| 圆周半径 $A$ | 振幅 $A$ |
| 角速度 $\omega$ | 角频率 $\omega$ |
| 初始角位置 $\varphi$ | 初相位 $\varphi$ |
| 周期 $T = \frac{2\pi}{\omega}$ | 周期 $T = \frac{2\pi}{\omega}$ |
| 线速度 $v_{圆} = \omega A$ | 最大速度 $v_{max} = \omega A$ |
| 向心加速度 $a_{圆} = \omega^2 A$ | 最大加速度 $a_{max} = \omega^2 A$ |

参考圆方法的物理价值在于：

1. **直观理解相位**：圆周上质点的角位置直接对应振动的相位，相位的变化对应质点在圆周上的运动。
2. **确定速度方向**：圆周上质点的速度沿切线方向，其在 $x$ 轴的投影即为振子速度的方向和大小。
3. **简化相位差分析**：两个同频率简谐运动的相位差对应于两个圆周上质点的角位置差。

### 4.2 与波动章节的衔接

机械振动是机械波产生的基础。波是振动在空间中的传播。二者的联系与区别如下：

| 特征 | 机械振动 | 机械波 |
|:---|:---|:---|
| 定义 | 单个质点在平衡位置附近的往复运动 | 振动状态在介质中的传播 |
| 研究对象 | 单个质点的位移随时间变化 | 介质中各质点的位移随空间和时间变化 |
| 图像 | $x-t$ 图像（振动图像） | $x-y$ 图像或 $x-t$ 图像（波动图像） |
| 变量 | 位移 $x$ 是时间 $t$ 的函数：$x = f(t)$ | 位移 $y$ 是位置 $x$ 和时间 $t$ 的函数：$y = f(x, t)$ |
| 能量 | 振子的动能和势能相互转化 | 波的能量沿传播方向传递 |
| 周期性 | 时间上的周期性（周期 $T$） | 时间和空间上的双重周期性（周期 $T$ 和波长 $\lambda$） |

简谐运动的波动推广：若质点 $O$ 的振动方程为 $y_O = A\sin(\omega t)$，则沿 $x$ 轴正方向传播的简谐波的波动方程为：

$$y = A\sin\left[\omega\left(t - \frac{x}{v}\right)\right] = A\sin(\omega t - kx)$$

其中 $k = \frac{\omega}{v} = \frac{2\pi}{\lambda}$ 为波数。波动方程中的 $(\omega t - kx)$ 正是振动相位的空间推广：时间变化引起相位变化（振动），空间位置变化同样引起相位变化（波动）。

### 4.3 与光学中干涉现象的内在联系

波的干涉是两列（或多列）频率相同、相位差恒定的波在空间叠加时，某些位置振动始终加强、某些位置振动始终减弱的现象。干涉现象的物理基础正是简谐振动的合成。

两列同频率简谐波在某点引起的振动分别为：

$$y_1 = A_1\sin(\omega t + \varphi_1)$$

$$y_2 = A_2\sin(\omega t + \varphi_2)$$

合振动为：

$$y = y_1 + y_2 = A\sin(\omega t + \varphi)$$

合振幅：

$$A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos(\varphi_2 - \varphi_1)}$$

当相位差 $\Delta\varphi = 2n\pi$（$n = 0, \pm 1, \pm 2, \cdots$）时，$\cos(\Delta\varphi) = 1$，$A = A_1 + A_2$，振动加强。

当相位差 $\Delta\varphi = (2n+1)\pi$（$n = 0, \pm 1, \pm 2, \cdots$）时，$\cos(\Delta\varphi) = -1$，$A = |A_1 - A_2|$，振动减弱。

光的双缝干涉中，明纹和暗纹的位置正是由两束光到达观察点的光程差决定相位差，进而决定振动加强或减弱的结果。因此，对简谐运动和相位概念的深入理解是掌握干涉现象的前提。

## 五、隐性考点

### 5.1 振动图像与波动图像的区别

振动图像（$x-t$ 图像）和波动图像（$y-x$ 图像）在外观上都是正弦曲线，但物理含义完全不同，这是考试中的高频易错点。

| 比较项目 | 振动图像 | 波动图像 |
|:---|:---|:---|
| 横轴 | 时间 $t$ | 空间位置 $x$ |
| 纵轴 | 位移 $x$ | 位移 $y$ |
| 描述对象 | 单个质点的位移随时间变化 | 某一时刻介质中各质点的位移分布 |
| 图像意义 | 反映一个质点的"运动历史" | 反映一列波的"空间快照" |
| 时间变化的效果 | 图像向右延伸（历史记录） | 波形整体沿传播方向平移 |
| 相邻波峰间距 | 时间上的周期 $T$ | 空间上的波长 $\lambda$ |

**判断方法**：观察横轴标注——横轴为 $t$ 则是振动图像，横轴为 $x$ 则是波动图像。

### 5.2 相位差的计算

同频率简谐运动的相位差 $\Delta\varphi = \varphi_2 - \varphi_1$ 是一个贯穿振动和波动问题的重要计算点。

**情形一：由振动方程求相位差**

直接读取两个振动的初相位相减。

**情形二：由时间差求相位差**

若两个振动存在时间延迟 $\Delta t$，则相位差为 $\Delta\varphi = \omega \Delta t = \frac{2\pi}{T}\Delta t$。

**情形三：由空间距离求相位差（波动问题）**

沿波传播方向距离为 $\Delta x$ 的两点，振动相位差为 $\Delta\varphi = \frac{2\pi}{\lambda}\Delta x$。

**情形四：由光程差求相位差（光学问题）**

光程差 $\delta$ 对应的相位差为 $\Delta\varphi = \frac{2\pi}{\lambda}\delta$，其中 $\lambda$ 为光在真空中的波长。

### 5.3 单摆测 $g$ 实验的误差分析

单摆测重力加速度实验中，误差分析是重要考查内容。系统误差的完整分析如下：

**导致 $g$ 偏大的因素：**

| 因素 | 原因分析 |
|:---|:---|
| 摆长测量值偏大 | 如将悬线长与小球直径之和作为摆长，但测量直径时偏大 |
| 周期测量值偏小 | 少计振动次数 $n$，使 $T = \frac{t}{n}$ 偏小 |
| 形成圆锥摆 | 圆锥摆的等效摆长为 $l\cos\theta$，周期小于同摆长单摆 |
| 摆角过小导致计时误差 | 振幅太小，摆球经过平衡位置时速度小，判断平衡位置时刻的相对误差大 |

**导致 $g$ 偏小的因素：**

| 因素 | 原因分析 |
|:---|:---|
| 摆长测量值偏小 | 悬点松动导致振动过程中摆长减小；未加小球半径 |
| 周期测量值偏大 | 计时开始过晚或结束过早；多计振动次数 |
| 摆角过大 | 实际周期 $T > T_0$，代入 $g = \frac{4\pi^2 l}{T^2}$ 使 $g$ 偏小 |
| 空气浮力 | 空气对小球的浮力减小了等效重力加速度 |

### 5.4 共振的应用与危害

共振现象的考查通常涉及实际应用中的物理分析。

**典型应用分析：**

1. **乐器共鸣**：弦振动带动共鸣箱内空气柱振动，当空气柱的固有频率与弦的频率一致时发生共振，放大声音。

2. **核磁共振（NMR）**：原子核在强磁场中的能级分裂，当射频场的频率与核能级跃迁频率一致时发生共振吸收，据此可进行物质结构分析。

3. **无线电接收**：调谐回路的固有频率通过改变电容或电感来调节，当与某电台的载波频率一致时发生电谐振，选出该电台信号。

**典型危害分析：**

1. **桥梁风毁**：1940年塔科马海峡大桥在风速约为 $64$ km/h时发生剧烈扭转振动后坍塌。风经过桥截面产生涡旋脱落的频率（卡门涡街频率）与桥梁的固有扭转频率一致，引发共振。此事件后，桥梁设计中必须考虑空气动力学因素。

2. **机械故障**：旋转机械（如涡轮机、电动机）的工作转速若接近其固有频率，将引发共振导致剧烈振动和损坏。工程上要求工作转速避开共振区（通常要求 $n_{工作} < 0.7n_{共振}$ 或 $n_{工作} > 1.3n_{共振}$）。

## 六、易错警示

### 6.1 平衡位置不一定是弹簧原长位置

在水平弹簧振子中，平衡位置恰好对应弹簧的原长位置（弹力为零处）。但在竖直弹簧振子或其他取向的弹簧振子中，平衡位置是回复力为零的位置，而非弹簧原长位置。

**竖直弹簧振子的具体分析：**

设弹簧劲度系数为 $k$，振子质量为 $m$。弹簧在平衡位置时的伸长量 $x_0$ 满足 $kx_0 = mg$，即 $x_0 = \frac{mg}{k}$。此时弹簧并非处于原长，而是伸长了 $x_0$。

若以弹簧原长位置为坐标原点计算位移，回复力将不直接等于 $-kx$，而是 $F = mg - k(x + x_0) = -kx$（经变换后）。因此，在分析问题时，**必须首先明确坐标原点的选取**，通常选取平衡位置为坐标原点最为简便。

**易错点**：误认为竖直弹簧振子经过平衡位置时弹簧弹力等于零，实际上此时弹力等于重力，弹簧处于伸长状态。

### 6.2 周期与振幅无关的适用条件

简谐运动的周期与振幅无关（等时性）是一个重要结论，但其成立有严格条件：

1. **回复力严格正比于位移**：$F = -kx$。若存在非线性项，则周期将依赖于振幅。

2. **小角度条件的满足**：单摆的等时性只在 $\theta < 5°$ 时成立。大角度时周期明显依赖于振幅。

3. **无阻尼条件**：实际系统存在阻尼时，振幅衰减过程中频率略有变化（严格说欠阻尼振动的频率 $\omega' = \sqrt{\omega_0^2 - \beta^2}$ 与阻尼有关），但对于小阻尼近似可认为周期不变。

**常见错误**：将等时性无条件推广到大角度单摆，或认为任何振动的周期都与振幅无关。

### 6.3 混淆位移和振幅的概念

位移和振幅是两个不同的物理量，必须严格区分。

| 物理量 | 定义 | 性质 | 取值范围 |
|:---|:---|:---|:---|
| 位移 $x$ | 振子相对平衡位置的位置矢量 | 状态量，随时间变化 | $-A \leq x \leq A$ |
| 振幅 $A$ | 振子离开平衡位置的最大距离 | 特征量，由系统能量决定 | $A > 0$，恒定（无阻尼时）|

**关键区别**：

- 位移是瞬时量，可以是正、负或零；振幅是恒正值（标量），表示位移的最大绝对值。
- 位移描述某一时刻的位置；振幅描述振动的强弱范围。
- 在振动图像中，曲线的纵坐标是位移；曲线的峰值（或谷值的绝对值）是振幅。

**常见错误表述**："振子的振幅为 $-5$ cm"——振幅恒取正值；"振子到达振幅位置"——应表述为"到达最大位移处"或"位移大小等于振幅的位置"。

### 6.4 周期计算中的常见错误

1. **全振动的判断**：一个全振动是指振子从某状态出发，再次回到同一状态且速度方向相同的过程。例如从正最大位移处出发，经负最大位移再回到正最大位移处，完成一个全振动。不是从一侧最大位移到另一侧最大位移就算一个周期。

2. **$\frac{1}{4}$ 周期内的路程不一定等于振幅**：只有在平衡位置或最大位移处开始计时，$\frac{1}{4}$ 周期内的路程才等于振幅。从其他位置开始，$\frac{1}{4}$ 周期内的路程不等于振幅（因为速度不均匀）。只有在完整周期的整数倍时间内，路程才确定等于 $4nA$。

3. **弹簧振子与单摆周期公式的混淆**：$T = 2\pi\sqrt{\frac{m}{k}}$ 适用于弹簧振子；$T = 2\pi\sqrt{\frac{l}{g}}$ 适用于单摆。前者与质量有关，后者与质量无关。

### 6.5 参考圆方法的应用误区

使用参考圆方法时，需注意对应关系的一致性：

1. 圆周运动的角速度 $\omega$ 对应简谐运动的角频率，而非振子实际运动的角速度（振子做直线运动，没有角速度）。

2. 圆周上质点的运动方向（顺时针或逆时针）决定了相位变化的正负。通常取逆时针方向对应相位增加。

3. 投影方向必须明确：可以是 $x$ 轴投影（余弦函数）或 $y$ 轴投影（正弦函数），对应不同的初相位表达。

## 七、思想方法

### 7.1 理想模型法

理想模型法是物理学研究的基本方法之一。在研究机械振动时，引入了多个理想模型：

**弹簧振子模型**：忽略弹簧质量、忽略摩擦阻力、将振子视为质点。这一模型使问题简化为一个自由度（位置 $x$）的力学问题，可用常微分方程精确求解。

**单摆模型**：绳不可伸长、无质量，摆球视为质点，忽略空气阻力。单摆只有一个自由度（角位置 $\theta$），在小角度近似下同样有解析解。

**简谐运动本身也是一种理想化**：严格满足 $F = -kx$ 的系统在实际中并不存在。但简谐运动作为一切振动在平衡位置附近的最低阶近似，具有普适性和基础性。

理想模型法的步骤：

1. **分析实际系统**：识别主要因素和次要因素。
2. **引入理想化假设**：忽略次要因素，保留主要因素。
3. **建立数学模型**：用方程描述理想系统的行为。
4. **求解与预测**：获得解析解或数值解。
5. **检验与修正**：与实验比较，必要时引入修正项（如阻尼、非线性项）。

### 7.2 类比法

类比法是通过比较两个不同系统在数学结构或物理行为上的相似性，将一个系统的已知结论推广到另一个系统的方法。

**力学-电磁学类比**：

LC 振荡电路与弹簧振子存在深刻的类比关系：

| 弹簧振子 | LC 振荡电路 |
|:---|:---|
| 位移 $x$ | 电荷 $q$ |
| 速度 $v = \frac{dx}{dt}$ | 电流 $i = \frac{dq}{dt}$ |
| 质量 $m$ | 电感 $L$ |
| 劲度系数 $k$ | 电容倒数 $\frac{1}{C}$ |
| 回复力 $F = -kx$ | 电容电压 $U_C = \frac{q}{C}$ |
| 动能 $E_k = \frac{1}{2}mv^2$ | 磁场能 $E_L = \frac{1}{2}Li^2$ |
| 势能 $E_p = \frac{1}{2}kx^2$ | 电场能 $E_C = \frac{1}{2}\frac{q^2}{C}$ |
| 运动方程 $\frac{d^2x}{dt^2} + \frac{k}{m}x = 0$ | 电路方程 $\frac{d^2q}{dt^2} + \frac{1}{LC}q = 0$ |
| 周期 $T = 2\pi\sqrt{\frac{m}{k}}$ | 周期 $T = 2\pi\sqrt{LC}$ |

这种类比不仅具有形式上的相似性，更反映了自然规律的统一性：不同领域的系统可以由相同的数学方程描述。

**振动-波动类比**：

简谐运动是一自由度系统的振动，而固体中的原子在晶格位置附近的热振动可视为三维的简谐运动。大量耦合振子的集体行为形成晶格波（声波），这种从振动到波动的推广也是类比思想的体现。

### 7.3 图像分析法

图像分析法是处理振动问题的有效工具，通过对 $x-t$、$v-t$、$a-t$ 等图像的分析，可以直观获取运动信息。

**从振动图像（$x-t$ 图）提取信息的方法：**

1. **确定振幅**：读取纵轴的最大绝对值。
2. **确定周期**：读取相邻两个同相位点（如相邻波峰）之间的时间间隔。
3. **确定某时刻的运动方向**：观察该时刻之后极短时间内的位移变化——若位移增大且为正，则速度为正；若位移减小，则速度为负。
4. **比较两时刻的加速度大小**：加速度大小正比于位移大小，位移越大加速度越大。
5. **判断能量状态**：动能正比于速度平方（图像斜率的平方），势能正比于位移平方。

**图像法的优势**：避免复杂的公式运算，直观判断运动特征；特别适合定性分析和快速判断。

**图像法的局限**：定量精度受限于图像读数精度；对于复杂运动（如阻尼振动、受迫振动），图像分析需结合公式。

### 7.4 微元分析法

微元法是分析连续介质中波动问题的基础。将连续分布的介质划分为无限多个无限小的质元，每个质元视为一个振子，质元之间通过弹性力相互作用。通过分析单个质元的受力和运动，建立波动方程。

一维波动方程的推导正是基于微元法：取介质中的一小段，分析其受到邻近部分的弹性力，应用牛顿第二定律，取极限后得到：

$$\frac{\partial^2 y}{\partial t^2} = v^2\frac{\partial^2 y}{\partial x^2}$$

其中 $v = \sqrt{\frac{F}{\rho}}$ 为波速，$F$ 为张力，$\rho$ 为线密度。这一方程表明，空间中每一点都在做简谐振动，且振动状态以速度 $v$ 传播。
