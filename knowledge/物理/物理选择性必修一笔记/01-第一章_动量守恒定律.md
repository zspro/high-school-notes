# 第一章 动量守恒定律
---

## 1.1 动量

### 一、来龙去脉：动量概念的历史渊源

#### 1.1.1 笛卡尔的原创性贡献

动量概念的雏形可追溯至17世纪笛卡尔（Rene Descartes, 1596-1650）的力学研究。笛卡尔在1644年出版的《哲学原理》（Principia Philosophiae）中首次系统阐述了运动量的概念。笛卡尔将物体的"运动量"定义为物体质量与运动速度的乘积，即 $p = mv$，并明确提出：当一个物体与另一个物体发生碰撞时，前者的运动量损失等于后者的运动量获得。这一表述构成了动量守恒思想的最早雏形。

笛卡尔提出这一概念的哲学背景是其机械论自然观。笛卡尔认为宇宙是一部精密的机器，所有自然现象均可通过物质粒子间的碰撞与运动来解释。在这一框架下，需要一个能够描述"运动之量"的物理量来量化物体间的相互作用效果。笛卡尔选择 $mv$ 而非 $mv^2$ 的根本原因在于：他关注的是运动在物体间的传递，而非运动本身作为能力的度量。

#### 1.1.2 牛顿的完善与确立

牛顿（Isaac Newton, 1643-1727）在《自然哲学的数学原理》（Philosophiae Naturalis Principia Mathematica, 1687）中对动量概念进行了严格化。牛顿将动量（拉丁文：quantitas motus）定义为"运动之量"，其度量等于质量与速度之积。在《原理》的定义II中，牛顿明确表述："运动量是速度与物质质量之联合度量"，即 $p = mv$。

牛顿第二定律的原始表述即以动量为核心：

$$\vec{F} = \frac{d\vec{p}}{dt}$$

此表述具有比 $F = ma$ 更广泛的适用范围，可直接推广至变质量系统与相对论情形。

#### 1.1.3 哈密顿形式主义的升华

19世纪，哈密顿（William Rowan Hamilton, 1805-1865）发展了分析力学的哈密顿形式主义，将动量提升至与坐标同等重要的独立变量地位。在哈密顿力学中，广义动量定义为：

$$p_i = \frac{\partial L}{\partial \dot{q}_i}$$

其中 $L = T - V$ 为拉格朗日量，$q_i$ 为广义坐标，$\dot{q}_i$ 为广义速度。这一推广使动量概念超越了 $p = mv$ 的原始定义，拓展至涵盖电磁动量、正则动量等更为普遍的物理内涵。

#### 1.1.4 为何采用 $mv$ 而非 $mv^2$

选择 $mv$ 而非 $mv^2$ 作为运动传递的度量，基于以下深层物理原因：

**第一**，从碰撞实验的实证角度分析。考虑两个质量分别为 $m_1$、$m_2$ 的物体，以初速度 $v_1$、$v_2$ 沿同一直线运动并发生碰撞。大量实验表明，量 $m_1v_1 + m_2v_2$ 在碰撞前后保持不变，而量 $m_1v_1^2 + m_2v_2^2$ 仅在特定条件（弹性碰撞）下守恒。因此 $mv$ 具有更普遍的守恒性。

**第二**，从矢量性角度分析。速度 $v$ 为矢量，故 $p = mv$ 亦为矢量，其方向与速度方向一致。这一矢量性质使动量能够完整描述运动的方向特征。而 $v^2$ 为标量，$mv^2$ 亦丧失方向信息，无法完备描述运动状态。

**第三**，从与力的关系分析。由牛顿第二定律 $F = ma$，对恒力作用下的匀变速运动，有 $a = (v' - v)/\Delta t$，代入得 $F\Delta t = m(v' - v) = mv' - mv = \Delta p$。力的时间累积效应直接对应动量的变化，而非动能的变化。这一关系在 $F - t$ 图像中表现为冲量等于图线与时间轴所围面积，具有直接的几何对应关系。

**第四**，从空间对称性角度分析。动量守恒本质源于物理系统的空间平移对称性（诺特定理）。$mv$ 作为空间平移生成元对应的守恒荷，其物理地位由时空对称性结构所决定。

#### 1.1.5 动量守恒与牛顿第三定律的内在关联

牛顿第三定律（作用力与反作用力定律）与动量守恒定律存在深刻的逻辑关联。考虑由两个质点组成的孤立系统，质点1对质点2的作用力为 $\vec{F}_{12}$，质点2对质点1的作用力为 $\vec{F}_{21}$。根据牛顿第三定律：

$$\vec{F}_{12} = -\vec{F}_{21}$$

由牛顿第二定律，两质点的动量变化率分别为：

$$\frac{d\vec{p}_1}{dt} = \vec{F}_{21}, \quad \frac{d\vec{p}_2}{dt} = \vec{F}_{12}$$

两式相加得：

$$\frac{d\vec{p}_1}{dt} + \frac{d\vec{p}_2}{dt} = \vec{F}_{21} + \vec{F}_{12} = 0$$

即：

$$\frac{d}{dt}(\vec{p}_1 + \vec{p}_2) = 0$$

由此得出系统总动量守恒：

$$\vec{p}_1 + \vec{p}_2 = \text{常量}$$

上述推导揭示：牛顿第三定律是动量守恒在质点系中的充分条件。然而需要明确，动量守恒的适用范围远超牛顿力学。在电磁场、相对论力学和量子力学中，牛顿第三定律可能失效（例如运动电荷间的相互作用不满足牛顿第三定律的瞬时性要求），但动量守恒仍然成立——只要将场动量纳入系统总动量。这一事实表明，动量守恒是比牛顿第三定律更为基本的物理规律。

### 二、基础精讲：动量的严格定义

#### 1.1.6 动量的定义式

质点的动量（momentum）定义为该质点的质量与瞬时速度矢量的乘积：

$$\vec{p} = m\vec{v}$$

**单位**：在国际单位制中，动量的单位为千克·米/秒（$kg \cdot m/s$），无专门名称。

**量纲**：$[p] = MLT^{-1}$

**性质**：

- **矢量性**：动量为矢量，方向与速度方向相同
- **瞬时性**：动量为状态量，对应于某一时刻的运动状态
- **相对性**：动量数值依赖于参考系的选择
- **可加性**：质点系总动量等于各质点动量的矢量和 $\vec{P} = \sum_i \vec{p}_i = \sum_i m_i\vec{v}_i$

#### 1.1.7 动量与动能的区别

| 比较维度 | 动量 $\vec{p} = m\vec{v}$ | 动能 $E_k = \frac{1}{2}mv^2$ |
|---------|------------------------|---------------------------|
| 标矢性 | 矢量 | 标量 |
| 单位 | $kg \cdot m/s$ | J（焦耳） |
| 与速度关系 | 线性关系 | 二次关系 |
| 时间累积 | 力的时间累积改变动量（冲量） | 力的空间累积改变动能（功） |
| 守恒条件 | 系统所受合外力为零 | 系统仅有保守内力做功 |
| 物理内涵 | 运动传递的量度 | 运动能力的量度 |

动量与动能的数学联系：由 $E_k = \frac{p^2}{2m}$ 或 $p = \sqrt{2mE_k}$，二者可相互表示。但物理意义截然不同：动量守恒源于时间平移对称性与空间平移对称性的联合要求，动能定理则源于功能原理。

## 1.2 动量定理

### 一、来龙去脉：从牛顿第二定律到动量定理

动量定理的历史演化与力学的整体发展同步。牛顿原始表述的第二定律 $F = dp/dt$ 本身即蕴含了动量定理的微分形式。将牛顿第二定律从微分形式积分至有限时间间隔，获得动量定理的积分形式，这一数学操作由18世纪的数学家兼物理学家完成，欧拉（Leonhard Euler, 1707-1783）在此方面作出了关键贡献。

欧拉系统发展了刚体力学，将牛顿定律推广至质点系，并明确引入了冲量（impulse）概念。动量定理的积分形式在工程力学中具有重要应用价值，尤其是在碰撞、冲击等力的瞬时作用问题中，由于力的大小难以直接测量，通过测量速度变化来计算冲量成为实验力学的基本方法。

### 二、基础精讲：冲量与动量定理

#### 1.2.1 冲量的严格定义

**恒力的冲量**：大小和方向均不变的力 $\vec{F}$ 在时间间隔 $\Delta t$ 内的冲量定义为：

$$\vec{I} = \vec{F}\Delta t$$

**变力的冲量**：当力随时间变化时，即 $\vec{F} = \vec{F}(t)$，在微小时间元 $dt$ 内的元冲量为 $d\vec{I} = \vec{F}(t)dt$。在有限时间间隔 $t_1$ 至 $t_2$ 内的总冲量为：

$$\vec{I} = \int_{t_1}^{t_2} \vec{F}(t)dt$$

冲量为矢量，方向与力的方向（恒力情形）或力矢量和的方向（变力情形）一致。

**单位**：牛顿·秒（$N \cdot s$），与动量单位等价：$1 N \cdot s = 1 kg \cdot m/s$。

#### 1.2.2 动量定理的推导

**从牛顿第二定律出发的严格推导**：

牛顿第二定律的动量表述：

$$\vec{F} = \frac{d\vec{p}}{dt}$$

对单一质点，设其在时刻 $t_1$ 的速度为 $\vec{v}_1$，动量为 $\vec{p}_1 = m\vec{v}_1$；在时刻 $t_2$ 的速度为 $\vec{v}_2$，动量为 $\vec{p}_2 = m\vec{v}_2$。

将牛顿第二定律改写为：

$$d\vec{p} = \vec{F}dt$$

对时间从 $t_1$ 至 $t_2$ 积分：

$$\int_{\vec{p}_1}^{\vec{p}_2} d\vec{p} = \int_{t_1}^{t_2} \vec{F}(t)dt$$

左端积分结果为：

$$\vec{p}_2 - \vec{p}_1 = \Delta \vec{p}$$

右端即为冲量的定义 $\vec{I}$。因此得到**动量定理**：

$$\vec{I} = \Delta \vec{p} = \vec{p}_2 - \vec{p}_1$$

或等价表述为：

$$\vec{I} = m\vec{v}_2 - m\vec{v}_1$$

**物理表述**：质点在一段时间内所受合外力的冲量，等于该质点在此时间内动量的增量。

#### 1.2.3 动量定理的物理内涵

动量定理建立了力的时间累积效应与质点运动状态变化之间的定量关系。与动能定理 $W = \Delta E_k$（力的空间累积效应）相比，动量定理具有以下特点：

- 动量定理为矢量方程，包含完整的方向信息
- 动量定理中冲量的计算无需知晓力作用点的位移
- 在碰撞问题中，由于作用时间极短且相互作用力极大（称为冲击力或冲力），动量定理提供了一种绕开力之细节、直接关联初末状态的有效方法

#### 1.2.4 平均冲力

在碰撞问题中，力 $\vec{F}(t)$ 随时间急剧变化，难以精确测量。引入平均冲力 $\vec{\bar{F}}$：

$$\vec{\bar{F}} = \frac{\vec{I}}{\Delta t} = \frac{\Delta \vec{p}}{\Delta t}$$

平均冲力 $\vec{\bar{F}}$ 为一恒力，其在 $\Delta t$ 时间内的冲量等于实际变力的冲量。这一概念为工程中的碰撞强度计算提供了实用工具。

## 1.3 动量守恒定律

### 一、来龙去脉：从经验定律到基本物理原理

动量守恒定律的发现史可追溯至17世纪的碰撞研究。惠更斯（Christiaan Huygens, 1629-1695）在1669年通过对完全弹性碰撞的系统研究，确认了"运动量"在碰撞中的守恒性。惠更斯运用了相对性原理（当时称为"运动相对性"），证明了在惯性参考系中动量守恒的一致性。

18至19世纪，随着分析力学的发展，动量守恒的地位不断提升。拉格朗日（Joseph-Louis Lagrange, 1736-1813）在《分析力学》（1788）中证明：动量守恒是系统拉格朗日量不显含某广义坐标的直接推论。这一结论后被诺特（Emmy Noether, 1882-1935）在1915年概括为一般性定理——诺特定理，从而将动量守恒提升至时空对称性的基本物理原理高度。

### 二、基础精讲：动量守恒定律的严格表述与证明

#### 1.3.1 质点系的动量定理

考虑由 $n$ 个质点组成的系统。对第 $i$ 个质点，其所受合力可分为内力与外力：

$$\vec{F}_i = \vec{F}_i^{(外)} + \sum_{j \neq i} \vec{f}_{ji}$$

其中 $\vec{F}_i^{(外)}$ 为系统外物体对第 $i$ 个质点的作用力，$\vec{f}_{ji}$ 为第 $j$ 个质点对第 $i$ 个质点的内力。

对第 $i$ 个质点应用动量定理：

$$\frac{d\vec{p}_i}{dt} = \vec{F}_i^{(外)} + \sum_{j \neq i} \vec{f}_{ji}$$

对所有质点求和：

$$\sum_{i=1}^n \frac{d\vec{p}_i}{dt} = \sum_{i=1}^n \vec{F}_i^{(外)} + \sum_{i=1}^n \sum_{j \neq i} \vec{f}_{ji}$$

根据牛顿第三定律，内力成对出现且等大反向：$\vec{f}_{ji} = -\vec{f}_{ij}$，故所有内力之和为零：

$$\sum_{i=1}^n \sum_{j \neq i} \vec{f}_{ji} = 0$$

因此：

$$\frac{d}{dt}\sum_{i=1}^n \vec{p}_i = \sum_{i=1}^n \vec{F}_i^{(外)}$$

定义系统总动量 $\vec{P} = \sum_i \vec{p}_i$，系统所受合外力 $\vec{F}^{(外)} = \sum_i \vec{F}_i^{(外)}$，得**质点系动量定理**：

$$\frac{d\vec{P}}{dt} = \vec{F}^{(外)}$$

或积分形式：

$$\vec{I}^{(外)} = \Delta \vec{P} = \vec{P}_2 - \vec{P}_1$$

#### 1.3.2 动量守恒定律的严格表述

**定律表述**：若系统所受合外力为零，即 $\vec{F}^{(外)} = 0$，则系统的总动量保持不变：

$$\vec{P} = \sum_i m_i\vec{v}_i = \text{常量}$$

**分量形式**：若系统所受合外力在某方向（如 $x$ 方向）的分量为零，即 $F_x^{(外)} = 0$，则该方向的总动量分量守恒：

$$P_x = \sum_i m_i v_{ix} = \text{常量}$$

这一分量守恒性质具有重要实用价值，因为在诸多物理情形中，系统在某一方向不受外力或所受外力可忽略，而在其他方向受显著外力作用。

#### 1.3.3 守恒条件分析

动量守恒的成立条件可作如下层次化分析：

**严格条件**：$\vec{F}^{(外)} = 0$，即系统所受合外力矢量和严格为零。

**近似条件**：

- 当内力远大于外力时（如碰撞、爆炸过程），外力可忽略，系统动量近似守恒
- 当系统在某方向所受合外力分量为零时，该方向动量分量守恒
- 当外力作用时间极短时，外力的冲量可忽略，系统动量近似守恒

#### 1.3.4 适用范围

动量守恒定律具有超越牛顿力学框架的普适性：

- **经典力学**：适用于宏观物体的低速运动
- **相对论力学**：在狭义相对论中，动量定义为 $\vec{p} = \gamma m\vec{v}$，其中 $\gamma = 1/\sqrt{1 - v^2/c^2}$，动量守恒仍然成立
- **量子力学**：波函数的动量期望值满足守恒关系
- **电磁现象**：需将电磁场动量纳入系统，总动量（物质动量 + 场动量）守恒
- **微观粒子反应**：基本粒子衰变、散射等过程中动量守恒严格成立
- **宇宙学尺度**：在宇宙学模型的构建中，动量守恒（或其推广形式）构成基本约束

## 1.4 实验：验证动量守恒定律

### 一、实验原理

验证动量守恒定律的实验基于以下物理设定：使两个物体在水平方向发生碰撞，测量碰撞前后的速度，验证 $m_1\vec{v}_1 + m_2\vec{v}_2 = m_1\vec{v}_1' + m_2\vec{v}_2'$ 是否成立。

实验设计的关键在于满足动量守恒的近似条件：在水平方向尽量减小摩擦力等外力影响，使系统在水平方向的合外力近似为零。

### 二、常用实验方案

#### 1.4.1 气垫导轨方案

**实验装置**：气垫导轨、光电门计时器、滑块（配质量块）、天平。

**实验步骤**：

1. 调节气垫导轨水平，接通气源使滑块悬浮
2. 用天平测量两滑块的质量 $m_1$、$m_2$
3. 将光电门置于导轨上合适位置，连接计时器
4. 使滑块1以一定初速度通过光电门，与静止滑块2碰撞
5. 记录碰撞前后两滑块通过光电门的时间 $t_1$、$t_1'$、$t_2'$，计算速度 $v = d/t$（$d$ 为挡光片宽度）
6. 验证 $m_1v_1 = m_1v_1' + m_2v_2'$（弹性碰撞情形）

**数据处理**：分别计算碰撞前系统总动量 $P = m_1v_1$ 和碰撞后系统总动量 $P' = m_1v_1' + m_2v_2'$，比较 $P$ 与 $P'$ 的相对误差。

#### 1.4.2 摆球碰撞方案

**实验装置**：等长双线悬挂的两钢球、量角器、天平。

**实验原理**：利用摆球下摆过程中的机械能守恒确定碰前速度，利用摆角确定碰后速度。

**速度测量**：摆球从角度 $\theta$ 静止释放，下摆至最低点时速度 $v = \sqrt{2gL(1 - \cos\theta)}$，其中 $L$ 为摆长。

**注意事项**：两摆球应在最低点发生碰撞，此时速度方向水平，便于验证水平方向动量守恒。

#### 1.4.3 打点计时器方案

**实验装置**：长木板、打点计时器、小车两辆、天平、撞针与橡皮泥。

**实验原理**：通过纸带上的点迹分析小车运动速度，验证碰撞前后动量守恒。

**数据处理**：选取纸带上点迹均匀的部分计算匀速运动速度，$v = \Delta x/\Delta t$。

### 三、误差分析

| 误差来源 | 产生原因 | 减小方法 |
|---------|---------|---------|
| 系统误差 | 气垫导轨未调平、摩擦力未完全消除 | 精确调平、充分通气 |
| 系统误差 | 摆球碰撞非完全水平 | 调整摆长与释放角度 |
| 偶然误差 | 光电门计时误差 | 多次测量取平均 |
| 偶然误差 | 质量测量误差 | 使用精密天平 |
| 操作误差 | 碰撞不正对（非对心碰撞） | 调整碰撞位置使对心 |

## 1.5 弹性碰撞和非弹性碰撞

### 一、来龙去脉：碰撞理论的发展

碰撞问题的系统研究始于17世纪。惠更斯在1669年的论文中首次对弹性碰撞进行了完整分析，引入了相对速度反向的概念。牛顿在《原理》中进一步发展了碰撞理论，并通过实验确定了碰撞前后速度关系的经验规律。

19世纪，泊松（Simeon Denis Poisson, 1781-1840）引入恢复系数（coefficient of restitution）对碰撞进行分类，建立了现代碰撞理论的数学框架。恢复系数的概念使碰撞问题从定性分析走向定量计算，为工程中的冲击问题提供了理论基础。

### 二、基础精讲：碰撞的分类与分析

#### 1.5.1 碰撞的基本特征

碰撞是指两个或多个物体在极短时间内发生强烈相互作用，导致物体运动状态发生显著变化的过程。碰撞过程具有以下特征：

- 相互作用时间极短（通常为 $10^{-3} \sim 10^{-1}$ 秒量级）
- 相互作用力极大（远大于系统所受外力）
- 碰撞前后物体位置无明显变化（位移可忽略）
- 系统动量守恒（内力远大于外力）

#### 1.5.2 碰撞的分类

**按能量关系分类**：

| 碰撞类型 | 动能关系 | 恢复系数 |
|---------|---------|---------|
| 完全弹性碰撞 | 动能守恒：$\sum E_k = \sum E_k'$ | $e = 1$ |
| 非弹性碰撞 | 动能有损失：$\sum E_k > \sum E_k'$ | $0 < e < 1$ |
| 完全非弹性碰撞 | 动能损失最大，碰后共速 | $e = 0$ |

**按空间维度分类**：

- 一维碰撞（正碰/对心碰撞）：碰撞前后速度均在两球心连线方向上
- 二维碰撞（斜碰）：碰撞前后速度不在同一直线上

#### 1.5.3 一维弹性碰撞的严格分析

考虑两球质量分别为 $m_1$、$m_2$，初速度分别为 $v_1$、$v_2$（设沿同一直线，以 $v_1$ 方向为正），碰撞后速度为 $v_1'$、$v_2'$。

**守恒方程**：

动量守恒：

$$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$$

动能守恒：

$$\frac{1}{2}m_1v_1^2 + \frac{1}{2}m_2v_2^2 = \frac{1}{2}m_1v_1'^2 + \frac{1}{2}m_2v_2'^2$$

**求解**：

将动量守恒方程改写为：

$$m_1(v_1 - v_1') = m_2(v_2' - v_2)$$

将动能守恒方程改写为：

$$m_1(v_1^2 - v_1'^2) = m_2(v_2'^2 - v_2^2)$$

因式分解得：

$$m_1(v_1 - v_1')(v_1 + v_1') = m_2(v_2' - v_2)(v_2' + v_2)$$

当 $v_1 \neq v_1'$（即发生实际碰撞）时，两式相除得：

$$v_1 + v_1' = v_2 + v_2'$$

即：

$$v_1 - v_2 = -(v_1' - v_2')$$

此式表明：弹性碰撞中，两球的相对速度在碰撞前后大小相等、方向相反。

联立求解得：

$$v_1' = \frac{(m_1 - m_2)v_1 + 2m_2v_2}{m_1 + m_2}$$

$$v_2' = \frac{(m_2 - m_1)v_2 + 2m_1v_1}{m_1 + m_2}$$

#### 1.5.4 重要特例

**等质量弹性碰撞**（$m_1 = m_2$）：

$$v_1' = v_2, \quad v_2' = v_1$$

两球交换速度。若 $v_2 = 0$（靶球静止），则 $v_1' = 0$，$v_2' = v_1$，入射球停止，靶球以入射球原速度飞出。

**重球碰轻球**（$m_1 \gg m_2$，$v_2 = 0$）：

$$v_1' \approx v_1, \quad v_2' \approx 2v_1$$

重球速度几乎不变，轻球以约两倍速度飞出。

**轻球碰重球**（$m_1 \ll m_2$，$v_2 = 0$）：

$$v_1' \approx -v_1, \quad v_2' \approx 0$$

轻球以原速率反弹，重球几乎不动。

#### 1.5.5 完全非弹性碰撞

碰撞后两球以相同速度运动（粘合在一起），设共同速度为 $v'$。

由动量守恒：

$$m_1v_1 + m_2v_2 = (m_1 + m_2)v'$$

解得：

$$v' = \frac{m_1v_1 + m_2v_2}{m_1 + m_2}$$

动能损失：

$$\Delta E = \frac{1}{2}m_1v_1^2 + \frac{1}{2}m_2v_2^2 - \frac{1}{2}(m_1 + m_2)v'^2 = \frac{m_1m_2(v_1 - v_2)^2}{2(m_1 + m_2)}$$

此动能损失转化为内能（热能）、形变势能等其他形式能量。

#### 1.5.6 恢复系数的严格定义

恢复系数 $e$（coefficient of restitution）定义为碰撞后两物体分离的相对速度与碰撞前接近的相对速度之比：

$$e = \frac{v_2' - v_1'}{v_1 - v_2}$$

注意：分子为分离时相对速度（取 $v_2' > v_1'$ 使 $e > 0$），分母为接近时相对速度（取 $v_1 > v_2$ 使分母为正）。

恢复系数的取值范围与物理意义：

- $e = 1$：完全弹性碰撞，无动能损失
- $0 < e < 1$：非弹性碰撞，部分动能损失
- $e = 0$：完全非弹性碰撞，分离速度为零（共速）
- $e > 1$：超弹性碰撞，系统动能增加（如爆炸情形，有化学能等其他形式能量转化为动能）

引入恢复系数后，一维碰撞问题的通解可表示为：

$$v_1' = v_1 - \frac{m_2(1 + e)(v_1 - v_2)}{m_1 + m_2}$$

$$v_2' = v_2 + \frac{m_1(1 + e)(v_1 - v_2)}{m_1 + m_2}$$

## 1.6 反冲现象与火箭

### 一、来龙去脉：从反冲现象到航天工程

反冲现象的观察可追溯至古代。中国宋代发明的火箭（"起火"）即是利用火药燃气向后喷射产生向前推力的反冲装置。17世纪，牛顿在《原理》中阐述了第三定律的物理内涵，为反冲现象提供了力学解释。

现代火箭理论的奠基人为俄国科学家齐奥尔科夫斯基（Konstantin Tsiolkovsky, 1857-1935）。1903年，齐奥尔科夫斯基发表了《利用喷气装置探索宇宙空间》，推导出著名的齐奥尔科夫斯基火箭方程，奠定了航天动力学的理论基础。该方程定量描述了火箭通过喷射工质获得速度增量的规律，成为火箭设计的核心理论依据。

### 二、基础精讲：反冲原理与火箭推进

#### 1.6.1 反冲运动的物理本质

反冲运动是指系统在内力作用下分裂为两部分，且两部分朝相反方向运动的现象。其物理本质为动量守恒：系统初始总动量为零（或某一确定值），分裂后各部分动量矢量和保持不变。

设静止系统总质量为 $M$，分裂后一部分质量为 $m$、速度为 $\vec{v}$，另一部分质量为 $M - m$、速度为 $\vec{V}$。由动量守恒：

$$m\vec{v} + (M - m)\vec{V} = 0$$

因此：

$$\vec{V} = -\frac{m\vec{v}}{M - m}$$

两部分速度方向相反，大小与质量成反比。

#### 1.6.2 火箭推进原理

火箭通过持续向后高速喷射燃气获得推力。设某时刻火箭（含剩余燃料）质量为 $M$，速度为 $v$；在极短时间 $dt$ 内喷出质量为 $dm$ 的燃气，喷气速度（相对火箭）为 $u$。

由动量守恒（以地面为参考系，设火箭飞行方向为正）：

$$Mv = (M - dm)(v + dv) + dm(v - u)$$

展开并忽略二阶小量 $dm \cdot dv$：

$$Mv = Mv + Mdv - vdm - udm$$

整理得：

$$Mdv = udm$$

由于喷气使火箭质量减少，$dm_{火箭} = -dm_{喷出}$，故 $dm = -dM$（$dM < 0$ 为火箭质量增量）：

$$Mdv = -udM$$

分离变量：

$$dv = -u\frac{dM}{M}$$

积分得**齐奥尔科夫斯基火箭方程**：

$$\Delta v = u\ln\frac{M_0}{M}$$

其中 $M_0$ 为火箭初始总质量（含燃料），$M$ 为燃料耗尽后火箭质量，$\Delta v$ 为火箭获得的速度增量。

#### 1.6.3 火箭方程的物理内涵

- **喷气速度 $u$**：由燃料性能与发动机设计决定，是衡量火箭发动机效率的重要参数
- **质量比 $M_0/M$**：火箭结构设计的关键指标，受材料强度与技术条件限制
- **多级火箭**：每级燃料耗尽后脱落空壳，提高后续飞行阶段的质量比，从而获得更大的总速度增量

## 深度理解

### 一、动量守恒的本质：空间平移对称性与诺特定理

#### 1.1 诺特定理的基本表述

1915年，数学家诺特证明了分析力学中的一条基本定理：**若物理系统的拉格朗日量在某一连续对称变换下保持不变，则该系统存在一个与之对应的守恒量**。

诺特定理建立了对称性与守恒定律之间的一一对应关系：

| 对称性 | 守恒量 |
|-------|-------|
| 时间平移对称性 | 能量守恒 |
| 空间平移对称性 | 动量守恒 |
| 空间旋转对称性 | 角动量守恒 |

#### 1.2 空间平移对称性

空间平移对称性是指物理规律不依赖于空间位置的选择。将实验装置从位置 $A$ 整体平移至位置 $B$，所有物理过程的发生规律完全相同。

数学表述：若系统拉格朗日量 $L$ 不显含某一广义坐标 $q_i$（即 $\partial L/\partial q_i = 0$），则对应的广义动量 $p_i = \partial L/\partial \dot{q}_i$ 守恒。

对于自由粒子或孤立系统，$L = T - V$，势能 $V$ 仅为相对位置的函数，系统整体平移不改变 $V$ 的值，故 $L$ 不显含系统质心坐标，由此导出系统总动量守恒。

#### 1.3 动量守恒比牛顿定律更基本

动量守恒的普适性远超牛顿力学框架：

- **微观领域**：在量子力学中，粒子以概率波形式描述，但动量期望值仍严格守恒
- **高速领域**：狭义相对论中动量定义为 $\vec{p} = \gamma m\vec{v}$，动量守恒在洛伦兹变换下协变
- **场论领域**：电磁场具有动量密度 $\vec{g} = \varepsilon_0\vec{E} \times \vec{B}$，物质动量与场动量之和守恒
- **宇宙学领域**：在广义相对论中，动量守恒以协变形式表述，成为爱因斯坦场方程的推论

这一普适性表明，动量守恒是自然规律深层对称性的体现，而非牛顿力学的派生结果。

### 二、一维碰撞中速度交换的条件

#### 2.1 速度交换的充分必要条件

在一维弹性碰撞中，等质量球体发生速度交换 ($v_1' = v_2$, $v_2' = v_1$) 的条件为 $m_1 = m_2$。在一般情形下，速度交换不成立。

对于 $m_1 \neq m_2$ 的弹性碰撞，若要求碰后入射球速度等于靶球初速度 ($v_1' = v_2$)，则需满足：

$$\frac{(m_1 - m_2)v_1 + 2m_2v_2}{m_1 + m_2} = v_2$$

解得 $(m_1 - m_2)(v_1 - v_2) = 0$。因此，速度交换仅当 $m_1 = m_2$ 或 $v_1 = v_2$（无实际碰撞）时成立。

#### 2.2 入射球静止的条件

弹性碰撞中，若要求入射球碰后静止 ($v_1' = 0$)，由公式：

$$(m_1 - m_2)v_1 + 2m_2v_2 = 0$$

若靶球初始静止 ($v_2 = 0$)，则需 $m_1 = m_2$，此时 $v_2' = v_1$，即速度交换。

#### 2.3 最大动能传递条件

在核反应堆慢化剂设计中，需使中子与 moderator 核碰撞时损失最大动能。设入射粒子质量 $m_1$、初速度 $v_1$，靶粒子质量 $m_2$、初速为零。

碰撞后入射粒子速度：

$$v_1' = \frac{m_1 - m_2}{m_1 + m_2}v_1$$

入射粒子动能损失最大对应 $|v_1'|$ 最小，即 $m_1 = m_2$ 时 $v_1' = 0$，动能全部传递给靶粒子。因此重水 ($D_2O$) 与普通水 ($H_2O$) 均为有效的中子慢化剂。

## 知识串联

### 一、动量守恒与牛顿运动定律的关系

#### 1.1 逻辑层级

牛顿运动定律与动量守恒定律之间存在层次化的逻辑关系：

**牛顿第二定律 $\rightarrow$ 动量定理**：牛顿第二定律 $F = dp/dt$ 的直接积分给出动量定理 $I = \Delta p$。动量定理是牛顿第二定律的时间积分形式，适用于质点。

**牛顿第二定律 + 第三定律 $\rightarrow$ 动量守恒**：对质点系，牛顿第二定律给出 $dP/dt = F^{(外)}$，牛顿第三定律保证内力成对抵消。当 $F^{(外)} = 0$ 时，$P =$ 常量。动量守恒是牛顿定律在特定条件（合外力为零）下的推论。

#### 1.2 适用范围对比

| 定律 | 适用条件 | 局限性 |
|-----|---------|-------|
| 牛顿第二定律 | 宏观、低速、惯性系 | 不适用于微观粒子和高速运动 |
| 牛顿第三定律 | 接触作用、瞬时可超距 | 不适用于电磁场等以有限速度传播的作用 |
| 动量守恒 | 孤立系统（或合外力为零） | 普适（经典、相对论、量子） |

动量守恒的适用范围远大于牛顿定律，这源于其作为时空对称性推论的根本地位。

#### 1.3 方法论差异

- 牛顿定律：分析-综合方法，从受力分析入手，通过运动微分方程求解运动状态
- 动量守恒：整体-守恒方法，绕开过程细节，直接建立初末状态的联系

在碰撞、爆炸等问题中，由于过程复杂（作用力急剧变化、形变细节未知），牛顿定律难以直接应用，而动量守恒提供了有效的分析工具。

### 二、动量守恒与机械能守恒的联系与区别

#### 2.1 守恒条件的对比

| 守恒定律 | 守恒量 | 守恒条件 |
|---------|-------|---------|
| 动量守恒 | $\vec{P} = \sum m_i\vec{v}_i$ | 合外力为零：$\vec{F}^{(外)} = 0$ |
| 机械能守恒 | $E = E_k + E_p$ | 仅有保守内力做功，非保守内力和外力不做功 |

**关键区别**：动量守恒仅要求合外力为零，与内力性质无关；机械能守恒要求非保守力（如摩擦力）不做功。

#### 2.2 弹性碰撞中的联合应用

在弹性碰撞中，动量守恒与动能守恒同时成立。这两个方程联立可唯一确定碰撞后的速度（一维情形）。

在完全非弹性碰撞中，仅动量守恒成立，动能不守恒（有损失）。需用一个额外条件（碰后共速）配合动量守恒求解。

#### 2.3 非弹性碰撞中的能量分析

非弹性碰撞中动量守恒但动能不守恒，动能损失为：

$$\Delta E_k = \frac{1}{2}(1 - e^2)\frac{m_1m_2}{m_1 + m_2}(v_1 - v_2)^2$$

当 $e = 0$（完全非弹性碰撞）时，动能损失最大；当 $e = 1$（弹性碰撞）时，动能损失为零。

### 三、反冲、爆炸与碰撞的统一定量描述

#### 3.1 共同物理基础

反冲、爆炸与碰撞均基于动量守恒定律进行定量描述。三者的共性在于：系统在内力作用下发生各部分运动状态的突变，且内力远大于外力，系统动量守恒。

#### 3.2 定量对比

| 过程 | 特征 | 动量关系 | 能量特征 |
|-----|------|---------|---------|
| 弹性碰撞 | 极短作用时间，碰后分离 | $\sum m_i\vec{v}_i = \sum m_i\vec{v}_i'$ | 动能守恒 |
| 完全非弹性碰撞 | 极短作用时间，碰后粘合 | $\sum m_i\vec{v}_i = (\sum m_i)\vec{v}'$ | 动能损失最大 |
| 反冲 | 系统分裂为两部分 | $0 = m_1\vec{v}_1 + m_2\vec{v}_2$（初始静止） | 其他形式能转化为动能 |
| 爆炸 | 系统分裂为多部碎片 | $\sum m_i\vec{v}_i = \vec{P}_{初}$ | 化学能大量转化为动能 |

#### 3.3 火箭运动的连续化描述

火箭推进可视为连续反冲过程的极限。通过质量连续喷射，火箭方程将离散的反冲推广至连续系统，体现了数学上从求和到积分的推广。

## 隐性考点

### 一、人船模型

#### 1.1 模型设定

质量为 $M$ 的船静止于水面，质量为 $m$ 的人从船头行至船尾。设船长为 $L$，忽略水的阻力，求人相对地面的位移与船相对地面的位移。

#### 1.2 定量分析

以地面为参考系，设人的速度为 $\vec{v}$（相对地面），船的速度为 $\vec{V}$（相对地面）。由水平方向动量守恒（系统初始静止）：

$$m\vec{v} + M\vec{V} = 0$$

即 $v = -\frac{M}{m}V$（设人行走方向为正）。

设人从船头走到船尾所用时间为 $t$，则：

$$x_{人} = \bar{v}t, \quad x_{船} = \bar{V}t$$

由平均速度关系 $\bar{v} = -\frac{M}{m}\bar{V}$，得：

$$x_{人} = -\frac{M}{m}x_{船}$$

由位移的几何约束（人相对船的位移等于船长 $L$）：

$$x_{人} - x_{船} = L$$

（人相对船的位移 = 人相对地面位移 - 船相对地面位移）

联立解得：

$$x_{人} = \frac{M}{M + m}L$$

$$x_{船} = -\frac{m}{M + m}L$$

**结论**：人相对地面位移 $\frac{M}{M+m}L$，船后退 $\frac{m}{M+m}L$，二者之和等于船长 $L$。

#### 1.3 推广形式

- 若系统初始具有动量，则以质心参考系分析，结论形式类似
- 人船模型的本质：系统质心位置不变（因无外力），各部分位移与质量成反比
- 推广至竖直方向（如人沿气球绳梯下滑），分析方法相同

### 二、子弹打木块问题

#### 2.1 模型设定

质量为 $m$ 的子弹以初速度 $v_0$ 射入静止于光滑水平面的质量为 $M$ 的木块中。

#### 2.2 情形分析

**情形一：子弹未穿出（嵌入木块）**

完全非弹性碰撞，由动量守恒：

$$mv_0 = (m + M)v$$

共同速度：

$$v = \frac{mv_0}{m + M}$$

动能损失（转化为内能和形变能）：

$$\Delta E = \frac{1}{2}mv_0^2 - \frac{1}{2}(m + M)v^2 = \frac{mM}{2(m + M)}v_0^2$$

**情形二：子弹穿出**

设子弹穿出时速度为 $v_1$，木块速度为 $v_2$。

动量守恒：

$$mv_0 = mv_1 + Mv_2$$

能量关系（非弹性碰撞，动能有损失）：

$$\frac{1}{2}mv_0^2 > \frac{1}{2}mv_1^2 + \frac{1}{2}Mv_2^2$$

动能损失等于摩擦力 $f$ 与相对位移（木块厚度 $d$）的乘积：

$$\Delta E = fd$$

#### 2.3 隐含条件的挖掘

- 子弹刚好穿出木块的临界条件：$v_1 = v_2$（在木块参考系中子弹末速为零）
- 木块位移、子弹位移与木块厚度的几何关系：$d = x_{子弹} - x_{木块}$
- 摩擦力对子弹做负功，对木块做正功，摩擦力乘以相对位移等于系统动能损失

### 三、多次碰撞问题

#### 3.1 基本分析方法

多次碰撞问题涉及多个物体间的连续碰撞，分析要点：

- 逐次碰撞，每次应用动量守恒（弹性碰撞同时应用动能守恒）
- 明确每次碰撞的对象系统（仅参与直接碰撞的两物体）
- 注意碰撞的先后顺序与碰撞条件（追上才能碰撞）

#### 3.2 典型情形：三球连续碰撞

三球质量分别为 $m_1$、$m_2$、$m_3$，沿直线排列。球1以 $v_0$ 撞击静止的球2，弹性碰撞后球2再撞击静止的球3。

第一碰撞（1与2）：

$$v_1' = \frac{m_1 - m_2}{m_1 + m_2}v_0, \quad v_2' = \frac{2m_1}{m_1 + m_2}v_0$$

第二碰撞（2与3）：

$$v_2'' = \frac{m_2 - m_3}{m_2 + m_3}v_2', \quad v_3' = \frac{2m_2}{m_2 + m_3}v_2'$$

联立得：

$$v_3' = \frac{4m_1m_2}{(m_1 + m_2)(m_2 + m_3)}v_0$$

**最大动量传递条件**：为使 $v_3'$ 最大，设 $m_1$、$m_3$ 固定，求最佳 $m_2$。由极值条件 $dv_3'/dm_2 = 0$ 得 $m_2 = \sqrt{m_1m_3}$（几何平均值）。

### 四、动量-能量综合问题

#### 4.1 滑块-木板模型

质量为 $m$ 的滑块以 $v_0$ 滑上静止于光滑水平面的质量为 $M$ 的木板，二者间有摩擦力 $f$。

动量守恒：

$$mv_0 = (m + M)v$$

能量关系（摩擦力乘以相对位移等于动能损失）：

$$fL_{相对} = \frac{1}{2}mv_0^2 - \frac{1}{2}(m + M)v^2 = \frac{mM}{2(m + M)}v_0^2$$

板长至少为 $L_{相对}$ 才能使滑块不滑出。

#### 4.2 弹簧连接体问题

两物块由弹簧连接，相互作用过程中动量守恒、机械能守恒（若仅保守力做功）。

最大压缩/伸长时两物块速度相等（相对速度为零），由动量守恒和能量守恒联立求解。

## 易错警示

### 一、动量守恒的系统选取错误

#### 1.1 常见错误

- 仅选取碰撞中的某一个物体为研究对象，应用动量守恒
- 系统选取不当，遗漏参与相互作用的物体
- 对多次碰撞问题，混淆不同碰撞过程的系统边界

#### 1.2 正确做法

动量守恒必须对**系统**成立。选取系统时需包含所有参与直接相互作用的物体。在碰撞瞬间，仅直接碰撞的两物体构成封闭系统（若忽略外力）。

#### 1.3 检验方法

验证系统所受合外力是否为零（或可忽略）：

- 水平面碰撞：竖直方向重力与支持力平衡，水平方向若无摩擦则合外力为零
- 竖直方向碰撞：需考虑重力是否可忽略（短时间碰撞中重力的冲量通常可忽略）

### 二、矢量方向的处理不当

#### 2.1 一维情形中的正方向约定

在一维碰撞问题中，必须首先明确规定正方向（通常取初速度较大者的方向为正）。所有速度、动量、冲量均按此约定代入正负号。

**错误示例**：已知 $v_1 = 5m/s$，$v_2 = -3m/s$，在动量守恒方程中直接代入 $m_1 \times 5 + m_2 \times 3 = ...$（忽略了 $v_2$ 的负号）。

**正确处理**：严格代入 $m_1 \times 5 + m_2 \times (-3) = ...$。

#### 2.2 弹性碰撞中相对速度公式

弹性碰撞中 $v_1 - v_2 = -(v_1' - v_2')$ 为矢量关系。在一维情形中需考虑方向：

$$v_1 - v_2 = v_2' - v_1'$$

（接近相对速度 = 分离相对速度）

若方向处理错误，会导致求解结果错误。

#### 2.3 动量定理中的方向一致性

应用动量定理 $\vec{I} = \Delta \vec{p}$ 时，冲量与动量变化均为矢量。在一维情形中需统一正方向，二维情形中需作正交分解。

### 三、碰撞中的能量关系错误

#### 3.1 混淆弹性与非弹性碰撞

- 弹性碰撞：动量守恒且动能守恒
- 非弹性碰撞：动量守恒但动能不守恒（减少）
- 完全非弹性碰撞：动量守恒，动能损失最大

**常见错误**：在非弹性碰撞中错误地列出动能守恒方程，或认为所有碰撞动能均守恒。

#### 3.2 能量损失方向错误

碰撞过程中系统动能不可能增加（无其他能量输入时）。若计算结果出现末态动能大于初态动能，说明计算有误。

例外：爆炸过程有化学能等其他形式能量转化为动能，系统动能增加，但动量仍守恒。

#### 3.3 恢复系数的取值范围

恢复系数满足 $0 \leq e \leq 1$（无外部能量输入时）。$e > 1$ 仅在系统有其他形式能量转化为动能时出现（如爆炸）。

### 四、参考系混淆

#### 4.1 地面参考系与相对参考系

- 动量守恒定律通常在惯性参考系（如地面）中表述
- 火箭方程中的喷气速度 $u$ 为相对火箭的速度
- 人船模型中人的速度与船的速度需相对同一参考系（地面）

**常见错误**：将相对速度与绝对速度混用，如直接使用人相对船的速度代入地面参考系的动量守恒方程。

#### 4.2 速度合成关系

$$\vec{v}_{A对地} = \vec{v}_{A对B} + \vec{v}_{B对地}$$

使用相对速度时需注意参考系的正确转换。

## 思想方法

### 一、守恒思想

#### 1.1 守恒思想的物理内涵

守恒思想是物理学中最为基本的思想方法之一。其核心在于：当系统满足特定对称性或约束条件时，系统的某个物理量不随时间变化，该物理量即为守恒量。

#### 1.2 守恒思想的分析步骤

1. **识别系统**：明确研究对象，确定系统边界
2. **检验条件**：分析系统是否满足守恒条件（合外力为零等）
3. **选取状态**：确定初态与末态（或任意两个状态）
4. **列方程**：写出守恒方程，代入已知量
5. **求解验证**：求解未知量，检验结果的合理性

#### 1.3 守恒思想的优势

- **绕开过程细节**：无需知晓相互作用的具体形式与时间演化
- **建立初末联系**：直接关联初态与末态的物理量
- **普适性强**：守恒定律跨越不同物理领域，具有广泛适用性

#### 1.4 动量守恒中的守恒思想应用

在碰撞问题中，由于碰撞过程复杂（形变、发热、声响等），牛顿定律难以直接应用。守恒思想通过动量守恒（弹性碰撞中还包括动能守恒），直接建立碰撞前后的速度关系，绕开了碰撞过程的力学细节。

### 二、系统分析法

#### 2.1 系统分析法的基本框架

系统分析法将研究对象从单个质点拓展至质点系，关注系统的整体性质而非个体细节。

#### 2.2 内力与外力的区分

- **内力**：系统内各质点间的相互作用力
- **外力**：系统外物体对系统内质点的作用力

关键性质：内力成对出现（牛顿第三定律），在系统整体方程中相互抵消，不影响系统总动量的变化。

#### 2.3 系统选取的灵活性

系统边界的选取具有人为性，可根据问题需要灵活调整：

- 若将参与碰撞的两物体视为系统，则碰撞力为内力
- 若仅考虑其中一个物体，则碰撞力为外力

合理的系统选取应使待求量尽可能多地出现在守恒方程中，且使复杂的外力作用最小化。

#### 2.4 质点系的质心运动

质点系的质心运动由系统所受合外力决定：

$$\vec{F}^{(外)} = M\vec{a}_c$$

其中 $M = \sum m_i$ 为系统总质量，$\vec{a}_c$ 为质心加速度。

当 $\vec{F}^{(外)} = 0$ 时，$\vec{a}_c = 0$，质心速度恒定。此即质心参考系中动量守恒的等价表述。

### 三、模型化思想

#### 3.1 理想化模型

物理分析中常用以下理想化模型：

- **质点**：忽略物体大小与形状，以质量集中于一点的理想物体
- **刚体**：忽略形变，碰撞中无能量损失于形变
- **光滑面**：忽略摩擦力，支持力垂直于接触面
- **弹性碰撞**：忽略动能损失，恢复系数 $e = 1$
- **完全非弹性碰撞**：碰后共速，恢复系数 $e = 0$

#### 3.2 模型化的方法论意义

模型化通过忽略次要因素、突出主要矛盾，将复杂实际问题转化为可解析处理的理想模型。模型化能力体现了物理学抓住问题本质的思维特征。

#### 3.3 模型适用条件的检验

每个理想模型均有其适用条件，解题后需进行检验：

- 质点模型要求物体尺寸远小于运动尺度
- 弹性碰撞模型要求碰撞过程中无显著永久形变
- 光滑面模型要求摩擦力远小于其他作用力

若模型条件不满足，需修正模型（如引入恢复系数 $0 < e < 1$）或采用更精确的理论描述。

#### 3.4 碰撞问题中的模型化

实际碰撞过程中：

- 有形变（非理想刚体）$\rightarrow$ 引入恢复系数 $e$
- 有摩擦力（非理想光滑）$\rightarrow$ 考虑切向冲量
- 有能量耗散 $\rightarrow$ 考虑热能、声能等

在高中物理范围内，通常采用理想化模型：一维碰撞、忽略摩擦、忽略转动。这些模型化处理使问题可解析求解，同时保留了碰撞的核心物理特征。
