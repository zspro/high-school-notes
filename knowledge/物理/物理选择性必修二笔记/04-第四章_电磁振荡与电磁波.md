# 第四章 电磁振荡与电磁波

---

## 一、来龙去脉：电磁理论的统一与演进

### 1.1 麦克斯韦电磁理论的建立（1865年）

19世纪中叶，电磁学研究已积累了大量实验定律。库仑（C. A. Coulomb）于1785年确立了静电力的平方反比规律；奥斯特（H. C. Ørsted）于1820年发现电流的磁效应；安培（A. M. Ampère）建立了电流元之间相互作用的定量规律；法拉第（M. Faraday）于1831年发现电磁感应现象，并引入场和力线的概念，为电磁场的物质性认识奠定了基础。

然而，这些定律在麦克斯韦（J. C. Maxwell）之前始终是相互孤立的。麦克斯韦自1855年起系统研究电磁现象，其核心贡献在于：

**第一**，提出涡旋电场假设，将法拉第电磁感应定律推广为普遍规律——变化的磁场激发有旋电场。

**第二**，提出位移电流假设，修正了安培环路定理。麦克斯韦指出，电场中电位移矢量 $\vec{D}$ 随时间的变化率 $\partial\vec{D}/\partial t$（即位移电流密度）与传导电流一样能够产生磁场。这一修正使方程组在电动力学过程中保持内在一致性。

1865年，麦克斯韦在论文《电磁场的动力学理论》（A Dynamical Theory of the Electromagnetic Field）中完成了电磁场方程组的完整表述。原始形式的麦克斯韦方程组包含20个标量方程，后经亥维赛（O. Heaviside）和赫兹等人简化为四个矢量方程的现代形式。该方程组表明：
- 变化的电场产生磁场
- 变化的磁场产生电场
- 电场与磁场相互耦合，形成统一的电磁场
- 电磁场可以在无源空间中自持传播，构成电磁波

方程组预言电磁波在真空中的传播速度为 $c = 1/\sqrt{\varepsilon_0\mu_0}$。麦克斯韦将这一理论值与当时测得的光速进行比较，发现二者高度吻合，由此得出光的电磁本质这一革命性结论——可见光不过是电磁波谱中的一个特定波段。

### 1.2 赫兹实验验证电磁波的存在（1887—1888年）

麦克斯韦的理论在其生前未获实验证实。1887年，德国物理学家赫兹（H. R. Hertz）设计了里程碑式的实验装置：

**发射端**：采用感应线圈与火花隙振荡器，产生高频电磁振荡。当感应线圈在火花隙两端感应出高电压时，空气被击穿形成火花放电，产生频率约为 $5\times10^8\,\text{Hz}$ 的阻尼电磁振荡。

**接收端**：采用带有微小气隙的环形导线作为谐振探测器。当电磁波传播至接收环时，电磁感应在环中激起电动势，于气隙处产生微弱的次级火花。

赫兹通过该实验系统证实了：
1. 电磁波可以在自由空间中传播
2. 电磁波具有反射、折射、干涉、偏振等波动特性
3. 电磁波的传播速度等于光速
4. 电磁波是横波，其电场矢量与磁场矢量相互垂直且均垂直于传播方向

1888年，赫兹发表《论空气中的电磁波及其反射》，标志着麦克斯韦电磁理论从数学预言上升为实验确立的物理定律。

### 1.3 马可尼实现无线电通信（1895年）

赫兹实验后，电磁波的实用性探索迅速展开。意大利工程师马可尼（G. Marconi）于1895年在博洛尼亚成功实现超过2公里的无线电报通信。1896年，马可尼赴英国申请专利并继续研究；1901年，他成功实现跨大西洋无线通信（从英国康沃尔至加拿大纽芬兰），传输距离约3500公里。

马可尼的关键技术改进包括：
- 采用垂直天线与接地系统构成开放振荡电路，显著提高辐射效率
- 引入调谐电路实现频率选择，使多路通信成为可能
- 发明粉末检波器（coherer）作为信号检测装置

1909年，马可尼与布劳恩（K. F. Braun）共同获得诺贝尔物理学奖，表彰他们在无线电信报发展中的贡献。从麦克斯韦理论到马可尼应用，历时30年，完成了从基础理论到改变人类通信方式的技术跃迁。

### 1.4 电磁波谱的发现历程

电磁波谱的完整认识经历了渐进过程：

**可见光**：人类最早认知的电磁波段。牛顿（I. Newton）于1666年通过棱镜分光实验揭示白光的色散本质；杨氏（T. Young）于1801年完成双缝干涉实验，确立光的波动性。

**红外线**：1800年，赫歇尔（W. Herschel）用温度计测量太阳光谱各区域的热效应，发现红光外侧存在不可见的"热线"，其热效应甚至强于可见光，命名为红外线。

**紫外线**：1801年，里特（J. W. Ritter）发现紫光外侧存在能使氯化银变黑不可见辐射，后称紫外线。

**无线电波**：1887—1888年，赫兹首次人工产生并检测无线电波。

**X射线**：1895年，伦琴（W. C. Röntgen）发现阴极射线管产生的具有强穿透性的未知辐射，命名为X射线。后证实其为波长极短（$10^{-12}\sim10^{-8}\,\text{m}$）的电磁波。

**γ射线**：1900年，维拉德（P. Villard）在研究镭的放射性时发现一种穿透力极强的辐射。1914年，卢瑟福（E. Rutherford）确认其为波长最短（$<10^{-11}\,\text{m}$）的电磁辐射，后称γ射线。

至此，电磁波谱的完整图景得以建立，按波长从长到短依次为：无线电波、微波、红外线、可见光、紫外线、X射线、γ射线。

## 二、基础精讲

### 2.1 电磁振荡（§4.1 LC振荡电路）

#### 2.1.1 LC振荡电路的构成与工作原理

LC振荡电路由电容器（电容 $C$）与电感线圈（自感系数 $L$）串联构成。当电容器已充电至电荷量 $Q_0$ 后闭合电路，电容器通过电感放电，电路中产生周期性变化的电流，形成电磁振荡。

振荡过程的物理机制如下：

**第一阶段（放电过程）**：电容器储存电场能 $E_\text{电} = Q_0^2/(2C)$。闭合电路后，电容器开始放电，电荷量 $q$ 逐渐减少。根据电磁感应定律，电感线圈中产生自感电动势 $\mathcal{E}_L = -L(\mathrm{d}i/\mathrm{d}t)$，阻碍电流的增大。随着电容器电荷量减少，电场能转化为磁场能，电感中磁场能 $E_\text{磁} = Li^2/2$ 逐渐增加。

**第二阶段（反向充电过程）**：当电容器电荷量降为零时，电场能全部转化为磁场能，电流达到最大值。此后电感释放磁场能，对电容器反向充电，电流逐渐减小。

**第三、四阶段**：电容器反向放电后再正向充电，完成一个完整振荡周期。

#### 2.1.2 振荡方程与周期公式推导

根据基尔霍夫电压定律，LC回路中任意时刻满足：

$$L\frac{\mathrm{d}i}{\mathrm{d}t} + \frac{q}{C} = 0$$

由于 $i = \mathrm{d}q/\mathrm{d}t$，代入得：

$$L\frac{\mathrm{d}^2q}{\mathrm{d}t^2} + \frac{q}{C} = 0$$

即：

$$\frac{\mathrm{d}^2q}{\mathrm{d}t^2} + \frac{1}{LC}q = 0$$

这是标准的简谐运动微分方程。令 $\omega^2 = 1/(LC)$，其通解为：

$$q(t) = Q_0\cos(\omega t + \varphi_0)$$

其中角频率 $\omega = 1/\sqrt{LC}$，振荡周期：

$$T = 2\pi\sqrt{LC}$$

回路中的电流：

$$i(t) = \frac{\mathrm{d}q}{\mathrm{d}t} = -\omega Q_0\sin(\omega t + \varphi_0) = I_0\cos\left(\omega t + \varphi_0 + \frac{\pi}{2}\right)$$

电荷量 $q$ 与电流 $i$ 之间存在 $\pi/2$ 的相位差：当电容器电荷量达最大值时，电流为零；当电荷量为零时，电流达最大值。

#### 2.1.3 无阻尼振荡与阻尼振荡

**无阻尼自由振荡**：上述LC回路为理想模型，回路中无电阻，无能量耗散，振荡振幅保持不变，总能量守恒。

**阻尼振荡**：实际电路中存在电阻 $R$，构成RLC回路。根据基尔霍夫定律：

$$L\frac{\mathrm{d}^2q}{\mathrm{d}t^2} + R\frac{\mathrm{d}q}{\mathrm{d}t} + \frac{q}{C} = 0$$

根据阻尼程度不同分为三种情形：
- **欠阻尼**（$R < 2\sqrt{L/C}$）：电荷量呈衰减振荡，振幅按指数规律衰减
- **临界阻尼**（$R = 2\sqrt{L/C}$）：电荷量最快地趋于零，无振荡
- **过阻尼**（$R > 2\sqrt{L/C}$）：电荷量单调衰减至零，无振荡

为维持等幅振荡，需通过外部电路（如正反馈放大器）适时补充能量，构成振荡器。

### 2.2 电磁场与电磁波（§4.2）

#### 2.2.1 麦克斯韦的两个基本假设

麦克斯韦电磁理论建立在两个具有根本性意义的假设之上：

**假设一：变化的磁场产生电场（涡旋电场假设）**

法拉第电磁感应定律表明，穿过闭合回路的磁通量发生变化时，回路中会产生感应电动势。麦克斯韦将其推广为：变化的磁场在其周围空间激发电场，这种电场称为感应电场或涡旋电场。其数学表述为：

$$\oint_L \vec{E}_\text{涡}\cdot\mathrm{d}\vec{l} = -\int_S \frac{\partial\vec{B}}{\partial t}\cdot\mathrm{d}\vec{S}$$

涡旋电场的电场线是闭合曲线，与由电荷产生的静电场有本质区别。

**假设二：变化的电场产生磁场（位移电流假设）**

麦克斯韦在研究电容器充电过程时发现，恒定条件下的安培环路定理 $\oint\vec{B}\cdot\mathrm{d}\vec{l} = \mu_0 I$ 在非恒定情形下出现内在矛盾——对于包围电容器极板的回路，穿过不同曲面的电流不同。

为解决这一矛盾，麦克斯韦引入位移电流概念：电位移通量随时间的变化率等效于一种"电流"，称为位移电流。定义位移电流密度：

$$\vec{j}_D = \frac{\partial\vec{D}}{\partial t} = \varepsilon_0\frac{\partial\vec{E}}{\partial t}$$

修正后的安培环路定理（全电流定律）为：

$$\oint_L \vec{B}\cdot\mathrm{d}\vec{l} = \mu_0\left(I + \varepsilon_0\frac{\mathrm{d}\Phi_E}{\mathrm{d}t}\right)$$

或表示为：

$$\nabla\times\vec{B} = \mu_0\vec{j} + \mu_0\varepsilon_0\frac{\partial\vec{E}}{\partial t}$$

这一假设揭示了电场与磁场之间深刻的内在联系：不仅变化的磁场产生电场，变化的电场也产生磁场。

#### 2.2.2 电磁波的存在与传播特性

由麦克斯韦方程组出发，在无自由电荷和传导电流的均匀介质中，电场强度 $\vec{E}$ 满足波动方程：

$$\nabla^2\vec{E} - \varepsilon\mu\frac{\partial^2\vec{E}}{\partial t^2} = 0$$

同理，磁感应强度 $\vec{B}$ 满足：

$$\nabla^2\vec{B} - \varepsilon\mu\frac{\partial^2\vec{B}}{\partial t^2} = 0$$

两式均为标准的波动方程，表明电磁场以波的形式传播。波速为：

$$v = \frac{1}{\sqrt{\varepsilon\mu}}$$

在真空中，$\varepsilon = \varepsilon_0$，$\mu = \mu_0$，电磁波传播速度：

$$c = \frac{1}{\sqrt{\varepsilon_0\mu_0}}$$

代入 $\varepsilon_0 = 8.854\times10^{-12}\,\text{F/m}$ 与 $\mu_0 = 4\pi\times10^{-7}\,\text{H/m}$，计算得 $c \approx 3.00\times10^8\,\text{m/s}$，与实验测得的光速精确一致。这是光即为电磁波的决定性证据。

#### 2.2.3 电磁波是横波的推导

考虑沿 $z$ 轴正方向传播的平面简谐电磁波，设其电场为：

$$\vec{E} = \vec{E}_0\cos(kz - \omega t)$$

由麦克斯韦方程组 $\nabla\cdot\vec{E} = 0$（无自由电荷区域），计算得：

$$\frac{\partial E_x}{\partial x} + \frac{\partial E_y}{\partial y} + \frac{\partial E_z}{\partial z} = 0$$

由于 $\vec{E}$ 仅为 $z$ 和 $t$ 的函数，前两项为零，故 $\partial E_z/\partial z = 0$，即 $E_z = 0$（设无恒定分量）。这表明电场矢量垂直于传播方向。

由法拉第电磁感应定律 $\nabla\times\vec{E} = -\partial\vec{B}/\partial t$，计算旋度得：

$$-\frac{\partial E_y}{\partial z}\hat{i} + \frac{\partial E_x}{\partial z}\hat{j} = -\frac{\partial\vec{B}}{\partial t}$$

解得：

$$B_x = -\frac{k}{\omega}E_y = -\frac{E_y}{v},\quad B_y = \frac{k}{\omega}E_x = \frac{E_x}{v}$$

这表明：
1. $B_z = 0$，磁场矢量也垂直于传播方向
2. $\vec{E}\perp\vec{B}$，且二者相互垂直
3. $\vec{E}$、$\vec{B}$ 与传播方向 $\vec{v}$ 构成右手正交系：$\vec{E}\times\vec{B}$ 指向波的传播方向

综上，电磁波是横波，满足 $\vec{E}\perp\vec{B}\perp\vec{v}$。

电磁波的能流密度由坡印廷矢量描述：

$$\vec{S} = \frac{1}{\mu_0}\vec{E}\times\vec{B}$$

电磁波携带能量和动量，其在真空中的传播不需要任何弹性介质。

### 2.3 无线电波的发射和接收（§4.3）

#### 2.3.1 有效发射电磁波的条件

根据电磁理论，振荡电路辐射电磁波的能力取决于两个关键因素：

**频率条件**：辐射功率与频率的四次方成正比（由拉莫尔公式 $P \propto \omega^4 p_0^2$ 描述，其中 $p_0$ 为电偶极矩振幅）。LC电路的辐射功率为：

$$P = \frac{\mu_0 p_0^2\omega^4}{12\pi c}$$

频率越高，辐射效率越高。因此需减小 $L$ 和 $C$ 以提高振荡频率。

**开放结构条件**：闭合LC回路中电场集中在电容器极板间，磁场集中在线圈内，电磁场束缚于电路内部，无法有效向外辐射。必须将电路"开放"，使电场和磁场能够扩散到空间中。

实践中，将电容器极板间距增大、面积减小，同时将电感线圈匝数减少、拉直，最终演化为一条直线——即天线。天线构成LC开放振荡电路的一部分，实现电磁波的有效辐射。

#### 2.3.2 调制：调幅（AM）与调频（FM）

声波等低频信号不能直接有效辐射，需将其加载到高频载波上，此过程称为调制。

**调幅（Amplitude Modulation, AM）**：使高频载波的振幅随调制信号的变化而变化。设载波为 $u_c(t) = U_c\cos(\omega_c t)$，调制信号为 $u_\Omega(t) = U_\Omega\cos(\Omega t)$，则调幅波为：

$$u_\text{AM}(t) = U_c\left[1 + m_a\cos(\Omega t)\right]\cos(\omega_c t)$$

其中 $m_a = U_\Omega/U_c$ 为调幅系数。调幅波的频谱包含载频 $\omega_c$ 及两个边频 $\omega_c\pm\Omega$。

**调频（Frequency Modulation, FM）**：使高频载波的频率随调制信号的变化而变化。调频波的频率偏移与调制信号振幅成正比：

$$\omega(t) = \omega_c + k_f u_\Omega(t)$$

调频的抗干扰能力强于调幅，因为外部干扰主要影响振幅而非频率，可通过限幅器消除。

#### 2.3.3 调谐与解调（检波）

**调谐（选频）**：接收天线感应出各种频率的电动势，通过LC调谐电路选择特定频率的信号。调谐电路的固有频率 $f_0 = 1/(2\pi\sqrt{LC})$，调节 $L$ 或 $C$ 使其与待接收信号频率一致，产生电谐振，该频率信号被放大，其他频率信号被抑制。

**解调（检波）**：从已调制的高频信号中提取原始低频信号的过程。对于AM信号，检波利用二极管的单向导电性，将调幅波进行半波或全波整流，再经低通滤波器滤除高频载波分量，还原出原始调制信号。

无线电广播发射与接收的完整流程：

发射端：声音信号 → 话筒（声电转换）→ 音频放大器 → 调制器（与高频载波合成）→ 高频功率放大器 → 发射天线

接收端：接收天线 → 调谐电路（选频）→ 高频放大器 → 检波器（解调）→ 音频放大器 → 扬声器

### 2.4 电磁波谱（§4.4）

电磁波按波长（或频率）排列形成电磁波谱。不同波段的电磁波具有共同的波动本质，但因波长差异而表现出不同的与物质相互作用特性。

#### 2.4.1 电磁波谱的分段与特征

| 波段 | 波长范围 | 频率范围 | 主要产生机制 | 典型应用 |
|------|----------|----------|-------------|----------|
| 无线电波 | $> 10^{-1}\,\text{m}$ | $< 3\times10^9\,\text{Hz}$ | LC电路电磁振荡 | 广播、通信、雷达 |
| 微波 | $10^{-3}\sim10^{-1}\,\text{m}$ | $3\times10^9\sim3\times10^{11}\,\text{Hz}$ | 电子管/固态器件振荡 | 卫星通信、微波炉、雷达 |
| 红外线 | $7.6\times10^{-7}\sim10^{-3}\,\text{m}$ | $3\times10^{11}\sim4\times10^{14}\,\text{Hz}$ | 分子热运动、电子跃迁 | 遥感、夜视、热成像 |
| 可见光 | $3.8\times10^{-7}\sim7.6\times10^{-7}\,\text{m}$ | $4\times10^{14}\sim8\times10^{14}\,\text{Hz}$ | 外层电子能级跃迁 | 视觉、照明、光学仪器 |
| 紫外线 | $10^{-9}\sim3.8\times10^{-7}\,\text{m}$ | $8\times10^{14}\sim3\times10^{17}\,\text{Hz}$ | 内层/外层电子跃迁 | 消毒、光刻、荧光分析 |
| X射线 | $10^{-12}\sim10^{-9}\,\text{m}$ | $3\times10^{17}\sim3\times10^{20}\,\text{Hz}$ | 内层电子跃迁、轫致辐射 | 医学影像、材料分析 |
| γ射线 | $< 10^{-12}\,\text{m}$ | $> 3\times10^{20}\,\text{Hz}$ | 核衰变、核反应 | 癌症治疗、工业探伤、天文观测 |

#### 2.4.2 各波段的物理特性与应用

**无线电波**：波长最长，波动性最显著，易于产生和接收。长波可沿地球表面传播（地波），中波夜间可通过电离层反射（天波），短波和微波主要以直线传播。现代5G通信使用毫米波频段（$24\sim100\,\text{GHz}$），具有较高的数据传输速率。

**微波**：波长介于无线电波与红外线之间，具有定向传播特性。微波与物质的相互作用主要表现为极性分子的转动共振吸收，微波炉即利用水分子对 $2.45\,\text{GHz}$ 微波的强吸收实现加热。

**红外线**：本质上是分子热辐射的主要波段。任何温度高于绝对零度的物体均辐射红外线，辐射强度与温度的四次方成正比（斯特藩-玻尔兹曼定律）。

**可见光**：人眼可感知的电磁波段，波长范围约 $380\,\text{nm}$（紫）至 $760\,\text{nm}$（红）。不同波长对应不同颜色视觉。可见光在电磁波谱中占据极窄范围，这一事实具有深刻的宇宙学意义。

**紫外线**：光子能量（$3\sim100\,\text{eV}$）足以打断部分化学键和电离原子，可导致生物细胞DNA损伤。大气层中的臭氧层对 $200\sim300\,\text{nm}$ 的紫外线有强烈吸收，构成地表生物的保护屏障。

**X射线**：由高速电子轰击金属靶产生的轫致辐射或原子内层电子跃迁产生。X射线光子能量高（$\text{keV}\sim\text{MeV}$ 量级），穿透能力强，在医学诊断和晶体结构分析中具有不可替代的作用。

**γ射线**：由原子核衰变或核反应产生，光子能量最高（$>\text{MeV}$），穿透力最强，对生物组织具有极强的电离损伤效应。

## 三、深度理解

### 3.1 LC振荡中的能量守恒

在理想LC振荡电路中，系统总能量保持恒定。设电容器电荷量为 $q$，回路电流为 $i$，则：

**电场能**（储存在电容器中）：

$$E_\text{电} = \frac{q^2}{2C} = \frac{Q_0^2}{2C}\cos^2(\omega t + \varphi_0)$$

**磁场能**（储存在电感中）：

$$E_\text{磁} = \frac{1}{2}Li^2 = \frac{1}{2}L\omega^2Q_0^2\sin^2(\omega t + \varphi_0) = \frac{Q_0^2}{2C}\sin^2(\omega t + \varphi_0)$$

总能量：

$$E_\text{总} = E_\text{电} + E_\text{磁} = \frac{Q_0^2}{2C}\left[\cos^2(\omega t + \varphi_0) + \sin^2(\omega t + \varphi_0)\right] = \frac{Q_0^2}{2C}$$

总能量等于电容器初始储能，为一守恒量。这一能量守恒关系可进一步表述为：

$$\frac{q^2}{2C} + \frac{1}{2}Li^2 = \text{常量}$$

从能量角度分析，LC振荡本质上是电场能与磁场能之间的周期性相互转化。当 $q = \pm Q_0$ 时，$E_\text{电}$ 达最大值 $Q_0^2/(2C)$，$E_\text{磁} = 0$；当 $q = 0$ 时，$E_\text{电} = 0$，$E_\text{磁}$ 达最大值 $Q_0^2/(2C)$。两种能量此消彼长，交替达到极值。

这一能量转化过程与简谐振动中动能与势能的转化具有完全相同的数学结构，$q$ 相当于位移，$i$ 相当于速度，$1/C$ 相当于弹性系数，$L$ 相当于惯性质量。

### 3.2 麦克斯韦方程组的对称美

#### 3.2.1 电场与磁场的对偶性

在无源真空区域（$\rho = 0$，$\vec{j} = \vec{0}$），麦克斯韦方程组简化为：

$$\nabla\cdot\vec{E} = 0,\quad \nabla\times\vec{E} = -\frac{\partial\vec{B}}{\partial t}$$
$$\nabla\cdot\vec{B} = 0,\quad \nabla\times\vec{B} = \mu_0\varepsilon_0\frac{\partial\vec{E}}{\partial t}$$

观察该方程组，存在显著的结构对称性：前两式和后两式在形式上几乎相同，仅通过变换 $\vec{E} \rightarrow c\vec{B}$、$\vec{B} \rightarrow -\vec{E}/c$ 即可互换。这种对称性称为电场与磁场的**对偶性**（duality）。

更一般地，在SI单位制下引入对偶变换：

$$\vec{E}' = \vec{E}\cos\xi + c\vec{B}\sin\xi$$
$$c\vec{B}' = -\vec{E}\sin\xi + c\vec{B}\cos\xi$$

其中 $\xi$ 为任意实常数。可直接验证，变换后的 $\vec{E}'$ 和 $\vec{B}'$ 同样满足麦克斯韦方程组。这一连续对偶对称性对应于SO(2)变换群。

#### 3.2.2 对称性破缺与磁单极子

上述对偶对称性仅在无源区域严格成立。当存在电荷和电流时，方程组出现不对称：

$$\nabla\cdot\vec{E} = \frac{\rho_e}{\varepsilon_0},\quad \nabla\times\vec{B} = \mu_0\vec{j}_e + \mu_0\varepsilon_0\frac{\partial\vec{E}}{\partial t}$$

电场的散度由电荷密度 $\rho_e$ 决定，而磁场的散度恒为零，表明不存在磁荷（磁单极子）。这种不对称性引发了物理学家长期探索：如果磁单极子存在，麦克斯韦方程组将具有完美的电—磁对称形式：

$$\nabla\cdot\vec{E} = \frac{\rho_e}{\varepsilon_0},\quad \nabla\times\vec{E} = -\frac{\partial\vec{B}}{\partial t} - \mu_0\vec{j}_m$$
$$\nabla\cdot\vec{B} = \mu_0\rho_m,\quad \nabla\times\vec{B} = \mu_0\vec{j}_e + \mu_0\varepsilon_0\frac{\partial\vec{E}}{\partial t}$$

1931年，狄拉克（P. A. M. Dirac）从量子力学角度论证，磁单极子的存在可以解释电荷的量子化。尽管迄今实验尚未确认磁单极子的存在，但其在规范场论和弦理论中扮演重要角色。

### 3.3 加速运动电荷辐射电磁波的物理机制

#### 3.3.1 拉莫尔公式

经典电动力学的一个核心结论是：做加速运动的电荷会辐射电磁波。对于非相对论性粒子（$v \ll c$），其辐射总功率由拉莫尔（J. J. Larmor）公式给出：

$$P = \frac{\mu_0 q^2 a^2}{6\pi c}$$

其中 $q$ 为电荷量，$a$ 为加速度。辐射功率与加速度的平方成正比，与电荷量的平方成正比。

#### 3.3.2 辐射机制的定性分析

匀速运动的电荷不产生辐射。当电荷加速时，其周围的电磁场发生重新调整，这一调整以有限速度 $c$ 向外传播，形成电磁波。具体而言：

电荷静止时，其电场呈径向对称分布。当电荷突然加速后，新的电场分布以电荷新位置为中心；但远处场点尚未获知加速信息，仍维持以原位置为中心的场分布。在"知"与"不知"的过渡区域，电场线发生弯折，这一横向扰动分量即以电磁波的形式向外传播。

因此，**只有加速运动的电荷才辐射电磁波**。LC振荡电路中的交变电流本质上就是电荷的加速运动，从而构成电磁波辐射的波源。载波频率越高，电荷加速度越大，辐射功率越高（$P \propto \omega^4$）。

#### 3.3.3 电偶极辐射

LC振荡电路（开放为天线后）的辐射可视为振荡电偶极子的辐射。设电偶极矩 $\vec{p} = \vec{p}_0\cos(\omega t)$，在远场区（$r \gg \lambda$），辐射场的电场和磁场分别为：

$$E_\theta = \frac{p_0\omega^2\sin\theta}{4\pi\varepsilon_0 c^2 r}\cos(kr - \omega t)$$
$$B_\varphi = \frac{E_\theta}{c} = \frac{\mu_0 p_0\omega^2\sin\theta}{4\pi c r}\cos(kr - \omega t)$$

辐射强度（单位面积功率）呈 $\sin^2\theta$ 分布，在偶极子赤道面最强，两极处为零。总辐射功率：

$$P = \frac{\mu_0 p_0^2\omega^4}{12\pi c}$$

与 $\omega^4$ 成正比，说明了高频辐射的必要性。

### 3.4 可见光在整个电磁波谱中只占极小范围的科学意义

可见光的波长范围约为 $380\,\text{nm}\sim760\,\text{nm}$，在电磁波谱中仅跨越不到一个数量级。人类视觉系统之所以进化出对这一窄波段的敏感性，主要基于以下物理和生物学原因：

**第一**，地球大气层的透明窗口。太阳光辐射的峰值位于可见光波段（维恩位移定律：$\lambda_\text{max}T = 2.898\times10^{-3}\,\text{m}\cdot\text{K}$，太阳表面温度约 $5778\,\text{K}$，峰值波长约 $502\,\text{nm}$）。地球大气层对可见光具有良好的透射性，而对大部分紫外线和红外线有强烈吸收。进化选择使得生物视觉系统对大气透明窗口敏感，从而最大化利用太阳辐射。

**第二**，水分子的吸收特性。生物组织的主要成分是水，水分子对红外和微波有强吸收，对紫外线有强散射和吸收。可见光波段恰处于水分子吸收较弱的区间，使其能在生物组织中有效穿透。

**第三**，衍射极限与分辨率的平衡。波长过短（如X射线、γ射线）虽可提高分辨率，但光子能量过高，对生物组织具有电离损伤效应；波长过长（如无线电波）则衍射效应显著，无法获得足够的空间分辨能力以辨识物体细节。可见光波段在分辨率与生物安全性之间取得了进化意义上的最优平衡。

**第四**，从更广阔的宇宙学视角审视，可见光窗口的狭窄性提醒我们：人类直接感知的物理现实仅是自然界全部信息的一个极小子集。现代天文学通过射电望远镜、X射线望远镜、γ射线望远镜等全波段观测手段，已大大拓展了对宇宙的认知边界。

## 四、知识串联

### 4.1 与电磁感应的深化

电磁振荡与电磁波理论的建立，是对电磁感应定律的深化和拓展。

**从法拉第定律到涡旋电场假设**。法拉第电磁感应定律的原始形式 $\mathcal{E} = -\mathrm{d}\Phi_B/\mathrm{d}t$ 描述的是回路中的感应电动势。麦克斯韦将其提升为场的观点：变化的磁场在其周围空间激发涡旋电场。这一推广使电磁感应从回路现象上升为空间普遍的场效应，是场概念发展的关键一步。

**从自感现象到LC振荡**。第二章学习的自感现象——回路中电流变化产生自感电动势阻碍电流变化——是LC振荡得以实现的物理基础。正是电感的"惯性"效应，使得电容器放电时电流不能瞬时达到无穷大，而是经历渐进建立的过程，从而形成振荡而非一次性能量耗散。

**能量转化视角的统一**。电磁感应中的能量转化（发电机将机械能转化为电能，电动机将电能转化为机械能）与LC振荡中的能量转化（电场能与磁场能的相互转化）遵循共同的物理原理——能量守恒定律。两种情形中，电磁场都是能量的载体和传递媒介。

### 4.2 与光学的统一

麦克斯韦电磁理论实现了电磁学与光学的统一，这是物理学史上的重大理论综合。

**光是电磁波的实验证据**：
1. 速度一致：电磁波速 $c = 1/\sqrt{\varepsilon_0\mu_0}$ 的理论计算值与斐索（A. Fizeau）、傅科（L. Foucault）等人测得的光速实验值精确吻合
2. 横波特性：光和电磁波均为横波，具有偏振性
3. 传播特性：光与电磁波在反射、折射、干涉、衍射等方面表现完全一致
4. 介质中的传播：光在介质中的速度 $v = c/n$，电磁波在介质中的速度 $v = 1/\sqrt{\varepsilon\mu} = c/\sqrt{\varepsilon_r\mu_r}$，折射率 $n = \sqrt{\varepsilon_r\mu_r}$，在弱磁性介质中 $n \approx \sqrt{\varepsilon_r}$

**光谱学与色散**。不同频率的可见光对应不同颜色，这一事实在电磁理论框架下获得解释：可见光的颜色差异本质上是电磁振荡频率的差异。介质的色散现象（折射率随频率变化）可通过介质中电子在交变电场作用下的受迫振荡模型定量解释。

**几何光学的极限**。当电磁波波长趋于零（或障碍物尺度远大于波长）时，波动光学过渡到几何光学。电磁理论的波动性内涵表明，几何光学中的光线只是波长 $\lambda \to 0$ 时的极限近似。

### 4.3 与原子物理的衔接

电磁波谱的完整框架为理解原子物理和量子力学提供了重要的前置知识。

**原子光谱与电磁辐射**。原子发射或吸收特定频率的电磁辐射，形成线状光谱。每一谱线对应原子在两个定态能级 $E_m$ 和 $E_n$ 之间的跃迁，辐射频率由玻尔频率条件确定：

$$h\nu = |E_m - E_n|$$

不同波段的原子光谱对应不同类型的电子跃迁：
- 无线电波/微波：超精细结构跃迁、分子转动能级跃迁
- 红外线：分子振动能级跃迁
- 可见光与紫外线：外层电子能级跃迁
- X射线：内层电子能级跃迁
- γ射线：核内能级跃迁

**光电效应与光子概念**。赫兹在验证电磁波的实验中已发现光电效应现象。爱因斯坦于1905年提出光量子假说，认为光由能量为 $E = h\nu$ 的光子组成，成功解释了光电效应。光子的能量与电磁波的频率成正比，动量 $p = h/\lambda$，建立了粒子性与波动性的定量联系。

**波粒二象性的统一**。电磁波在传播过程中表现出波动性（干涉、衍射），在与物质相互作用时表现出粒子性（光电效应、康普顿效应）。这一波粒二象性不仅是光的特性，也是所有微观粒子的普遍属性，是量子力学的基本概念。

## 五、隐性考点

### 5.1 LC振荡中各物理量的相位关系

LC振荡电路中，电容器电荷量 $q$、回路电流 $i$、电场能 $E_\text{电}$、磁场能 $E_\text{磁}$ 之间存在确定的相位关系，这是解题的关键。

设 $q(t) = Q_0\cos\omega t$，则：

| 物理量 | 表达式 | 与 $q$ 的相位差 | 极值时刻 |
|--------|--------|-----------------|---------|
| 电荷量 $q$ | $Q_0\cos\omega t$ | 0 | $\omega t = 0, \pi$ |
| 电流 $i$ | $-\omega Q_0\sin\omega t$ | $-\pi/2$（超前） | $\omega t = \pi/2, 3\pi/2$ |
| 电压 $u_C$ | $(Q_0/C)\cos\omega t$ | 0 | 同 $q$ |
| 电场能 $E_\text{电}$ | $(Q_0^2/2C)\cos^2\omega t$ | 0（频率二倍） | 同 $q$ |
| 磁场能 $E_\text{磁}$ | $(Q_0^2/2C)\sin^2\omega t$ | $-\pi/2$（频率二倍） | 同 $i$ |

**关键结论**：
- $q$ 与 $i$ 相位差 $\pi/2$：$q$ 最大时 $i = 0$，$q = 0$ 时 $i$ 最大
- $E_\text{电}$ 与 $E_\text{磁}$ 以 $2\omega$ 的频率交替达到极值
- $E_\text{电}$ 最大时 $E_\text{磁} = 0$，反之亦然

### 5.2 电磁波在介质中传播的速度与波长变化

电磁波从真空进入折射率为 $n$ 的介质时：

**频率不变**：电磁波的频率由波源决定，与传播介质无关。

**速度变化**：$v = c/n = 1/\sqrt{\varepsilon\mu}$

**波长变化**：$\lambda' = v/f = \lambda_0/n$，即波长缩短为真空中的 $1/n$。

对于非磁性介质（$\mu_r \approx 1$），$n \approx \sqrt{\varepsilon_r}$。由于 $\varepsilon_r > 1$，总有 $v < c$，$\lambda' < \lambda_0$。

这一结论在天线的电长度设计中有重要应用：实际天线在介质中的有效电长度增大，导致谐振频率降低。

### 5.3 开放电路的必要性

LC闭合回路辐射效率极低，根本原因在于：

**场的空间分布限制**。闭合回路中电场集中于电容器极板之间，磁场集中于电感线圈内部，电磁场被束缚在电路元件附近的空间区域内，难以向远方传播。

**辐射电阻极小**。闭合回路的线度通常远小于波长（$l \ll \lambda$），构成电小天线，其辐射电阻与 $(l/\lambda)^2$ 成正比，数值极小。回路的欧姆电阻远大于辐射电阻，能量主要在回路中以焦耳热形式耗散。

**开放电路的演进路径**：
1. 将电容器极板间距增大、面积减小，使电场延伸至空间中
2. 将电感线圈拉直、减少匝数，使磁场扩散至空间中
3. 最终形成直线型天线，电场和磁场充分分布于空间中

有效辐射的条件：
- 频率足够高（$\omega$ 大，辐射功率 $P \propto \omega^4$）
- 电路结构开放（场分布扩展至空间）
- 天线线度与波长可比拟（$l \sim \lambda/4$ 或 $\lambda/2$ 时辐射效率最佳）

### 5.4 振荡电路的频率选择性

LC电路的固有频率 $f_0 = 1/(2\pi\sqrt{LC})$ 决定了其频率选择性。当外加信号频率等于 $f_0$ 时，电路发生谐振，阻抗最小（串联谐振）或最大（并联谐振），电流或电压达到极值。

**品质因数**：

$$Q = \frac{\omega_0 L}{R} = \frac{1}{R}\sqrt{\frac{L}{C}}$$

$Q$ 值反映电路的频率选择锐度。$Q$ 值越高，谐振峰越尖锐，频率选择性越好。在无线电接收中，高 $Q$ 值的调谐电路可有效分离频率相近的不同电台信号。

## 六、易错警示

### 6.1 电荷量最大时电流为零

**错误认识**：电容器电荷量最大时，放电速度最快，电流最大。

**正确理解**：由 $i = \mathrm{d}q/\mathrm{d}t$，当 $q = \pm Q_0$ 时，$q(t) = Q_0\cos\omega t$ 对时间的导数为零，即 $i = 0$。从物理过程分析，电荷量最大时电容器两极板间电压最大，此时放电恰好开始，电流从零逐渐增加。类比简谐运动：位移最大时速度为零。

### 6.2 $T = 2\pi\sqrt{LC}$ 的 $L$ 和 $C$ 是电路固有属性

**错误认识**：振荡周期可通过改变外部驱动频率来调节。

**正确理解**：$T = 2\pi\sqrt{LC}$ 中的 $L$（自感系数）和 $C$（电容）完全由电路本身的结构和元件参数决定：
- $L$ 取决于线圈的匝数、几何尺寸、磁芯材料
- $C$ 取决于极板面积、极板间距、介质介电常数

振荡周期与初始条件（初始电荷量 $Q_0$、初始电压）无关，也与外部驱动无关（自由振荡情形）。这与弹簧振子 $T = 2\pi\sqrt{m/k}$ 中 $m$、$k$ 为系统固有参数完全类似。

### 6.3 麦克斯韦假设与赫兹实验的逻辑关系

**错误认识**：麦克斯韦方程组是基于大量实验事实归纳总结的经验定律。

**正确理解**：麦克斯韦的两个基本假设（涡旋电场和位移电流）在提出时并无直接的实验支撑，而是基于理论内部一致性要求提出的理论预言。麦克斯韦的工作本质上是理论创造，而非实验归纳。

赫兹实验的核心意义在于**验证**了麦克斯韦理论的正确性，使电磁波从数学预言成为实验事实。这一关系属于"理论预言—实验验证"的典型科学范式。

### 6.4 电磁波传播不需要介质

**错误认识**：电磁波传播需要以太作为介质。

**正确理解**：麦克斯韦方程组在真空中同样成立，电磁波是电磁场的自我维持传播，不依赖任何弹性介质。迈克尔逊-莫雷实验（1887年）否定了以太的存在，爱因斯坦狭义相对论（1905年）进一步从理论上确立了电磁场作为独立物理实在的地位。

### 6.5 调制与解调的对象区分

**易混淆点**：
- **调制**在发射端进行，将低频信号加载到高频载波上
- **解调（检波）**在接收端进行，从已调波中提取低频信号
- **调谐**在接收端进行，选择特定频率的信号

三者的作用环节不可混淆。调谐是选频，调制是加载信息，解调是还原信息。

### 6.6 电谐振与机械谐振的类比限度

LC电路的电谐振与弹簧振子的机械谐振在数学形式上完全一致，但物理本质不同：
- 机械谐振：位移与动量的周期性转化
- 电谐振：电荷（电场能）与电流（磁场能）的周期性转化

类比有助于理解，但不可将物理图像简单迁移。特别是辐射阻尼在机械振动中没有对应概念——LC振荡电路通过天线辐射能量导致的振幅衰减，是电磁系统特有的耗散机制。

## 七、思想方法

### 7.1 对称与统一的思想

电磁学理论的发展深刻体现了对称与统一这一物理学核心思想。

**电与磁的统一**。奥斯特发现电流的磁效应（电生磁），法拉第发现电磁感应（磁生电），麦克斯韦引入位移电流（变化电场产生磁场），完成了电与磁的理论统一。电磁场是一个不可分割的整体，电场与磁场是同一物理实在在不同参考系或不同条件下的表现。

**电场与磁场的对称**。真空中无源麦克斯韦方程组在电场与磁场之间具有对偶对称性。这一对称性虽因电荷存在而破缺，但仍是理解电磁场结构的重要线索。狄拉克基于对称性考虑预言磁单极子，体现了对称性思想在理论物理中的启发功能。

**电磁学与光学的统一**。麦克斯韦理论将光学纳入电磁学框架，光不再被视为独立实体，而是电磁波的一个波段。这一统一是19世纪物理学最重大的理论成就之一，为20世纪相对论和量子论的建立奠定了基础。

### 7.2 守恒思想

守恒定律是物理学最基本的规律，贯穿于电磁振荡与电磁波的全部内容。

**能量守恒**。LC振荡电路中电场能与磁场能的总量守恒。这一定量关系 $q^2/(2C) + Li^2/2 = \text{常量}$ 是分析振荡过程的核心工具。当引入电阻后，电磁能转化为热能，总能量（电磁能+内能）仍守恒。

**电荷守恒**。麦克斯韦方程组与电荷守恒定律 $\partial\rho/\partial t + \nabla\cdot\vec{j} = 0$ 自洽。位移电流的引入正是为了保证电荷守恒在非恒定条件下的成立。

**动量守恒与角动量守恒**。电磁波携带动量和角动量，与物质相互作用时满足相应的守恒定律。光压（辐射压力）和角动量转移（圆偏振光使物体旋转）是电磁波具有力学属性的直接实验证据。

### 7.3 模型法

物理模型是对实际系统的抽象和简化，是理论分析的基本工具。

**LC理想电路模型**。忽略电阻、辐射、分布电容等非理想因素，将实际振荡电路抽象为由理想电感和理想电容构成的二元件模型。该模型精确描述无阻尼自由振荡的核心物理，是理解更复杂实际电路的基础。

**电偶极辐射模型**。将天线辐射抽象为振荡电偶极子的辐射，导出远场辐射场的分布规律。该模型解释了辐射的方向性、频率依赖性和功率特征。

**平面电磁波模型**。将远离波源处的电磁波近似为平面波，简化波动方程的分析。平面波模型是研究电磁波反射、折射、干涉、偏振等现象的基础。

理想模型的建立遵循"抓住主要矛盾、忽略次要因素"的原则。模型适用范围外的偏差（如LC模型中的阻尼衰减、平面波模型在近场区的失效）正是进一步深入研究的切入点。

### 7.4 理论预言与实验检验的科学方法论

电磁理论的发展展示了"假设—演绎—检验"的经典科学方法论：

1. **理论假设**：麦克斯韦基于数学自洽性提出位移电流假设
2. **逻辑演绎**：从方程组推导出电磁波的存在及其传播速度等于光速
3. **实验检验**：赫兹通过实验产生并检测电磁波，验证理论预言
4. **技术应用**：马可尼等人将理论成果转化为无线电通信技术

这一方法论链条体现了基础理论研究的价值：看似抽象的数学方程可以导出可检验的物理预言，进而引发技术革命。麦克斯韦方程组到现代无线通信的演进，是"科学—技术—社会"互动的典范案例。
