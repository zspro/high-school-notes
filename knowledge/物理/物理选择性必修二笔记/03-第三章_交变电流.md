# 第三章 交变电流

## 一、来龙去脉

### 1.1 直流与交流的技术之争

19世纪末，电气照明与动力传输技术进入商业化阶段，围绕电能传输方式的技术路线之争成为电气工程史上的关键事件。托马斯·爱迪生（Thomas Edison）于1882年在美国纽约建成世界上第一座商用直流发电站——珍珠街发电站（Pearl Street Station），该系统采用110 V直流电压向用户提供照明用电。直流电系统的优势在于电压稳定、控制简便，且当时直流电动机技术已较为成熟。然而，直流输电存在根本性技术限制：发电端与用电端电压相同，无法通过简单装置实现电压变换，导致远距离传输时线路损耗极大。为降低损耗，爱迪生系统只能在短距离内供电，发电站与用户的距离通常不超过1英里。

尼古拉·特斯拉（Nikola Tesla）在1887年发明了多相交流感应电动机，并于1888年获得专利。随后，乔治·威斯汀豪斯（George Westinghouse）购买了特斯拉的交流电专利，开始推广交流输电系统。交流电的核心优势在于可通过变压器实现电压的升高与降低，从而突破直流电的传输距离限制。

技术路线的竞争在1893年芝加哥世界博览会上达到高潮。威斯汀豪斯公司以交流电系统成功点亮了博览会全场超过20万只灯泡，展示了交流输电的可靠性。最终，1896年建成的尼亚加拉大瀑布水电站（Niagara Falls Power Station）采用交流电输出电力，将电能输送至26英里外的纽约州布法罗市。该工程的成功标志着交流电技术在大型电力系统中的主导地位得以确立。水电站采用三相交流发电机，输出电压经变压器升至高压进行远距离传输，再经降压变压器分配至用户端，形成了现代电力系统的基本架构。

### 1.2 变压器的技术演进

变压器的工作原理源于法拉第于1831年发现的电磁感应现象。1836年，法拉第发明了感应圈（induction coil），利用互感原理实现低电压直流电向高电压脉冲的转换，该装置成为变压器的技术原型。感应圈的工作原理为：通过机械断续器使初级线圈中的电流周期性通断，在次级线圈中感应出高电压。然而，由于输入为脉冲式直流，感应圈无法用于连续变换交流电压。

1882年，匈牙利工程师德里·米哈伊（Mechwart Dezső）和布拉什·奥托（Bláthy Ottó）发明了首台用于交流照明系统的闭合磁路变压器。1885年，齐佩尔诺夫斯基·卡罗伊（Zipernowsky Károly）、德里·米哈伊和布拉什·奥托三位工程师合作设计了第一台具有实用价值的交流变压器，采用并联连接方式，用于配电系统中的电压变换。此后，变压器技术迅速发展，核心设计逐步优化为采用闭合铁芯以减小磁阻、降低漏磁，并采用叠片铁芯结构以抑制涡流损耗。

### 1.3 高压输电的物理基础

输电线路上的能量损耗主要由导线的电阻引起，其功率损耗由焦耳定律给出：

$$P_{\text{损}} = I^2 R$$

其中 $I$ 为线路电流，$R$ 为输电线总电阻。设输送功率为 $P$，输电电压为 $U$，则线路电流 $I = P/U$。代入损耗表达式得：

$$P_{\text{损}} = \left(\frac{P}{U}\right)^2 R = \frac{P^2 R}{U^2}$$

由上式可知，在输送功率 $P$ 和线路电阻 $R$ 一定时，功率损耗与输电电压的平方成反比。因此，将输电电压提高至原来的 $n$ 倍，线路损耗降低为原来的 $1/n^2$。例如，将电压从1 kV升至10 kV，损耗降至原来的1/100。这一定量关系是高压输电技术的物理基础，也是交流电优于直流电的关键原因——变压器可方便地实现交流电压的大幅提升。

## 二、基础精讲

### 2.1 交变电流的产生与描述

#### 2.1.1 正弦式交变电流的产生

正弦式交变电流由矩形线圈在匀强磁场中绕垂直于磁场方向的固定轴匀速转动产生。设匀强磁场的磁感应强度为 $B$，线圈面积为 $S$，匝数为 $N$，线圈绕垂直于磁场方向的轴以角速度 $\omega$ 匀速转动。取线圈平面与中性面（即与磁场方向垂直的平面）重合时为计时起点 $t = 0$。

在时刻 $t$，线圈平面与中性面的夹角为 $\theta = \omega t$。穿过线圈的磁通量为：

$$\Phi = BS\cos\theta = BS\cos\omega t$$

根据法拉第电磁感应定律，感应电动势为：

$$e = -N\frac{\mathrm{d}\Phi}{\mathrm{d}t} = -N\frac{\mathrm{d}}{\mathrm{d}t}(BS\cos\omega t) = NBS\omega\sin\omega t$$

定义峰值电动势（最大电动势）$E_m = NBS\omega$，则：

$$e = E_m\sin\omega t$$

若电路总电阻为 $R$，则电流瞬时值为：

$$i = \frac{e}{R} = \frac{E_m}{R}\sin\omega t = I_m\sin\omega t$$

其中 $I_m = E_m/R$ 为电流峰值。若电路为纯电阻电路，电压瞬时值为 $u = U_m\sin\omega t$，其中 $U_m = I_m R$。

若计时起点不是线圈位于中性面的时刻，而是线圈平面与中性面已有夹角 $\varphi_0$，则：

$$e = E_m\sin(\omega t + \varphi_0)$$

其中 $\varphi_0$ 为初相位。

#### 2.1.2 交变电流的周期、频率与角频率

周期 $T$ 为交变电流完成一次完整周期性变化所需的时间，单位为秒（s）。

频率 $f$ 为单位时间内完成的周期性变化的次数，单位为赫兹（Hz）。

周期与频率的关系为：

$$f = \frac{1}{T}$$

角频率 $\omega$ 为线圈转动的角速度，单位为弧度每秒（rad/s）。角频率与周期、频率的关系为：

$$\omega = \frac{2\pi}{T} = 2\pi f$$

#### 2.1.3 峰值与有效值

峰值（最大值）$E_m$、$U_m$、$I_m$ 分别为电动势、电压、电流在一个周期内达到的最大瞬时值。

有效值是根据电流的热效应定义的。设交变电流 $i(t)$ 通过阻值为 $R$ 的电阻，在一个周期 $T$ 内产生的热量与一个恒定直流电流 $I$ 通过同一电阻在相同时间内产生的热量相等，则该直流电流 $I$ 即为交变电流的有效值。

由热效应等效条件：

$$\int_0^T i^2(t)R\,\mathrm{d}t = I^2RT$$

对于正弦式交变电流 $i = I_m\sin\omega t$：

$$I^2RT = R\int_0^T I_m^2\sin^2\omega t\,\mathrm{d}t = RI_m^2\int_0^T \frac{1-\cos 2\omega t}{2}\,\mathrm{d}t$$

$$= RI_m^2\left[\frac{t}{2} - \frac{\sin 2\omega t}{4\omega}\right]_0^T = RI_m^2 \cdot \frac{T}{2}$$

因此：

$$I^2 = \frac{I_m^2}{2}$$

$$I = \frac{I_m}{\sqrt{2}}$$

同理，电动势有效值和电压有效值分别为：

$$E = \frac{E_m}{\sqrt{2}}, \quad U = \frac{U_m}{\sqrt{2}}$$

日常所说的交流电压220 V、380 V均指有效值，交流电压表和电流表的示数也为有效值。

#### 2.1.4 平均值

电动势在一个周期内的平均值定义为：

$$\bar{E} = \frac{1}{T}\int_0^T e(t)\,\mathrm{d}t$$

对于正弦式交变电流 $e = E_m\sin\omega t$：

$$\bar{E} = \frac{1}{T}\int_0^T E_m\sin\omega t\,\mathrm{d}t = \frac{E_m}{T}\left[-\frac{\cos\omega t}{\omega}\right]_0^T = 0$$

正弦交流电在一个完整周期内的平均值为零。计算电荷量时需用平均值：

$$q = \bar{I}\Delta t = \frac{\bar{E}}{R}\Delta t = N\frac{\Delta\Phi}{R}$$

#### 2.1.5 相位

交变电流的瞬时值表达式 $e = E_m\sin(\omega t + \varphi_0)$ 中，$\omega t + \varphi_0$ 称为相位，$\varphi_0$ 称为初相位。两个同频率交变电流的相位之差称为相位差。若两个交变电流的相位差为零，则二者同相；若相位差为 $\pi$，则二者反相。

### 2.2 变压器

#### 2.2.1 理想变压器的基本构造

变压器由闭合铁芯和绕在铁芯上的两个（或多个）线圈组成。与电源相连的线圈称为原线圈（初级线圈），与负载相连的线圈称为副线圈（次级线圈）。铁芯由高磁导率的硅钢片叠压而成，以增大磁通量并减小涡流损耗。

#### 2.2.2 理想变压器的基本假设

理想变压器满足以下假设条件：

（1）无铜损：原、副线圈的电阻为零，线圈不产生焦耳热；

（2）无铁损：铁芯中不产生涡流损耗和磁滞损耗；

（3）无磁漏：原、副线圈产生的磁通量全部通过铁芯，无漏磁；

（4）铁芯的磁导率趋于无穷大，建立交变磁通所需的励磁电流趋于零。

#### 2.2.3 理想变压器的三大规律

**电压比规律**

设原线圈匝数为 $n_1$，副线圈匝数为 $n_2$。当原线圈接入交变电压 $U_1$ 时，原线圈中的交变电流产生交变磁通 $\Phi$，该磁通通过铁芯全部穿过副线圈。根据法拉第电磁感应定律：

$$U_1 = n_1\frac{\Delta\Phi}{\Delta t}, \quad U_2 = n_2\frac{\Delta\Phi}{\Delta t}$$

两式相除得：

$$\frac{U_1}{U_2} = \frac{n_1}{n_2}$$

即原、副线圈的电压之比等于其匝数之比。若 $n_2 > n_1$，则 $U_2 > U_1$，为升压变压器；若 $n_2 < n_1$，则 $U_2 < U_1$，为降压变压器。

**功率守恒**

理想变压器无能量损耗，输入功率等于输出功率：

$$P_1 = P_2$$

即：

$$U_1 I_1 = U_2 I_2$$

**电流比规律**

由功率守恒和电压比规律：

$$U_1 I_1 = U_2 I_2 \Rightarrow \frac{I_1}{I_2} = \frac{U_2}{U_1} = \frac{n_2}{n_1}$$

即原、副线圈的电流之比等于其匝数的反比。上式仅在只有一个副线圈时成立。

#### 2.2.4 多组副线圈变压器

若变压器有多个副线圈，各副线圈的电压仍满足：

$$\frac{U_1}{n_1} = \frac{U_2}{n_2} = \frac{U_3}{n_3} = \cdots$$

功率关系为：

$$P_1 = P_2 + P_3 + \cdots$$

即：

$$U_1 I_1 = U_2 I_2 + U_3 I_3 + \cdots$$

电流比 $I_1/I_2 = n_2/n_1$ 不再适用于多副线圈情形。

### 2.3 电能的输送

#### 2.3.1 远距离输电系统的构成

远距离输电系统由发电站、升压变压器、输电线路、降压变压器和用户组成。发电站输出的电压经升压变压器升至高压（如110 kV、220 kV、500 kV或更高），通过输电线路传输至负荷中心，再经多级降压变压器降至用户所需电压（如380 V/220 V）。

#### 2.3.2 输电损耗的定量分析

设发电站输出功率为 $P$，升压变压器输出电压为 $U$，输电线总电阻为 $R$，则线路电流为：

$$I = \frac{P}{U}$$

输电线上的功率损耗为：

$$P_{\text{损}} = I^2 R = \frac{P^2 R}{U^2}$$

输电线上的电压降为：

$$\Delta U = IR = \frac{PR}{U}$$

用户端获得的功率为：

$$P_{\text{用}} = P - P_{\text{损}} = P\left(1 - \frac{PR}{U^2}\right)$$

输电效率为：

$$\eta = \frac{P_{\text{用}}}{P} = 1 - \frac{PR}{U^2} = \frac{U - \Delta U}{U}$$

#### 2.3.3 高压输电的经济性

采用高压输电时，在输送功率一定的情况下，线路电流减小，从而带来以下效益：

（1）线路损耗 $P_{\text{损}} = I^2 R$ 大幅降低；

（2）线路电压降 $\Delta U = IR$ 减小，用户端电压更加稳定；

（3）在允许损耗范围内，可使用截面积较小的导线，节约有色金属。

设输送功率为 $P$，允许损耗率为 $\alpha$（$P_{\text{损}}/P \leq \alpha$），则所需最小电压为：

$$U \geq \sqrt{\frac{PR}{\alpha}}$$

## 三、深度理解

### 3.1 有效值定义的数学本质

交变电流有效值的定义式为：

$$I = \sqrt{\frac{1}{T}\int_0^T i^2(t)\,\mathrm{d}t}$$

该式在数学上称为函数 $i(t)$ 在一个周期内的均方根值（Root Mean Square, RMS），其运算顺序为：先平方（S）、再取平均（M）、最后开平方根（R）。

均方根值具有明确的物理意义：由于电阻发热功率 $P = i^2 R$ 与电流的平方成正比，热量累积效应取决于 $i^2$ 的时间平均值，因此有效值实质上是对 squared quantity 进行时间平均后再恢复线性量纲的结果。

对于正弦波 $i = I_m\sin\omega t$，均方根值为峰值除以 $\sqrt{2}$。对于其他波形的交变电流，有效值必须通过均方根积分计算，不能简单地用峰值除以 $\sqrt{2}$。

### 3.2 变压器不能变换直流电压的原理

变压器的工作基础是电磁感应中的互感现象。原线圈中的交变电流产生交变磁通，该交变磁通穿过副线圈时在副线圈中感应出电动势。根据法拉第电磁感应定律，感应电动势的大小与磁通量的变化率成正比：

$$E = -N\frac{\mathrm{d}\Phi}{\mathrm{d}t}$$

当原线圈接入直流电压时，稳定状态下电流恒定，产生恒定磁通，$\mathrm{d}\Phi/\mathrm{d}t = 0$，副线圈中无感应电动势。仅在直流电源接通或断开的瞬间，磁通量发生变化，副线圈中才会产生短暂的感应电动势。因此，变压器无法实现直流电压的持续变换。

### 3.3 输电效率的计算

远距离输电系统的效率定义为：

$$\eta = \frac{P_{\text{用户}}}{P_{\text{总}}} \times 100\%$$

其中 $P_{\text{总}}$ 为发电站输出的总功率，$P_{\text{用户}}$ 为用户端实际获得的功率。

设输电电压为 $U$，输送功率为 $P$，线路电阻为 $R$，则：

$$\eta = \frac{P - I^2 R}{P} = 1 - \frac{P R}{U^2}$$

当输电电压 $U = 220\ \text{kV}$，输送功率 $P = 200\ \text{MW}$，线路电阻 $R = 10\ \Omega$ 时：

$$\eta = 1 - \frac{200 \times 10^6 \times 10}{(220 \times 10^3)^2} = 1 - \frac{2 \times 10^9}{4.84 \times 10^{10}} = 1 - 0.0413 = 95.87\%$$

若电压降至 $U = 110\ \text{kV}$，其余条件不变：

$$\eta = 1 - \frac{2 \times 10^9}{(1.1 \times 10^5)^2} = 1 - \frac{2 \times 10^9}{1.21 \times 10^{10}} = 1 - 0.165 = 83.5\%$$

电压降低一半，输电效率从约96%降至约84%，损耗率从约4%升至约17%。

### 3.4 相位关系与功率因数

在纯电阻交流电路中，电压与电流同相。对于纯电感电路，电压超前电流 $\pi/2$；对于纯电容电路，电压滞后电流 $\pi/2$。一般情况下，交流电路的瞬时功率为：

$$p = ui = U_m I_m \sin\omega t \sin(\omega t + \varphi)$$

其中 $\varphi$ 为电压与电流的相位差。平均功率（有功功率）为：

$$P = UI\cos\varphi$$

$\cos\varphi$ 称为功率因数。当 $\varphi = 0$ 时，$\cos\varphi = 1$，功率最大；当 $\varphi = \pm\pi/2$ 时，$\cos\varphi = 0$，纯感性或纯容性负载不消耗有功功率。

## 四、知识串联

### 4.1 与电磁感应的直接联系

交变电流的产生和变压器的工作原理均直接建立在电磁感应定律的基础上。

**交变电流的产生**：线圈在磁场中转动时，穿过线圈的磁通量发生周期性变化，根据法拉第电磁感应定律 $E = -N\mathrm{d}\Phi/\mathrm{d}t$，产生感应电动势。当线圈以匀角速度转动时，磁通量按余弦规律变化，其导数为正弦函数，因此产生正弦式交变电动势。

**变压器的工作原理**：变压器的工作基于互感现象。原线圈中的交变电流产生交变磁场，该磁场通过铁芯耦合至副线圈，使副线圈中的磁通量发生变化，从而在副线圈中产生感应电动势。互感系数 $M$ 表征两个线圈之间的磁耦合程度，副线圈中的感应电动势可表示为 $E_2 = -M\mathrm{d}i_1/\mathrm{d}t$。

### 4.2 与电路分析的联系

交流电路的分析方法与直流电路有本质区别。直流电路中，电阻是唯一的电路参数，欧姆定律形式为 $U = IR$。交流电路中，电感和电容对交变电流呈现不同的阻碍作用：

**感抗**：电感对交变电流的阻碍作用称为感抗，$X_L = \omega L = 2\pi f L$。频率越高，感抗越大。

**容抗**：电容对交变电流的阻碍作用称为容抗，$X_C = \frac{1}{\omega C} = \frac{1}{2\pi f C}$。频率越高，容抗越小。

**阻抗**：$R$-$L$-$C$ 串联电路的总阻抗为：

$$Z = \sqrt{R^2 + (X_L - X_C)^2} = \sqrt{R^2 + \left(\omega L - \frac{1}{\omega C}\right)^2}$$

交流欧姆定律：$I = U/Z$。

### 4.3 与实际应用的联系

**电力系统架构**：现代电力系统由发电、输电、变电、配电和用电五个环节组成。发电厂（火力、水力、核能、风力等）产生电能后，经升压变压器升至超高压（如500 kV、1000 kV），通过输电线路传输至区域变电站，再经高压配电、中压配电、低压配电多级降压后供给用户。

**直流输电的补充**：随着电力电子技术的发展，高压直流（HVDC）输电在长距离、大容量输电中得到应用。交流电经整流变为直流后输送，在受端再逆变为交流。直流输电的线路损耗更小，且无交流输电的稳定性问题，但换流站成本高，适用于海底电缆或超远距离输电。

**电网频率**：中国大陆电网的标准频率为50 Hz，对应周期 $T = 0.02\ \text{s}$。美国、日本等部分国家采用60 Hz标准。发电厂必须维持频率稳定，频率偏差会影响电动机转速和电网同步运行。

## 五、隐性考点

### 5.1 非正弦交流电有效值的计算

非正弦交流电（如方波、锯齿波、半波整流波形等）的有效值不能直接用 $I = I_m/\sqrt{2}$ 计算，必须根据热效应等效定义，通过均方根积分求解。

**方波交流电**：设方波电流在一个周期 $T$ 内，前 $T/2$ 时间为 $I_0$，后 $T/2$ 时间为 $-I_0$，则：

$$I^2 T = I_0^2 \cdot \frac{T}{2} + (-I_0)^2 \cdot \frac{T}{2} = I_0^2 T$$

因此 $I = I_0$。方波的有效值等于其幅值。

**锯齿波交流电**：设锯齿波电流 $i = I_m \frac{t}{T}$（$0 \leq t \leq T$），则：

$$I^2 T = \int_0^T I_m^2 \frac{t^2}{T^2}\,\mathrm{d}t = \frac{I_m^2}{T^2} \cdot \frac{T^3}{3} = \frac{I_m^2 T}{3}$$

因此：

$$I = \frac{I_m}{\sqrt{3}}$$

**半波整流正弦波**：仅保留正弦波的正半周，负半周为零。设 $i = I_m\sin\omega t$（$0 \leq t \leq T/2$），$i = 0$（$T/2 \leq t \leq T$），则：

$$I^2 T = \int_0^{T/2} I_m^2\sin^2\omega t\,\mathrm{d}t = I_m^2 \cdot \frac{T}{4}$$

因此：

$$I = \frac{I_m}{2}$$

**全波整流正弦波**：将负半周翻转为正，则：

$$I^2 T = 2\int_0^{T/2} I_m^2\sin^2\omega t\,\mathrm{d}t = I_m^2 \cdot \frac{T}{2}$$

因此：

$$I = \frac{I_m}{\sqrt{2}}$$

### 5.2 变压器动态分析

当变压器副线圈的负载发生变化时，原、副线圈的电压和电流将发生连锁变化。分析此类问题需遵循以下逻辑链条：

（1）原线圈电压 $U_1$ 由电源决定，通常保持不变；

（2）根据电压比 $U_1/U_2 = n_1/n_2$，副线圈电压 $U_2$ 保持不变；

（3）副线圈电流 $I_2 = U_2/R_{\text{负载}}$，随负载电阻变化；

（4）根据功率守恒 $U_1 I_1 = U_2 I_2$（或电流比），原线圈电流 $I_1$ 随之变化；

（5）若考虑电源内阻，$U_1$ 可能因 $I_1$ 变化而变化，则需迭代分析。

**负载减小（$R_{\text{负载}}$ 减小）**：$I_2$ 增大 → $P_2$ 增大 → $P_1$ 增大 → $I_1$ 增大。

**负载增大（$R_{\text{负载}}$ 增大）**：$I_2$ 减小 → $P_2$ 减小 → $P_1$ 减小 → $I_1$ 减小。

**副线圈断路（$R_{\text{负载}} \to \infty$）**：$I_2 = 0$ → $P_2 = 0$ → $P_1 = 0$ → $I_1 = 0$（理想变压器）。

### 5.3 远距离输电的等效电路分析

远距离输电系统可等效为包含电源、升压变压器、线路阻抗、降压变压器和负载的完整电路。

设发电站输出电压为 $U_0$，经升压变压器（匝数比 $n_1:n_2$）升至 $U_1$，线路电阻为 $R$，电流为 $I$，则线路损耗 $P_{\text{损}} = I^2 R$，降压变压器输入电压为 $U_1 - IR$，用户端电压为 $U_{\text{用}}$。

等效电路分析步骤：

（1）根据输送功率 $P$ 和输电电压 $U_1$，计算线路电流 $I = P/U_1$；

（2）计算线路损耗 $P_{\text{损}} = I^2 R$；

（3）计算降压变压器输入电压 $U_{\text{降入}} = U_1 - IR$；

（4）根据降压变压器匝数比，计算用户端电压；

（5）计算输电效率 $\eta = (P - P_{\text{损}})/P$。

**定量例题**：某水电站输出功率 $P = 200\ \text{kW}$，升压后输电电压 $U_1 = 2000\ \text{V}$，线路电阻 $R = 0.5\ \Omega$，降压变压器匝数比 $n_3:n_4 = 95:1$。求：

（1）线路电流：$I = P/U_1 = 200 \times 10^3 / 2000 = 100\ \text{A}$

（2）线路损耗：$P_{\text{损}} = I^2 R = 100^2 \times 0.5 = 5000\ \text{W} = 5\ \text{kW}$

（3）降压变压器输入电压：$U_3 = U_1 - IR = 2000 - 100 \times 0.5 = 1950\ \text{V}$

（4）用户端电压：$U_4 = U_3 \times \frac{n_4}{n_3} = 1950 \times \frac{1}{95} = 20.5\ \text{V}$

（5）输电效率：$\eta = (200 - 5)/200 = 97.5\%$

若将输电电压提高至 $U_1 = 10000\ \text{V}$：

$$I = 200000/10000 = 20\ \text{A}$$

$$P_{\text{损}} = 20^2 \times 0.5 = 200\ \text{W}$$

$$U_3 = 10000 - 20 \times 0.5 = 9990\ \text{V}$$

$$U_4 = 9990/95 = 105.2\ \text{V}$$

$$\eta = (200 - 0.2)/200 = 99.9\%$$

电压提升至5倍，损耗降至原来的1/25，用户端电压显著升高，效率大幅提升。

## 六、易错警示

### 6.1 有效值不是平均值

有效值与平均值是两个完全不同的物理量，其定义、计算方法和物理意义均不相同。

**有效值**基于热效应等效定义，数学本质为均方根值（RMS）。对于正弦交流电，有效值 $I = I_m/\sqrt{2} \approx 0.707I_m$，该值恒定且不为零。

**平均值**为电流在一个周期内对时间的算术平均。对于正弦交流电，一个完整周期内的平均值为零，因为正半周与负半周对称抵消。

**常见错误**：将有效值与平均值混淆，认为正弦交流电的平均值等于有效值或 $2I_m/\pi$。实际上，$2I_m/\pi$ 是正弦交流电在半个周期内的绝对平均值（即全波整流后的平均值），而非完整周期的平均值。

**正确区分**：

| 物理量 | 定义依据 | 正弦波（完整周期） | 正弦波（半周期绝对值） |
|:---:|:---:|:---:|:---:|
| 有效值 | 热效应等效 | $I_m/\sqrt{2}$ | $I_m/\sqrt{2}$ |
| 平均值 | 算术平均 | $0$ | $2I_m/\pi$ |

计算电荷量 $q = \bar{I}t$ 时需用电流的平均值（按 $\bar{I} = N\Delta\Phi/Rt$ 计算），计算发热功率 $P = I^2 R$ 时需用有效值。

### 6.2 变压器不改变交变电流的频率

变压器仅改变交变电压和电流的大小，不改变交变电流的频率。原线圈中交变电流的频率由电源决定，副线圈中感应电动势的变化频率与原线圈相同，因此副线圈输出电流的频率等于原线圈输入电流的频率。

**错误认知**：认为升压变压器输出频率升高，降压变压器输出频率降低。实际上，对于理想变压器，$f_1 = f_2$ 恒成立。

**物理原因**：副线圈中感应电动势的产生源于原线圈产生的交变磁通，该磁通的变化频率与原线圈电流频率相同，因此副线圈感应电动势的频率也与原线圈相同。变压器只能传递已有的交变磁通变化，不能改变其频率。

### 6.3 电流比公式的适用范围

电流比公式 $I_1/I_2 = n_2/n_1$ 仅适用于只有一个副线圈的理想变压器。对于多副线圈变压器，该公式不成立。

**多副线圈变压器的正确功率关系**：

$$U_1 I_1 = U_2 I_2 + U_3 I_3 + \cdots + U_n I_n$$

原线圈电流 $I_1$ 由所有副线圈的输出功率共同决定，不能简单地与某一副线圈的电流成反比。

**常见错误**：面对多副线圈问题时，仍套用 $I_1/I_2 = n_2/n_1$，导致计算结果错误。

### 6.4 高压输电升高的是电压而非功率

高压输电的目的是在输送功率一定的前提下，通过提高电压来减小线路电流，从而降低线路损耗。输电系统不能"升高功率"，发电站输出功率是确定的。

**错误表述**："高压输电可以增大输送功率。"

**正确理解**：设线路允许的最大电流为 $I_{\max}$，线路电阻为 $R$，则最大输送功率为 $P_{\max} = U \cdot I_{\max}$。提高电压 $U$ 确实可以增大最大输送功率，但这是在受线路电流限制条件下的间接效果，高压输电的本质目的仍是降低损耗。

### 6.5 原线圈电压与电源电动势的区别

当原线圈所在电路存在电源内阻或其他串联电阻时，原线圈电压 $U_1$ 不等于电源电动势 $E$。此时：

$$U_1 = E - I_1 r$$

其中 $r$ 为电源内阻。当副线圈负载变化导致 $I_1$ 变化时，$U_1$ 也会随之变化，进而影响 $U_2$。

### 6.6 变压器副线圈接二极管的处理

当副线圈回路中串联二极管时，二极管只允许单方向电流通过，使得负载上得到的是半波整流电流。此时负载电阻上的有效值需按半波整流波形计算，即 $I = I_m/2$，而非 $I = I_m/\sqrt{2}$。

### 6.7 线圈经过中性面时的特殊性质

当线圈平面与中性面重合时：

（1）穿过线圈的磁通量最大：$\Phi = BS$；

（2）磁通量的变化率为零：$\mathrm{d}\Phi/\mathrm{d}t = 0$；

（3）感应电动势为零：$e = 0$；

（4）感应电流为零，电流方向在此刻发生改变。

当线圈平面与中性面垂直时（即线圈平面与磁场方向平行）：

（1）穿过线圈的磁通量为零：$\Phi = 0$；

（2）磁通量的变化率最大；

（3）感应电动势最大：$e = E_m$。

## 七、思想方法

### 7.1 等效思想

**有效值等效**：交流电的有效值概念是典型的等效替代思想的应用。交变电流的大小和方向随时间变化，其热效应也随时间变化。通过引入有效值这一物理量，将一个变化的交变电流等效为一个恒定的直流电流，使得二者在相同时间内通过相同电阻产生的热量相等。这种等效简化了交流电功率、热量的计算，使得交流电路的分析可以采用与直流电路相似的形式，如 $P = UI = I^2 R = U^2/R$ 中的 $U$ 和 $I$ 均使用有效值。

**变压器等效阻抗**：从原线圈两端看进去的等效输入阻抗为：

$$Z_1 = \frac{U_1}{I_1} = \frac{(n_1/n_2)U_2}{(n_2/n_1)I_2} = \left(\frac{n_1}{n_2}\right)^2 \frac{U_2}{I_2} = \left(\frac{n_1}{n_2}\right)^2 Z_{\text{负载}}$$

即副线圈负载 $Z_{\text{负载}}$ 反映到原线圈的等效阻抗为 $(n_1/n_2)^2 Z_{\text{负载}}$。变压器同时改变了电压、电流和阻抗的量值，但保持了功率不变。

### 7.2 理想模型法

理想变压器是物理学中理想模型法的典型应用。实际变压器存在多种能量损耗：

**铜损**：原、副线圈导线具有电阻，电流通过时产生焦耳热，$P_{\text{铜损}} = I_1^2 r_1 + I_2^2 r_2$。

**铁损**包括：

（1）涡流损耗：铁芯中的交变磁通感应出涡电流，产生焦耳热。采用叠片铁芯可减小涡流。

（2）磁滞损耗：铁芯材料在交变磁场中反复磁化，磁畴翻转消耗能量。

**磁漏**：并非所有磁通都同时穿过原、副线圈，漏磁通不参与能量传递。

理想模型忽略以上所有损耗和磁漏，假设铁芯磁导率无穷大，从而得到简洁的三大规律。实际变压器的效率通常在95%~99%之间，大型电力变压器效率可达99%以上。

### 7.3 能量守恒思想

能量守恒是分析变压器和输电问题的核心思想。

**变压器中的能量守恒**：理想变压器输入功率等于输出功率，$P_1 = P_2$。实际变压器中 $P_1 = P_2 + P_{\text{损}}$，能量损耗以热的形式散失。

**输电系统中的能量守恒**：发电站输出的总功率等于用户获得的功率与线路上损耗的功率之和：

$$P_{\text{总}} = P_{\text{用户}} + P_{\text{损}}$$

输电系统的设计目标是在满足用户用电需求的前提下，使 $P_{\text{损}}$ 最小化。由 $P_{\text{损}} = P^2 R/U^2$ 可知，提高输电电压是降低损耗的最有效手段。

**能量守恒在动态分析中的应用**：当副线圈负载变化时，副线圈功率变化，根据能量守恒，原线圈输入功率相应变化，原线圈电流随之调整，实现了从副线圈到原线圈的"反馈"。

### 7.4 对称性思想

正弦式交变电流的波形具有时间平移对称性。线圈在匀强磁场中匀速转动，产生的电动势为正弦函数，其正负半周对称。这一对称性导致正弦交流电在一个完整周期内的平均值为零，也是有效值计算中系数 $\sqrt{2}$ 的来源。

### 7.5 微元与积分思想

交变电流的有效值定义涉及积分运算：

$$I = \sqrt{\frac{1}{T}\int_0^T i^2(t)\,\mathrm{d}t}$$

这体现了将连续变化的过程分解为无穷多个微元，再对每个微元的贡献进行累积（积分）的数学思想。正弦函数在一个周期内的积分特性（$\int_0^T \sin^2\omega t\,\mathrm{d}t = T/2$）是有效值计算的关键。

### 7.6 控制变量法

在分析输电损耗 $P_{\text{损}} = P^2 R/U^2$ 时，需采用控制变量法：

（1）输送功率 $P$ 一定时，$P_{\text{损}} \propto 1/U^2$，提高电压可显著降低损耗；

（2）输电电压 $U$ 一定时，$P_{\text{损}} \propto P^2$，输送功率增大时损耗急剧增加；

（3）线路电阻 $R$ 由导线材料和截面积决定，$R = \rho L/S$，增大截面积可减小电阻，但增加材料成本。

实际工程中需综合考虑技术可行性与经济成本，选择最优的输电电压等级。

## 十、典型问题分析范式

### 10.1 交变电流产生问题

**分析步骤**：

（1）确定计时起点（通常取中性面为 $t = 0$）；

（2）写出磁通量随时间变化关系 $\Phi(t)$；

（3）由 $e = -N\mathrm{d}\Phi/\mathrm{d}t$ 求感应电动势；

（4）确定峰值 $E_m = NBS\omega$；

（5）写出瞬时值表达式 $e = E_m\sin\omega t$；

（6）由欧姆定律求电流瞬时值。

### 10.2 变压器问题

**分析步骤**：

（1）确认变压器为理想变压器（题目默认或明确说明）；

（2）根据电压比求副线圈电压；

（3）由副线圈负载求副线圈电流；

（4）根据功率守恒或电流比求原线圈电流；

（5）如涉及多副线圈，用 $U_1I_1 = \sum U_i I_i$。

### 10.3 远距离输电问题

**分析步骤**：

（1）明确已知量：$P$、$U_1$、$R$、变压器匝数比；

（2）计算线路电流 $I = P/U_1$；

（3）计算线路损耗 $P_{\text{损}} = I^2 R$；

（4）计算降压变压器输入电压 $U_3 = U_1 - IR$；

（5）计算用户端电压和功率；

（6）计算输电效率 $\eta$。

## 十一、补充说明

### 11.1 三相交流电简介

现代电力系统普遍采用三相交流电。三相交流发电机包含三个互成120°的线圈，产生三组频率相同、幅值相等、相位差互为120°的交变电动势：

$$e_A = E_m\sin\omega t$$
$$e_B = E_m\sin(\omega t - 120°)$$
$$e_C = E_m\sin(\omega t - 240°)$$

三相电的优势在于：

（1）输电效率更高，三相输电仅需三根导线；

（2）三相电动机结构简单、启动性能优良；

（3）三相瞬时功率为恒定值，电动机输出转矩平稳。

### 11.2 我国电力系统电压等级

我国输配电系统的标准电压等级（额定电压/kV）包括：

**输电电压**：1000（特高压）、750、500、330、220、110

**配电电压**：35、10

**用户电压**：0.38（三相动力）、0.22（单相照明）

特高压输电（1000 kV交流或 ±800 kV直流）可实现数千公里的大规模能源输送，将西部丰富的水电、风电、光电资源输送至东部负荷中心。

### 11.3 变压器与自耦变压器

自耦变压器只有一个线圈，原线圈和副线圈共用一部分绕组。其电压比和电流比关系与普通变压器相同，但结构更简单、成本更低。自耦变压器不可用作安全隔离变压器，因为原、副线圈之间存在直接的电气连接。

调压器是一种特殊的自耦变压器，通过滑动触头改变副线圈的匝数，从而连续调节输出电压。
