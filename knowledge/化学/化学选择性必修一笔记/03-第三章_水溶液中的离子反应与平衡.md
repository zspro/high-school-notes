# 第三章 水溶液中的离子反应与平衡

---

## 章节总述

本章研究水溶液中离子反应的平衡规律，核心线索为：电离平衡（弱电解质）$\rightarrow$ 水的电离平衡与pH $\rightarrow$ 盐类水解平衡 $\rightarrow$ 沉淀溶解平衡。四种平衡均服从化学平衡的一般规律（勒夏特列原理、平衡常数表征），构成水溶液中离子平衡的完整理论框架。

---

## 第一节 电离平衡

---

### 【来龙去脉】

#### 1.1 电解质理论的三次革命

**阿伦尼乌斯电离学说（1884）**

阿伦尼乌斯（S. A. Arrhenius）提出：电解质溶于水时自动离解为带电粒子（离子），溶液的导电性源于离子的定向迁移。该学说成功解释了以下事实：
- 电解质溶液的依数性异常（范特霍夫因子 $i > 1$）
- 导电性与浓度的关系
- 酸碱中和反应的实质是 $\ce{H+ + OH- -> H2O}$

**布朗斯特-劳里酸碱质子理论（1923）**

丹麦化学家布朗斯特（J. N. Brønsted）与英国化学家劳里（T. M. Lowry）独立提出：酸是质子（$\ce{H+}$）给予体，碱是质子接受体。酸碱反应的本质是质子转移：

$$\text{酸}_1 + \text{碱}_2 \rightleftharpoons \text{碱}_1 + \text{酸}_2$$

例如 $\ce{CH3COOH + H2O <=> CH3COO- + H3O+}$ 中，$\ce{CH3COOH}$ 是酸（给予质子），$\ce{H2O}$ 是碱（接受质子）。该理论将酸碱概念扩展至非水溶剂体系，并引入了**共轭酸碱对**的概念。

**路易斯酸碱电子理论（1923）**

路易斯（G. N. Lewis）提出更广义定义：酸是电子对接受体，碱是电子对给予体。该理论涵盖所有配位反应，但高中阶段主要应用阿伦尼乌斯与布朗斯特-劳里理论。

#### 1.2 为什么要研究电离平衡

- 强电解质完全电离，离子浓度可直接由化学式确定
- 弱电解质部分电离，存在电离平衡，需用平衡常数定量描述其电离程度
- 弱酸弱碱的酸性/碱性强弱比较、缓冲体系设计、滴定指示剂选择等均依赖电离平衡理论

---

### 【基础精讲】

#### 1.2 电解质与非电解质

**定义**（严格）：
- 电解质：在水溶液中或熔融状态下能够电离（产生自由移动离子）的化合物
- 非电解质：在水溶液和熔融状态下均不能电离的化合物

| 类别 | 导电条件 | 实例 |
|:---:|:---:|:---:|
| 电解质 | 水溶液或熔融态 | $\ce{NaCl}$、$\ce{HCl}$、$\ce{CH3COOH}$、$\ce{NaOH}$ |
| 非电解质 | 均不导电 | $\ce{C2H5OH}$、$\ce{CO2}$、$\ce{NH3}$、蔗糖 |

**注意**：$\ce{CO2}$、$\ce{NH3}$ 的水溶液能导电，但导电离子来自 $\ce{H2CO3}$、$\ce{NH3\cdot H2O}$ 的电离，而非 $\ce{CO2}$、$\ce{NH3}$ 本身电离，故 $\ce{CO2}$、$\ce{NH3}$ 属于非电解质。

#### 1.3 强电解质与弱电解质

**本质区别**：电离程度不同。

| | 强电解质 | 弱电解质 |
|:---:|:---:|:---:|
| 定义 | 在水溶液中**完全电离** | 在水溶液中**部分电离** |
| 电离方程式 | $\ce{NaCl = Na+ + Cl-}$ | $\ce{CH3COOH <=> CH3COO- + H+}$ |
| 溶液中微粒 | 离子（无水合分子） | 离子 + 未电离分子 |
| 实例 | 强酸、强碱、大部分盐 | 弱酸、弱碱、水 |
| 电离度 $\alpha$ | $\alpha \approx 100\%$ | $\alpha \ll 100\%$ |

**强酸**：$\ce{HCl}$、$\ce{HBr}$、$\ce{HI}$、$\ce{H2SO4}$（第一步）、$\ce{HNO3}$、$\ce{HClO4}$、$\ce{HMnO4}$

**弱酸**：$\ce{CH3COOH}$、$\ce{H2CO3}$、$\ce{H2S}$、$\ce{H2SO3}$、$\ce{H3PO4}$、$\ce{HF}$、$\ce{HClO}$、$\ce{HCN}$、$\ce{H2SiO3}$

**强碱**：$\ce{NaOH}$、$\ce{KOH}$、$\ce{Ba(OH)2}$、$\ce{Ca(OH)2}$

**弱碱**：$\ce{NH3\cdot H2O}$、$\ce{Al(OH)3}$、$\ce{Fe(OH)3}$、$\ce{Cu(OH)2}$ 等难溶性氢氧化物

#### 1.4 电离平衡

**定义**：在一定温度下，弱电解质溶于水时，分子电离成离子的速率与离子重新结合成分子的速率相等时，所建立的动态平衡。

**电离平衡的特征**（勒夏特列原理适用）：
- 逆：可逆过程 $\ce{HA <=> H+ + A-}$
- 等：$v_{\text{电离}} = v_{\text{结合}}$
- 动：动态平衡，微粒不断交换
- 定：各组分浓度恒定
- 变：条件改变时平衡移动

#### 1.5 电离平衡常数 $K_a$ / $K_b$

**一元弱酸的电离平衡常数** $K_a$：

对于电离平衡 $\ce{HA <=> H+ + A-}$，定义

$$K_a = \frac{[\ce{H+}][\ce{A-}]}{[\ce{HA}]}$$

**一元弱碱的电离平衡常数** $K_b$：

对于 $\ce{BOH <=> B+ + OH-}$（或 $\ce{B + H2O <=> BH+ + OH-}$），定义

$$K_b = \frac{[\ce{BH+}][\ce{OH-}]}{[\ce{B}]}$$

**多元弱酸的逐级电离**（以 $\ce{H2S}$ 为例）：

$$\ce{H2S <=> H+ + HS-} \quad K_{a1} = \frac{[\ce{H+}][\ce{HS-}]}{[\ce{H2S}]}$$

$$\ce{HS- <=> H+ + S^{2-}} \quad K_{a2} = \frac{[\ce{H+}][\ce{S^{2-}}]}{[\ce{HS-}]}$$

**关键性质**：$K_{a1} \gg K_{a2} \gg K_{a3} \gg \cdots$（通常 $K_{a1} / K_{a2} \sim 10^4 \sim 10^5$），因此多元弱酸的 $[\ce{H+}]$ 主要由第一步电离贡献。

**$K_a$ 的意义**：
- $K_a$ 值越大，弱酸电离程度越大，酸性越强
- $K_a$ 只与温度有关，与浓度无关（温度升高，弱电解质电离程度增大，$K_a$ 增大）
- 可通过 $K_a$ 比较酸的相对强弱：$K_a(\ce{CH3COOH}) = 1.8 \times 10^{-5} > K_a(\ce{HClO}) = 3.0 \times 10^{-8}$，故 $\ce{CH3COOH}$ 酸性强于 $\ce{HClO}$

#### 1.6 电离度 $\alpha$

**定义**：达到电离平衡时，已电离的弱电解质分子数占原有弱电解质分子总数的百分比。

$$\alpha = \frac{\text{已电离的分子数}}{\text{原有分子总数}} \times 100\% = \frac{[\ce{A-}]}{c_0} \times 100\%$$

其中 $c_0$ 为弱电解质的初始浓度。

**$\alpha$ 与 $K_a$ 的定量关系**（稀释定律，Ostwald 稀释定律）：

对于 $\ce{HA <=> H+ + A-}$，设初始浓度为 $c$，平衡时 $[\ce{H+}] = [\ce{A-}] = c\alpha$，$[\ce{HA}] = c(1-\alpha)$，则

$$K_a = \frac{(c\alpha)^2}{c(1-\alpha)} = \frac{c\alpha^2}{1-\alpha}$$

当 $\alpha \ll 1$ 时（通常 $K_a / c \leq 10^{-3}$），$1 - \alpha \approx 1$，得近似公式：

$$K_a \approx c\alpha^2 \quad \Rightarrow \quad \alpha \approx \sqrt{\frac{K_a}{c}}$$

此即**稀释定律**：一定温度下，弱电解质溶液越稀，电离度越大（但 $[\ce{H+}] = c\alpha = \sqrt{K_a c}$ 反而越小）。

---

### 【深度理解】

#### 1.7 为什么弱酸越稀释电离度越大但 $[\ce{H+}]$ 越小？

设弱酸 $\ce{HA}$ 初始浓度为 $c$，由稀释定律 $\alpha = \sqrt{K_a/c}$，当 $c$ 减小时，$\alpha$ 增大。但

$$[\ce{H+}] = c\alpha = c \cdot \sqrt{\frac{K_a}{c}} = \sqrt{K_a c}$$

当 $c$ 减小时，$\sqrt{K_a c}$ 减小，故 $[\ce{H+}]$ 减小。

**本质理解**：
- 稀释使单位体积内分子和离子总数减少，离子间碰撞结合的概率降低，平衡正向移动（勒夏特列原理：减小产物浓度，平衡向生成产物方向移动）
- 但稀释使总分子数在更大体积中分布，即使电离比例增大，单位体积内的 $[\ce{H+}]$ 仍下降
- 类比定量描述：$\alpha$ 是相对量（比例），$[\ce{H+}]$ 是绝对量（浓度），两者变化趋势可以相反

#### 1.8 弱酸溶液 $[\ce{H+}]$ 的精确计算

对于一元弱酸 $\ce{HA}$，设初始浓度为 $c$，水的电离贡献不可忽略时：

电荷守恒：$[\ce{H+}] = [\ce{A-}] + [\ce{OH-}]$

物料守恒：$c = [\ce{HA}] + [\ce{A-}]$

由 $K_a = [\ce{H+}][\ce{A-}]/[\ce{HA}]$ 和 $K_w = [\ce{H+}][\ce{OH-}]$，联立得：

$$[\ce{H+}]^3 + K_a[\ce{H+}]^2 - (K_a c + K_w)[\ce{H+}] - K_a K_w = 0$$

此为关于 $[\ce{H+}]$ 的一元三次方程。高中阶段根据条件采用以下近似：

| 条件 | 近似公式 |
|:---:|:---:|
| $c \gg [\ce{H+}] \gg [\ce{OH-}]$（一般弱酸） | $[\ce{H+}] \approx \sqrt{K_a c}$ |
| 极稀弱酸（$c$ 接近 $10^{-7}\ \mathrm{mol/L}$） | 须解三次方程或迭代 |
| 较强弱酸（$K_a \geq 10^{-3}$ 或 $c/K_a < 400$） | 用 $K_a = \frac{[\ce{H+}]^2}{c - [\ce{H+}]}$ 解二次方程 |

---

### 【知识串联】

- 电离平衡是化学平衡在水溶液中的具体应用，完全服从勒夏特列原理
- 电离平衡常数 $K_a$、$K_b$ 的表达式与平衡常数 $K$ 的定义一致
- 电离平衡的定量计算为后续pH计算、盐类水解、缓冲溶液奠定基础
- 电离理论的发展体现了科学认识的深化过程：从现象到本质、从特殊到一般

---

### 【隐性考点】

1. **同离子效应**：向弱电解质溶液中加入含有相同离子的强电解质，使弱电解质电离度减小。如在 $\ce{CH3COOH}$ 溶液中加入 $\ce{CH3COONa}$，$[\ce{CH3COO-}]$ 增大，平衡 $\ce{CH3COOH <=> CH3COO- + H+}$ 逆向移动，$\alpha$ 减小。

2. **电离度与浓度的定量关系**：$\alpha = \sqrt{K_a/c}$（稀溶液近似），考频高但教材未充分展开。

3. **多元弱酸的酸式盐酸碱性判断**：比较 $K_{a2}$ 与 $K_h = K_w/K_{a1}$ 的相对大小。如 $\ce{NaHCO3}$ 溶液中，$\ce{HCO3-}$ 的电离 $K_{a2} = 4.7 \times 10^{-11}$ 与水解 $K_h = K_w/K_{a1} = 10^{-14}/(4.3 \times 10^{-7}) = 2.3 \times 10^{-8}$，$K_h > K_{a2}$，故溶液呈碱性。

---

### 【易错警示】

1. **混淆导电性强弱与电解质强弱**：导电性取决于溶液中离子浓度和离子所带电荷数，而非仅取决于电解质强弱。极稀的强酸溶液导电性可能弱于较浓的弱酸溶液。

2. **强电解质溶液中不存在分子？**：错误。强电解质在溶液中完全电离为离子，但存在水合离子，且部分盐可能形成离子对（高中阶段不要求）。

3. **电离方程式可逆号的遗漏**：弱电解质、多元弱酸的第二步及以后电离、弱碱的电离必须使用 $\ce{<=>}$。

4. **$K_a$ 只与温度有关，但 $\alpha$ 还与浓度有关**：$K_a$ 是平衡常数，温度不变则不变；$\alpha$ 受浓度影响。

---

### 【思想方法】

**平衡移动思想**：电离平衡作为化学平衡的特例，勒夏特列原理完全适用。分析电离平衡移动时，应从改变条件 $\rightarrow$ 平衡移动方向 $\rightarrow$ 各组分浓度变化的逻辑链条进行推理。

**守恒思想**：处理电离平衡计算问题时，电荷守恒（正电荷总量 = 负电荷总量）和物料守恒（某元素的总浓度 = 各形态浓度之和）是建立方程的基础。

**定量计算思想**：由 $K_a$ 和初始浓度 $c$，通过建立平衡关系求解 $[\ce{H+}]$，体现了"平衡常数 + 守恒方程 $\rightarrow$ 精确浓度"的定量化学分析思路。

## 第二节 水的电离和溶液的pH

---

### 【来龙去脉】

#### 2.1 水的电离——被长期忽视的事实

水曾被认为不导电，是"非电解质"。精确测量技术的进步表明，纯水的电导率 $\kappa \approx 5.5 \times 10^{-6}\ \mathrm{S \cdot m^{-1}}$（$25\ ^\circ\mathrm{C}$），虽然极小但不为零，证明水存在微弱的电离：

$$\ce{H2O <=> H+ + OH-}$$

更准确写为：$\ce{2H2O <=> H3O+ + OH-}$，即水分子间的质子自递反应（autoprotolysis）。

#### 2.2 pH概念的提出

1909年，丹麦生物化学家瑟伦森（S. P. L. Sørensen）在研究啤酒酿造过程中酶活性与氢离子浓度的关系时，提出pH标度。pH的定义为：

$$\mathrm{pH} = -\lg a_{\ce{H+}}$$

其中 $a_{\ce{H+}}$ 为氢离子活度。在稀溶液中，活度近似等于浓度：$\mathrm{pH} \approx -\lg[\ce{H+}]$。

**pH标度的优势**：
- 将跨越十几个数量级的 $[\ce{H+}]$ 压缩至 $0 \sim 14$ 的范围，便于表达和比较
- 对数标度与许多生理过程、反应速率的依赖关系呈线性

**$25\ ^\circ\mathrm{C}$ 下的pH标度**：

| 溶液性质 | $[\ce{H+}]$ 与 $[\ce{OH-}]$ 关系 | pH 范围 |
|:---:|:---:|:---:|
| 酸性 | $[\ce{H+}] > [\ce{OH-}]$ | $\mathrm{pH} < 7$ |
| 中性 | $[\ce{H+}] = [\ce{OH-}]$ | $\mathrm{pH} = 7$ |
| 碱性 | $[\ce{H+}] < [\ce{OH-}]$ | $\mathrm{pH} > 7$ |

---

### 【基础精讲】

#### 2.3 水的电离平衡与离子积 $K_w$

**电离方程式**：$\ce{H2O <=> H+ + OH-}$

**水的离子积常数** $K_w$：

$$K_w = [\ce{H+}][\ce{OH-}]$$

**$K_w$ 的关键性质**：
- $K_w$ 只与温度有关（吸热过程，升温使 $K_w$ 增大）
- 在 $25\ ^\circ\mathrm{C}$ 时，$K_w = 1.0 \times 10^{-14}$
- 纯水中 $[\ce{H+}] = [\ce{OH-}] = \sqrt{K_w} = 1.0 \times 10^{-7}\ \mathrm{mol/L}$

**不同温度下的 $K_w$**：

| 温度 / $^\circ\mathrm{C}$ | $K_w$ | $[\ce{H+}]$ / $\mathrm{mol/L}$ | pH（纯水） |
|:---:|:---:|:---:|:---:|
| 0 | $1.14 \times 10^{-15}$ | $3.38 \times 10^{-8}$ | 7.47 |
| 25 | $1.00 \times 10^{-14}$ | $1.00 \times 10^{-7}$ | 7.00 |
| 50 | $5.47 \times 10^{-14}$ | $2.34 \times 10^{-7}$ | 6.63 |
| 100 | $5.13 \times 10^{-13}$ | $7.16 \times 10^{-7}$ | 6.14 |

**核心结论**：纯水中 $[\ce{H+}] = [\ce{OH-}]$ 恒成立，但 $\mathrm{pH} = 7$ 仅在 $25\ ^\circ\mathrm{C}$ 时对应中性。$100\ ^\circ\mathrm{C}$ 时纯水的 $\mathrm{pH} = 6.14$，仍为中性（因 $[\ce{H+}] = [\ce{OH-}]$）。

#### 2.4 pH 的严格定义与计算

**定义**：$\mathrm{pH} = -\lg[\ce{H+}]$（$[\ce{H+}]$ 单位为 $\mathrm{mol \cdot L^{-1}}$）

**pOH 的定义**：$\mathrm{pOH} = -\lg[\ce{OH-}]$

**$25\ ^\circ\mathrm{C}$ 时的关系**：

$$\mathrm{pH} + \mathrm{pOH} = -\lg([\ce{H+}][\ce{OH-}]) = -\lg K_w = 14$$

**pH 计算的基本类型**：

**（1）强酸溶液**

$\ce{HCl}$ 溶液：完全电离 $\ce{HCl = H+ + Cl-}$

$$[\ce{H+}] = c_0 \quad \Rightarrow \quad \mathrm{pH} = -\lg c_0$$

若 $c_0 = 0.1\ \mathrm{mol/L}$，则 $\mathrm{pH} = -\lg(0.1) = 1$。

**（2）强碱溶液**

$\ce{NaOH}$ 溶液：完全电离 $\ce{NaOH = Na+ + OH-}$

$$[\ce{OH-}] = c_0 \quad \Rightarrow \quad \mathrm{pOH} = -\lg c_0 \quad \Rightarrow \quad \mathrm{pH} = 14 - \mathrm{pOH}$$

若 $c_0 = 0.01\ \mathrm{mol/L}$，则 $\mathrm{pOH} = 2$，$\mathrm{pH} = 12$。

**（3）一元弱酸溶液**

$$\ce{HA <=> H+ + A-}$$

近似条件：$K_a \ll c$ 且 $c \gg 10^{-7}\ \mathrm{mol/L}$（水的电离可忽略）

$$[\ce{H+}] \approx \sqrt{K_a c} \quad \Rightarrow \quad \mathrm{pH} = -\frac{1}{2}\lg(K_a c) = \frac{1}{2}(\mathrm{p}K_a - \lg c)$$

其中 $\mathrm{p}K_a = -\lg K_a$。

**（4）一元弱碱溶液**

$$[\ce{OH-}] \approx \sqrt{K_b c} \quad \Rightarrow \quad \mathrm{pOH} = -\frac{1}{2}\lg(K_b c) \quad \Rightarrow \quad \mathrm{pH} = 14 - \mathrm{pOH}$$

**（5）强酸与强碱混合（过量法）**

设强酸体积 $V_a$，浓度 $c_a$；强碱体积 $V_b$，浓度 $c_b$。

- 若酸过量：$[\ce{H+}] = \frac{c_a V_a - c_b V_b}{V_a + V_b}$
- 若碱过量：$[\ce{OH-}] = \frac{c_b V_b - c_a V_a}{V_a + V_b}$

**等体积等浓度强酸强碱混合**：恰好完全中和，$\mathrm{pH} = 7$（$25\ ^\circ\mathrm{C}$）。

**（6）弱酸与强碱混合**

分三种情况讨论：

- **恰好完全反应**：生成弱酸盐，溶液呈碱性（水解所致），用盐水解计算
- **酸过量**：形成 $\ce{HA/NaA}$ 缓冲体系，用 Henderson-Hasselbalch 方程
- **碱过量**：强碱抑制弱酸电离，$[\ce{OH-}]$ 主要由过量强碱提供

#### 2.5 酸碱中和滴定

**原理**：以已知浓度的标准溶液（滴定剂）滴定待测溶液，通过计量点消耗体积计算待测液浓度。

**核心方程**：酸提供的 $\ce{H+}$ 物质的量 = 碱提供的 $\ce{OH-}$ 物质的量

$$c_{\text{酸}} V_{\text{酸}} = c_{\text{碱}} V_{\text{碱}} \quad \text{（一元酸碱）}$$

**滴定曲线**：以加入滴定剂体积为横坐标、溶液pH为纵坐标作图。

**强酸-强碱滴定曲线特征**：
- 计量点附近pH突跃范围大（如 $0.1\ \mathrm{mol/L}$ $\ce{HCl}$ 滴定 $\ce{NaOH}$，突跃范围为 $\mathrm{pH} \approx 4 \sim 10$）
- 任何在突跃范围内变色的指示剂均适用（甲基橙 $\mathrm{pH} \ 3.1 \sim 4.4$、酚酞 $\mathrm{pH} \ 8.2 \sim 10.0$）

**弱酸-强碱滴定曲线特征**：
- 计量点pH $> 7$（生成弱酸盐水解呈碱性）
- pH突跃范围偏向碱性区域
- 只能选用酚酞等碱性范围指示剂

**指示剂选择原则**：指示剂的变色范围应落在滴定曲线的pH突跃范围内。

---

### 【深度理解】

#### 2.6 缓冲溶液的原理

**定义**：能够抵抗少量酸、碱或适当稀释而保持pH基本不变的溶液。

**组成**：弱酸及其共轭碱（如 $\ce{CH3COOH}$ + $\ce{CH3COONa}$），或弱碱及其共轭酸（如 $\ce{NH3\cdot H2O}$ + $\ce{NH4Cl}$）。

** Henderson-Hasselbalch 方程推导**：

对于 $\ce{HA <=> H+ + A-}$，由 $K_a = [\ce{H+}][\ce{A-}]/[\ce{HA}]$，取负对数：

$$-\lg[\ce{H+}] = -\lg K_a - \lg\frac{[\ce{HA}]}{[\ce{A-}]}$$

$$\mathrm{pH} = \mathrm{p}K_a + \lg\frac{[\ce{A-}]}{[\ce{HA}]}$$

**缓冲机制**：
- 加少量强酸：$\ce{A- + H+ -> HA}$，$[\ce{A-}]$ 略减，$[\ce{HA}]$ 略增，$\frac{[\ce{A-}]}{[\ce{HA}]}$ 变化小，pH变化小
- 加少量强碱：$\ce{HA + OH- -> A- + H2O}$，$[\ce{HA}]$ 略减，$[\ce{A-}]$ 略增，$\frac{[\ce{A-}]}{[\ce{HA}]}$ 变化小，pH变化小
- 稀释时：$[\ce{A-}]$ 和 $[\ce{HA}]$ 同比减小，比值不变，pH不变

**缓冲容量最大条件**：当 $[\ce{A-}] = [\ce{HA}]$ 即 $\mathrm{pH} = \mathrm{p}K_a$ 时，缓冲能力最强。

#### 2.7 酸碱混合后pH的精确分析框架

设混合酸和碱，判断pH的思维路径：

1. 判断谁过量（计算 $n_{\ce{H+}}$ 与 $n_{\ce{OH-}}$ 的相对大小）
2. 若恰好完全反应：
   - 强酸 + 强碱 $\rightarrow$ $\mathrm{pH} = 7$（$25\ ^\circ\mathrm{C}$）
   - 弱酸 + 强碱 $\rightarrow$ 盐水解，溶液呈碱性
   - 强酸 + 弱碱 $\rightarrow$ 盐水解，溶液呈酸性
   - 弱酸 + 弱碱 $\rightarrow$ 比较复杂，比较 $K_a$ 与 $K_b$
3. 若酸或碱过量：按过量部分计算，注意弱酸/弱碱的电离贡献

---

### 【知识串联】

- 水的电离平衡 $K_w = [\ce{H+}][\ce{OH-}]$ 是所有水溶液pH计算的基础
- 任何水溶液中（酸性、碱性、中性），$K_w = [\ce{H+}][\ce{OH-}]$ 恒成立（温度一定）
- pH计算中常常需要判断：水的电离是否可以忽略？（一般当酸碱浓度 $\geq 10^{-6}\ \mathrm{mol/L}$ 时可忽略）
- 酸碱中和滴定的定量关系 $c_1V_1 = c_2V_2$ 是容量分析的基础
- 缓冲溶液原理在生物体液（血液pH $\approx$ 7.35 $\sim$ 7.45）维持稳定中起关键作用

---

### 【隐性考点】

1. **酸碱混合过量法的精确应用**：
   - 等体积混合时，浓度减半
   - pH = a 的强酸与 pH = b 的强碱等体积混合，若 a + b = 14，则恰好中和
   - pH = a 的强酸中 $[\ce{H+}] = 10^{-a}$；pH = b 的强碱中 $[\ce{OH-}] = 10^{b-14}$

2. **酸碱稀释规律**：
   - 强酸稀释 $10^n$ 倍，pH 增加 $n$（上限 $\leq$ 7，不可能超过7）
   - 弱酸稀释 $10^n$ 倍，pH 增加小于 $n$（稀释促进电离，$[\ce{H+}]$ 下降较慢）

3. **酸碱等体积混合后pH的快速判断**：
   - pH之和 = 14 的强酸强碱等体积混合：中性
   - pH之和 = 14 的弱酸强碱等体积混合：碱性（弱酸部分未电离，实际酸不足）
   - pH之和 = 14 的强酸弱碱等体积混合：酸性（弱碱部分未电离，实际碱不足）

4. **水的电离程度判断**：酸和碱均抑制水的电离，盐类水解促进水的电离。在 $\mathrm{pH} = 2$ 的盐酸中，水电离出的 $[\ce{H+}]_{\text{水}} = [\ce{OH-}]_{\text{水}} = 10^{-12}\ \mathrm{mol/L}$；在 $\mathrm{pH} = 2$ 的 $\ce{NH4Cl}$ 溶液中，水电离出的 $[\ce{H+}]_{\text{水}} = 10^{-2}\ \mathrm{mol/L}$。

---

### 【易错警示】

1. **$\mathrm{pH} = 7$ 不等于中性**（温度影响！）：$100\ ^\circ\mathrm{C}$ 时 $K_w = 5.13 \times 10^{-13}$，此时 $\mathrm{pH} = 6.14$ 为中性，$\mathrm{pH} = 7$ 反而呈碱性。

2. **忽略水的电离贡献**：当酸碱浓度极稀（$< 10^{-6}\ \mathrm{mol/L}$）或酸碱极弱时，水的电离贡献不可忽略。

3. **$[\ce{H+}]$ 与水电离出的 $[\ce{H+}]$ 混淆**：酸溶液中 $[\ce{H+}]$ 主要来自酸的电离，水电离出的 $[\ce{H+}] = [\ce{OH-}]_{\text{水}} = K_w/[\ce{H+}]$。

4. **pH计算中忘记混合后体积变化**：混合后总体积近似等于两溶液体积之和（稀溶液），浓度需重新计算。

---

### 【思想方法】

**守恒思想的应用**：

**电荷守恒**（任意电解质溶液恒成立）：

$$\sum_+ z_+ [\text{正离子}] = \sum_- |z_-| [\text{负离子}]$$

如 $\ce{Na2CO3}$ 溶液中：$[\ce{Na+}] + [\ce{H+}] = [\ce{HCO3-}] + 2[\ce{CO3^{2-}}] + [\ce{OH-}]$

**物料守恒**（元素守恒）：

某元素的总浓度 = 该元素以各种形态存在浓度之和。

如 $\ce{Na2CO3}$ 溶液中（$c_0$ 为初始浓度）：$[\ce{Na+}] = 2c_0 = 2([\ce{H2CO3}] + [\ce{HCO3-}] + [\ce{CO3^{2-}}])$

**质子守恒**（水的电离守恒）：

水电离出的 $[\ce{H+}]_{\text{水}} = [\ce{OH-}]_{\text{水}}$，结合电荷守恒与物料守恒推导。

如 $\ce{Na2CO3}$ 溶液中：$[\ce{OH-}] = [\ce{H+}] + [\ce{HCO3-}] + 2[\ce{H2CO3}]$

## 第三节 盐类的水解

---

### 【来龙去脉】

#### 3.1 水解现象的发现与认识

盐溶于水呈酸碱性的现象早在18世纪即被观察到。人们发现 $\ce{NH4Cl}$ 溶液呈酸性、$\ce{Na2CO3}$ 溶液呈碱性，但当时无法解释。阿伦尼乌斯电离学说提出后，才明白这些盐的离子与水发生了反应，改变了水中 $[\ce{H+}]$ 与 $[\ce{OH-}]$ 的平衡。

盐类水解的本质，是盐的离子（弱酸根或弱碱阳离子）与水电离出的 $\ce{H+}$ 或 $\ce{OH-}$ 结合，生成弱电解质，从而破坏水的电离平衡，使溶液呈酸性或碱性。

#### 3.2 为什么某些盐溶液呈酸/碱性

以 $\ce{CH3COONa}$ 为例：

$\ce{CH3COONa}$ 完全电离：$\ce{CH3COONa = CH3COO- + Na+}$

$\ce{CH3COO-}$ 与水电离的 $\ce{H+}$ 结合：$\ce{CH3COO- + H2O <=> CH3COOH + OH-}$

结果：$[\ce{OH-}] > [\ce{H+}]$，溶液呈碱性。

---

### 【基础精讲】

#### 3.2 盐类水解的本质

**严格定义**：盐溶于水时，盐的离子与水电离出的 $\ce{H+}$ 或 $\ce{OH-}$ 结合生成弱电解质（弱酸或弱碱）的反应。

**水解发生的条件**（必须同时满足）：
1. 盐溶于水
2. 盐的离子能与 $\ce{H+}$ 或 $\ce{OH-}$ 结合生成弱电解质

**四类盐的水解规律**：

| 盐的类型 | 组成特点 | 水解情况 | 溶液酸碱性 | 实例 |
|:---:|:---:|:---:|:---:|:---:|
| 强酸强碱盐 | 强酸根 + 强碱阳离子 | 不水解 | 中性 | $\ce{NaCl}$、$\ce{KNO3}$、$\ce{BaCl2}$ |
| 强酸弱碱盐 | 强酸根 + 弱碱阳离子 | 阳离子水解 | 酸性 | $\ce{NH4Cl}$、$\ce{Al2(SO4)3}$、$\ce{FeCl3}$ |
| 弱酸强碱盐 | 弱酸根 + 强碱阳离子 | 阴离子水解 | 碱性 | $\ce{CH3COONa}$、$\ce{Na2CO3}$、$\ce{NaCN}$ |
| 弱酸弱碱盐 | 弱酸根 + 弱碱阳离子 | 双水解 | 视 $K_a$、$K_b$ 相对大小 | $\ce{CH3COONH4}$、$\ce{NH4F}$ |

**水解方程式的书写**：

- 用 $\ce{<=>}$（可逆号），不用 $\ce{=}$
- 一般只写一步（多元弱酸根分步水解，以第一步为主）
- 不标气体符号 $\uparrow$ 或沉淀符号 $\downarrow$（水解程度通常很小）

**示例**：

$$\ce{CH3COO- + H2O <=> CH3COOH + OH-}$$

$$\ce{NH4+ + H2O <=> NH3\cdot H2O + H+}$$

$$\ce{CO3^{2-} + H2O <=> HCO3- + OH-} \quad \text{（第一步，主要）}$$

$$\ce{HCO3- + H2O <=> H2CO3 + OH-} \quad \text{（第二步，次要）}$$

#### 3.3 水解常数 $K_h$

**定义**：盐类水解反应的平衡常数。

**一元弱酸强碱盐（如 $\ce{CH3COONa}$）**：

水解反应：$\ce{A- + H2O <=> HA + OH-}$

$$K_h = \frac{[\ce{HA}][\ce{OH-}]}{[\ce{A-}]}$$

**$K_h$ 与 $K_a$、$K_w$ 的关系推导**：

$$K_h = \frac{[\ce{HA}][\ce{OH-}]}{[\ce{A-}]} = \frac{[\ce{HA}][\ce{OH-}][\ce{H+}]}{[\ce{A-}][\ce{H+}]} = \frac{K_w}{K_a}$$

即：$K_h = \dfrac{K_w}{K_a}$

**一元弱碱强酸盐（如 $\ce{NH4Cl}$）**：

$$K_h = \frac{K_w}{K_b}$$

**多元弱酸根的水解常数**：

对于 $\ce{CO3^{2-}}$：

$$K_{h1} = \frac{K_w}{K_{a2}} = \frac{10^{-14}}{4.7 \times 10^{-11}} = 2.1 \times 10^{-4}$$

$$K_{h2} = \frac{K_w}{K_{a1}} = \frac{10^{-14}}{4.3 \times 10^{-7}} = 2.3 \times 10^{-8}$$

由于 $K_{h1} \gg K_{h2}$，故 $\ce{CO3^{2-}}$ 溶液的碱性主要由第一步水解决定。

**弱酸弱碱盐的双水解**（以 $\ce{CH3COONH4}$ 为例）：

$$\ce{CH3COO- + NH4+ + H2O <=> CH3COOH + NH3\cdot H2O}$$

$$K_h = \frac{K_w}{K_a \cdot K_b} \cdot K_w = \frac{K_w}{K_a(\ce{CH3COOH}) \cdot K_b(\ce{NH3})}$$

$\ce{CH3COONH4}$ 溶液的酸碱性取决于 $K_a(\ce{CH3COOH}) = 1.8 \times 10^{-5}$ 与 $K_b(\ce{NH3}) = 1.8 \times 10^{-5}$ 的相对大小。因 $K_a \approx K_b$，溶液近似中性。

#### 3.4 影响水解平衡的因素

| 影响因素 | 变化方向 | 水解程度变化 | 溶液酸碱性变化 |
|:---:|:---:|:---:|:---:|
| 升温 | 水解平衡正向移动 | 增大（水解吸热） | 增强 |
| 稀释 | 水解平衡正向移动 | 增大（稀释促进水解） | 减弱（$[\ce{H+}]$ 或 $[\ce{OH-}]$ 减小） |
| 加酸 | 对阴离子水解：抑制；对阳离子水解：促进 | 视情况而定 | 视情况而定 |
| 加碱 | 对阳离子水解：抑制；对阴离子水解：促进 | 视情况而定 | 视情况而定 |
| 加入含相同离子的盐 | 同离子效应，抑制水解 | 减小 | 减弱 |

#### 3.5 水解的应用

**（1）判断溶液酸碱性**：如 $\ce{NaCN}$ 溶液呈碱性（$\ce{CN-}$ 水解），$\ce{CuSO4}$ 溶液呈酸性（$\ce{Cu^{2+}}$ 水解）。

**（2）盐溶液的配制**：配制 $\ce{FeCl3}$ 溶液时，先将 $\ce{FeCl3}$ 溶于浓盐酸抑制水解，再加水稀释。因 $\ce{Fe^{3+} + 3H2O <=> Fe(OH)3 + 3H+}$，加酸平衡逆向移动。

**（3）胶体的制备**：$\ce{FeCl3 + 3H2O \xrightarrow{\Delta} Fe(OH)3(胶体) + 3HCl}$

**（4）泡沫灭火器原理**：$\ce{Al2(SO4)3}$ 与 $\ce{NaHCO3}$ 溶液混合，$\ce{Al^{3+}}$ 与 $\ce{HCO3-}$ 发生双水解：

$$\ce{Al^{3+} + 3HCO3- = Al(OH)3 \downarrow + 3CO2 \uparrow}$$

**（5）纯碱去油污**：$\ce{CO3^{2-} + H2O <=> HCO3- + OH-}$，升温促进水解，$[\ce{OH-}]$ 增大，油脂在碱性条件下水解为可溶物质。

**（6）离子共存问题**：能发生双水解且趋于完全的离子不能大量共存。如 $\ce{Al^{3+}}$ 与 $\ce{CO3^{2-}}$、$\ce{HCO3-}$、$\ce{S^{2-}}$、$\ce{HS-}$、$\ce{AlO2-}$ 等。

---

### 【深度理解】

#### 3.6 水解促进水电离的分析

以 $\ce{CH3COONa}$ 溶液为例：

纯水：$\ce{H2O <=> H+ + OH-}$，$[\ce{H+}] = [\ce{OH-}] = 10^{-7}\ \mathrm{mol/L}$（$25\ ^\circ\mathrm{C}$）

加入 $\ce{CH3COO-}$ 后：$\ce{CH3COO- + H2O <=> CH3COOH + OH-}$

$\ce{CH3COO-}$ 消耗水电离出的 $\ce{H+}$，使水的电离平衡正向移动。结果：

- 水电离出的 $[\ce{OH-}]_{\text{水}}$ 增大（$> 10^{-7}\ \mathrm{mol/L}$）
- 水电离出的 $[\ce{H+}]_{\text{水}}$ 也增大，但大部分 $\ce{H+}$ 被 $\ce{CH3COO-}$ 结合，游离 $[\ce{H+}]$ 减小

**定量关系**：在 $\ce{CH3COONa}$ 溶液中，$[\ce{OH-}] = [\ce{OH-}]_{\text{水}} = [\ce{H+}]_{\text{水}}$（水电离出的 $\ce{H+}$ 一部分被消耗，一部分以游离态存在）。

#### 3.7 盐类水解与电离的辨析

| | 盐类水解 | 弱电解质电离 |
|:---:|:---:|:---:|
| 研究对象 | 盐（强电解质）的离子 | 弱酸、弱碱、水 |
| 反应实质 | 离子与水电离的 $\ce{H+}$ 或 $\ce{OH-}$ 结合 | 分子电离为离子 |
| 方程式方向 | 盐离子 + 水 $\rightarrow$ 弱电解质 + $\ce{OH-}$/$\ce{H+}$ | 分子 $\rightarrow$ 离子 |
| 对水的电离 | 促进 | 弱酸/弱碱抑制水的电离 |

**特别注意**：盐类水解方程式中，水是反应物，不是溶剂（虽然同时也是溶剂）。

#### 3.8 酸式盐溶液酸碱性的严格判据

对于酸式盐 $\ce{NaHA}$（$\ce{H2A}$ 为二元弱酸），$\ce{HA-}$ 在水溶液中存在两种竞争反应：

**电离**：$\ce{HA- <=> H+ + A^{2-}}$，$K_{a2}$

**水解**：$\ce{HA- + H2O <=> H2A + OH-}$，$K_h = K_w/K_{a1}$

| 条件 | 溶液酸碱性 | 实例 |
|:---:|:---:|:---:|
| $K_{a2} > K_w/K_{a1}$ | 酸性（电离为主） | $\ce{NaHSO3}$、$\ce{NaH2PO4}$ |
| $K_{a2} < K_w/K_{a1}$ | 碱性（水解为主） | $\ce{NaHCO3}$、$\ce{NaHS}$、$\ce{Na2HPO4}$ |

**实例分析**：$\ce{NaHCO3}$

$K_{a2}(\ce{H2CO3}) = 4.7 \times 10^{-11}$，$K_w/K_{a1} = 10^{-14}/(4.3 \times 10^{-7}) = 2.3 \times 10^{-8}$

$K_{a2} = 4.7 \times 10^{-11} < 2.3 \times 10^{-8} = K_w/K_{a1}$，故 $\ce{NaHCO3}$ 溶液呈碱性。

---

### 【知识串联】

- 盐类水解是电离平衡的延伸应用：弱酸根/弱碱阳离子与水电离产物结合，生成弱电解质，破坏水的电离平衡
- 水解平衡常数 $K_h = K_w/K_a$（或 $K_w/K_b$）的推导体现了平衡常数之间的关系
- 盐类水解与沉淀溶解平衡的关系：某些离子水解生成氢氧化物沉淀（如 $\ce{Fe^{3+}}$、$\ce{Al^{3+}}$ 的净水原理）
- 盐类水解与酸碱中和滴定的联系：弱酸弱碱盐滴定终点pH偏离7，影响指示剂选择

---

### 【隐性考点】

1. **盐溶液中水电离程度的比较**：
   - 酸/碱溶液抑制水的电离：$\mathrm{pH} = 2$ 的盐酸中，水电离的 $[\ce{H+}]_{\text{水}} = 10^{-12}\ \mathrm{mol/L}$
   - 水解盐促进水的电离：$\mathrm{pH} = 2$ 的 $\ce{FeCl3}$ 溶液中，水电离的 $[\ce{H+}]_{\text{水}} = 10^{-2}\ \mathrm{mol/L}$
   - 盐溶液的 $\mathrm{pH} = a$，则水电离的 $[\ce{H+}]_{\text{水}} = 10^{-a}$（酸性盐）或 $10^{a-14}$（碱性盐）

2. **离子浓度大小比较**：
   - $\ce{CH3COONa}$ 溶液中：$[\ce{Na+}] > [\ce{CH3COO-}] > [\ce{OH-}] > [\ce{H+}]$
   - 原因：$\ce{CH3COO-}$ 部分水解，浓度略小于 $\ce{Na+}$
   - 利用电荷守恒验证：$[\ce{Na+}] + [\ce{H+}] = [\ce{CH3COO-}] + [\ce{OH-}]$

3. **三种守恒关系的综合应用**：
   - 电荷守恒：溶液呈电中性
   - 物料守恒：元素总量守恒
   - 质子守恒：水电离的 $\ce{H+}$ 与 $\ce{OH-}$ 数量相等

4. **双水解完全与不完全的区分**：
   - 双水解完全：如 $\ce{Al^{3+}}$ 与 $\ce{HCO3-}$、$\ce{CO3^{2-}}$、$\ce{AlO2-}$，写 $\ce{=}$，标 $\downarrow$ 和 $\uparrow$
   - 双水解不完全：如 $\ce{CH3COONH4}$，仍写 $\ce{<=>}$

---

### 【易错警示】

1. **盐类水解方程式用可逆号 $\ce{<=>}$**：不能用 $\ce{=}$（水解是可逆的、微弱的），但双水解趋于完全的例外。

2. **不标沉淀和气体符号**：一般水解程度很小，不生成沉淀和气体（双水解完全的除外）。

3. **多元弱酸根分步水解**：$\ce{CO3^{2-}}$ 水解分两步，第一步远大于第二步。写方程式时应注明分步，或只写第一步。

4. **误认为强酸强碱盐一定不水解，溶液一定中性**：正确。强酸强碱盐的离子不与 $\ce{H+}$ 或 $\ce{OH-}$ 结合，不影响水的电离平衡。

5. **$K_h$ 只与温度有关**：水解常数与平衡常数一样，只受温度影响，与盐溶液浓度无关。

6. **盐类水解促进水电离，但溶液不一定呈中性**：水解使水电离程度增大，但生成的 $\ce{H+}$ 或 $\ce{OH-}$ 使溶液呈酸性或碱性。

---

### 【思想方法】

**守恒思想（三种守恒的综合应用）**：

以 $\ce{Na2CO3}$ 溶液为例（初始浓度 $c_0$）：

**电荷守恒**：

$$[\ce{Na+}] + [\ce{H+}] = [\ce{HCO3-}] + 2[\ce{CO3^{2-}}] + [\ce{OH-}]$$

**物料守恒**：

$$[\ce{Na+}] = 2c_0 = 2([\ce{H2CO3}] + [\ce{HCO3-}] + [\ce{CO3^{2-}}])$$

**质子守恒**（由电荷守恒减去物料守恒消去 $[\ce{Na+}]$）：

$$[\ce{OH-}] = [\ce{H+}] + [\ce{HCO3-}] + 2[\ce{H2CO3}]$$

**意义**：质子守恒表达了水电离的 $\ce{OH-}$ 的去向——一部分以游离态存在，一部分与 $\ce{CO3^{2-}}$ 结合生成 $\ce{HCO3-}$，一部分与 $\ce{CO3^{2-}}$ 结合生成 $\ce{H2CO3}$（每生成1个 $\ce{H2CO3}$ 消耗2个 $\ce{H+}$）。

## 第四节 沉淀溶解平衡

---

### 【来龙去脉】

#### 4.1 沉淀溶解平衡的认识历程

19世纪末至20世纪初，分析化学家发现：在定性分析中，通过控制沉淀剂浓度和溶液条件，可实现离子的选择性沉淀与分离。这一实践需求推动了沉淀溶解平衡理论的建立。

1889年，能斯特（W. Nernst）提出溶度积原理，将化学平衡理论推广至固液平衡体系。1923年，溶度积规则被系统化表述为：当离子积 $Q_c > K_{sp}$ 时生成沉淀，$Q_c = K_{sp}$ 时达平衡，$Q_c < K_{sp}$ 时沉淀溶解。

**沉淀溶解平衡在分析化学中的应用**：
- **定性分析**：经典阳离子分组分析（硫化氢系统、碳酸铵系统），依据各硫化物、氢氧化物 $K_{sp}$ 差异实现离子分离
- **定量分析**：重量分析法（通过沉淀完全后称量确定含量）
- **沉淀滴定**：如银量法（莫尔法、佛尔哈德法）测定 $\ce{Cl-}$、$\ce{Br-}$、$\ce{I-}$
- **工业生产**：水垢去除、废水处理、矿物浮选

#### 4.2 沉淀并非绝对不溶

实验事实表明：向 $\ce{AgNO3}$ 溶液中加入 $\ce{NaCl}$ 生成 $\ce{AgCl}$ 白色沉淀后，上层清液中仍存在少量 $\ce{Ag+}$（可用 $\ce{Na2S}$ 检验：加入后生成黑色 $\ce{Ag2S}$ 沉淀）。这说明 $\ce{AgCl}$ 在水中存在微弱的溶解，建立了沉淀与离子之间的动态平衡。

---

### 【基础精讲】

#### 4.2 沉淀溶解平衡的建立

**定义**：在一定温度下，当难溶电解质溶于水时，沉淀溶解的速率与溶液中离子重新结合成沉淀的速率相等时，所建立的动态平衡。

$$\ce{AgCl(s) <=> Ag+(aq) + Cl-(aq)}$$

**溶解平衡的特征**：
- 逆：溶解与沉淀是可逆过程
- 等：$v_{\text{溶解}} = v_{\text{沉淀}}$
- 动：动态平衡，固体表面不断有离子溶解和沉淀
- 定：饱和溶液中离子浓度恒定
- 变：改变条件（温度、浓度等），平衡移动

#### 4.3 溶度积 $K_{sp}$ 的定义

**定义**：在一定温度下，难溶电解质饱和溶液中各离子浓度幂的乘积为一常数，称为溶度积常数（solubility product constant），记为 $K_{sp}$。

对于一般难溶电解质 $\ce{A_mB_n(s) <=> mA^{n+}(aq) + nB^{m-}(aq)}$：

$$K_{sp} = [\ce{A^{n+}}]^m \cdot [\ce{B^{m-}}]^n$$

**常见难溶电解质的 $K_{sp}$（$25\ ^\circ\mathrm{C}$）**：

| 难溶电解质 | $K_{sp}$ | 难溶电解质 | $K_{sp}$ |
|:---:|:---:|:---:|:---:|
| $\ce{AgCl}$ | $1.8 \times 10^{-10}$ | $\ce{AgBr}$ | $5.0 \times 10^{-13}$ |
| $\ce{AgI}$ | $8.3 \times 10^{-17}$ | $\ce{Ag2S}$ | $6.3 \times 10^{-50}$ |
| $\ce{BaSO4}$ | $1.1 \times 10^{-10}$ | $\ce{CaCO3}$ | $2.8 \times 10^{-9}$ |
| $\ce{CaSO4}$ | $4.9 \times 10^{-5}$ | $\ce{Fe(OH)3}$ | $2.6 \times 10^{-39}$ |
| $\ce{Mg(OH)2}$ | $5.6 \times 10^{-12}$ | $\ce{Cu(OH)2}$ | $2.2 \times 10^{-20}$ |
| $\ce{Al(OH)3}$ | $1.3 \times 10^{-33}$ | $\ce{ZnS}$ | $1.6 \times 10^{-24}$ |

**$K_{sp}$ 的性质**：
- $K_{sp}$ 只与温度和难溶电解质本性有关，与溶液中离子浓度无关
- 属于平衡常数，服从化学平衡的一般规律
- 反映难溶电解质的溶解能力：$K_{sp}$ 越大，溶解度通常越大（同类型比较）

#### 4.4 溶度积规则（判断沉淀生成/溶解/平衡的准则）

定义离子积 $Q_c$（反应商）：

$$Q_c = [\ce{A^{n+}}]^m \cdot [\ce{B^{m-}}]^n$$

其中离子浓度为任意状态下的浓度（不一定是平衡浓度）。

| 关系 | 平衡移动方向 | 现象 |
|:---:|:---:|:---:|
| $Q_c > K_{sp}$ | 平衡逆向移动 | 生成沉淀 |
| $Q_c = K_{sp}$ | 平衡状态 | 饱和溶液，动态平衡 |
| $Q_c < K_{sp}$ | 平衡正向移动 | 沉淀溶解（或不生成沉淀） |

#### 4.5 $K_{sp}$ 与溶解度 $S$ 的换算

设难溶电解质 $\ce{A_mB_n}$ 的溶解度为 $S\ \mathrm{mol/L}$，则：

$$[\ce{A^{n+}}] = mS, \quad [\ce{B^{m-}}] = nS$$

$$K_{sp} = (mS)^m \cdot (nS)^n = m^m \cdot n^n \cdot S^{m+n}$$

**特殊类型**：

- **AB 型**（$m = n = 1$，如 $\ce{AgCl}$、$\ce{BaSO4}$）：

$$K_{sp} = S^2 \quad \Rightarrow \quad S = \sqrt{K_{sp}}$$

- **AB$_2$ 或 A$_2$B 型**（如 $\ce{Mg(OH)2}$、$\ce{Ag2CrO4}$）：

$$K_{sp} = 4S^3 \quad \Rightarrow \quad S = \sqrt[3]{\frac{K_{sp}}{4}}$$

- **AB$_3$ 或 A$_3$B 型**（如 $\ce{Fe(OH)3}$）：

$$K_{sp} = 27S^4 \quad \Rightarrow \quad S = \sqrt[4]{\frac{K_{sp}}{27}}$$

**注意**：不同类型（$\ce{A_mB_n}$ 中 $m$、$n$ 不同）的难溶电解质，不能直接用 $K_{sp}$ 比较溶解度大小，必须通过上式换算为 $S$ 后比较。

#### 4.6 影响沉淀溶解平衡的因素

| 影响因素 | 变化规律 | 本质 |
|:---:|:---:|:---:|
| 温度 | 多数难溶电解质升温溶解度增大（$K_{sp}$ 增大），少数相反 | 溶解过程的热效应 |
| 同离子效应 | 加入含相同离子的强电解质，溶解度减小 | 平衡逆向移动 |
| 盐效应 | 加入不含相同离子的强电解质，溶解度略有增大 | 离子活度减小（离子强度增大） |
| 酸效应 | 对于弱酸盐/弱碱盐沉淀，加酸使溶解度增大 | $\ce{H+}$ 与弱酸根结合，降低 $[\ce{A^{n-}}]$ |
| 配位效应 | 形成配合物使溶解度增大 | 金属离子被配位，降低游离 $[\ce{M^{n+}}]$ |

**同离子效应的定量计算**：

设 $\ce{AgCl}$ 在 $0.01\ \mathrm{mol/L}$ $\ce{NaCl}$ 溶液中的溶解度为 $S$，则：

$$[\ce{Ag+}] = S, \quad [\ce{Cl-}] = 0.01 + S \approx 0.01$$

$$K_{sp} = [\ce{Ag+}][\ce{Cl-}] = S \times 0.01 = 1.8 \times 10^{-10}$$

$$S = 1.8 \times 10^{-8}\ \mathrm{mol/L}$$

对比纯水中 $S = \sqrt{1.8 \times 10^{-10}} = 1.34 \times 10^{-5}\ \mathrm{mol/L}$，同离子效应使溶解度减小了约 $750$ 倍。

### 【深度理解】

#### 4.7 沉淀的生成

**（1）加沉淀剂法**

通过加入含目标离子的沉淀剂，使 $Q_c > K_{sp}$，从而生成沉淀。

**沉淀完全的标准**：在定性分析中，通常认为某离子浓度 $\leq 10^{-5}\ \mathrm{mol/L}$（定量分析中要求 $\leq 10^{-6}\ \mathrm{mol/L}$）即为沉淀完全。

**（2）调节pH法**

对于氢氧化物或弱酸盐沉淀，通过调节pH控制沉淀生成。

**实例**：$\ce{Fe^{3+}}$ 开始沉淀和完全沉淀的pH计算

$$\ce{Fe(OH)3(s) <=> Fe^{3+}(aq) + 3OH-(aq)}$$

$$K_{sp} = [\ce{Fe^{3+}}][\ce{OH-}]^3 = 2.6 \times 10^{-39}$$

当 $[\ce{Fe^{3+}}] = 0.01\ \mathrm{mol/L}$ 时，开始沉淀所需 $[\ce{OH-}]$：

$$[\ce{OH-}] = \sqrt[3]{\frac{2.6 \times 10^{-39}}{0.01}} = \sqrt[3]{2.6 \times 10^{-37}} = 6.4 \times 10^{-13}\ \mathrm{mol/L}$$

$$\mathrm{pOH} = 12.19 \quad \Rightarrow \quad \mathrm{pH} = 14 - 12.19 = 1.81$$

当 $[\ce{Fe^{3+}}] = 10^{-5}\ \mathrm{mol/L}$ 时（沉淀完全）：

$$[\ce{OH-}] = \sqrt[3]{\frac{2.6 \times 10^{-39}}{10^{-5}}} = \sqrt[3]{2.6 \times 10^{-34}} = 6.4 \times 10^{-12}\ \mathrm{mol/L}$$

$$\mathrm{pOH} = 11.19 \quad \Rightarrow \quad \mathrm{pH} = 14 - 11.19 = 2.81$$

结论：$\ce{Fe^{3+}}$ 在 $\mathrm{pH} \approx 1.81$ 开始沉淀，$\mathrm{pH} \approx 2.81$ 沉淀完全。

#### 4.8 沉淀的溶解

使 $Q_c < K_{sp}$，沉淀溶解。常用方法：

**（1）加酸溶解**（适用于弱酸盐、氢氧化物等）

$$\ce{CaCO3(s) <=> Ca^{2+} + CO3^{2-}}$$

$$\ce{CO3^{2-} + 2H+ -> H2O + CO2 \uparrow}$$

$[\ce{CO3^{2-}}]$ 降低，$Q_c < K_{sp}$，平衡正向移动，沉淀溶解。

**（2）加氧化剂/还原剂溶解**

$$\ce{3CuS + 8HNO3(稀) -> 3Cu(NO3)2 + 3S \downarrow + 2NO \uparrow + 4H2O}$$

$\ce{S^{2-}}$ 被氧化为 $\ce{S}$，$[\ce{S^{2-}}]$ 急剧降低，使 $Q_c < K_{sp}$。

**（3）配位溶解**

$$\ce{AgCl(s) + 2NH3 -> [Ag(NH3)2]+ + Cl-}$$

$[\ce{Ag+}]$ 因配位而降低，使 $Q_c < K_{sp}$。

#### 4.9 沉淀的转化

**定义**：由一种难溶电解质转化为另一种更难溶电解质的过程。

**原理**：向含某沉淀的体系中加入含另一种阴/阳离子的溶液，若新沉淀的 $K_{sp}$ 更小，则原沉淀转化为新沉淀。

**方向判据**：沉淀转化的方向是从 $K_{sp}$ 较大的沉淀向 $K_{sp}$ 较小的沉淀进行（同类型时）。

**转化反应方程式**（以 $\ce{AgCl -> AgBr -> AgI -> Ag2S}$ 为例）：

$$\ce{AgCl(s) + Br- <=> AgBr(s) + Cl-}$$

$$K = \frac{[\ce{Cl-}]}{[\ce{Br-}]} = \frac{K_{sp}(\ce{AgCl})}{K_{sp}(\ce{AgBr})} = \frac{1.8 \times 10^{-10}}{5.0 \times 10^{-13}} = 360 \gg 1$$

平衡常数 $K \gg 1$，反应正向进行程度很大，转化容易实现。

$$\ce{2AgI(s) + S^{2-} <=> Ag2S(s) + 2I-}$$

$$K = \frac{[\ce{I-}]^2}{[\ce{S^{2-}}]} = \frac{[K_{sp}(\ce{AgI})]^2}{K_{sp}(\ce{Ag2S})} = \frac{(8.3 \times 10^{-17})^2}{6.3 \times 10^{-50}} = \frac{6.9 \times 10^{-33}}{6.3 \times 10^{-50}} = 1.1 \times 10^{17}$$

$K$ 极大，转化完全。

**不同类型沉淀转化的注意**：$K_{sp}(\ce{Ag2CrO4}) = 1.1 \times 10^{-12}$，$K_{sp}(\ce{AgCl}) = 1.8 \times 10^{-10}$，虽然 $K_{sp}(\ce{Ag2CrO4}) < K_{sp}(\ce{AgCl})$，但 $\ce{Ag2CrO4}$ 含2个 $\ce{Ag+}$，不能直接比较。须计算转化反应的平衡常数判断方向。

$$\ce{2AgCl(s) + CrO4^{2-} <=> Ag2CrO4(s) + 2Cl-}$$

$$K = \frac{[\ce{Cl-}]^2}{[\ce{CrO4^{2-}}]} = \frac{[K_{sp}(\ce{AgCl})]^2}{K_{sp}(\ce{Ag2CrO4})} = \frac{(1.8 \times 10^{-10})^2}{1.1 \times 10^{-12}} = \frac{3.24 \times 10^{-20}}{1.1 \times 10^{-12}} = 2.9 \times 10^{-8} \ll 1$$

$K \ll 1$，说明 $\ce{AgCl}$ 不能转化为 $\ce{Ag2CrO4}$，实际上转化方向是 $\ce{Ag2CrO4 -> AgCl}$。

---

### 【知识串联】

- 沉淀溶解平衡是化学平衡理论在固液多相体系中的应用
- 溶度积 $K_{sp}$ 与电离平衡常数 $K_a$、$K_b$、$K_w$ 同属平衡常数，具有相似的数学形式和物理意义
- 沉淀溶解平衡与酸碱平衡的联系：酸效应（加酸使弱酸盐/氢氧化物溶解）、同离子效应
- 沉淀溶解平衡与配位平衡的联系：配位效应（形成配合物促进溶解）
- 与氧化还原反应的联系：通过氧化还原改变离子浓度，使 $Q_c < K_{sp}$（如 $\ce{CuS}$ 溶于硝酸）
- 工业生产应用：锅炉除垢（$\ce{CaSO4 -> CaCO3 -> Ca^{2+}}$）、废水处理、矿物加工

---

### 【隐性考点】

1. **$K_{sp}$ 与溶解度的换算及不同类型沉淀的比较**：
   - $\ce{AgCl}$（AB型）：$S = \sqrt{1.8 \times 10^{-10}} = 1.34 \times 10^{-5}\ \mathrm{mol/L}$
   - $\ce{Ag2CrO4}$（A$_2$B型）：$S = \sqrt[3]{1.1 \times 10^{-12}/4} = 6.5 \times 10^{-5}\ \mathrm{mol/L}$
   - 虽然 $K_{sp}(\ce{AgCl}) > K_{sp}(\ce{Ag2CrO4})$，但 $S(\ce{AgCl}) < S(\ce{Ag2CrO4})$
   - **结论**：不同类型沉淀不能直接由 $K_{sp}$ 比较溶解度

2. **沉淀顺序判断**：
   - 向含 $\ce{Cl-}$ 和 $\ce{I-}$ 的混合溶液中逐滴加入 $\ce{AgNO3}$，谁先沉淀？
   - $\ce{AgI}$ 的 $K_{sp} = 8.3 \times 10^{-17} < K_{sp}(\ce{AgCl}) = 1.8 \times 10^{-10}$
   - $\ce{AgI}$ 先沉淀（$K_{sp}$ 小的先沉淀，同类型时）
   - 当 $\ce{AgCl}$ 开始沉淀时，$[\ce{Ag+}] = K_{sp}(\ce{AgCl})/[\ce{Cl-}]$
   - 此时溶液中 $[\ce{I-}] = K_{sp}(\ce{AgI})/[\ce{Ag+}] = K_{sp}(\ce{AgI}) \cdot [\ce{Cl-}]/K_{sp}(\ce{AgCl})$

3. **分步沉淀（选择性沉淀）**：
   - 工业上利用 $K_{sp}$ 差异分离金属离子
   - 如某溶液含 $\ce{Fe^{3+}}$（$0.01\ \mathrm{mol/L}$）和 $\ce{Cu^{2+}}$（$0.01\ \mathrm{mol/L}$）
   - $\ce{Fe(OH)3}$ 开始沉淀：$\mathrm{pH} = 1.81$（见前文计算）
   - $\ce{Cu(OH)2}$ 开始沉淀：$[\ce{OH-}] = \sqrt{2.2 \times 10^{-20}/0.01} = 4.7 \times 10^{-10}$，$\mathrm{pOH} = 9.33$，$\mathrm{pH} = 4.67$
   - 调节 $\mathrm{pH}$ 至 $2.8 \sim 4.5$，可使 $\ce{Fe^{3+}}$ 完全沉淀而 $\ce{Cu^{2+}}$ 不沉淀

4. **沉淀完全的条件控制**：
   - 一般认为残留离子浓度 $\leq 10^{-5}\ \mathrm{mol/L}$ 即为沉淀完全
   - 实际应用中，利用同离子效应（加入过量沉淀剂）使沉淀更完全
   - 过量沉淀剂一般在 $20\% \sim 50\%$

---

### 【易错警示】

1. **$K_{sp}$ 比较只适用于同类型沉淀**：
   - AB型与A$_2$B型不能直接比较溶解度
   - 例：$K_{sp}(\ce{AgCl}) = 1.8 \times 10^{-10} > K_{sp}(\ce{Ag2CrO4}) = 1.1 \times 10^{-12}$
   - 但 $S(\ce{AgCl}) = 1.34 \times 10^{-5}\ \mathrm{mol/L} < S(\ce{Ag2CrO4}) = 6.5 \times 10^{-5}\ \mathrm{mol/L}$

2. **饱和溶液中离子浓度不一定相等**：
   - $\ce{AgCl}$ 饱和溶液中 $[\ce{Ag+}] = [\ce{Cl-}]$
   - $\ce{Ag2SO4}$ 饱和溶液中 $[\ce{Ag+}] = 2[\ce{SO4^{2-}}]$（不是相等！）

3. **$K_{sp}$ 小的沉淀一定能转化为 $K_{sp}$ 大的沉淀？**：不一定。不同类型沉淀需要通过计算转化反应的平衡常数判断。

4. **忽略溶解平衡的可逆性**：沉淀溶解平衡是动态平衡，溶解和沉淀同时进行。加入固体不影响平衡（固体浓度视为常数）。

5. **溶度积只适用于饱和溶液**：不饱和溶液中没有沉淀溶解平衡，不能用 $K_{sp}$ 直接计算离子浓度。

6. **沉淀完全的判断**：一般离子浓度 $\leq 10^{-5}\ \mathrm{mol/L}$ 视为沉淀完全，不是绝对为零。

---

### 【思想方法】

**平衡移动思想在沉淀溶解平衡中的应用**：

沉淀溶解平衡 $\ce{A_mB_n(s) <=> mA^{n+}(aq) + nB^{m-}(aq)}$ 的移动方向由 $Q_c$ 与 $K_{sp}$ 的相对大小决定。改变条件的分析逻辑：

1. 分析条件改变对 $[\ce{A^{n+}}]$ 或 $[\ce{B^{m-}}]$ 的影响
2. 计算或判断 $Q_c$ 与 $K_{sp}$ 的关系
3. 确定平衡移动方向
4. 推断实验现象（沉淀生成/溶解/不变）

**定量计算思想**：

沉淀溶解平衡的计算通常遵循以下模式：
1. 写出溶解平衡方程式和 $K_{sp}$ 表达式
2. 设未知数（溶解度 $S$ 或某离子浓度）
3. 列方程求解
4. 检验近似是否合理（如忽略与不可忽略的项）

### 【全章知识串联】

#### 一、四种平衡的统一框架

本章学习的四种水溶液中的离子平衡，本质上均服从化学平衡的一般规律，可纳入统一理论框架：

| 平衡类型 | 平衡方程式 | 平衡常数 | 表达式 |
|:---:|:---:|:---:|:---:|
| 弱酸电离 | $\ce{HA <=> H+ + A-}$ | $K_a$ | $K_a = \dfrac{[\ce{H+}][\ce{A-}]}{[\ce{HA}]}$ |
| 弱碱电离 | $\ce{B + H2O <=> BH+ + OH-}$ | $K_b$ | $K_b = \dfrac{[\ce{BH+}][\ce{OH-}]}{[\ce{B}]}$ |
| 水的电离 | $\ce{H2O <=> H+ + OH-}$ | $K_w$ | $K_w = [\ce{H+}][\ce{OH-}]$ |
| 盐类水解 | $\ce{A- + H2O <=> HA + OH-}$ | $K_h$ | $K_h = \dfrac{K_w}{K_a}$ |
| 沉淀溶解 | $\ce{A_mB_n(s) <=> mA^{n+} + nB^{m-}}$ | $K_{sp}$ | $K_{sp} = [\ce{A^{n+}}]^m[\ce{B^{m-}}]^n$ |

**关键关系链**：

$$K_h = \frac{K_w}{K_a} \quad \text{或} \quad K_h = \frac{K_w}{K_b}$$

这一关系体现了水解平衡与电离平衡、水的电离平衡之间的内在联系。

#### 二、与化学平衡（第二章）的联系

本章所有平衡均服从勒夏特列原理：
- 改变浓度：平衡向减弱该改变的方向移动
- 改变温度：吸热反应升温正向移动，放热反应升温逆向移动
- 改变压强：对溶液中的离子平衡影响可忽略（沉淀溶解平衡除外，压缩对固液体系影响极小）

平衡常数的共性：
- 只与温度有关，与浓度无关
- 表达式遵循"产物浓度幂之积除以反应物浓度幂之积"
- 可借助平衡常数判断反应进行的方向和程度

#### 三、与酸碱中和滴定的定量关系

酸碱中和滴定的核心方程：$c_{\text{酸}}V_{\text{酸}} = c_{\text{碱}}V_{\text{碱}}$（一元酸碱）

滴定终点与计量点：
- 强酸-强碱：计量点 $\mathrm{pH} = 7$，终点 $\mathrm{pH}$ 在突跃范围内（$4 \sim 10$），指示剂甲基橙、酚酞均可
- 弱酸-强碱：计量点 $\mathrm{pH} > 7$（盐水解呈碱性），须选酚酞（$8.2 \sim 10.0$）
- 强酸-弱碱：计量点 $\mathrm{pH} < 7$（盐水解呈酸性），须选甲基橙（$3.1 \sim 4.4$）

#### 四、与生物体液的pH调节

**人体血液的pH调节**（$\mathrm{pH} \approx 7.35 \sim 7.45$）：

血液中存在多重缓冲体系：
- $\ce{H2CO3/NaHCO3}$ 体系（主要）：$\mathrm{p}K_{a1}(\ce{H2CO3}) = 6.35$，当 $\mathrm{pH} = 7.4$ 时，$\dfrac{[\ce{HCO3-}]}{[\ce{H2CO3}]} = 10^{7.4-6.35} = 10^{1.05} \approx 11$
- $\ce{NaH2PO4/Na2HPO4}$ 体系：$\mathrm{p}K_{a2}(\ce{H3PO4}) = 7.20$
- 血浆蛋白缓冲体系

缓冲机制：代谢产生酸性物质时，$\ce{HCO3-}$ 与之反应；产生碱性物质时，$\ce{H2CO3}$ 与之反应。肺通过调节 $\ce{CO2}$ 呼出量控制 $[\ce{H2CO3}]$，肾通过调节 $[\ce{HCO3-}]$ 排泄量，共同维持血液pH稳定。

**偏离正常范围的后果**：
- $\mathrm{pH} < 7.35$：酸中毒（代谢性/呼吸性）
- $\mathrm{pH} > 7.45$：碱中毒（代谢性/呼吸性）
- $\mathrm{pH} < 6.8$ 或 $\mathrm{pH} > 7.8$：危及生命

### 【隐性考点汇总】

#### 考点1：电离度与浓度的定量关系

由稀释定律 $\alpha = \sqrt{K_a/c}$，可判断：
- 同一弱酸，浓度越稀，电离度越大
- 不同弱酸同浓度时，$K_a$ 越大，电离度越大
- 弱酸稀释 $n$ 倍，pH增加量小于 $\lg n$（弱酸不完全电离，稀释促进电离）

#### 考点2：酸碱混合后pH计算（过量法）

- 先判断谁过量（$n_{\ce{H+}}$ vs $n_{\ce{OH-}}$）
- 注意：弱酸与强碱恰好反应后，溶液呈碱性（盐水解）
- 注意：强酸与弱碱恰好反应后，溶液呈酸性（盐水解）
- 等体积等浓度一元强酸与一元弱碱混合：溶液呈酸性（生成强酸弱碱盐）

#### 考点3：盐类水解促进水电离的分析

酸/碱抑制水的电离：纯水中水电离的 $[\ce{H+}]_{\text{水}} = 10^{-7}\ \mathrm{mol/L}$
- $\mathrm{pH} = 2$ 的盐酸中，$[\ce{H+}] = 10^{-2}$，则 $[\ce{OH-}] = 10^{-12}$，水电离的 $[\ce{H+}]_{\text{水}} = [\ce{OH-}] = 10^{-12}\ \mathrm{mol/L}$
- $\mathrm{pH} = 12$ 的 $\ce{NaOH}$ 中，$[\ce{OH-}] = 10^{-2}$，则 $[\ce{H+}] = 10^{-12}$，水电离的 $[\ce{H+}]_{\text{水}} = 10^{-12}\ \mathrm{mol/L}$

盐水解促进水的电离：
- $\mathrm{pH} = 5$ 的 $\ce{NH4Cl}$ 溶液中，$[\ce{H+}] = 10^{-5}$，全部 $\ce{H+}$ 来自水的电离，故 $[\ce{H+}]_{\text{水}} = 10^{-5}\ \mathrm{mol/L}$
- $\mathrm{pH} = 9$ 的 $\ce{CH3COONa}$ 溶液中，$[\ce{OH-}] = 10^{-5}$，全部 $\ce{OH-}$ 来自水的电离，故 $[\ce{OH-}]_{\text{水}} = 10^{-5}\ \mathrm{mol/L}$

#### 考点4：$K_{sp}$ 与溶解度的换算

不同类型沉淀须换算为 $S$ 后比较：
- AB型：$S = \sqrt{K_{sp}}$
- AB$_2$ 型：$S = \sqrt[3]{K_{sp}/4}$
- AB$_3$ 型：$S = \sqrt[4]{K_{sp}/27}$

#### 考点5：沉淀顺序判断

向含多种离子的溶液中加入沉淀剂：
- 同类型沉淀：$K_{sp}$ 小的先沉淀
- 不同类型沉淀：需分别计算开始沉淀所需的沉淀剂浓度，浓度小的先沉淀

#### 考点6：缓冲溶液的pH计算

Henderson-Hasselbalch 方程：

$$\mathrm{pH} = \mathrm{p}K_a + \lg\frac{[\text{共轭碱}]}{[\text{弱酸}]}$$

当 $[\text{共轭碱}] = [\text{弱酸}]$ 时，$\mathrm{pH} = \mathrm{p}K_a$，缓冲能力最大。

#### 考点7：守恒关系的灵活应用

三种守恒关系的建立方法：
- 电荷守恒：所有正电荷 = 所有负电荷
- 物料守恒：某元素各种形态浓度之和 = 初始浓度
- 质子守恒：由电荷守恒和物料守恒消去不参加水解/电离的离子得到

### 【易错警示汇总】

#### 错误1：混淆 $\mathrm{pH} = 7$ 与中性

$\mathrm{pH} = 7$ 仅在 $25\ ^\circ\mathrm{C}$ 时对应中性。温度升高时，$K_w$ 增大，中性溶液的 $\mathrm{pH} < 7$。

| 温度 | $K_w$ | 中性时 $[\ce{H+}]$ | 中性pH |
|:---:|:---:|:---:|:---:|
| $25\ ^\circ\mathrm{C}$ | $1.0 \times 10^{-14}$ | $1.0 \times 10^{-7}$ | 7.00 |
| $100\ ^\circ\mathrm{C}$ | $5.13 \times 10^{-13}$ | $7.16 \times 10^{-7}$ | 6.14 |

判断溶液酸碱性的根本标准：$[\ce{H+}]$ 与 $[\ce{OH-}]$ 的相对大小。

#### 错误2：忽略水的电离贡献

以下情况必须考虑水的电离：
- 极稀的酸碱溶液（$c < 10^{-6}\ \mathrm{mol/L}$）
- 极弱的酸或碱（$K_a$ 或 $K_b$ 很小）
- 盐溶液（水解促进水的电离）

#### 错误3：盐类水解方程式可逆号的遗漏

盐类水解是可逆的、微弱的，水解方程式必须用 $\ce{<=>}$。例外：双水解趋于完全的用 $\ce{=}$ 并标 $\downarrow$ 和 $\uparrow$。

#### 错误4：$K_{sp}$ 比较只适用于同类型沉淀

AB型与A$_2$B型等不同类型的沉淀，$K_{sp}$ 的表达式中浓度指数不同，不能直接比较。须换算为溶解度 $S$ 后比较。

#### 错误5：认为沉淀完全即离子浓度为零

沉淀完全是指离子浓度降至 $10^{-5}\ \mathrm{mol/L}$ 或更低，而非绝对为零。沉淀溶解平衡是动态平衡，溶液中仍存在微量离子。

#### 错误6：将电离度与 $[\ce{H+}]$ 混为一谈

弱酸稀释时，电离度 $\alpha$ 增大（更多分子电离），但 $[\ce{H+}] = c\alpha = \sqrt{K_a c}$ 反而减小。两者变化趋势可以相反。

#### 错误7：强电解质溶液中忽略离子间的相互作用

严格来说，强电解质溶液中应使用活度 $a = \gamma c$（$\gamma$ 为活度系数）代替浓度。高中阶段稀溶液中 $\gamma \approx 1$，直接用浓度即可。

#### 错误8：盐溶液pH判断的常见错误

| 盐 | 溶液酸碱性 | 原因 |
|:---:|:---:|:---:|
| $\ce{NaHSO4}$ | 酸性 | $\ce{HSO4-}$ 电离为主（中学阶段视为强酸的酸式盐） |
| $\ce{NaHCO3}$ | 碱性 | $\ce{HCO3-}$ 水解（$K_w/K_{a1}$）$>$ 电离（$K_{a2}$） |
| $\ce{NaHSO3}$ | 酸性 | $\ce{HSO3-}$ 电离（$K_{a2}$）$>$ 水解（$K_w/K_{a1}$） |
| $\ce{NH4Cl}$ | 酸性 | $\ce{NH4+}$ 水解 |
| $\ce{CH3COONH4}$ | 近似中性 | $K_a(\ce{CH3COOH}) \approx K_b(\ce{NH3})$ |

### 【思想方法总结】

#### 一、平衡移动思想

本章所有离子平衡均服从勒夏特列原理，分析问题时遵循以下思维路径：

$$\text{改变条件} \rightarrow \text{分析对 }Q_c\text{ 或浓度的影响} \rightarrow \text{判断平衡移动方向} \rightarrow \text{推断结果}$$

具体应用：
- 加水稀释弱电解质：电离平衡正向移动，电离度增大
- 升温：促进电离和水解（吸热过程），促进水的电离
- 加入含相同离子的电解质：同离子效应，抑制电离/溶解
- 改变pH：影响弱酸盐/弱碱盐的水解平衡和沉淀的酸效应

#### 二、守恒思想（三种守恒）

**电荷守恒**：溶液呈电中性，正电荷总数等于负电荷总数。

$$\sum_+ z_+ [\text{正离子}] = \sum_- |z_-| [\text{负离子}]$$

**物料守恒**：某元素在溶液中的总浓度等于其以各种形态存在的浓度之和。

$$c_0(\text{某元素}) = \sum_i [\text{该元素的第 }i\text{ 种形态}]$$

**质子守恒**：水电离出的 $\ce{H+}$ 数目等于水电离出的 $\ce{OH-}$ 数目（考虑 $\ce{H+}$ 和 $\ce{OH-}$ 被消耗的情况）。

$$[\ce{H+}]_{\text{水}} = [\ce{OH-}]_{\text{水}}$$

或写为：溶液中 "得质子产物" 的总浓度 = "失质子产物" 的总浓度。

#### 三、定量计算思想

本章定量计算的核心模式：

$$\text{平衡常数定义} + \text{守恒关系} \rightarrow \text{建立方程} \rightarrow \text{求解}$$

关键公式汇总：

| 计算类型 | 公式 | 适用条件 |
|:---:|:---:|:---:|
| 弱酸 $[\ce{H+}]$ | $[\ce{H+}] = \sqrt{K_a c}$ | $K_a \ll c$ 且 $c \gg 10^{-7}$ |
| 弱碱 $[\ce{OH-}]$ | $[\ce{OH-}] = \sqrt{K_b c}$ | $K_b \ll c$ 且 $c \gg 10^{-7}$ |
| 盐水解 $[\ce{OH-}]$ 或 $[\ce{H+}]$ | 类似弱酸/弱碱公式 | 水解程度小 |
| 缓冲溶液pH | $\mathrm{pH} = \mathrm{p}K_a + \lg\dfrac{[\text{碱}]}{[\text{酸}]}$ | 缓冲对浓度不太稀 |
| 沉淀溶解度 | $S = \sqrt[m+n]{\dfrac{K_{sp}}{m^m n^n}}$ | 无同离子效应 |
| 沉淀开始生成 | $[\ce{M^{n+}}][\ce{A^{m-}}] = K_{sp}$ | 计算临界浓度 |

#### 四、比较与分类思想

- 比较强弱电解质：电离程度（完全 vs 部分）
- 比较酸碱性强弱：$K_a$ 或 $K_b$ 的大小
- 比较盐的酸碱性：水解程度（"谁强显谁性"）
- 比较沉淀溶解性：$K_{sp}$（同类型时）或 $S$
- 分类处理：按盐的类型判断水解情况，按沉淀类型换算溶解度

### 【典型定量分析示例】

#### 示例1：弱酸溶液中各组分浓度的计算

已知 $\ce{CH3COOH}$ 的 $K_a = 1.8 \times 10^{-5}$，计算 $0.1\ \mathrm{mol/L}$ $\ce{CH3COOH}$ 溶液的pH和各组分浓度。

**解**：设电离平衡时 $[\ce{H+}] = x$

$$\ce{CH3COOH <=> H+ + CH3COO-}$$

初始：$0.1$　　$0$　　$0$

平衡：$0.1 - x$　　$x$　　$x$

$$K_a = \frac{x^2}{0.1 - x} = 1.8 \times 10^{-5}$$

检验近似：$c/K_a = 0.1/(1.8 \times 10^{-5}) = 5.6 \times 10^3 \gg 400$，可用近似 $0.1 - x \approx 0.1$

$$x^2 = 1.8 \times 10^{-6} \quad \Rightarrow \quad x = 1.34 \times 10^{-3}\ \mathrm{mol/L}$$

$$[\ce{H+}] = [\ce{CH3COO-}] = 1.34 \times 10^{-3}\ \mathrm{mol/L}$$

$$[\ce{CH3COOH}] \approx 0.1 - 0.00134 = 0.0987\ \mathrm{mol/L}$$

$$[\ce{OH-}] = \frac{K_w}{[\ce{H+}]} = \frac{10^{-14}}{1.34 \times 10^{-3}} = 7.5 \times 10^{-12}\ \mathrm{mol/L}$$

$$\mathrm{pH} = -\lg(1.34 \times 10^{-3}) = 2.87$$

电离度：$\alpha = \dfrac{1.34 \times 10^{-3}}{0.1} \times 100\% = 1.34\%$

#### 示例2：$K_{sp}$ 与溶解度换算

已知 $K_{sp}(\ce{AgCl}) = 1.8 \times 10^{-10}$，$K_{sp}(\ce{Ag2CrO4}) = 1.1 \times 10^{-12}$，比较两者在纯水中的溶解度。

**解**：

$\ce{AgCl}$（AB型）：

$$S(\ce{AgCl}) = \sqrt{K_{sp}} = \sqrt{1.8 \times 10^{-10}} = 1.34 \times 10^{-5}\ \mathrm{mol/L}$$

$\ce{Ag2CrO4}$（A$_2$B型）：

$$\ce{Ag2CrO4(s) <=> 2Ag+ + CrO4^{2-}}$$

$$K_{sp} = (2S)^2 \cdot S = 4S^3 = 1.1 \times 10^{-12}$$

$$S = \sqrt[3]{\frac{1.1 \times 10^{-12}}{4}} = \sqrt[3]{2.75 \times 10^{-13}} = 6.5 \times 10^{-5}\ \mathrm{mol/L}$$

结论：虽然 $K_{sp}(\ce{AgCl}) > K_{sp}(\ce{Ag2CrO4})$，但 $S(\ce{AgCl}) < S(\ce{Ag2CrO4})$。$\ce{Ag2CrO4}$ 溶解度约为 $\ce{AgCl}$ 的 $4.9$ 倍。

#### 示例3：沉淀转化平衡常数计算

判断 $\ce{BaCO3}$ 能否转化为 $\ce{BaSO4}$。已知 $K_{sp}(\ce{BaCO3}) = 2.8 \times 10^{-9}$，$K_{sp}(\ce{BaSO4}) = 1.1 \times 10^{-10}$。

**解**：转化反应：

$$\ce{BaCO3(s) + SO4^{2-}(aq) <=> BaSO4(s) + CO3^{2-}(aq)}$$

$$K = \frac{[\ce{CO3^{2-}}]}{[\ce{SO4^{2-}}]} = \frac{[\ce{CO3^{2-}}][\ce{Ba^{2+}}]}{[\ce{SO4^{2-}}][\ce{Ba^{2+}}]} = \frac{K_{sp}(\ce{BaCO3})}{K_{sp}(\ce{BaSO4})} = \frac{2.8 \times 10^{-9}}{1.1 \times 10^{-10}} = 25.5$$

$K > 1$，说明 $\ce{BaCO3}$ 可以转化为 $\ce{BaSO4}$（加入足量 $\ce{SO4^{2-}}$ 即可）。但 $K$ 不太大，转化不如 $\ce{AgCl -> AgBr}$ 那样完全。
