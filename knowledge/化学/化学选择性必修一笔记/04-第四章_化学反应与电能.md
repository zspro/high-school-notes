# 第四章 化学反应与电能

---

## 0. 【来龙去脉】电化学学科的起源与发展

### 0.1 从生物电到化学电：伽伐尼与伏打的论争

1780年，意大利解剖学家路易吉·伽伐尼（Luigi Galvani）在解剖青蛙时偶然发现：当用铜钩钩住青蛙腿并使其与铁栏杆接触时，蛙腿会发生痉挛性收缩。伽伐尼将其解释为生物体内存在"动物电"（animal electricity），认为电储存在蛙腿肌肉中，金属导体仅起释放作用。

1799—1800年，意大利物理学家亚历山德罗·伏打（Alessandro Volta）通过系统实验推翻了伽伐尼的生物电假说。伏打将不同金属（如锌与铜）用浸有盐溶液的布片隔开，叠成柱状结构——**伏打电堆**（voltaic pile）。该装置无需生物组织即可持续产生电流，证明电的来源是两种不同金属与电解质溶液之间的化学反应，而非生物体内的特殊电液。伏打电堆是人类历史上第一个化学电源，标志着电化学学科的正式诞生。

### 0.2 法拉第电解定律的定量奠基

1833—1834年，迈克尔·法拉第（Michael Faraday）通过大量电解实验总结出两条基本定律：

**第一定律**：电解时，电极上析出或溶解的物质的量与通过的电量成正比。

**第二定律**：当通过相同电量时，不同物质析出或溶解的物质的量与其化学当量成正比。

数学表达为：

$$m = \frac{M}{nF} \cdot Q = \frac{M}{nF} \cdot I \cdot t$$

其中 $M$ 为摩尔质量，$n$ 为电极反应中转移的电子数，$F$ 为法拉第常数（$F \approx 96485 \ \mathrm{C \cdot mol^{-1}}$），$Q$ 为电量，$I$ 为电流强度，$t$ 为通电时间。

法拉第定律首次将电学量与化学量定量联系起来，建立了电化学的数学基础。需要特别指出，法拉第定律不受温度、压强、电解质浓度、电极材料等因素影响，是自然科学中最精确的定律之一。

### 0.3 电极电势理论的建立

1889年，瓦尔特·能斯特（Walther Nernst）基于热力学理论推导出**能斯特方程**（Nernst equation），定量描述了电极电势与离子浓度、温度的关系：

$$\varphi = \varphi^\ominus - \frac{RT}{nF} \ln Q$$

或常用对数形式（$T = 298.15 \ \mathrm{K}$ 时）：

$$\varphi = \varphi^\ominus - \frac{0.0592}{n} \lg Q$$

其中 $\varphi^\ominus$ 为标准电极电势，$Q$ 为反应商。能斯特方程揭示了电极电势的本质——**电极电势是电极反应进行趋势的度量**，电势越高，氧化态物质的氧化能力越强；电势越低，还原态物质的还原能力越强。这一理论为判断氧化还原反应方向、计算电池电动势提供了严格的理论基础。

### 0.4 电池技术的演变与当代发展

| 年代 | 技术里程碑 | 电极材料 | 电解质 | 特点 |
|------|-----------|---------|--------|------|
| 1800 | 伏打电堆 | Zn/Cu | 盐溶液 | 最早的化学电源 |
| 1859 | 铅酸蓄电池 | Pb/PbO$_2$ | 稀H$_2$SO$_4$ | 可充电，至今仍广泛使用 |
| 1866 | 锌锰干电池 | Zn/MnO$_2$ | NH$_4$Cl糊状 | 一次电池，便宜便携 |

### 0.5 金属腐蚀的经济学与防护意义

据国际腐蚀学会（ICC）统计，全球每年因金属腐蚀造成的经济损失约占各国GDP的3%~4%。以中国为例，2023年GDP约126万亿元，腐蚀损失估算达3.8~5.0万亿元。这一损失远超自然灾害造成的直接经济损失之和。腐蚀不仅造成材料浪费，还可能导致结构失效引发安全事故。因此，理解电化学腐蚀机理、采取有效防护措施具有重大经济价值和工程意义。

## 第一节 原电池

---

### 1.1 【基础精讲】原电池的严格定义与构成条件

#### 1.1.1 定义

**原电池**（galvanic cell / voltaic cell）是将化学能直接转化为电能的装置。其本质是通过自发的氧化还原反应，使电子经由外电路定向移动形成电流。

#### 1.1.2 四个必要条件（缺一不可）

**条件一：两个活泼性不同的电极**

电极材料可以是金属（如 $\ce{Zn}$、$\ce{Cu}$、$\ce{Ag}$），也可以是导电非金属（如石墨）。两个电极的活泼性差异是产生电势差的根本原因。需要澄清："活泼性"在此语境下应理解为**电极电势的高低**，而非单纯的金属活动性顺序。电极电势较低的金属作负极，发生氧化反应。

**条件二：电解质溶液**

电解质溶液（或熔融电解质）提供可以自由移动的离子，使电极反应得以进行，并在溶液内部形成电流通路。电解质的选择需保证其不与电极材料发生非电化学反应。

**条件三：形成闭合回路**

外电路（导线连接两极）用于电子传导，内电路（电解质溶液中离子迁移）用于离子传导。两电路构成完整的电流通路。

**条件四：能自发进行的氧化还原反应**

该反应的 $\Delta G < 0$，即 $\Delta G = -nFE < 0$，从而 $E > 0$。这是原电池工作的热力学基础。

#### 1.1.3 铜锌原电池（丹尼尔电池）的结构分析

以 $\ce{Zn}$|$\ce{Zn^{2+}}$||$\ce{Cu^{2+}}$|$\ce{Cu}$ 为例：

| 项目 | 负极（阳极） | 正极（阴极） |
|------|------------|------------|
| 电极材料 | 锌片 | 铜片 |
| 电极反应 | $\ce{Zn - 2e- -> Zn^{2+}}$（氧化） | $\ce{Cu^{2+} + 2e- -> Cu}$（还原） |
| 反应类型 | 失电子，化合价升高 | 得电子，化合价降低 |
| 电子流向 | 电子流出 | 电子流入 |
| 离子移向 | 阴离子移向负极 | 阳离子移向正极 |
| 质量变化 | 溶解，质量减小 | 析出，质量增大 |
| 电极电势 | 电势低 | 电势高 |

总反应：$\ce{Zn + Cu^{2+} -> Zn^{2+} + Cu}$

### 1.2 【基础精讲】盐桥的作用原理

#### 1.2.1 无盐桥时的电路中断问题

若将锌片直接插入 $\ce{CuSO4}$ 溶液中，虽然 $\ce{Zn}$ 与 $\ce{Cu^{2+}}$ 可直接发生置换反应，但电子转移发生在接触界面，无法形成定向电流。即使将两电极分置两烧杯，随着反应进行：

- $\ce{ZnSO4}$ 烧杯中 $\ce{Zn^{2+}}$ 增多，正电荷过剩
- $\ce{CuSO4}$  烧杯中 $\ce{Cu^{2+}}$ 减少，$\ce{SO^{2-}_4}$ 相对过剩，负电荷过剩

这种电荷积累产生反向电势，阻碍反应继续进行，约几秒钟后电流即降至零。

#### 1.2.2 盐桥的三重功能

**功能一：离子通道，维持电荷平衡**

盐桥中通常装有含 $\ce{KCl}$ 琼脂凝胶。当 $\ce{ZnSO4}$ 半电池中 $\ce{Zn^{2+}}$ 过剩时，盐桥中的阴离子（$\ce{Cl-}$）向该半电池迁移；当 $\ce{CuSO4}$ 半电池中 $\ce{Cu^{2+}}$ 减少时，盐桥中的阳离子（$\ce{K+}$）向该半电池迁移。离子迁移使两半电池维持电中性，确保反应持续进行。

**功能二：消除液接电势**

不同电解质溶液直接接触时，由于各种离子迁移速率不同，在界面处会产生电势差，称为**液接电势**（liquid junction potential）。盐桥中高浓度的 $\ce{K+}$ 和 $\ce{Cl-}$（两者迁移速率相近，$t_{\ce{K+}} \approx t_{\ce{Cl-}}$）可显著降低液接电势。

**功能三：隔离反应体系**

盐桥将氧化半反应与还原半反应物理隔离，防止反应物直接接触发生化学反应，确保电子只能通过外电路转移。

#### 1.2.3 盐桥使用注意事项

- 盐桥使用一段时间后需更换或再生，因为离子会逐渐耗尽
- 若电解质溶液中含 $\ce{Ag+}$，不能用 $\ce{KCl}$ 盐桥（$\ce{Ag+ + Cl- -> AgCl v}$），应改用 $\ce{KNO3}$
- 盐桥不能无限期地维持电流，属于实验室装置，实际电池采用多孔隔膜替代

### 1.3 【基础精讲】电极反应式的书写方法

#### 1.3.1 书写步骤（严格的操作程序）

**步骤一：确定正负极**

比较两极材料的电极电势，电势低者为负极（氧化），电势高者为正极（还原）。

**步骤二：分别写出氧化半反应和还原半反应**

氧化半反应：还原剂 $\rightarrow$ 氧化产物 $+ \ ne-$

还原半反应：氧化剂 $+ \ ne- \rightarrow$ 还原产物

**步骤三：配平（原子守恒与电荷守恒）**

酸性介质中：用 $\ce{H+}$ 平衡电荷，用 $\ce{H2O}$ 平衡氧原子

碱性介质中：用 $\ce{OH-}$ 平衡电荷，用 $\ce{H2O}$ 平衡氧原子

熔融盐介质：无 $\ce{H+}$、$\ce{OH-}$，直接用相应离子配平

**步骤四：验证**

- 原子守恒：反应前后各元素原子数相等
- 电荷守恒：反应前后净电荷相等
- 电子守恒：负极失电子数 = 正极得电子数

#### 1.3.2 典型示例

**示例1：酸性条件下的氢氧燃料电池**

负极（氧化）：$\ce{H2 - 2e- -> 2H+}$

正极（还原）：$\ce{O2 + 4H+ + 4e- -> 2H2O}$

总反应：$\ce{2H2 + O2 -> 2H2O}$

**示例2：碱性条件下的氢氧燃料电池**

负极（氧化）：$\ce{H2 + 2OH- - 2e- -> 2H2O}$

正极（还原）：$\ce{O2 + 2H2O + 4e- -> 4OH-}$

总反应：$\ce{2H2 + O2 -> 2H2O}$

**示例3：甲烷燃料电池（酸性介质）**

负极：$\ce{CH4 + 2H2O - 8e- -> CO2 + 8H+}$

正极：$\ce{2O2 + 8H+ + 8e- -> 4H2O}$

总反应：$\ce{CH4 + 2O2 -> CO2 + 2H2O}$

#### 1.3.3 不同介质下正极反应的差异（核心考点）

同一氧化剂在不同介质中，其还原产物和电极反应式截然不同：

| 氧化剂 | 酸性介质 | 碱性介质 | 熔融碳酸盐 |
|--------|---------|---------|-----------|
| $\ce{O2}$ | $\ce{O2 + 4H+ + 4e- -> 2H2O}$ | $\ce{O2 + 2H2O + 4e- -> 4OH-}$ | $\ce{O2 + 2CO2 + 4e- -> 2CO^{2-}_3}$ |
| $\ce{H2O2}$ | $\ce{H2O2 + 2H+ + 2e- -> 2H2O}$ | $\ce{H2O2 + 2e- -> 2OH-}$ | — |

### 1.4 【基础精讲】常见化学电源

#### 1.4.1 一次电池（不可充电）

**碱性锌锰电池**

负极（$\ce{Zn}$）：$\ce{Zn + 2OH- - 2e- -> Zn(OH)2}$

正极（$\ce{MnO2}$）：$\ce{2MnO2 + 2H2O + 2e- -> 2MnOOH + 2OH-}$

总反应：$\ce{Zn + 2MnO2 + 2H2O -> Zn(OH)2 + 2MnOOH}$

电解质：$\ce{KOH}$ 溶液。与酸性锌锰电池相比，碱性条件下 $\ce{Zn}$ 的腐蚀更慢，自放电小，容量更大。

**纽扣电池（银锌电池）**

负极：$\ce{Zn + 2OH- - 2e- -> Zn(OH)2}$

正极：$\ce{Ag2O + H2O + 2e- -> 2Ag + 2OH-}$

总反应：$\ce{Zn + Ag2O + H2O -> Zn(OH)2 + 2Ag}$

特点：电压稳定（约1.5V），体积小，用于手表、计算器等精密仪器。

#### 1.4.2 二次电池（可充电）

**铅酸蓄电池**

放电时：

负极（$\ce{Pb}$）：$\ce{Pb + SO^{2-}_4 - 2e- -> PbSO4}$

正极（$\ce{PbO2}$）：$\ce{PbO2 + 4H+ + SO^{2-}_4 + 2e- -> PbSO4 + 2H2O}$

总反应：$\ce{Pb + PbO2 + 2H2SO4 -> 2PbSO4 + 2H2O}$

充电时上述反应逆向进行。铅酸蓄电池的充放电循环本质是 $\ce{PbSO4}$ 的反复生成与分解。

**锂离子电池（嵌入反应机理）**

锂离子电池的工作原理与传统电池不同，其电极反应为**嵌入/脱嵌反应**（intercalation/deintercalation），而非传统的氧化还原溶解/析出：

放电时：

负极（石墨）：$\ce{Li_xC6 - xe- -> xLi+ + 6C}$

正极（$\ce{LiCoO2}$）：$\ce{Li_{1-x}CoO2 + xLi+ + xe- -> LiCoO2}$

总反应：$\ce{Li_xC6 + Li_{1-x}CoO2 -> 6C + LiCoO2}$

锂离子电池中 $\ce{Li+}$ 在正负极之间迁移，电子经外电路流动。电解质为含锂盐的有机溶液（非水体系），防止 $\ce{Li}$ 与水反应。

#### 1.4.3 燃料电池

燃料电池的本质是**将燃料的燃烧反应分步进行**：燃料在负极被氧化，氧化剂在正极被还原，化学能直接转化为电能，不受卡诺循环效率限制。

**氢氧燃料电池（酸性）**

负极：$\ce{2H2 - 4e- -> 4H+}$

正极：$\ce{O2 + 4H+ + 4e- -> 2H2O}$

理论效率可达83%（$\Delta G/\Delta H$ 之比），实际效率约40%~60%，远高于内燃机。

### 1.5 【深度理解】电极电势的本质与负极判断

#### 1.5.1 电极电势的热力学定义

电极电势 $\varphi$ 与吉布斯自由能变的关系：

$$\Delta G = -nFE$$

其中 $E = \varphi_{正} - \varphi_{负} = \varphi_{阴} - \varphi_{阳}$ 为电池电动势。

当 $\varphi_{正} > \varphi_{负}$ 时，$E > 0$，$\Delta G < 0$，反应自发进行。

标准电极电势 $\varphi^\ominus$ 的物理意义：在标准状态（各离子活度为1，$T = 298.15 \ \mathrm{K}$）下，某电极与标准氢电极（SHE，$\varphi^\ominus_{\ce{H+/H2}} \equiv 0 \ \mathrm{V}$）组成的原电池的电动势。

#### 1.5.2 为什么"活泼金属作负极"？

金属活动性顺序本质上反映了金属的标准电极电势的相对大小：

| 金属 | $\varphi^\ominus_{\ce{M^{n+}/M}}$ / V | 活动性 |
|------|--------------------------------------|--------|
| $\ce{K}$ | -2.93 | 强 |
| $\ce{Zn}$ | -0.76 | 中 |
| $\ce{Fe}$ | -0.44 | 中 |
| $\ce{Cu}$ | +0.34 | 弱 |
| $\ce{Ag}$ | +0.80 | 弱 |

活泼金属的 $\varphi^\ominus$ 值低（负值大），其还原态（金属单质）失电子趋势大，故在一般的原电池中作负极发生氧化反应。但此规律有例外：

- **浓差电池**：两极材料相同，因离子浓度不同而产生电势差
- **钝化金属**：铝在浓硝酸中钝化，此时不能简单地用活动性判断
- **非水体系**：电极电势与溶剂化能有关，金属活动性顺序仅适用于水溶液

#### 1.5.3 浓差电池原理

浓差电池的电极材料相同，仅电解质浓度不同。以 $\ce{Cu}$|$\ce{Cu^{2+}(c1)}$||$\ce{Cu^{2+}(c2)}$|$\ce{Cu}$ 为例：

$$E = \frac{RT}{nF} \ln\frac{c_2}{c_1} = \frac{0.0592}{2} \lg\frac{c_2}{c_1} \quad (c_2 > c_1)$$

浓度大的一侧 $\ce{Cu^{2+}}$ 更容易被还原（$\ce{Cu^{2+} + 2e- -> Cu}$），故浓度大的一侧为正极，浓度小的一侧 $\ce{Cu}$ 溶解（$\ce{Cu -> Cu^{2+} + 2e-}$），为负极。反应的总效果是 $\ce{Cu^{2+}}$ 从高浓度区向低浓度区迁移，直至浓度相等，$E = 0$。

浓差电池是理解**盐桥中离子迁移驱动力**的关键模型。

## 第二节 电解池

---

### 2.1 【基础精讲】电解原理

#### 2.1.1 定义与本质

**电解池**（electrolytic cell）是将电能转化为化学能的装置。电解是在外加直流电源作用下，电解质溶液或熔融电解质中发生非自发氧化还原反应的过程。

电解池与原电池的核心区别：

| 比较项目 | 原电池 | 电解池 |
|---------|--------|--------|
| 能量转化 | 化学能 $\rightarrow$ 电能 | 电能 $\rightarrow$ 化学能 |
| 反应自发性 | 自发（$\Delta G < 0$） | 非自发（$\Delta G > 0$） |
| 驱动力 | 化学势差 | 外加电源 |
| 电子流向 | 负极 $\rightarrow$ 正极 | 电源负极 $\rightarrow$ 阴极，阳极 $\rightarrow$ 电源正极 |
| 电极名称 | 负极/正极 | 阴极/阳极 |
| 电极反应 | 负极氧化，正极还原 | 阴极还原，阳极氧化 |

#### 2.1.2 电解池的构成条件

1. **直流电源**：提供持续的定向电势差
2. **两个电极**：与电源负极相连的为**阴极**（还原反应），与电源正极相连的为**阳极**（氧化反应）
3. **电解质**：提供可自由移动的离子
4. **闭合回路**

#### 2.1.3 电解 $\ce{CuCl2}$ 溶液的实例分析

阳极（与电源正极相连，氧化）：$\ce{2Cl- - 2e- -> Cl2 ^}$

阴极（与电源负极相连，还原）：$\ce{Cu^{2+} + 2e- -> Cu}$

总反应：$\ce{CuCl2 \xrightarrow{\text{电解}} Cu + Cl2 ^}$

离子移动方向：

- 阳离子（$\ce{Cu^{2+}}$、$\ce{H+}$）向阴极移动
- 阴离子（$\ce{Cl-}$、$\ce{OH-}$）向阳极移动

### 2.2 【基础精讲】电解时离子的放电顺序

#### 2.2.1 放电顺序的本质——电极电势的比较

"放电"指离子在电极上得失电子发生电极反应的过程。离子的放电顺序由其电极电势决定：

- **阴极**（还原反应）：电极电势高的阳离子优先被还原
- **阳极**（氧化反应）：电极电势低的阴离子优先被氧化（或电极材料优先被氧化）

#### 2.2.2 阴极放电顺序（阳离子还原）

$$\ce{Ag+ > Hg^{2+} > Fe^{3+} > Cu^{2+} > H+（酸）> Pb^{2+} > Sn^{2+} > Fe^{2+} > Zn^{2+} > H+（水）> Al^{3+} > Mg^{2+} > Na+ > Ca^{2+} > K+}$$

简化记忆：

- 位于 $\ce{Cu^{2+}}$ 之后的金属阳离子（如 $\ce{Ag+}$、$\ce{Hg^{2+}}$）一般优先于 $\ce{H+}$ 放电
- $\ce{Cu^{2+}}$ 到 $\ce{Zn^{2+}}$ 之间的离子放电能力与 $\ce{H+}$ 的竞争关系需结合浓度分析（能斯特方程）
- 位于 $\ce{Zn^{2+}}$ 之前的活泼金属离子（$\ce{Al^{3+}}$、$\ce{Na+}$ 等）在水溶液中不放电，而是 $\ce{H+}$（来自水）放电产生 $\ce{H2}$

#### 2.2.3 阳极放电顺序

**惰性电极**（$\ce{Pt}$、石墨、$\ce{Au}$）：

$$\ce{S^{2-} > I- > Br- > Cl- > OH- > 含氧酸根（如SO^{2-}_4、NO^-3）> F-}$$

**活性电极**（$\ce{Cu}$、$\ce{Ag}$、$\ce{Zn}$、$\ce{Fe}$ 等，除 $\ce{Pt}$、$\ce{Au}$ 外的大多数金属）：

**电极材料本身优先放电溶解**：$\ce{M - ne- -> M^{n+}}$

例如用 $\ce{Cu}$ 作阳极电解 $\ce{CuSO4}$ 溶液：

阳极：$\ce{Cu - 2e- -> Cu^{2+}}$（铜电极溶解，而非 $\ce{OH-}$ 或 $\ce{SO^{2-}_4}$ 放电）

阴极：$\ce{Cu^{2+} + 2e- -> Cu}$

总效果：$\ce{Cu}$ 从阳极迁移到阴极，溶液中 $\ce{Cu^{2+}}$ 浓度保持不变。此即**铜的电解精炼**原理。

#### 2.2.4 过电位对放电顺序的影响

实际电解时，离子的放电顺序并非严格遵循标准电极电势，还需考虑**过电位**（overpotential，亦称超电势）。

过电位 $\eta$ 定义为实际析出电势与平衡电势之差：

$$\varphi_{实际} = \varphi_{平衡} + \eta$$

以 $\ce{H+}$ 在阴极还原为例：

$$\ce{2H+ + 2e- -> H2}$$

该反应在多数金属电极上具有较高的过电位（如 $\ce{Pb}$ 上约 $-0.8 \ \mathrm{V}$），导致 $\ce{H2}$ 的实际析出电势远低于理论值。这一效应使得：

- $\ce{Zn^{2+}}$（$\varphi^\ominus = -0.76 \ \mathrm{V}$）可在酸性条件下先于 $\ce{H+}$ 放电，镀锌成为可能
- 活泼金属（$\ce{Na}$、$\ce{K}$、$\ce{Al}$）不能通过水溶液电解获得，需电解熔融盐

过电位的存在是**电化学动力学**的核心问题，其大小与电极材料、电流密度、温度密切相关。

### 2.3 【基础精讲】电解的重要应用

#### 2.3.1 氯碱工业（电解饱和食盐水）

阳极（石墨或金属阳极）：$\ce{2Cl- - 2e- -> Cl2 ^}$

阴极（铁网）：$\ce{2H2O + 2e- -> H2 ^ + 2OH-}$

总反应：$\ce{2NaCl + 2H2O \xrightarrow{\text{电解}} 2NaOH + H2 ^ + Cl2 ^}$

离子交换膜技术：使用阳离子交换膜分隔阳极室和阴极室，只允许 $\ce{Na+}$ 从阳极室迁移到阴极室，防止 $\ce{Cl2}$ 与 $\ce{NaOH}$ 反应，同时保证产品纯度。

#### 2.3.2 电解精炼铜

阳极（粗铜，含 $\ce{Fe}$、$\ce{Zn}$、$\ce{Ag}$、$\ce{Au}$ 等杂质）：

$\ce{Cu - 2e- -> Cu^{2+}}$（主反应）

$\ce{Fe - 2e- -> Fe^{2+}}$、$\ce{Zn - 2e- -> Zn^{2+}}$（比 $\ce{Cu}$ 活泼的杂质溶解）

$\ce{Ag}$、$\ce{Au}$ 不放电，以**阳极泥**形式沉积。

阴极（纯铜薄片）：$\ce{Cu^{2+} + 2e- -> Cu}$（纯铜析出）

结果：纯铜在阴极沉积，不活泼杂质沉积为阳极泥可回收贵金属。

#### 2.3.3 电镀

电镀是利用电解原理在金属表面沉积一层均匀、致密、附着牢固的其他金属或合金的过程。

以镀铜为例：

- 待镀金属制品作**阴极**
- **铜片**作阳极
- $\ce{CuSO4}$ 溶液作电镀液

阴极：$\ce{Cu^{2+} + 2e- -> Cu}$（铜镀层）

阳极：$\ce{Cu - 2e- -> Cu^{2+}}$（补充 $\ce{Cu^{2+}}$）

电镀的关键：控制电流密度、温度、电镀液浓度和pH，以获得致密、均匀的镀层。

#### 2.3.4 电冶金

**电解熔融氧化铝（霍尔-埃鲁法）**

由于 $\ce{Al^{3+}}$ 在水溶液中不放电（$\ce{H+}$ 优先），工业上采用电解熔融 $\ce{Al2O3}$ 制备铝：

$$\ce{2Al2O3（熔融）\xrightarrow[冰晶石]{电解} 4Al + 3O2 ^}$$

冰晶石（$\ce{Na3AlF6}$）的作用是降低 $\ce{Al2O3}$ 的熔点（从约 $2050\mathrm{^\circ C}$ 降至约 $960\mathrm{^\circ C}$），节约能源。

阳极（石墨）：$\ce{2O^{2-} - 4e- -> O2 ^}$（高温下石墨被氧化消耗，需定期更换）

阴极（石墨）：$\ce{Al^{3+} + 3e- -> Al}$

### 2.4 【深度理解】电解池与原电池的统一性

#### 2.4.1 可逆电池与电动势

同一氧化还原反应体系，既可构成原电池（$E > 0$，放电），也可构成电解池（$E_{外} > E$，充电）。

铅酸蓄电池的充放电过程即为典型：

放电（原电池）：$\ce{Pb + PbO2 + 2H2SO4 -> 2PbSO4 + 2H2O}$，$\Delta G < 0$

充电（电解池）：$\ce{2PbSO4 + 2H2O -> Pb + PbO2 + 2H2SO4}$，$\Delta G > 0$

电池的标准电动势与平衡常数的关系：

$$E^\ominus = \frac{RT}{nF} \ln K^\ominus = \frac{0.0592}{n} \lg K^\ominus$$

此式揭示了电化学与化学平衡的本质联系：$E^\ominus$ 越大，$K^\ominus$ 越大，反应进行越完全。

#### 2.4.2 分解电压

使电解持续进行所需的最小外加电压称为**分解电压**（$E_{分解}$）：

$$E_{分解} = E_{理论} + \eta_{阳} + \eta_{阴} + IR$$

其中 $E_{理论}$ 为由能斯特方程计算的理论值，$\eta_{阳}$、$\eta_{阴}$ 为过电位，$IR$ 为溶液电阻产生的电压降。

### 2.5 【隐性考点】电解计算——电子守恒法

#### 2.5.1 核心原理

电解过程中，阴极得电子总数 = 阳极失电子总数 = 电路中通过的电子总数。

$$n(\text{电子}) = \frac{Q}{F} = \frac{I \cdot t}{F}$$

#### 2.5.2 计算示例

用 $2 \ \mathrm{A}$ 的电流电解 $\ce{CuSO4}$ 溶液 $965 \ \mathrm{s}$，求阴极析出铜的质量。

解：$Q = I \cdot t = 2 \times 965 = 1930 \ \mathrm{C}$

$$n(e^-) = \frac{1930}{96485} \approx 0.02 \ \mathrm{mol}$$

阴极反应：$\ce{Cu^{2+} + 2e- -> Cu}$

$$n(\ce{Cu}) = \frac{n(e^-)}{2} = 0.01 \ \mathrm{mol}$$

$$m(\ce{Cu}) = 0.01 \times 64 = 0.64 \ \mathrm{g}$$

#### 2.5.3 串联电解池问题

多个电解池串联时，各池通过的电子数相等。若串联电解 $\ce{NaCl}$ 溶液和 $\ce{CuSO4}$ 溶液，当第一个池阴极析出 $0.1 \ \mathrm{mol}$ $\ce{H2}$ 时：

$$n(e^-) = 2 \times 0.1 = 0.2 \ \mathrm{mol}$$

第二个池阴极析出 $\ce{Cu}$：

$$n(\ce{Cu}) = \frac{0.2}{2} = 0.1 \ \mathrm{mol}$$

第二个池阳极（惰性）产生 $\ce{O2}$：

$$\ce{2H2O - 4e- -> O2 + 4H+}$$

$$n(\ce{O2}) = \frac{0.2}{4} = 0.05 \ \mathrm{mol}$$

## 第三节 金属的腐蚀与防护

---

### 3.1 【基础精讲】金属腐蚀的定义与分类

#### 3.1.1 定义

金属腐蚀（corrosion）是金属与周围环境发生化学或电化学作用而引起的破坏或变质现象。

#### 3.1.2 分类

| 腐蚀类型 | 原理 | 特征 |
|---------|------|------|
| 化学腐蚀 | 金属与氧化剂直接发生化学反应 | 无电流产生，高温下常见 |
| 电化学腐蚀 | 金属在电解质溶液中形成原电池 | 有微弱电流产生，常温下最普遍 |

电化学腐蚀是自然界和工程环境中最主要的腐蚀形式，占金属腐蚀损失的绝大部分。

### 3.2 【基础精讲】电化学腐蚀的两种类型

#### 3.2.1 析氢腐蚀（酸性环境，pH < 4.3）

条件：金属表面有水膜，且水膜酸性较强。

负极（$\ce{Fe}$）：$\ce{Fe - 2e- -> Fe^{2+}}$

正极（杂质如 $\ce{C}$，或另一区域）：$\ce{2H+ + 2e- -> H2 ^}$

总反应：$\ce{Fe + 2H+ -> Fe^{2+} + H2 ^}$

后续：$\ce{Fe^{2+}}$ 可进一步被氧化为 $\ce{Fe^{3+}}$，最终形成铁锈（水合氧化铁）。

#### 3.2.2 吸氧腐蚀（弱酸性、中性或碱性环境，pH $\geq$ 4.3）

条件：金属表面有薄层电解质溶液，溶解氧存在。这是自然界中最普遍的腐蚀类型。

负极（$\ce{Fe}$）：$\ce{2Fe - 4e- -> 2Fe^{2+}}$

正极（$\ce{O2}$ 在碳或氧化物表面还原）：$\ce{O2 + 2H2O + 4e- -> 4OH-}$

总反应：$\ce{2Fe + O2 + 2H2O -> 2Fe(OH)2}$

后续反应：

$$\ce{4Fe(OH)2 + O2 + 2H2O -> 4Fe(OH)3}$$

$$\ce{2Fe(OH)3 -> Fe2O3 \cdot nH2O + (3-n)H2O}$$

$\ce{Fe2O3 \cdot nH2O}$ 即为铁锈，结构疏松，不能阻止内部铁继续腐蚀。

#### 3.2.3 两种腐蚀类型的比较

| 比较项目 | 析氢腐蚀 | 吸氧腐蚀 |
|---------|---------|---------|
| 水膜酸碱性 | 较强酸性（pH < 4.3） | 弱酸性、中性、碱性（pH $\geq$ 4.3） |
| 正极反应物 | $\ce{H+}$ | $\ce{O2}$ |
| 正极反应 | $\ce{2H+ + 2e- -> H2}$ | $\ce{O2 + 2H2O + 4e- -> 4OH-}$ |
| 发生条件 | 酸性环境 | 需溶解氧，普遍存在于大气中 |
| 普遍性 | 较少 | 最普遍 |

### 3.3 【基础精讲】金属腐蚀的防护方法

#### 3.3.1 覆盖保护层法

在金属表面覆盖一层致密的保护膜，隔离金属与腐蚀介质接触：

- **涂油脂、油漆、搪瓷**：物理隔离
- **电镀（镀铬、镀镍）**：镀层需致密完整，若破损可能加速腐蚀
- **烤蓝（发蓝处理）**：在钢铁表面生成致密的 $\ce{Fe3O4}$ 氧化膜
- **钝化**：不锈钢中的 $\ce{Cr}$ 形成致密 $\ce{Cr2O3}$ 膜

#### 3.3.2 改变金属内部结构

- **合金化**：不锈钢（加 $\ce{Cr}$、$\ce{Ni}$）、黄铜（$\ce{Cu-Zn}$ 合金）等
- **冶炼时控制成分**：降低杂质含量，减少形成微电池的可能性

#### 3.3.3 电化学保护法

**方法一：牺牲阳极的阴极保护法**

原理：在被保护金属上连接一种更活泼的金属（如 $\ce{Zn}$、$\ce{Mg}$），构成原电池。活泼金属作负极被腐蚀（牺牲），被保护金属作正极不被腐蚀。

应用：船体外壳嵌锌块、输油管道外壁包锌皮、地下钢管连接镁合金。

负极（$\ce{Zn}$）：$\ce{Zn - 2e- -> Zn^{2+}}$

正极（$\ce{Fe}$）：$\ce{O2 + 2H2O + 4e- -> 4OH-}$（$\ce{Fe}$ 本身不反应）

**方法二：外加电流的阴极保护法**

原理：将被保护金属与外接直流电源的负极相连，作为电解池的阴极。外加电源提供电子，使被保护金属表面处于电子过剩状态，抑制其失电子（氧化）。

应用：大型钢结构（桥梁、水库闸门、输油管道）。

阳极（惰性，如石墨）：$\ce{2Cl- - 2e- -> Cl2}$ 或 $\ce{4OH- - 4e- -> O2 + 2H2O}$

阴极（被保护的 $\ce{Fe}$）：$\ce{O2 + 2H2O + 4e- -> 4OH-}$（外加电子使 $\ce{Fe}$ 不氧化）

**两种电化学保护法的比较**

| 方法 | 牺牲阳极法 | 外加电流法 |
|------|-----------|-----------|
| 原理 | 原电池原理 | 电解池原理 |
| 电源 | 无需外接电源 | 需要直流电源 |
| 被保护金属 | 原电池正极 | 电解池阴极 |
| 辅助电极 | 更活泼的金属（被消耗） | 惰性电极（不被消耗） |
| 适用范围 | 小型结构、分散设备 | 大型结构、集中管理 |

#### 3.3.4 改变环境条件

- **干燥存放**：降低湿度，减少电解质溶液的形成
- **除氧**：锅炉用水除氧处理，防止吸氧腐蚀
- **添加缓蚀剂**：在介质中加入少量能抑制腐蚀的物质（如磷酸盐、铬酸盐）

## 4. 【知识串联】电化学知识网络

### 4.1 与氧化还原反应的联系（本质联系）

氧化还原反应：$\ce{氧化剂 + 还原剂 -> 还原产物 + 氧化产物}$

电化学装置将该反应拆解为两个半反应：

- 负极（阳极）：还原剂 $\rightarrow$ 氧化产物 $+ \ ne-$（氧化半反应）
- 正极（阴极）：氧化剂 $+ \ ne- \rightarrow$ 还原产物（还原半反应）

氧化还原反应的电子转移在电化学装置中具有了**方向性**（外电路中从高电势到低电势）和**可计量性**（通过电量 $Q = nF$）。

氧化还原反应的规律在电化学中完全适用：

- 氧化性：$\ce{氧化剂}$ > $\ce{氧化产物}$
- 还原性：$\ce{还原剂}$ > $\ce{还原产物}$
- 电极电势：$\varphi_{氧化剂/还原产物}$ > $\varphi_{氧化产物/还原剂}$

### 4.2 与化学平衡的联系

对于可逆电池反应：

$$\Delta G = \Delta G^\ominus + RT \ln Q = -nFE$$

$$\Delta G^\ominus = -nFE^\ominus = -RT \ln K^\ominus$$

由此得到：

$$E = E^\ominus - \frac{RT}{nF} \ln Q = E^\ominus - \frac{0.0592}{n} \lg Q$$

此式即为能斯特方程的电池形式。当 $Q = K^\ominus$ 时，$E = 0$，反应达到平衡；当 $Q < K^\ominus$ 时，$E > 0$，反应正向自发进行；当 $Q > K^\ominus$ 时，$E < 0$，反应逆向自发进行。

这一关系说明：**电池的电动势随反应进行而降低，当电动势降至零时，电池"耗尽"**。

### 4.3 与热力学第一定律的联系

电化学过程中能量的严格定量关系：

$$\Delta G = -nFE$$

$$\Delta H = -nFE + nFT\left(\frac{\partial E}{\partial T}\right)_p$$

$$\Delta S = nF\left(\frac{\partial E}{\partial T}\right)_p$$

在恒温恒压可逆条件下，电池输出的最大电功：

$$W_{电,max} = -\Delta G = nFE$$

此即原电池将化学能转化为电能的理论上限。

### 4.4 与生产生活的联系

| 应用领域 | 涉及原理 | 典型实例 |
|---------|---------|---------|
| 化学电源 | 原电池原理 | 干电池、锂电池、燃料电池 |
| 金属冶炼 | 电解原理 | 电解铝、电解铜、电解钠 |
| 材料加工 | 电解原理 | 电镀、电铸、电解抛光 |
| 化工生产 | 电解原理 | 氯碱工业、电解水制氢 |
| 环境保护 | 电解原理 | 电渗析淡化、电浮选除污 |
| 金属防护 | 电化学腐蚀与保护 | 牺牲阳极、外加电流保护 |
| 生物体系 | 氧化还原与电子传递 | 细胞呼吸、光合作用 |

## 5. 【隐性考点】高考常见隐性考点深度解析

### 5.1 复杂电极反应式的书写

**考点特征**：给定复杂氧化还原反应，要求书写特定介质中的电极反应式。

**示例**：肼（$\ce{N2H4}$）-空气燃料电池（碱性介质）

总反应：$\ce{N2H4 + O2 -> N2 + 2H2O}$

负极分析：$\ce{N2H4}$ 中 $\ce{N}$ 为 $-2$ 价，产物 $\ce{N2}$ 中 $\ce{N}$ 为 $0$ 价，每个 $\ce{N}$ 失 $2$ 个电子，共失 $4$ 个电子。

负极：$\ce{N2H4 + 4OH- - 4e- -> N2 + 4H2O}$

正极：$\ce{O2 + 2H2O + 4e- -> 4OH-}$

验证：负极失 $4e-$，正极得 $4e-$，电子守恒；原子守恒；碱性介质中用 $\ce{OH-}$ 配平。

### 5.2 燃料电池在不同介质中的电极反应差异

以乙醇燃料电池为例：

**酸性介质**：

负极：$\ce{C2H5OH + 3H2O - 12e- -> 2CO2 + 12H+}$

正极：$\ce{3O2 + 12H+ + 12e- -> 6H2O}$

**碱性介质**：

负极：$\ce{C2H5OH + 16OH- - 12e- -> 2CO^{2-}_3 + 11H2O}$

注意：碱性条件下 $\ce{CO2}$ 不能与 $\ce{OH-}$ 共存，产物为 $\ce{CO^{2-}_3}$。

正极：$\ce{3O2 + 6H2O + 12e- -> 12OH-}$

**熔融碳酸盐介质**（$\ce{CO^{2-}_3}$ 传导）：

负极：$\ce{C2H5OH + 6CO^{2-}_3 - 12e- -> 8CO2 + 3H2O}$

正极：$\ce{3O2 + 6CO2 + 12e- -> 6CO^{2-}_3}$

**固体氧化物介质**（$\ce{O^{2-}}$ 传导）：

负极：$\ce{C2H5OH + 6O^{2-} - 12e- -> 2CO2 + 3H2O}$

正极：$\ce{3O2 + 12e- -> 6O^{2-}}$

### 5.3 电解计算中的电子守恒法

**核心公式链**：

$$n(e^-) = \frac{Q}{F} = \frac{I \cdot t}{F} = n_{阴极得电子} = n_{阳极失电子}$$

**多池串联**：通过的电子数相等。

**分阶段电解**：电解质溶液中离子浓度随电解进行而变化，可能发生阶段性电极反应变化。

**示例**：用惰性电极电解 $\ce{CuSO4}$ 和 $\ce{NaCl}$ 的混合溶液。

阳极放电顺序：$\ce{Cl-}$ > $\ce{OH-}$ > $\ce{SO^{2-}_4}$，先 $\ce{Cl-}$ 放电，后 $\ce{OH-}$ 放电。

阴极放电顺序：$\ce{Cu^{2+}}$ > $\ce{H+}$，先 $\ce{Cu^{2+}}$ 放电，后 $\ce{H+}$ 放电。

### 5.4 腐蚀速率的比较与影响因素

影响腐蚀速率的因素：

1. **电解质溶液的浓度与导电性**：导电性越强，腐蚀越快
2. **氧气的浓度与流速**：吸氧腐蚀中，氧气是反应物
3. **温度**：温度升高加速腐蚀
4. **金属纯度**：含杂质越多，形成微电池越多，腐蚀越快
5. **pH值**：酸性增强促进析氢腐蚀
6. **应力状态**：应力集中处电位较低，易形成腐蚀电池

## 6. 【易错警示】学生常见错误深度剖析

### 易错点一：混淆原电池与电解池中离子的移动方向

| 离子类型 | 原电池中 | 电解池中 |
|---------|---------|---------|
| 阳离子 | 向正极移动 | 向阴极移动 |
| 阴离子 | 向负极移动 | 向阳极移动 |

**本质理解**：离子移动方向始终遵循"异性相吸"——阳离子向发生还原反应的电极移动（该电极带负电或相对电势低），阴离子向发生氧化反应的电极移动（该电极带正电或相对电势高）。

在原电池中：负极失电子带正电，吸引阴离子；正极得电子带负电，吸引阳离子。

在电解池中：阴极与电源负极相连，外电路输入电子使阴极带负电，吸引阳离子；阳极与电源正极相连，失去电子使阳极带正电，吸引阴离子。

### 易错点二：忽略介质对电极反应的影响

同一燃料在不同介质中，电极反应式完全不同：

**根本原因**：电极反应必须满足原子守恒和电荷守恒，不同介质中可参与平衡的离子不同（酸性用 $\ce{H+}$，碱性用 $\ce{OH-}$）。

**检验方法**：将正、负极反应式相加，看是否得到正确的总反应式，且总反应式应与介质条件一致（如在碱性介质中不应出现 $\ce{H+}$）。

### 易错点三：混淆电化学腐蚀的两种类型

| 错误认知 | 正确理解 |
|---------|---------|
| "金属腐蚀都产生 $\ce{H2}$" | 只有析氢腐蚀产生 $\ce{H2}$，吸氧腐蚀消耗 $\ce{O2}$ 产生 $\ce{OH-}$ |
| "铁锈就是 $\ce{Fe2O3}$" | 铁锈是水合氧化铁 $\ce{Fe2O3 \cdot nH2O}$，是吸氧腐蚀的最终产物 |
| "纯铁不生锈" | 纯铁腐蚀慢但仍会腐蚀（表面可形成局部电池） |

### 易错点四：活性电极与惰性电极的区分

**惰性电极**（石墨、$\ce{Pt}$、$\ce{Au}$）：不参与反应，仅起导电作用，离子按放电顺序放电。

**活性电极**（常见金属，除 $\ce{Pt}$、$\ce{Au}$ 外）：阳极时金属本身优先溶解（$\ce{M -> M^{n+} + ne-}$），而非溶液中阴离子放电。

**典型错误**：用 $\ce{Cu}$ 作阳极电解 $\ce{Na2SO4}$ 溶液，误以为阳极产生 $\ce{O2}$。实际上 $\ce{Cu}$ 优先溶解。

### 易错点五：可充电电池的充放电电极名称混淆

放电时（原电池模式）：负极（氧化）、正极（还原）

充电时（电解池模式）：阴极（还原）、阳极（氧化）

对于同一电极：

- 放电时的**负极** $\ce{Li_xC6}$ $\xrightarrow{充电}$ 电解池的**阴极**
- 放电时的**正极** $\ce{Li_{1-x}CoO2}$ $\xrightarrow{充电}$ 电解池的**阳极**

充电时反应逆向进行，但电极名称改变。

### 易错点六：原电池中"活泼金属一定作负极"的绝对化

反例一：$\ce{Mg}$-$\ce{Al}$-NaOH 溶液原电池

$\ce{Mg}$ 与 NaOH 不反应，$\ce{Al}$ 与 NaOH 反应：$\ce{2Al + 2OH- + 2H2O -> 2AlO^-2 + 3H2 ^}$

负极：$\ce{Al}$（虽然 $\ce{Mg}$ 更活泼，但 $\ce{Mg}$ 不参与反应）

正极：$\ce{Mg}$

反例二：钝化金属（如 $\ce{Al}$ 在浓硝酸中）

$\ce{Al}$ 被钝化，此时 $\ce{Cu}$ 与浓硝酸反应，$\ce{Cu}$ 作负极。

## 7. 【思想方法】电化学中的核心思想方法

### 7.1 氧化还原思想

电化学是氧化还原反应的**具体化和定量化**。全部电化学分析的核心是：

1. **判断氧化与还原**：失电子为氧化，得电子为还原
2. **确定电子转移数**：根据化合价变化计算
3. **比较氧化还原能力**：电极电势高者氧化能力强
4. **书写半反应**：分别表示氧化过程和还原过程

### 7.2 能量转化思想

电化学过程的本质是化学能与电能的相互转化：

$$\text{化学能} \underset{\text{充电（电解）}}{\stackrel{\text{放电（原电池）}}{\rightleftharpoons}} \text{电能}$$

转化的定量关系由 $\Delta G = -nFE$ 严格确定。自发过程（$\Delta G < 0$，$E > 0$）释放电能；非自发过程（$\Delta G > 0$，$E < 0$）需要输入电能驱动。

能量转化效率：

$$\eta = \frac{W_{实际}}{W_{理论,max}} = \frac{W_{实际}}{nFE}$$

实际效率受内阻、过电位等因素影响，总是小于100%。

### 7.3 守恒思想（电子守恒）

电子守恒是电化学计算的根本原则：

$$n_{失电子} = n_{得电子} = n_{通过电路的电子}$$

具体表达：

$$\sum_i n_i \cdot z_i = \sum_j n_j \cdot z_j$$

其中 $n_i$ 为物质的量，$z_i$ 为转移电子数。

应用电子守恒法进行电解计算时，不需要写出每一步的中间产物，只需抓住"电子得失总数相等"这一核心关系即可快速求解。

### 7.4 模型化思想

1. **半反应模型**：将复杂的氧化还原反应分解为两个半反应分别分析
2. **原电池模型**：将金属腐蚀理解为无数个微电池的共同作用
3. **电极电势模型**：用电极电势的大小关系判断反应方向和放电顺序
4. **等效电路模型**：将电化学体系抽象为具有内阻、电动势的电路进行分析

### 7.5 辩证统一思想

- 原电池与电解池的辩证统一：同一装置在不同条件下可扮演不同角色（二次电池）
- 腐蚀与防护的辩证关系：腐蚀是自发趋势，防护是人为干预
- 理论与实际的统一：理论电极电势与实际过电位的差异体现了热力学与动力学的统一
