# 第七章 有机化合物

> **本章地位**：本章是人教版高中化学必修第二册的收官章节，是从无机化学向有机化学过渡的关键桥梁。学生通过本章学习，初步建立"结构决定性质"的有机化学核心观念，为选择性必修《有机化学基础》奠定认知基础。

## 一、来龙去脉：从无机到有机——有机化学的诞生与发展

### 1.1 "生命力论"的破产与有机化学的诞生

19世纪以前，化学家将化合物分为两大类：
- **无机物**：可从矿物中获得，如食盐(NaCl)、硫酸(H$_2$SO$_4$)等
- **有机物**：只能从动植物等**有生命**的有机体中获得，如尿素、油脂、糖类等

当时流行**"生命力论"**(Vitalism)，认为有机物中含有一种神秘的"生命力"，无法通过人工方法从无机物合成。

**里程碑事件——1828年，维勒(Frédéric Wöhler)合成尿素**：

$$\text{NH}_4\text{CN}O \xrightarrow{\Delta} \text{CO}(\text{NH}_2)_2$$

维勒在加热氰酸铵(NH$_4$CNO)时，意外得到了尿素——一种典型的有机物。这一发现打破了"生命力论"的桎梏，证明了无机物可以转化为有机物，标志着**有机化学作为一门独立学科正式诞生**。

> **启示**：科学理论需要接受实验的检验，"生命力"这种不可证伪的概念终将被淘汰。

### 1.2 有机化学的定义演变

| 时期 | 定义 | 局限 |
|------|------|------|
| 19世纪初 | 只能来自生物体的化合物 | 维勒实验后被否定 |
| 19世纪中 | 含碳的化合物 | CO、CO$_2$、碳酸盐等仍归属无机 |
| 现代 | **含碳化合物**(除碳的氧化物、碳酸、碳酸盐、氰化物等少数物质外) | 沿用至今 |

### 1.3 为什么有机物种类如此繁多？——碳的四价键合特性

有机物种类超过3000万种，远超无机物，根本原因在于**碳原子的独特结构**：

**（1）四价成键特性**

碳原子最外层有4个电子，既不易失去也不易得到电子，主要通过**共价键**与其他原子结合：

- 可形成**4个共价键**，达到8电子稳定结构
- 可与**自身**（碳碳键）或其他原子（H、O、N、S、卤素等）成键

**（2）碳骨架的多样性**

碳原子之间可以形成：

| 键型 | 结构示意 | 特点 |
|------|----------|------|
| 碳碳单键(C—C) | 饱和链/环 | 可旋转，构象多样 |
| 碳碳双键(C=C) | 平面结构 | 不能旋转，有顺反异构 |
| 碳碳三键(C≡C) | 直线结构 | 键长短，键能大 |
| 碳环结构 | 三元环~六元环等 | 环张力与稳定性并存 |

**（3）同分异构现象的普遍存在**

相同数目的碳原子可以通过不同的连接方式形成不同的骨架，产生**同分异构体**。

> **核心结论**：有机物的多样性 = 碳的四价特性 × 碳骨架多样性 × 同分异构现象

## 二、基础精讲

### 7.1 认识有机化合物

#### 1. 有机物的特点

| 比较维度 | 有机物 | 无机物 |
|----------|--------|--------|
| **组成元素** | 主要含C、H，常含O、N、S、P、卤素 | 百余种元素均可 |
| **化学键** | 主要为共价键 | 离子键、共价键均有 |
| **结构** | 结构复杂，同分异构普遍 | 结构相对简单 |
| **溶解性** | 多数难溶于水，易溶于有机溶剂 | 多数易溶于水 |
| **熔沸点** | 多数较低(分子晶体) | 多数较高(离子晶体) |
| **导电性** | 多数为非电解质，不导电 | 多为电解质，熔融或溶于水可导电 |
| **反应特点** | 反应复杂、副反应多、速率慢、常需催化剂 | 反应简单、速率快、副反应少 |
| **表示方法** | 需用结构式、结构简式表示 | 分子式往往足以确定物质 |

#### 2. 碳骨架——有机物的"骨架系统"

有机物的碳骨架可分为：

```
链状骨架：CH₃—CH₂—CH₂—CH₃ (正丁烷)
         CH₃—CH(CH₃)—CH₃ (异丁烷)

环状骨架：  △  环丙烷    ◇  环丁烷
           ⬡  环己烷    ⬠  苯环(特殊环)
```

**碳骨架类型总结**：

| 类型 | 示例 | 特点 |
|------|------|------|
| 直链 | 正丁烷 CH₃CH₂CH₂CH₃ | 锯齿形排布 |
| 支链 | 异丁烷 (CH₃)₃CH | 有侧链取代基 |
| 环状 | 环己烷 C₆H₁₂ | 闭合碳环 |
| 芳香环 | 苯 C₆H₆ | 特殊稳定结构 |

#### 3. 同分异构体——有机化学的核心概念

**定义**：分子式相同，但结构不同的化合物互称为**同分异构体**。

**本质**：分子中原子的**连接顺序**或**空间排布**不同。

**分类体系**：

```
同分异构体
├── 构造异构(结构异构)
│   ├── 碳链异构：碳骨架不同
│   │       例：正丁烷 CH₃CH₂CH₂CH₃ 与 异丁烷 (CH₃)₂CHCH₃
│   ├── 位置异构：官能团位置不同
│   │       例：1-丙醇 CH₃CH₂CH₂OH 与 2-丙醇 CH₃CH(OH)CH₃
│   └── 官能团异构：官能团类别不同
│           例：乙醇 CH₃CH₂OH 与 二甲醚 CH₃OCH₃
└── 立体异构(选修内容)
    ├── 顺反异构
    └── 对映异构(手性异构)
```

**书写方法——"减碳法"（以烷烃为例）**：

1. **写出最长碳链**的直链结构
2. **逐次减少主链碳原子**，将减少的碳作为**甲基**支链连接在剩余碳链上
3. 注意避免重复（利用**对称性**判断等效位置）

**例题**：写出C₅H₁₂的所有同分异构体

```
① 正戊烷：CH₃—CH₂—CH₂—CH₂—CH₃  (最长链5个C)
② 异戊烷：CH₃—CH₂—CH(CH₃)—CH₃  (最长链4个C，甲基在2号位)
③ 新戊烷：(CH₃)₄C  即 C(CH₃)₄      (最长链3个C，两个甲基在2号位)
```

> **注意**：书写同分异构体时，主链选择要遵循"**最长碳链**"原则，编号要遵循"**最低系列**"原则（使取代基位次和最小）。

#### 4. 官能团——决定有机物性质的"功能基团"

**定义**：决定有机化合物**特殊性质**的原子或原子团。

**核心思想**：**官能团决定性质**。有机物发生什么反应，主要由其含有的官能团决定。

| 有机物类别 | 官能团 | 官能团名称 | 典型代表 | 主要化学性质 |
|------------|--------|------------|----------|--------------|
| 烷烃 | — | 无(仅C—C、C—H) | 甲烷CH₄ | 取代反应 |
| 烯烃 | C=C | 碳碳双键 | 乙烯CH₂=CH₂ | 加成反应、加聚反应、氧化反应 |
| 炔烃 | C≡C | 碳碳三键 | 乙炔CH≡CH | 加成反应、加聚反应 |
| 芳香烃 | — | 苯环(特殊结构) | 苯C₆H₆ | 取代、加成(难) |
| **醇** | —OH | **羟基**(与链烃基相连) | 乙醇C₂H₅OH | 取代、氧化、消去 |
| **酚** | —OH | **羟基**(与苯环直接相连) | 苯酚C₆H₅OH | 弱酸性、显色反应 |
| **羧酸** | —COOH | **羧基** | 乙酸CH₃COOH | 酸性、酯化反应 |
| **酯** | —COOR | **酯基** | 乙酸乙酯CH₃COOC₂H₅ | 水解反应 |
| 醛 | —CHO | 醛基 | 乙醛CH₃CHO | 氧化、还原 |
| 酮 | —CO— | 羰基 | 丙酮CH₃COCH₃ | 还原反应 |
| 醚 | —O— | 醚键 | 乙醚C₂H₅OC₂H₅ | 较稳定 |
| 卤代烃 | —X | 卤素原子 | 溴乙烷C₂H₅Br | 取代(水解)、消去 |

> **关键区分**：羟基(—OH)连接在**链烃基**上为醇，连接在**苯环**上为酚，二者性质差异显著。

#### 5. 系统命名法初步——烷烃的命名

**命名步骤口诀**："**选主链，称某烷；编号位，定支链；取代基，写在前；标位置，短线连；不同基，简到繁；相同基，合并算**"

**具体步骤**：

1. **选主链**：选择**最长**的碳链作为主链，按碳原子数称为"某烷"
   - 1~10个碳：甲、乙、丙、丁、戊、己、庚、辛、壬、癸
   - 10个以上：十一烷、十二烷...

2. **编序号**：从**离支链最近**的一端开始编号，使支链位次尽可能小

3. **写名称**：取代基位置 + 取代基名称 + 母体名称

**示例**：命名下列化合物

```
    CH₃
     \vert
CH₃—C—CH₂—CH—CH₃
     \|      \|
     CH₃      CH₃
```

解析：
- 最长碳链有**5个碳** → 主链为"戊烷"
- 编号从左或从右？右侧两个甲基更近 → 从右编号：1, 2, 4位有甲基
- 名称：**2,2,4-三甲基戊烷**

### 7.2 乙烯与有机高分子材料

#### 1. 乙烯的结构——平面型分子

| 项目 | 内容 |
|------|------|
| **分子式** | C₂H₄ |
| **结构式** | H—C=C—H (每个C还连两个H，平面结构) |
| **结构简式** | CH₂=CH₂ |
| **电子式** | H:C::C:H (每个C还有2个H) |
| **空间构型** | **平面形**，6个原子共平面 |
| **键角** | 约120° |
| **键能** | C=C键能(615 kJ/mol) < 2×C—C键能(2×347 kJ/mol) |

**结构要点**：

- 碳碳双键由**1个σ键**和**1个π键**组成
- **π键**的电子云分布在双键平面的上下两侧，受原子核束缚较弱
- π键键能较小，容易断裂，这是乙烯**化学性质活泼**的根本原因

#### 2. 乙烯的化学性质——以加成反应为核心

##### (1) 氧化反应

**① 燃烧**：火焰明亮，伴有黑烟（含碳量较高）

$$\text{CH}_2=\text{CH}_2 + 3\text{O}_2 \xrightarrow{\text{点燃}} 2\text{CO}_2 + 2\text{H}_2\text{O}$$

**② 被酸性KMnO₄氧化**：乙烯使酸性高锰酸钾溶液**褪色**（氧化反应，非加成）

$$5\text{CH}_2=\text{CH}_2 + 12\text{KMnO}_4 + 18\text{H}_2\text{SO}_4 \rightarrow 10\text{CO}_2 + 12\text{MnSO}_4 + 6\text{K}_2\text{SO}_4 + 28\text{H}_2\text{O}$$

> **应用**：可用酸性KMnO₄或溴水鉴别甲烷(不能使二者褪色)和乙烯(可使二者褪色)。
> **注意**：酸性KMnO₄鉴别乙烯会产生CO₂，若后续需检验乙烯，会引入杂质。

##### (2) 加成反应——乙烯的标志性反应

**定义**：有机物分子中**不饱和键(双键或三键)两端的原子**，与其他原子或原子团**直接结合**生成新化合物的反应。

**反应机理**：双键中的**π键断裂**，双键变为单键，两端碳原子各连接一个新的原子或原子团。

$$\text{CH}_2=\text{CH}_2 + \text{X}_2 \longrightarrow \text{CH}_2\text{X}—\text{CH}_2\text{X}$$

| 试剂 | 反应条件 | 产物 | 现象/应用 |
|------|----------|------|-----------|
| Br₂(溴水) | 常温 | 1,2-二溴乙烷 | 溴水**褪色**，用于检验双键 |
| H₂ | 催化剂(Ni/Pt/Pd)、加热 | 乙烷 | 催化加氢(还原) |
| HCl | 催化剂 | 氯乙烷 | 制备卤代烃 |
| H₂O | 催化剂、加热加压 | **乙醇** | 工业制乙醇 |

**与溴水加成（重点）**：

$$\text{CH}_2=\text{CH}_2 + \text{Br}_2 \longrightarrow \text{CH}_2\text{Br}—\text{CH}_2\text{Br}$$

> **实验现象**：溴水或溴的CCl₄溶液的红棕色**褪去**，溶液分层（1,2-二溴乙烷为无色液体，密度大于水）。
> **反应类型**：**加成反应**，不是取代反应（无需光照，产物唯一）。

##### (3) 加聚反应——形成高分子

**定义**：由不饱和的单体通过**加成反应**相互结合生成高分子化合物的反应。

$$n\text{CH}_2=\text{CH}_2 \xrightarrow{\text{催化剂}} \left[—\text{CH}_2—\text{CH}_2—\right]_n$$

- **单体**：CH₂=CH₂（乙烯）
- **链节**：—CH₂—CH₂—
- **聚合度**：n（正整数，数值很大，不确定）
- **高分子**：聚乙烯

#### 3. 烯烃的同系物与通性

| 项目 | 内容 |
|------|------|
| **定义** | 结构相似，分子组成上相差一个或若干个CH₂原子团的物质 |
| **通式** | CₙH₂ₙ (n≥2) |
| **代表** | 乙烯(C₂H₄)、丙烯(C₃H₆)、丁烯(C₄H₈) |
| **共性** | 都含C=C，都能发生加成、加聚、氧化反应 |

#### 4. 有机高分子材料

##### (1) 高分子化合物的特征

| 特征 | 说明 |
|------|------|
| **相对分子质量** | 很大，通常在10⁴~10⁶以上 |
| **结构特点** | 由重复的结构单元(链节)组成 |
| **n值** | n为**平均聚合度**，每个分子的n值不同，故高分子化合物是混合物 |
| **分类** | 天然高分子(淀粉、纤维素、蛋白质、天然橡胶) vs 合成高分子 |

##### (2) 三大合成材料

| 类别 | 代表物质 | 单体 | 链节 | 应用 |
|------|----------|------|------|------|
| **塑料** | 聚乙烯(PE) | CH₂=CH₂ | —CH₂—CH₂— | 食品包装膜 |
| | 聚氯乙烯(PVC) | CH₂=CHCl | —CH₂—CHCl— | 管道、型材 |
| | 聚苯乙烯(PS) | CH₂=CH(C₆H₅) | —CH₂—CH(C₆H₅)— | 泡沫塑料 |
| **合成纤维** | 涤纶(聚酯纤维) | 对苯二甲酸+乙二醇 | 复杂酯链 | 服装面料 |
| | 尼龙(聚酰胺) | 己二酸+己二胺 | 酰胺键连接 | 绳索、丝袜 |
| **合成橡胶** | 顺丁橡胶 | CH₂=CH—CH=CH₂ | —CH₂—CH=CH—CH₂— | 轮胎 |
| | 丁苯橡胶 | 丁二烯+苯乙烯 | 混合链节 | 轮胎 |

> **注意**：塑料 = 合成树脂 + 添加剂（增塑剂、防老剂、着色剂等）

##### (3) 加聚反应 vs 缩聚反应（本节拓展，与后续衔接）

| 比较项目 | **加聚反应** | **缩聚反应** |
|----------|--------------|--------------|
| **单体特征** | 含不饱和键(C=C、C≡C等) | 含两个或以上官能团(—OH、—COOH、—NH₂等) |
| **产物** | 仅生成高分子 | 生成高分子 + 小分子(H₂O、HCl等) |
| **化学键变化** | 不饱和键断裂，彼此连接 | 官能团之间反应，脱去小分子 |
| **示例** | 乙烯→聚乙烯 | 乙二酸+乙二醇→聚酯 + H₂O |
| **方程式特点** | 不需要写小分子 | 必须写脱去的小分子 |

> **本章重点**：加聚反应。缩聚反应在后续学习涤纶、尼龙时涉及，选择性必修会深入讲解。

### 7.3 乙醇与乙酸

#### 1. 乙醇——重要的含氧衍生物

##### (1) 物理性质

| 性质 | 数据/描述 |
|------|-----------|
| 状态 | 无色透明液体 |
| 气味 | 特殊香味 |
| 沸点 | 78.5 °C |
| 密度 | 0.789 g/cm³ (比水小) |
| 溶解性 | **与水任意比互溶**（因含—OH，可与水形成氢键） |
| 医用消毒 | 75%(体积分数)乙醇杀菌效果最佳 |

##### (2) 分子结构

| 项目 | 内容 |
|------|------|
| 分子式 | C₂H₆O |
| 结构简式 | CH₃CH₂OH 或 C₂H₅OH |
| 官能团 | **—OH（羟基）** |
| 结构特点 | 可看作乙烷中1个H被—OH取代；O—H键极性强，易断裂 |

##### (3) 化学性质

**① 与活泼金属反应（取代反应）**

$$2\text{CH}_3\text{CH}_2\text{OH} + 2\text{Na} \longrightarrow 2\text{CH}_3\text{CH}_2\text{ONa} + \text{H}_2\uparrow$$

> **现象**：钠沉于底部，缓慢反应产生气泡（比钠与水反应**平缓得多**）。
> **结论**：乙醇中O—H的H活性**弱于水**中H的活性（因乙基是推电子基，使O—H键极性减弱）。

**② 氧化反应**

**(a) 燃烧**：

$$\text{C}_2\text{H}_5\text{OH} + 3\text{O}_2 \xrightarrow{\text{点燃}} 2\text{CO}_2 + 3\text{H}_2\text{O}$$

**(b) 催化氧化**（**重点**）：

$$2\text{CH}_3\text{CH}_2\text{OH} + \text{O}_2 \xrightarrow{\text{Cu或Ag}, \Delta} 2\text{CH}_3\text{CHO} + 2\text{H}_2\text{O}$$

- **反应实质**：去氢氧化（脱去与—OH相连C上的1个H和—OH中的H）
- **现象**：铜丝先灼烧变黑(Cu→CuO)，插入乙醇后变红(CuO被还原为Cu)，产生刺激性气味（乙醛）
- **产物**：**乙醛(CH₃CHO)**，含**醛基(—CHO)**

> **反应机理**：
> $2\text{Cu} + \text{O}_2 \xrightarrow{\Delta} 2\text{CuO}$
> $\text{CH}_3\text{CH}_2\text{OH} + \text{CuO} \xrightarrow{\Delta} \text{CH}_3\text{CHO} + \text{Cu} + \text{H}_2\text{O}$
> Cu在反应中作**催化剂**（参与中间过程，最终复原）。

**(c) 被强氧化剂氧化**：乙醇可被酸性KMnO₄或酸性K₂Cr₂O₇直接氧化为**乙酸**。

$$\text{CH}_3\text{CH}_2\text{OH} \xrightarrow{[\text{O}]} \text{CH}_3\text{CHO} \xrightarrow{[\text{O}]} \text{CH}_3\text{COOH}$$

> **应用**：交警用**重铬酸钾检测仪**检验酒驾，橙色的K₂Cr₂O₇被还原为绿色的Cr³⁺。

**③ 消去反应（实验室制乙烯）**

$$\text{CH}_3\text{CH}_2\text{OH} \xrightarrow{\text{浓H}_2\text{SO}_4, 170^\circ\text{C}} \text{CH}_2=\text{CH}_2\uparrow + \text{H}_2\text{O}$$

- **条件**：浓H₂SO₄作催化剂和脱水剂，温度**170 °C**
- **机理**：从相邻两个碳上脱去—OH和1个H（β-H），形成双键
- **副反应**：温度在140 °C时发生**分子间脱水**生成乙醚：

$$2\text{CH}_3\text{CH}_2\text{OH} \xrightarrow{\text{浓H}_2\text{SO}_4, 140^\circ\text{C}} \text{CH}_3\text{CH}_2\text{OCH}_2\text{CH}_3 + \text{H}_2\text{O}$$

> **关键控制**：温度计水银球插入反应液中，控制温度**迅速升至170 °C**，避免在140 °C停留过久。

#### 2. 乙酸——羧酸类的代表

##### (1) 物理性质

| 性质 | 数据/描述 |
|------|-----------|
| 状态 | 无色液体 |
| 气味 | 强烈刺激性气味(纯醋酸称"冰醋酸") |
| 沸点 | 118 °C |
| 熔点 | 16.6 °C (低于此温度凝结成冰状晶体) |
| 溶解性 | 与水任意比互溶 |

##### (2) 分子结构

| 项目 | 内容 |
|------|------|
| 分子式 | C₂H₄O₂ |
| 结构简式 | CH₃COOH |
| 官能团 | **—COOH（羧基）** |
| 结构特点 | 羧基中C=O和O—H相互作用，使O—H极性增强，易电离出H⁺ |

##### (3) 弱酸性

乙酸是**一元弱酸**，酸性：CH₃COOH > H₂CO₃ > C₆H₅OH > H₂O > C₂H₅OH

| 反应 | 方程式 |
|------|--------|
| 与指示剂 | 使紫色石蕊试液变红 |
| 与活泼金属 | 2CH₃COOH + 2Na → 2CH₃COONa + H₂↑ |
| 与碱 | CH₃COOH + NaOH → CH₃COONa + H₂O |
| 与碱性氧化物 | 2CH₃COOH + CuO → (CH₃COO)₂Cu + H₂O |
| 与弱酸盐 | 2CH₃COOH + Na₂CO₃ → 2CH₃COONa + H₂O + CO₂↑ |

> **证明乙酸强于碳酸**：CH₃COOH能与Na₂CO₃反应放出CO₂，而H₂CO₃是产物。

#### 3. 酯化反应——可逆反应的典型

##### (1) 反应方程式

$$\text{CH}_3\text{COOH} + \text{C}_2\text{H}_5\text{OH} \underset{\Delta}{\stackrel{\text{浓H}_2\text{SO}_4}{\rightleftharpoons}} \text{CH}_3\text{COOC}_2\text{H}_5 + \text{H}_2\text{O}$$

| 项目 | 说明 |
|------|------|
| **反应类型** | 取代反应（羧酸脱—OH，醇脱—H） |
| **反应本质** | 酸脱羟基，醇脱氢 |
| **条件** | 浓H₂SO₄、加热 |
| **可逆性** | **可逆反应**，用"⇌"表示 |
| **浓H₂SO₄作用** | ① **催化剂** ② **吸水剂**（吸收生成的水，使平衡右移） |

##### (2) 反应机理（同位素示踪验证）

用¹⁸O标记乙醇中的氧：

$$\text{CH}_3\text{COOH} + \text{C}_2\text{H}_5^{18}\text{OH} \rightleftharpoons \text{CH}_3\text{CO}^{18}\text{OC}_2\text{H}_5 + \text{H}_2\text{O}$$

实验发现¹⁸O出现在酯中而非水中，证明：**羧酸脱羟基，醇脱氢**。

##### (3) 提高产率的措施（勒夏特列原理的应用）

| 措施 | 原理 |
|------|------|
| 浓H₂SO₄吸收水 | 减少生成物浓度，平衡右移 |
| 乙醇过量 | 增加廉价反应物浓度，平衡右移 |
| 加热 | 适当升温加快反应速率 |
| 蒸出产物 | 分离酯和水，使平衡持续右移(工业上) |

##### (4) 酯的水解——逆反应

$$\text{CH}_3\text{COOC}_2\text{H}_5 + \text{H}_2\text{O} \underset{\Delta}{\stackrel{\text{稀酸或碱}}{\rightleftharpoons}} \text{CH}_3\text{COOH} + \text{C}_2\text{H}_5\text{OH}$$

| 条件 | 特点 |
|------|------|
| **酸性水解** | 可逆反应，稀H₂SO₄作催化剂 |
| **碱性水解** | 不可逆（NaOH中和生成的酸，使平衡不断右移），又称**皂化反应**（油脂在碱性条件下水解） |

### 7.4 基本营养物质

> **衔接**：糖类、油脂、蛋白质都是天然有机高分子（除单糖、二糖和低聚糖外），是生命活动不可缺少的物质，也是人类食物的主要成分。

#### 1. 糖类——"碳水化合物"

**通式**：Cₙ(H₂O)ₘ（大多数符合，但脱氧核糖C₅H₁₀O₄、甲醛CH₂O等例外，故"碳水化合物"名称不科学，沿用至今）

##### (1) 分类体系

```
糖类
├── 单糖：不能水解的糖
│       葡萄糖 C₆H₁₂O₆、果糖 C₆H₁₂O₆、半乳糖
│       （互为同分异构体）
├── 二糖(低聚糖)：水解生成2分子单糖
│       蔗糖 C₁₂H₂₂O₁₁、麦芽糖 C₁₂H₂₂O₁₁
│       （互为同分异构体）
└── 多糖：水解生成多个单糖分子
        淀粉 (C₆H₁₀O₅)_n、纤维素 (C₆H₁₀O₅)_n
        （分子式形式相同，但n值不同，结构不同，不是同分异构体）
```

##### (2) 葡萄糖——最重要的单糖

| 项目 | 内容 |
|------|------|
| 分子式 | C₆H₁₂O₆ |
| 结构简式 | CH₂OH(CHOH)₄CHO |
| 官能团 | —OH（5个）、—CHO（1个） |
| 物理性质 | 白色晶体，易溶于水，有甜味 |

**化学性质**：
- **还原性**：含醛基(—CHO)，属于**还原糖**
  - 与银氨溶液反应：水浴加热产生**银镜**
  - 与新制Cu(OH)₂反应：加热产生**砖红色沉淀(Cu₂O)**
- **氧化反应**：人体中缓慢氧化提供能量

$$\text{C}_6\text{H}_{12}\text{O}_6 + 6\text{O}_2 \longrightarrow 6\text{CO}_2 + 6\text{H}_2\text{O} \quad \Delta H < 0$$

- **酯化反应**：含多个—OH，可与酸发生酯化
- **发酵反应**：

$$\text{C}_6\text{H}_{12}\text{O}_6 \xrightarrow{\text{酒化酶}} 2\text{C}_2\text{H}_5\text{OH} + 2\text{CO}_2\uparrow$$

##### (3) 蔗糖与麦芽糖

| 比较 | 蔗糖 | 麦芽糖 |
|------|------|--------|
| 分子式 | C₁₂H₂₂O₁₁ | C₁₂H₂₂O₁₁ |
| 来源 | 甘蔗、甜菜 | 淀粉水解产物 |
| 是否同分异构体 | **是** | — |
| 官能团 | 无醛基 | 有醛基 |
| 还原性 | **非还原糖** | **还原糖** |
| 水解产物 | 葡萄糖 + **果糖** | 葡萄糖 + **葡萄糖** |

##### (4) 淀粉与纤维素

| 比较 | 淀粉 | 纤维素 |
|------|------|--------|
| 分子式 | (C₆H₁₀O₅)_n | (C₆H₁₀O₅)_n |
| n值 | 较大，不定 | 更大，不定 |
| 是否同分异构体 | **不是**(n值不同) | — |
| 结构 | 直链淀粉 + 支链淀粉 | 直链，无支链 |
| 水解最终产物 | **葡萄糖** | **葡萄糖** |
| 人体消化 | 可被淀粉酶水解吸收 | **不能**（人体无纤维素酶） |
| 遇碘水 | **变蓝色** | 不变色 |

**淀粉水解的逐步过程**：

$$\text{淀粉} \xrightarrow{\text{部分水解}} \text{糊精} \xrightarrow{\text{进一步水解}} \text{麦芽糖} \xrightarrow{\text{完全水解}} \text{葡萄糖}$$

- **糊精**：淀粉初步水解产物，分子量较淀粉小，遇碘呈**红紫色**（非蓝色）
- 检验淀粉水解程度的方法：

| 实验操作 | 现象 | 结论 |
|----------|------|------|
| 取水解液，加碘水 | 变蓝 | 仍有淀粉未水解 |
| 取水解液，加NaOH调至碱性，加银氨溶液，水浴加热 | 产生银镜 | 已有葡萄糖生成 |

> **注意**：淀粉水解需用**稀H₂SO₄作催化剂**，水解后必须先加**NaOH中和酸**，再加银氨溶液检验，否则酸性环境会破坏银氨络离子。

> **核心考点**：淀粉遇碘变蓝是**物理变化**（碘分子嵌入淀粉螺旋结构中的**包合反应/包埋作用**），不是化学反应。

#### 2. 油脂——高级脂肪酸甘油酯

##### (1) 组成与结构

油脂是**高级脂肪酸**与**甘油（丙三醇）**形成的**酯**。

```
        CH₂—O—CO—R₁
         \vert
        CH—O—CO—R₂
         \vert
        CH₂—O—CO—R₃
```

- R₁、R₂、R₃：高级脂肪酸的烃基（可相同或不同）
- 若R为饱和烃基 → **脂肪**（动物油，常温固态）
- 若R含不饱和键 → **油**（植物油，常温液态）

##### (2) 重要化学性质

**① 水解反应**

$$\text{油脂} + 3\text{H}_2\text{O} \underset{\Delta}{\stackrel{\text{酸或碱}}{\rightleftharpoons}} \text{甘油} + 3\text{高级脂肪酸(盐)}$$

- **碱性水解** = **皂化反应** → 制肥皂

**② 氢化反应（油脂的硬化）**

液态植物油中的C=C与H₂加成，变为半固态脂肪：

$$\text{不饱和油脂} + \text{H}_2 \xrightarrow{\text{Ni}, \Delta} \text{人造脂肪(硬化油)}$$

- 应用：将植物油转化为人造黄油，便于储存和运输

##### (3) 油脂 vs 高分子化合物

> **易错警示**：油脂**不是高分子化合物**！
> - 油脂的相对分子质量通常在1000左右，远小于高分子的10⁴门槛
> - 油脂是小分子酯的聚集体（甘油三酯），不是由重复链节聚合而成

#### 3. 蛋白质——生命的物质基础

##### (1) 组成

- **元素组成**：C、H、O、N（特征元素）、S等
- **基本结构单元**：**氨基酸**
- 氨基酸通过**肽键(—CO—NH—)**连接成多肽，多肽卷曲折叠形成蛋白质

##### (2) 重要性质

| 性质 | 条件/试剂 | 现象 | 说明 |
|------|-----------|------|------|
| **盐析** | 加入浓(NH₄)₂SO₄或Na₂SO₄溶液 | 蛋白质析出，加水**可重新溶解** | **可逆过程**，物理变化，保持生理活性 |
| **变性** | 加热、强酸、强碱、重金属盐、紫外线、乙醇、甲醛 | 蛋白质凝固，加水**不溶解** | **不可逆过程**，化学变化，失去生理活性 |
| **显色反应** | 浓硝酸 | 蛋白质变**黄色** | 含苯环的蛋白质（如皮肤、指甲遇浓硝酸变黄） |
| **灼烧** | 火焰 | 有**烧焦羽毛气味** | 鉴别蛋白质 vs 合成纤维 |

> **盐析 vs 变性核心区别**：
> | | 盐析 | 变性 |
> |---|------|------|
> | 可逆性 | **可逆** | **不可逆** |
> | 本质 | 降低溶解度，物理变化 | 空间结构破坏，化学变化 |
> | 活性 | 保留 | 丧失 |
> | 应用 | 分离提纯蛋白质 | 消毒（酒精、高温） |

> **应用**：误食重金属盐可立即服用大量牛奶/蛋清，让蛋白质在消化道中变性，减少重金属离子吸收。

## 三、深度理解

### 3.1 乙烯加成反应机理——π键断裂，双变单

**微观过程**：

1. 乙烯分子中C=C双键由**1个σ键**（头碰头重叠，轴对称，较稳定）和**1个π键**（肩并肩重叠，镜面对称，电子云分散在双键平面上下方）组成
2. 加成试剂（如Br₂）接近时，π键电子云受试剂影响发生**极化**
3. **π键断裂**（键能较小，约264 kJ/mol，仅为σ键的60%左右），两个碳原子各获得1个电子
4. 两个溴原子分别与两个碳原子形成新的**C—Br σ键**
5. 结果：C=C双键 → 2个C—Br单键 + 1个C—C单键

```
    H   H                    H   H
     \\ /                      \| \|
      C═C      +   Br₂   →     C—C
     / \\                      / \vert
    H   H                    Br  Br
     
   [π键断裂]              [两个新σ键形成]
```

> **本质**：加成反应是不饱和键的**π键断裂**，不饱和碳原子与其他原子或原子团结合，最终变为饱和键的过程。

### 3.2 酯化反应的可逆性——平衡移动原理的深度应用

酯化反应是可逆反应的典范，其平衡处理体现了勒夏特列原理的完整应用：

$$\text{CH}_3\text{COOH} + \text{C}_2\text{H}_5\text{OH} \rightleftharpoons \text{CH}_3\text{COOC}_2\text{H}_5 + \text{H}_2\text{O} \quad \Delta H < 0$$

**各条件的作用机理**：

| 条件 | 对正反应速率 | 对逆反应速率 | 对平衡的影响 | 实际作用 |
|------|-------------|-------------|-------------|----------|
| 浓H₂SO₄ | 加快(催化) | 加快(催化) | 右移(吸水) | 催化剂 + 吸水剂 |
| 加热 | 加快 | 加快 | 左移(放热) | 主要目的是加快速率 |
| 乙醇过量 | 不变 | 加快 | 右移 | 提高乙酸转化率 |
| 移走酯 | 减慢 | 减慢 | 右移 | 工业上连续蒸出产物 |

**长导管的作用（实验装置关键）**：

在酯化反应实验装置中，导管不宜插入饱和Na₂CO₃溶液液面以下，原因有二：
1. **冷凝回流**：蒸气在长导管中冷却，部分乙醇和乙酸冷凝回流到反应瓶中继续反应
2. **导气**：将生成的乙酸乙酯蒸气导入收集装置
3. **防倒吸**：若导管插入液面下，因乙醇、乙酸易溶于Na₂CO₃溶液，装置内气压骤降，会发生**倒吸**

**饱和Na₂CO₃溶液的作用**：
1. **中和乙酸**：除去混有的乙酸蒸气（乙酸与Na₂CO₃反应）
2. **溶解乙醇**：吸收未反应的乙醇
3. **降低酯溶解度**：Na₂CO₃溶液减小乙酸乙酯在水中的溶解度，利于**分层**

### 3.3 淀粉水解的逐步过程——渐进式的分子降解

淀粉在酸或酶作用下的水解是**逐步进行**的：

$$\text{淀粉}(\text{高分子}, n>100) \xrightarrow{\text{酸/酶}} \text{糊精}(\text{中分子}, n=10\sim100) \xrightarrow{\text{进一步水解}} \text{麦芽糖}(\text{二糖}, n=2) \xrightarrow{\text{麦芽糖酶}} \text{葡萄糖}(\text{单糖}, n=1)$$

**各阶段的特征**：

| 阶段 | 分子量范围 | 遇碘现象 | 还原性(银镜反应) |
|------|-----------|----------|-----------------|
| 淀粉 | 10⁴~10⁶ | **蓝色** | 无 |
| 红糊精 | ~10⁴ | **红紫色** | 微弱 |
| 麦芽糖 | 342 | 无色 | **有(银镜)** |
| 葡萄糖 | 180 | 无色 | **有(银镜)** |

> **检验淀粉水解程度的三步法**：
> 1. 取水解液，加碘水 → 检验是否还有淀粉
> 2. 取水解液，先用NaOH中和酸，再加银氨溶液水浴加热 → 检验是否有葡萄糖
> 3. 综合判断：
>    - ①变蓝 + ②无银镜 = **未水解**
>    - ①变蓝 + ②有银镜 = **部分水解**
>    - ①不变蓝 + ②有银镜 = **完全水解**

## 四、实验思想

### 4.1 乙烯的实验室制法——乙醇消去反应

**反应原理**：

$$\text{CH}_3\text{CH}_2\text{OH} \xrightarrow{\text{浓H}_2\text{SO}_4, 170^\circ\text{C}} \text{CH}_2=\text{CH}_2\uparrow + \text{H}_2\text{O}$$

**实验装置与操作要点**：

| 要点 | 说明 |
|------|------|
| **反应容器** | 圆底烧瓶，加入乙醇和浓H₂SO₄混合液（体积比约1:3） |
| **碎瓷片** | **防止暴沸**（液体混合物加热剧烈沸腾） |
| **温度计位置** | 水银球插入**反应液中**（不是液面上方！） |
| **温度控制** | **170 °C**，迅速通过140 °C区间，减少乙醚生成 |
| **收集方法** | 排水集气法（乙烯密度与空气接近，不用排空气法） |

**副反应与杂质**：

| 副反应 | 条件 | 产物 |
|--------|------|------|
| 分子间脱水 | 140 °C | 乙醚(CH₃CH₂OCH₂CH₃) |
| 碳化氧化 | 浓H₂SO₄强氧化性 | C、CO₂、SO₂等 |

> **产物净化**：若需纯净乙烯，需通过**NaOH溶液**除去SO₂、CO₂等酸性气体，再通过**浓硫酸**干燥。

> **与溴水反应检验**：乙烯通入溴水，溴水褪色，可证明乙烯的生成。

### 4.2 酯化反应的实验装置

**装置要点**：

```
          长导管(冷凝回流+导气)
              ↓
    [圆底烧瓶:乙醇+乙酸+浓H₂SO₄] ———→ [饱和Na₂CO₃溶液]
              ↑                      (导管口在液面上)
           酒精灯加热
```

| 装置部件 | 作用 | 注意事项 |
|----------|------|----------|
| **长导管** | ① 冷凝回流：使乙醇、乙酸蒸气冷却回流<br>② 导气：导出乙酸乙酯蒸气 | 导管口置于饱和Na₂CO₃液面上方，**防倒吸** |
| **浓H₂SO₄** | 催化剂 + 吸水剂 | 混合时类似稀释浓硫酸：将浓H₂SO₄缓缓加入乙醇中 |
| **饱和Na₂CO₃溶液** | ① 中和乙酸<br>② 溶解乙醇<br>③ 降低酯溶解度，利于分层 | 不可用NaOH溶液（会促进酯水解） |
| **加热** | 加快反应速率 | 小火微沸即可 |

**产物特征**：
- 乙酸乙酯：无色透明油状液体，**密度比水小**
- 有**芳香气味**
- 在上层（若加指示剂可观察分层界面）

## 六、隐性考点

### 6.1 同分异构体的书写方法——系统思维

**书写顺序**：**碳链异构 → 位置异构 → 官能团异构**

**步骤示例（以C₅H₁₂O为例，写出属于醇的所有同分异构体）**：

**第一步：确定官能团类型**
- C₅H₁₂O符合饱和一元醇或醚的通式
- 先写醇类（—OH连接在碳链上）

**第二步：写出碳骨架（碳链异构）**

```
① C—C—C—C—C    (正戊烷骨架)
② C—C—C—C      (异戊烷骨架，带1个甲基)
      \vert
      C
③   C            (新戊烷骨架，带2个甲基)
     \vert
  C—C—C
     \vert
      C
```

**第三步：移动官能团位置（位置异构）**

在每种碳骨架上移动—OH位置（注意对称性减少重复）：

| 碳骨架 | 羟基位置 | 名称 | 结构简式 |
|--------|----------|------|----------|
| ①直链 | 1号C | 1-戊醇 | CH₃CH₂CH₂CH₂CH₂OH |
| ①直链 | 2号C | 2-戊醇 | CH₃CH₂CH₂CH(OH)CH₃ |
| ①直链 | 3号C | 3-戊醇 | CH₃CH₂CH(OH)CH₂CH₃ |
| ②异构 | 1号C(端位) | 3-甲基-1-丁醇 | (CH₃)₂CHCH₂CH₂OH |
| ②异构 | 2号C | 3-甲基-2-丁醇 | (CH₃)₂CHCH(OH)CH₃ |
| ②异构 | 3号C(即甲基上) | 2-甲基-1-丁醇 | CH₃CH₂CH(CH₃)CH₂OH |
| ②异构 | 2号C的另一个位置 | 2-甲基-2-丁醇 | CH₃CH₂C(OH)(CH₃)CH₃ |
| ③新戊 | 端位(唯一位置) | 2,2-二甲基-1-丙醇 | (CH₃)₃CCH₂OH |

> **共8种醇类同分异构体**。若再写醚类，还有6种，总计14种。

**位置异构的对称性判断技巧**：
- 找到碳骨架的**对称轴**
- 对称位置是**等效碳**，羟基连在这些碳上得到的是同一种物质
- 例如正丁烷CH₃CH₂CH₂CH₃中，1号位和4号位等效，2号位和3号位等效

### 6.2 高分子化合物n值的平均性

**核心理解**：

- 高分子化合物如聚乙烯的分子式写作 $\left[—\text{CH}_2—\text{CH}_2—\right]_n$
- 但**n不是一个确定的整数**，不同分子的n值不同
- 例如聚乙烯样品中，可能有的分子n=1000，有的n=1500，有的n=2000
- 我们说的n是**平均聚合度**，是相对分子质量的平均值
- 因此，聚乙烯、淀粉、蛋白质等高分子化合物本质上是**混合物**

> **推论**：高分子化合物**没有固定的熔沸点**（混合物无固定熔沸点），只有**熔融温度范围**。

### 6.3 淀粉遇碘变蓝是物理变化（包合反应）

**本质**：不是化学反应，而是**物理的包合作用**

- 淀粉分子（尤其是直链淀粉）呈**螺旋状结构**
- 碘分子(I₂)恰好可以**嵌入**螺旋管道中
- 碘分子与淀粉分子通过**范德华力**结合
- 这种包合作用改变了电子跃迁能级，使体系呈现**蓝色**

> **注意**：
> - 加热时蓝色褪去：分子热运动加剧，包合结构被破坏，I₂释放出来
> - 冷却后蓝色恢复：温度降低，螺旋结构重新形成，I₂重新进入
> - 这是**可逆的物理过程**，证明其为物理变化

## 七、易错警示

### 7.1 分子式与结构式的区别

| 概念 | 含义 | 示例（乙醇） | 能否确定物质 |
|------|------|-------------|-------------|
| **分子式** | 表示分子中原子的种类和数目 | C₂H₆O | **不能**（还可能是二甲醚） |
| **结构式** | 完整表示所有原子的连接方式 | H—C—C—O—H（完整） | **能** |
| **结构简式** | 简化表示，突出官能团 | CH₃CH₂OH | **能** |
| **最简式(实验式)** | 原子个数的最简整数比 | C₂H₆O（与分子式相同） | **不能** |

> **警示**：分子式相同的物质不一定是同一种物质（同分异构体）；结构简式可以区分同分异构体。

### 7.2 消去反应的条件——邻位碳上必须有H

**消去反应定义**：有机化合物在一定条件下，从一个分子中**脱去一个小分子**(如H₂O、HX等)，生成含不饱和键化合物的反应。

**乙醇消去反应的结构要求**：

```
   H   H
    \| \|
H—C—C—H   →   CH₂=CH₂ + H₂O
    \| \|
   H   OH
        
消去的是—OH和邻位C上的H（β-H）
```

**不能发生消去反应的情况**：

| 结构 | 能否消去 | 原因 |
|------|----------|------|
| CH₃OH（甲醇） | **不能** | 只有一个碳，无邻位碳 |
| (CH₃)₃CCH₂OH | **不能** | —OH所在碳的邻位碳上无H（被三个甲基占满） |
| CH₃CH₂OH | **能** | 邻位碳有2个H |

> **口诀**："**无邻不消去，无氢不消去**"

### 7.3 油脂不是高分子化合物

| 误区 | 正确认识 |
|------|----------|
| "油脂是天然高分子" | **错误**。油脂是甘油三酯，相对分子质量约800~900，远小于10⁴的高分子门槛 |
| "淀粉和纤维素是同分异构体" | **错误**。(C₆H₁₀O₅)_n中n值不同，且淀粉含支链、纤维素为直链 |
| "蛋白质是高分子，所以油脂也是" | **错误**。虽然都是天然物质，但油脂是小分子酯 |

### 7.4 蛋白质的盐析（可逆）vs 变性（不可逆）

| 比较项 | 盐析 | 变性 |
|--------|------|------|
| **定义** | 加入高浓度中性盐，使蛋白质溶解度降低而析出 | 物理或化学因素使蛋白质空间结构破坏 |
| **条件** | 浓(NH₄)₂SO₄、Na₂SO₄等**轻金属盐** | 加热、强酸、强碱、**重金属盐**、紫外线、有机溶剂 |
| **可逆性** | **可逆**——加水可重新溶解 | **不可逆**——加水不溶解 |
| **结构变化** | 不改变蛋白质空间结构 | **破坏**蛋白质空间结构 |
| **生物活性** | **保留** | **丧失** |
| **应用** | 分离提纯蛋白质 | 消毒（酒精、高温煮） |

> **易错点**：
> - CuSO₄等**重金属盐**导致的是**变性**，不是盐析！
> - 只有**高浓度轻金属盐**(如(NH₄)₂SO₄、NaCl饱和溶液)引起的是盐析
> - 盐析属于物理变化，变性属于化学变化

## 八、思想方法

### 8.1 结构决定性质——有机化学的核心思想

**内涵**：有机物的化学性质主要由其**分子结构**，特别是**官能团**决定。

**本章的体现**：

| 结构特征 | 决定性质 | 实例 |
|----------|----------|------|
| C=C（碳碳双键） | 易发生加成、加聚、氧化 | 乙烯使溴水褪色 |
| —OH（羟基） | 可与Na反应、可被氧化、可发生酯化/消去 | 乙醇的三类反应 |
| —COOH（羧基） | 酸性、可发生酯化 | 乙酸的弱酸性 |
| —CHO（醛基） | 还原性（银镜反应、斐林反应） | 葡萄糖的还原性 |

**学习有机物的方法**："**见官能团，想性质**"——看到分子中的官能团，立即联想其特征反应。

### 8.2 模型认知——球棍模型与空间结构

**本章涉及的模型**：

| 有机物 | 空间构型 | 球棍模型特征 |
|--------|----------|-------------|
| 甲烷(CH₄) | **正四面体** | 碳在中心，4个氢在四面体四角 |
| 乙烯(CH₂=CH₂) | **平面形** | 6个原子共平面，键角约120° |
| 乙炔(CH≡CH) | **直线形** | 4个原子共直线 |
| 苯(C₆H₆) | **平面正六边形** | 12个原子共平面 |
| 乙醇 | — | 非平面，可绕C—C、C—O键旋转 |

> **应用**：判断原子共面、共线问题的基础。例如乙烯中，若一个H被甲基取代（丙烯），则甲基中的3个H最多只有1个能与双键碳共平面。

### 8.3 分类思想——按官能团分类有机物

**本章的有机物分类框架**：

```
烃（仅含C、H）
├── 烷烃：饱和链烃，通式CₙH₂ₙ₊₂
├── 烯烃：含C=C，通式CₙH₂ₙ
└── 芳香烃：含苯环

烃的衍生物（烃分子中H被其他原子或原子团取代）
├── 卤代烃：含—X
├── 醇：含—OH（链烃基上）
├── 酚：含—OH（苯环上）
├── 醛：含—CHO
├── 羧酸：含—COOH
├── 酯：含—COOR
└── 醚：含—O—
```

> **学习策略**：每学一类新有机物，按"**结构 → 物理性质 → 化学性质 → 制法 → 用途**"五维度整理，形成知识卡片。
