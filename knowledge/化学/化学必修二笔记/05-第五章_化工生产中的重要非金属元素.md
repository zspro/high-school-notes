# 第五章 化工生产中的重要非金属元素

> **核心素养目标**：认识硫、氮、硅等非金属元素及其化合物在化工生产中的重要地位，体会化学工业对人类文明的推动作用；掌握常见非金属元素化合物的性质与转化规律，建立"价类二维图"分析思维；了解工业制备中的条件优化思想，培养科学态度与社会责任。

---

## 【来龙去脉】为什么称"化工生产中的重要非金属元素"？

高中化学将硫、氮、硅所在的章节命名为"化工生产中的重要非金属元素"，其核心原因在于：**硫酸（$H_2SO_4$）、硝酸（$HNO_3$）和氨（$NH_3$）是化学工业的基石**，被誉为"三大基础化工原料"，它们的产量直接反映一个国家的化学工业水平和综合国力。

### 1. 硫酸："化学工业之母"

硫酸是世界上生产量最大、用途最广的化工产品之一。工业上采用**接触法**制备硫酸，以硫黄（或黄铁矿）为原料，经由$SO_2\rightarrow SO_3\rightarrow H_2SO_4$的转化路线。硫酸不仅本身是重要的化工原料（用于化肥、农药、染料、炸药、石油精炼、金属冶炼等），还是许多化学反应的催化剂和脱水剂。可以说，没有硫酸工业，就没有现代化学工业和现代农业。

### 2. 硝酸与氨：化肥与炸药工业的基础

氨是合成氮肥（尿素、硝酸铵、硫酸铵等）的唯一工业起点。德国化学家哈伯（F. Haber）在1909年发明了**合成氨法**（$N_2 + 3H_2 \xrightleftharpoons[高温高压]{催化剂} 2NH_3$），使人类摆脱了仅依赖天然氮肥（鸟粪石、硝石）的困境，开启了现代农业的"绿色革命"。由氨进一步氧化可制得硝酸，硝酸既是氮肥原料，也是炸药（TNT、硝化甘油等）工业的基础。可以说，合成氨技术直接改变了人类粮食安全格局，并深刻影响了世界军事与能源格局。

### 3. 硅与无机非金属材料：信息文明的基石

硅酸盐材料（陶瓷、玻璃、水泥）是人类最早使用的材料之一；而高纯硅单质则是现代半导体、芯片、光伏产业的根本；二氧化硅是光纤的核心材料。硅基材料推动了从农业文明到信息文明的跨越。

**综上所述**，硫、氮、硅及其化合物的工业化生产，不仅提供了化肥、炸药、材料等基础物资，还深刻塑造了现代农业、国防军工、电子信息等人类文明的核心领域，因此称其为"化工生产中的重要非金属元素"。

## 5.1 硫及其化合物

### 一、硫单质的性质

| 性质 | 内容 |
|------|------|
| 物理性质 | 淡黄色固体，质脆，不溶于水，微溶于酒精，易溶于$CS_2$（二硫化碳）。熔点约$112^\circ C$，沸点约$444^\circ C$。 |
| 化学性质 | 既有氧化性又有还原性，但通常表现为弱氧化性。硫的化合价有$-2, 0, +4, +6$等多种价态。 |
| 与金属反应 | $Fe + S \xrightarrow{\Delta} FeS$（生成低价硫化物，对比：$2Fe + 3Cl_2 \xrightarrow{点燃} 2FeCl_3$，说明$S$氧化性弱于$Cl_2$）；$Cu + S \xrightarrow{\Delta} Cu_2S$；$Hg + S = HgS$（常温即可，用于处理洒落的汞）。 |
| 与非金属反应 | $S + O_2 \xrightarrow{点燃} SO_2$；$S + H_2 \xrightarrow{\Delta} H_2S$。 |
| 与碱反应 | $3S + 6NaOH \xrightarrow{\Delta} 2Na_2S + Na_2SO_3 + 3H_2O$（歧化反应，$S$既升价又降价）。 |

> **要点**：硫与变价金属反应时，一般生成**低价态硫化物**，这是硫氧化性较弱的重要证据。

### 二、二氧化硫（$SO_2$）—— 本节核心物质

#### 1. 物理性质

无色、有**刺激性气味**的有毒气体，密度比空气大，易液化，**易溶于水**（1体积水约溶解40体积$SO_2$）。

#### 2. 化学性质（三维性质体系）

$SO_2$是典型的"三维物质"，同时具有**酸性氧化物通性**、**还原性**和**漂白性**，三者缺一不可，也是高考考查的重中之重。

**(1) 酸性氧化物通性 —— "形似$CO_2$"**

$SO_2$溶于水生成亚硫酸（$H_2SO_3$），属于中强酸，具有酸性氧化物的全部通性：

- **与水反应**：$SO_2 + H_2O \rightleftharpoons H_2SO_3$
- **与碱反应**：
  - $SO_2 + 2NaOH = Na_2SO_3 + H_2O$（$SO_2$少量）
  - $SO_2 + NaOH = NaHSO_3$（$SO_2$过量）
  - $SO_2 + Ca(OH)_2 = CaSO_3\downarrow + H_2O$（继续通入则沉淀溶解生成$Ca(HSO_3)_2$，与$CO_2$和澄清石灰水现象类似）
- **与碱性氧化物反应**：$SO_2 + CaO = CaSO_3$（工业上利用此反应进行"钙基固硫"，减少燃煤$SO_2$排放）
- **与盐反应**：$SO_2 + Na_2CO_3 = Na_2SO_3 + CO_2$（亚硫酸酸性强于碳酸）

**(2) 还原性 —— "$S^{4+}$可被多种氧化剂氧化"**

$SO_2$中硫为$+4$价，处于中间价态，可被氧化至$+6$价，具有较强还原性：

- **与$O_2$反应（催化氧化）**：
  $$2SO_2 + O_2 \xrightleftharpoons[\Delta]{催化剂} 2SO_3$$
  这是接触法制硫酸的**核心步骤**，催化剂为$V_2O_5$。

- **与卤素单质反应**：
  - $SO_2 + Br_2 + 2H_2O = H_2SO_4 + 2HBr$
  - $SO_2 + Cl_2 + 2H_2O = H_2SO_4 + 2HCl$
  > 现象：溴水或氯水褪色。**注意**：此褪色是**还原褪色**，与$SO_2$的漂白性无关。

- **与强氧化性酸反应**：
  - $5SO_2 + 2KMnO_4 + 2H_2O = K_2SO_4 + 2MnSO_4 + 2H_2SO_4$（酸性$KMnO_4$溶液褪色）
  - $3SO_2 + 2HNO_3(\text{稀}) + 2H_2O = 3H_2SO_4 + 2NO\uparrow$

- **与$Fe^{3+}$反应**：$SO_2 + 2Fe^{3+} + 2H_2O = SO_4^{2-} + 2Fe^{2+} + 4H^+$

**(3) 漂白性 —— "选择性、可逆性漂白"**

$SO_2$能与某些有色物质（如品红、纸浆、草帽等）结合生成**不稳定的无色化合物**，从而使有色物质褪色。其漂白特点：

- **选择性**：仅能漂白品红、纸浆、丝毛等有机色素，**不能漂白酸碱指示剂**。
- **可逆性**：加热后无色化合物分解，颜色恢复。如$SO_2$使品红溶液褪色，加热后溶液重新变红。

反应原理：$SO_2 + \text{有机色素} \rightleftharpoons \text{无色化合物}$

#### 3. $\boldsymbol{SO_2}$与$\boldsymbol{Cl_2}$漂白原理深度对比

| 对比维度 | $SO_2$漂白 | $Cl_2$（或$HClO$）漂白 |
|---------|-------------|----------------------|
| **漂白原理** | **化合漂白**：与有色物质化合生成不稳定的无色化合物 | **氧化漂白**：$HClO$将有色物质**氧化分解**为无色物质 |
| **本质变化** | 化学变化（化合），无色物质不稳定 | 化学变化（氧化还原），破坏发色基团 |
| **可逆性** | **可逆**，加热可恢复原色 | **不可逆**，加热不能恢复 |
| **漂白范围** | 有选择性（只能漂白品红等特定有机色素） | 范围广，可漂白大多数有色物质 |
| **指示剂** | **不能使酸碱指示剂褪色**（通入石蕊溶液中，溶液只变红不褪色） | **能使酸碱指示剂褪色**（次氯酸氧化指示剂） |
| **典型应用** | 纸浆、草帽、丝毛漂白 | 自来水消毒、织物漂白 |

> **【隐性考点①】**：将等物质的量的$SO_2$和$Cl_2$同时通入品红溶液，漂白效果**消失**（相互反应：$SO_2 + Cl_2 + 2H_2O = H_2SO_4 + 2HCl$，产物均无漂白性）。

### 三、三氧化硫（$SO_3$）

- **物理性质**：熔点$16.8^\circ C$，沸点$44.8^\circ C$，常温下为无色液体/晶体（标准状况下为固态，常考陷阱点！）。
- **化学性质**：酸性氧化物，与水剧烈反应放出大量热：$SO_3 + H_2O = H_2SO_4$。
- **工业意义**：接触法制硫酸中，$SO_3$用$98.3\%$的浓硫酸吸收（而非直接用水），以防止形成酸雾，提高吸收效率。

### 四、硫酸（$H_2SO_4$）

#### 1. 稀硫酸的性质

具有酸的通性（与活泼金属、碱性氧化物、碱、盐反应），实质是$H^+$的性质。

#### 2. 浓硫酸的特性 —— "三大特性"

| 特性 | 原理与表现 | 实例 |
|------|-----------|------|
| **吸水性** | 吸收现成的水分子（游离水或结晶水），属于物理变化为主 | 干燥剂（不能干燥$NH_3$、$H_2S$、$HI$等）；吸收$CuSO_4\cdot 5H_2O$中的结晶水使其变白 |
| **脱水性** | 按$H:O = 2:1$的原子个数比夺取有机物中的氢、氧元素，生成水，属于化学变化 | 使蔗糖炭化（"黑面包实验"）；使纸张、木条变黑； $C_{12}H_{22}O_{11} \xrightarrow{浓H_2SO_4} 12C + 11H_2O$ |
| **强氧化性** | $\overset{+6}{S}$被还原 | 与铜反应：$Cu + 2H_2SO_4(浓) \xrightarrow{\Delta} CuSO_4 + SO_2\uparrow + 2H_2O$；与碳反应：$C + 2H_2SO_4(浓) \xrightarrow{\Delta} CO_2\uparrow + 2SO_2\uparrow + 2H_2O$；常温下使$Fe$、$Al$**钝化**（致密氧化膜） |

> **【隐性考点②】浓硫酸的吸水性vs脱水性vs强氧化性辨析**：
> - 吸收$CuSO_4\cdot 5H_2O$中的结晶水 → **吸水性**（吸收"现成的水"）
> - 使蔗糖变黑 → **脱水性**（从有机物中"夺取"$H$、$O$生成水）
> - 使蔗糖变黑后体积膨胀、有刺激性气味 → **强氧化性**（进一步氧化碳单质生成$CO_2$、$SO_2$）

> **【易错警示】**：浓硫酸与金属反应时，还原产物通常为$SO_2$（而非$H_2$），随着反应进行，浓硫酸变稀后反应停止（如与$Cu$反应）或转为生成$H_2$（如与$Zn$反应后期）。

### 五、$\boldsymbol{SO_4^{2-}}$的检验

1. **试剂**：稀盐酸、$BaCl_2$溶液。
2. **步骤与原理**：
   - 先加**稀盐酸**酸化，排除$CO_3^{2-}$、$SO_3^{2-}$、$Ag^+$等干扰：
     - $CO_3^{2-} + 2H^+ = CO_2\uparrow + H_2O$
     - $SO_3^{2-} + 2H^+ = SO_2\uparrow + H_2O$
     - $Ag^+ + Cl^- = AgCl\downarrow$（若产生白色沉淀，说明有$Ag^+$，此时$SO_4^{2-}$的检验需换用$Ba(NO_3)_2$并配合其他操作，但高中一般默认无$Ag^+$干扰）
   - 再加$BaCl_2$溶液，产生白色沉淀：$Ba^{2+} + SO_4^{2-} = BaSO_4\downarrow$。
3. **顺序不可颠倒**：若先加$BaCl_2$，后加稀盐酸，则$Ag^+$会干扰（$AgCl$也是白色沉淀且不溶于酸）。

### 六、深度理解：接触法制硫酸的工业条件优化

接触法是工业制硫酸的核心方法，分为三步，每一步都体现了化学热力学与动力学的工业平衡。

#### 第一步：造气 —— 生成$SO_2$

- **硫黄法**：$S + O_2 \xrightarrow{点燃} SO_2$（ cleaner，现代主流）
- **煅烧黄铁矿**：$4FeS_2 + 11O_2 \xrightarrow{高温} 2Fe_2O_3 + 8SO_2$（传统方法，污染较大）

#### 第二步：催化氧化 —— 核心反应

$$2SO_2(g) + O_2(g) \xrightleftharpoons[\Delta]{V_2O_5} 2SO_3(g) \quad \Delta H < 0$$

这是一个**气体分子数减少**的**放热反应**。根据勒夏特列原理与工业实际，条件选择如下：

| 条件 | 理论依据 | 工业实际选择 | 原因 |
|------|---------|------------|------|
| **温度** | 低温有利于平衡正向移动（放热反应） | **400$^\circ C$ ~ 500$^\circ C$** | 温度过低则反应速率太慢，催化剂活性也低；此为催化剂活性最佳温度区间，兼顾速率与平衡转化率（约$97\%$ ~ $98\%$） |
| **压强** | 高压有利于平衡正向移动（气体分子数减少：$3\rightarrow 2$） | **常压** | 常压下转化率已经很高（约$90\%$以上），加压对转化率提升有限，但会大幅增加设备成本与动力消耗，得不偿失 |
| **催化剂** | 加快反应速率，缩短达到平衡的时间 | **$V_2O_5$（五氧化二钒）** | 目前广泛使用的催化剂，在该温度范围内活性最高 |
| **浓度** | 增大反应物浓度使平衡正向移动 | 使用**过量空气**（$O_2$过量） | 提高$SO_2$的转化率，且空气廉价易得；同时加快反应速率 |

#### 第三步：吸收 —— 制得硫酸

- $SO_3 + H_2O = H_2SO_4$（理论上）
- **工业实际**：用$98.3\%$的浓硫酸吸收$SO_3$，生成发烟硫酸（$H_2SO_4\cdot nSO_3$），再稀释成所需浓度。
- **不可直接用水吸收**：$SO_3$与水反应剧烈放热，形成酸雾（微小液滴），阻碍$SO_3$的进一步吸收，吸收效率低下。

> **【思想方法】工业条件优化思想**：工业生产中选择反应条件，不是简单追求理论最高转化率，而是综合考虑**化学平衡（转化率）、反应速率（生产效率）、催化剂活性、设备成本、能耗、安全性**等多重因素，寻求经济效益最大化的"最优解"。

### 七、硫元素的价类二维图与转化关系

以硫元素的**化合价**为纵轴、**物质类别**为横轴，建立"价类二维图"，可以系统梳理硫及其化合物的转化规律。

| 价态 / 类别 | 单质 | 氧化物 | 酸 | 盐 |
|------------------|------|--------|-----|-----|
| **$-2$** | — | — | $H_2S$ | $Na_2S$、$FeS$、$CuS$ |
| **$0$** | $S$ | — | — | — |
| **$+4$** | — | $SO_2$ | $H_2SO_3$ | $Na_2SO_3$、$NaHSO_3$、$CaSO_3$ |
| **$+6$** | — | $SO_3$ | $H_2SO_4$ | $Na_2SO_4$、$BaSO_4$、$CuSO_4$ |

**核心转化路线（氧化还原主线）**：

$$\overset{-2}{S} \xrightarrow{氧化} \overset{0}{S} \xrightarrow{氧化} \overset{+4}{SO_2} \xrightarrow[催化剂]{O_2} \overset{+6}{SO_3} \xrightarrow{H_2O} H_2SO_4$$

- **$S^{2-} \rightarrow S$**：$2H_2S + O_2 = 2S\downarrow + 2H_2O$（不完全燃烧）或$H_2S + Cl_2 = S\downarrow + 2HCl$
- **$S \rightarrow SO_2$**：燃烧
- **$SO_2 \leftrightarrow H_2SO_3 \leftrightarrow SO_3^{2-}$**：酸性氧化物通性（非氧化还原）
- **$SO_2 \rightarrow SO_4^{2-}$**：被氧化剂氧化（体现还原性）

> **【守恒思想】**：在复杂转化中，始终抓住**硫原子守恒**和**电子转移守恒**。例如，浓硫酸与铜反应时，每生成1 mol $SO_2$，转移2 mol电子，消耗2 mol $H_2SO_4$（其中1 mol作氧化剂，1 mol体现酸性）。

### 八、实验思想：$SO_2$性质探究实验设计

#### 实验装置思路（性质一体化检验）

常用亚硫酸钠与较浓硫酸反应制备$SO_2$：$Na_2SO_3 + H_2SO_4(较浓) = Na_2SO_4 + SO_2\uparrow + H_2O$。

典型检验流程：

1. **通入紫色石蕊溶液** → 溶液变红（证明酸性氧化物性质）。
   > **【易错警示①】**：$SO_2$不能使石蕊褪色！只变红不褪色，这是与$Cl_2$的本质区别。

2. **通入品红溶液** → 红色褪去，加热后恢复红色（证明漂白性，且为可逆漂白）。

3. **通入酸性$KMnO_4$溶液** → 紫色褪去（证明还原性，离子方程式：$5SO_2 + 2MnO_4^- + 2H_2O = 5SO_4^{2-} + 2Mn^{2+} + 4H^+$）。

4. **通入溴水** → 橙色褪去（证明还原性：$SO_2 + Br_2 + 2H_2O = H_2SO_4 + 2HBr$）。

5. **尾气处理**：用$NaOH$溶液吸收（$SO_2 + 2NaOH = Na_2SO_3 + H_2O$），防止大气污染（$SO_2$是主要大气污染物，形成酸雨）。

> **【知识串联】**：$SO_2$的还原性实验（使$KMnO_4$、溴水褪色）与漂白性实验（使品红褪色）常联合考查，需注意区分**褪色原因**不同。

## 5.2 氮及其化合物

氮元素在自然界中主要以$N_2$（大气中约$78\%$）和硝酸盐、铵盐等形式存在。氮的化合价从$-3$到$+5$，是典型的变价非金属元素。

### 一、氮气（$N_2$）

- **结构**：$N\equiv N$（氮氮三键），键能极大（$946\,kJ\cdot mol^{-1}$），故$N_2$化学性质非常稳定。
- **性质**：常温下不活泼，高温或放电条件下可与部分物质反应。
  - 与$O_2$：$N_2 + O_2 \xrightarrow{放电或高温} 2NO$（雷雨固氮，自然界氮循环的起点）
  - 与$H_2$：$N_2 + 3H_2 \xrightleftharpoons[高温高压]{催化剂} 2NH_3$（工业合成氨——哈伯法）
  - 与活泼金属：$3Mg + N_2 \xrightarrow{点燃} Mg_3N_2$
- **用途**：保护气、液氮作制冷剂、合成氨原料。

---

### 二、氮的氧化物（NO、$NO_2$）

#### 1. 一氧化氮（NO）

- **物理性质**：无色、无味、不溶于水的有毒气体。
- **化学性质**：
  - 极易与氧气反应：$2NO + O_2 = 2NO_2$（现象：无色→红棕色，实验室不可用排空气法收集NO）
  - 与血红蛋白结合能力强（有毒原因）
- **收集方法**：**排水法**（不溶于水，且易与空气中$O_2$反应）。

#### 2. 二氧化氮（$NO_2$）

- **物理性质**：红棕色、有刺激性气味的有毒气体，密度比空气大，易液化，**易溶于水**。
- **化学性质**：
  - **与水反应**：$3NO_2 + H_2O = 2HNO_3 + NO$
    > 此为工业制硝酸的基础反应之一，也是考查重点。每3 mol $NO_2$参与反应，生成1 mol NO（可循环氧化），转移2 mol电子。
  - **自身化合**：$2NO_2 \rightleftharpoons N_2O_4$（无色，放热反应，温度升高平衡左移，颜色加深）
  - **强氧化性**：可氧化$SO_2$、$KI$等。

#### 3. NO与$NO_2$的制备与收集

| 物质 | 实验室制法 | 收集方法 |
|------|-----------|---------|
| $NO$ | $3Cu + 8HNO_3(稀) = 3Cu(NO_3)_2 + 2NO\uparrow + 4H_2O$ | 排水法 |
| $NO_2$ | $Cu + 4HNO_3(浓) = Cu(NO_3)_2 + 2NO_2\uparrow + 2H_2O$ | 向上排空气法 |

> **【易错警示】**：NO不能用排空气法收集；$NO_2$不能用排水法收集（会与水反应）。

---

### 三、氨气（$NH_3$）

#### 1. 物理性质

无色、有**刺激性气味**的气体，密度比空气小（$M = 17\,g\cdot mol^{-1} < 29$），**极易溶于水**（1体积水约溶解700体积$NH_3$，常温下溶解度约为$1:700$），易液化（液氨汽化吸热，可作制冷剂）。

#### 2. 化学性质

**(1) 碱性 —— "唯一碱性气体"**

- **与水反应**：$NH_3 + H_2O \rightleftharpoons NH_3\cdot H_2O \rightleftharpoons NH_4^+ + OH^-$
  > $NH_3\cdot H_2O$（一水合氨）是弱碱，部分电离。氨水呈弱碱性，能使酚酞变红、使石蕊变蓝。
  > **注意**：$NH_3$本身不是碱，溶于水后生成的$NH_3\cdot H_2O$才是碱。

- **与酸反应**：$NH_3 + HCl = NH_4Cl$（白烟，可用于检验$NH_3$泄漏）
  - 与浓硝酸也产生白烟（$NH_4NO_3$）
  - 与硫酸：$2NH_3 + H_2SO_4 = (NH_4)_2SO_4$（无白烟，因硫酸不挥发）

- **与盐溶液反应**：
  - $Al^{3+} + 3NH_3\cdot H_2O = Al(OH)_3\downarrow + 3NH_4^+$（制$Al(OH)_3$，沉淀不溶解）
  - $Fe^{3+} + 3NH_3\cdot H_2O = Fe(OH)_3\downarrow + 3NH_4^+$

**(2) 还原性**

$NH_3$中氮为$-3$价，是最低价态，可被氧化：

- **氨的催化氧化**（制硝酸的核心）：
  $$4NH_3 + 5O_2 \xrightarrow[\Delta]{催化剂} 4NO + 6H_2O$$
  催化剂为铂铑合金，这是工业制硝酸的第一步。

- **与氧化铜反应**：$2NH_3 + 3CuO \xrightarrow{\Delta} 3Cu + N_2 + 3H_2O$

**(3) 与氯气反应**：

- $2NH_3 + 3Cl_2 = N_2 + 6HCl$（氨少量）
- $8NH_3 + 3Cl_2 = N_2 + 6NH_4Cl$（氨过量，产生白烟，可用于检验氯气泄漏）

#### 3. 基础精讲：氨气的喷泉实验

**(1) 实验原理**

喷泉实验的本质是利用压强差：当$NH_3$溶于水（或发生反应）时，烧瓶内气体迅速减少，压强急剧降低，外界大气压将烧杯中的液体压入烧瓶，形成喷泉。

$NH_3$喷泉实验成功的关键：
- **$NH_3$要充满烧瓶**（确保纯度，减少空气残留）
- **装置气密性良好**
- **烧瓶要干燥**（若有水，$NH_3$提前溶解，无法充满）
- **挤出少量水（或打开止水夹）即可引发**（$NH_3$极易溶于水，少量水即可溶解大量$NH_3$，压强骤降）

**(2) 实验操作要点**

- 收集满$NH_3$的圆底烧瓶，塞上带玻璃管和胶头滴管的塞子；
- 玻璃管末端插入盛有水和酚酞的烧杯中；
- 挤压胶头滴管，使少量水进入烧瓶；
- 打开止水夹，立即形成红色喷泉（氨水呈碱性，酚酞变红）。

**(3) 能形成喷泉的其他组合**

| 气体 | 液体 | 原理 |
|------|------|------|
| $HCl$ | 水 | 极易溶于水（$1:500$） |
| $NO_2$ | 水 | 与水反应：$3NO_2 + H_2O = 2HNO_3 + NO$ |
| $SO_2$ | $NaOH$溶液 | 与碱反应被吸收 |
| $CO_2$ | $NaOH$溶液 | 与碱反应被吸收 |
| $Cl_2$ | $NaOH$溶液 | 与碱反应被吸收 |

> **【思想方法】**：喷泉实验的拓展本质是"通过溶解或反应快速创造较大压强差"。判断某气体能否做喷泉实验，关键是看其在水或某溶液中的溶解度是否足够大，或能否快速发生反应被吸收。

#### 4. 氨气的实验室制法

- **原理**：$2NH_4Cl + Ca(OH)_2 \xrightarrow{\Delta} CaCl_2 + 2NH_3\uparrow + 2H_2O$
- **装置**：固体+固体加热制气装置（与制$O_2$相同）。
- **干燥**：用**碱石灰**（$CaO + NaOH$），**不能用浓硫酸、无水氯化钙**（$CaCl_2$与$NH_3$形成配合物$CaCl_2\cdot 8NH_3$）。
- **收集**：向下排空气法（密度小于空气），导管口塞一团浸有稀硫酸的棉花（吸收逸出的$NH_3$，防止对流，确保收集纯净）。
- **验满**：
  - 湿润的红色石蕊试纸放在瓶口，变蓝则满；
  - 蘸有浓盐酸的玻璃棒放在瓶口，产生白烟则满。

---

### 四、铵盐

#### 1. 通性

铵盐是由$NH_4^+$和酸根离子组成的离子化合物，易溶于水，受热易分解。

- **不稳定性**：
  - $NH_4Cl \xrightarrow{\Delta} NH_3\uparrow + HCl\uparrow$（遇冷重新化合，类似升华）
  - $NH_4HCO_3 \xrightarrow{\Delta} NH_3\uparrow + CO_2\uparrow + H_2O$
  - $(NH_4)_2SO_4$、$NH_4NO_3$分解较复杂，产物与温度有关。

- **与碱反应**（铵盐的通性，用于制$NH_3$和检验$NH_4^+$）：
  $$NH_4^+ + OH^- \xrightarrow{\Delta} NH_3\uparrow + H_2O$$

#### 2. 实验思想：铵根离子（$NH_4^+$）的检验

**原理**：利用铵盐与强碱共热放出碱性气体$NH_3$。

**操作步骤**：
1. 取少量待测样品于试管中；
2. 加入**浓$NaOH$溶液**（或固体$Ca(OH)_2$），**加热**；
3. 用湿润的**红色石蕊试纸**放在试管口（或蘸有浓盐酸的玻璃棒靠近试管口）；
4. 若试纸变蓝（或产生白烟），则证明原样品中含有$NH_4^+$。

> **注意**：必须加热！因为$NH_3$极易溶于水，若不加热，产生的少量$NH_3$会溶解在溶液中无法逸出，导致检验失败。

### 五、硝酸（$HNO_3$）

#### 1. 物理性质

无色、易挥发、有刺激性气味的液体，与水以任意比例互溶。常用浓硝酸质量分数约为$63\%$ ~ $68\%$，密度约$1.4\,g\cdot cm^{-3}$；发烟硝酸浓度更高。

> **【易错警示②】**：浓硝酸常呈**黄色**，是因为久置或见光分解产生的$NO_2$溶于硝酸中：$4HNO_3 \xrightarrow{光照或加热} 4NO_2\uparrow + O_2\uparrow + 2H_2O$。因此浓硝酸应保存在**棕色试剂瓶**中，置于**阴凉处**。

#### 2. 化学性质

**(1) 酸的通性（稀硝酸表现）**

硝酸是一元强酸，具有强酸性。但由于其强氧化性，与金属反应时不生成$H_2$。

**(2) 不稳定性**

$$4HNO_3 \xrightarrow{\Delta或光照} 4NO_2\uparrow + O_2\uparrow + 2H_2O$$

浓度越大越易分解，温度越高越易分解，光照促进分解。所以浓硝酸呈黄色。

**(3) 强氧化性 —— 硝酸最核心的性质**

硝酸中氮为$+5$价（最高价态），具有强氧化性，浓度越大氧化性越强。

**① 与金属反应（基础精讲核心）**

| 金属 | 浓硝酸 | 稀硝酸 |
|------|--------|--------|
| $Cu$ | $Cu + 4HNO_3(浓) = Cu(NO_3)_2 + 2NO_2\uparrow + 2H_2O$ | $3Cu + 8HNO_3(稀) = 3Cu(NO_3)_2 + 2NO\uparrow + 4H_2O$ |
| $Ag$ | 类似铜，生成$NO_2$ | 类似铜，生成$NO$ |
| $Zn$、$Fe$、$Al$ | 常温下**钝化**（见下文） | 反应复杂，稀硝酸还原产物可为$NO$、$N_2O$、$NH_4NO_3$等，与浓度和温度有关 |

> **核心规律**：硝酸与金属反应时，**还原产物与硝酸浓度有关**——浓硝酸通常被还原为$NO_2$（$+4$价），稀硝酸通常被还原为$NO$（$+2$价），极稀时可能进一步被还原为$N_2O$、$N_2$甚至$NH_4^+$。

> **电子守恒计算示例**：铜与稀硝酸反应，每3 mol Cu失去6 mol电子，对应2 mol $HNO_3$被还原为NO（N从$+5\rightarrow +2$，每mol得3 mol电子），另有6 mol $HNO_3$仅起酸性作用生成$Cu(NO_3)_2$。**注意**：参加反应的硝酸只有$1/4$被还原（浓硝酸则是$1/2$被还原）。

**② 钝化现象 —— 【隐性考点③】**

常温下，**冷的浓硝酸、浓硫酸**可使$Fe$、$Al$表面形成一层致密的氧化物保护膜，阻止内部金属继续与酸反应，这种现象称为**钝化**。

- **本质**：化学变化（生成氧化膜），不是不反应。
- **条件**：必须同时满足**冷**、**浓**、$Fe$/$Al$三个条件。
- **应用**：可用铝槽车运输浓硝酸或浓硫酸。
- **反例**：加热后钝化失效；稀硝酸不钝化。

**③ 与非金属反应**

浓硝酸可氧化$C$、$S$、$P$等非金属：
- $C + 4HNO_3(浓) \xrightarrow{\Delta} CO_2\uparrow + 4NO_2\uparrow + 2H_2O$
- $S + 6HNO_3(浓) \xrightarrow{\Delta} H_2SO_4 + 6NO_2\uparrow + 2H_2O$

**④ 与还原性化合物反应**

浓硝酸可氧化$H_2S$、$HI$、$SO_2$、$Fe^{2+}$等。因此浓硝酸不能用于制取$H_2S$、$HI$、$SO_2$等还原性气体。

### 六、深度理解：氨的催化氧化制硝酸（工业制硝酸）

工业制硝酸采用**氨催化氧化法**，又称**奥斯特瓦尔德法**，分为三步：

#### 第一步：氨的催化氧化（核心反应）

$$4NH_3 + 5O_2 \xrightarrow[\Delta]{Pt-Rh} 4NO + 6H_2O \quad \Delta H < 0$$

- **催化剂**：铂铑合金网（$Pt-Rh$）
- **温度**：约$800^\circ C$ ~ $900^\circ C$
- **原料气**：氨气和过量空气混合（氨气占比约$10\%$，防止爆炸）

> **【工业优化】**：高温有利于反应速率和催化剂活性，虽然对放热反应的平衡转化率不利，但可以通过及时分离产物、补充原料等方式促使平衡正向移动。

#### 第二步：NO氧化为$NO_2$

$$2NO + O_2 = 2NO_2$$

利用第一步剩余的$O_2$将NO氧化为$NO_2$，此反应无需催化剂，常温即可进行。

#### 第三步：$NO_2$吸收制硝酸

$$3NO_2 + H_2O = 2HNO_3 + NO$$

- 生成的NO可循环使用，重新氧化为$NO_2$。
- 多次循环氧化吸收，可提高原料利用率。
- 最终制得约$50\%$ ~ $60\%$的稀硝酸，经蒸馏或加入脱水剂（如$Mg(NO_3)_2$）可制得浓硝酸。

**总反应（循环后）**：

$NH_3 + 2O_2 = HNO_3 + H_2O$（简化表达）

> **【思想方法】守恒思想与循环利用**：工业生产中常采用"循环操作"提高原料利用率，如NO的循环氧化、合成氨中未反应$N_2$、$H_2$的循环利用。这体现了**原子经济**和**绿色化学**理念。

### 七、氮元素的价类二维图与转化关系

| 价态 / 类别 | 单质 | 氧化物 | 酸 | 盐 |
|------------------|------|--------|-----|-----|
| **$-3$** | — | — | $NH_3\cdot H_2O$（弱碱） | 铵盐（$NH_4Cl$、$NH_4NO_3$等） |
| **$0$** | $N_2$ | — | — | — |
| **$+1$** | — | $N_2O$ | — | — |
| **$+2$** | — | $NO$ | — | — |
| **$+3$** | — | — | $HNO_2$（亚硝酸） | 亚硝酸盐（$NaNO_2$） |
| **$+4$** | — | $NO_2$、$N_2O_4$ | — | — |
| **$+5$** | — | $N_2O_5$ | $HNO_3$ | 硝酸盐（$NaNO_3$、$Cu(NO_3)_2$等） |

**核心氧化还原转化链**：

$$\overset{-3}{NH_3} \xrightarrow[催化氧化]{O_2} \overset{+2}{NO} \xrightarrow{O_2} \overset{+4}{NO_2} \xrightarrow{H_2O} \overset{+5}{HNO_3}$$

**自然界氮循环关键反应**：
- **固氮**：$N_2 \rightarrow NH_3$（人工固氮/生物固氮）
- **硝化**：$NH_3 \rightarrow NO_2^- \rightarrow NO_3^-$（微生物作用）
- **反硝化**：$NO_3^- \rightarrow N_2$（微生物作用）

### 八、实验思想：硝酸与铜反应实验的注意事项

#### 1. 浓硝酸与铜反应

$$Cu + 4HNO_3(浓) = Cu(NO_3)_2 + 2NO_2\uparrow + 2H_2O$$

- **现象**：铜片逐渐溶解，溶液变蓝（$Cu^{2+}$），产生**红棕色气体**（$NO_2$）。
- **装置要求**：必须在**通风橱**中进行（$NO_2$为有毒气体）。
- **尾气吸收**：用$NaOH$溶液吸收：$2NO_2 + 2NaOH = NaNO_3 + NaNO_2 + H_2O$。
- **注意**：若将生成的$NO_2$直接通入水中，会发生$3NO_2 + H_2O = 2HNO_3 + NO$，但NO会逸出造成污染，故实验室最好用$NaOH$溶液吸收。

#### 2. 稀硝酸与铜反应

$$3Cu + 8HNO_3(稀) = 3Cu(NO_3)_2 + 2NO\uparrow + 4H_2O$$

- **现象**：铜片溶解，溶液变蓝，产生**无色气体**（NO），在试管口遇空气变为**红棕色**（$2NO + O_2 = 2NO_2$）。
- **装置特点**：通常使用**具支试管**或简易气体发生装置，先让NO将装置内空气排尽，否则试管口会出现红棕色干扰观察。
- **尾气处理**：由于NO与空气中$O_2$反应生成$NO_2$，最终都需用$NaOH$溶液吸收处理，或在密闭系统中进行，防止氮氧化物污染空气。

> **【思想方法】实验安全与绿色化学**：涉及有毒气体（$NO_2$、NO、$SO_2$、$NH_3$等）的实验，必须考虑：①反应在通风橱或密闭系统中进行；②尾气用适当试剂吸收；③尽可能选择低毒替代方案或微型实验。

> **【知识串联】硝酸的强氧化性实验规律**：硝酸与铜反应时，随着反应进行，浓硝酸逐渐变稀，还原产物由$NO_2$逐渐过渡到$NO$。因此，足量铜与一定量浓硝酸反应，最终收集到的气体是$NO_2$和NO的混合物。此类型计算常用**原子守恒**和**电子守恒**联立求解。

### 九、硫与氮的价类二维图比较与氧化还原深化

| 比较维度 | 硫元素 | 氮元素 |
|---------|--------|--------|
| **主要价态** | $-2, 0, +4, +6$ | $-3, 0, +2, +4, +5$ |
| **典型中间价态物质** | $SO_2$（$+4$）——既升又降 | $NO_2$（$+4$）——歧化；$NO$（$+2$）——既升又降 |
| **歧化反应** | $3S + 6OH^- \xrightarrow{\Delta} 2S^{2-} + SO_3^{2-} + 3H_2O$ | $3NO_2 + H_2O = 2NO_3^- + NO + 2H^+$ |
| **归中反应** | $2H_2S + SO_2 = 3S\downarrow + 2H_2O$ | $6NO + 4NH_3 = 5N_2 + 6H_2O$（SCR脱硝原理） |
| **工业氧化路线** | $\overset{+4}{SO_2} \xrightarrow{O_2} \overset{+6}{SO_3}$ | $\overset{-3}{NH_3} \xrightarrow{O_2} \overset{+2}{NO} \xrightarrow{O_2} \overset{+4}{NO_2}$ |

> **氧化还原深化**：判断非金属化合物之间能否发生反应，核心方法是分析**化合价变化的可能性**。例如$SO_2$与$H_2S$能反应（$+4$和$-2$归中为$0$），但$SO_2$与浓硫酸不能反应（无中间价态）；$NO_2$与$NH_3$在一定条件下可反应生成$N_2$（归中）。

## 5.3 无机非金属材料

无机非金属材料是以某些元素的氧化物、碳化物、氮化物、卤素化合物、硼化物以及硅酸盐、铝酸盐、磷酸盐等为主要成分的材料，是除金属材料、高分子材料以外的所有材料的统称。本节重点学习硅、二氧化硅、硅酸盐以及新型无机非金属材料。

---

### 一、硅单质（Si）

#### 1. 物理性质

晶体硅为灰黑色、有金属光泽的固体，熔点高（$1410^\circ C$）、硬度大、脆性大，是良好的**半导体材料**（导电性介于导体和绝缘体之间）。

#### 2. 化学性质

硅的化学性质不活泼，常温下仅与少数物质反应：

- **与氟气**：$Si + 2F_2 = SiF_4$
- **与氢氟酸**：$Si + 4HF = SiF_4\uparrow + 2H_2\uparrow$
- **与强碱**：$Si + 2NaOH + H_2O = Na_2SiO_3 + 2H_2\uparrow$

加热或高温下：
- **与$O_2$**：$Si + O_2 \xrightarrow{\Delta} SiO_2$
- **与$Cl_2$**：$Si + 2Cl_2 \xrightarrow{高温} SiCl_4$

#### 3. 制备与用途

- **工业制备**：用碳在高温下还原二氧化硅：
  $$SiO_2 + 2C \xrightarrow{高温} Si + 2CO\uparrow$$
  > **注意**：产物是$CO$而非$CO_2$，因为高温下碳过量且$CO_2$会与C反应生成CO。制得的是**粗硅**，需进一步提纯（如转化为$SiCl_4$再氢还原）得到**高纯硅**（纯度达99.9999999%以上，用于半导体）。

- **用途**：半导体材料（芯片、集成电路）、太阳能电池、硅合金。

### 二、二氧化硅（$SiO_2$）

#### 1. 物理性质与结构

$SiO_2$晶体属于**原子晶体**（与金刚石类似），每个Si原子与4个O原子形成共价键，每个O原子与2个Si原子相连，形成空间网状结构。因此熔点极高（约$1700^\circ C$）、硬度大、不溶于水。

自然界中的石英、水晶、玛瑙、沙子的主要成分都是$SiO_2$。

#### 2. 化学性质

$SiO_2$是**酸性氧化物**，但化学性质稳定，不与水反应生成对应的酸（硅酸不溶于水）。

**(1) 酸性氧化物通性（与碱、碱性氧化物反应）**

- **与强碱**：$SiO_2 + 2NaOH = Na_2SiO_3 + H_2O$
  > 因此盛放碱液的试剂瓶**不能用玻璃塞**（玻璃含$SiO_2$，会生成具有粘性的硅酸钠，将瓶塞与瓶口粘住），应使用橡胶塞。

- **与碱性氧化物**：$SiO_2 + CaO \xrightarrow{高温} CaSiO_3$（炼铁中除脉石的主要反应）

- **与盐（高温）**：$SiO_2 + Na_2CO_3 \xrightarrow{高温} Na_2SiO_3 + CO_2\uparrow$（工业制玻璃的反应之一）

**(2) 特性：与氢氟酸反应 —— 【易错警示③】**

$$SiO_2 + 4HF = SiF_4\uparrow + 2H_2O$$

> **【易错警示③】**：$SiO_2$是酸性氧化物，但**能与HF反应**，这是其特殊性质。因此氢氟酸**不能用玻璃瓶盛放**（可用塑料瓶），氢氟酸可用于雕刻玻璃。
> 
> 注意：不能因为$SiO_2$能与HF反应就否定其酸性氧化物的归类——酸性氧化物的定义是"能与碱反应生成盐和水的氧化物"，HF不是典型的含氧酸，此反应不违背定义。

### 三、硅酸与硅酸盐

#### 1. 硅酸（$H_2SiO_3$）

- **制备**：硅酸钠溶液与酸反应：$Na_2SiO_3 + 2HCl = 2NaCl + H_2SiO_3\downarrow$（胶状沉淀）
- **性质**：不溶于水的弱酸，酸性弱于碳酸。受热分解：$H_2SiO_3 \xrightarrow{\Delta} SiO_2 + H_2O$。

#### 2. 硅酸钠（$Na_2SiO_3$）—— 水玻璃

- 其水溶液俗称**水玻璃**，有粘性，可作粘合剂、防火剂、木材防腐剂。
- 与$CO_2$反应：$Na_2SiO_3 + CO_2 + H_2O = H_2SiO_3\downarrow + Na_2CO_3$（证明碳酸酸性强于硅酸）。

#### 3. 深度理解：硅酸盐的结构特点 —— $SiO_4$四面体

硅酸盐是构成地壳岩石、土壤、陶瓷、玻璃、水泥的主要成分，其结构极为丰富，核心结构单元是**硅氧四面体**（$SiO_4$）。

- **结构单元**：每个Si原子位于四面体中心，与4个O原子相连（Si—O键），形成$[SiO_4]^{4-}$四面体。
- **连接方式**：通过共用顶角氧原子，硅氧四面体可以连接成链状、层状或三维网状骨架结构：
  - **链状硅酸盐**：如石棉，$SiO_4$四面体共用2个顶角氧，形成无限长链。
  - **层状硅酸盐**：如黏土、滑石、云母，$SiO_4$四面体共用3个顶角氧，形成二维平面层，层间可嵌入$K^+$、$Mg^{2+}$等阳离子。
  - **骨架状硅酸盐**：如沸石、长石，$SiO_4$四面体共用全部4个顶角氧，形成三维网状骨架，空隙中可容纳阳离子和水分子。

> **【高考关联】**：虽然不要求画四面体连接方式，但需理解**硅酸盐结构的复杂性决定了其种类繁多**，且其结构稳定性与Si—O共价键强度高有关。水泥硬化、陶瓷烧制、玻璃软化等工艺本质上都与硅酸盐网络结构的断裂与重组有关。

#### 4. 传统无机非金属材料

| 材料 | 原料 | 主要反应/工艺 | 主要成分 |
|------|------|--------------|---------|
| **陶瓷** | 黏土（含水铝硅酸盐） | 高温烧结 | 复杂硅酸盐 |
| **玻璃** | 纯碱、石灰石、石英砂 | 高温熔融：$Na_2CO_3 + SiO_2 \xrightarrow{高温} Na_2SiO_3 + CO_2\uparrow$；$CaCO_3 + SiO_2 \xrightarrow{高温} CaSiO_3 + CO_2\uparrow$ | $Na_2SiO_3$、$CaSiO_3$、$SiO_2$的混合物（无固定熔点） |
| **水泥** | 石灰石、黏土、石膏 | 研磨→煅烧→加石膏磨细 | 硅酸三钙（$3CaO\cdot SiO_2$）、硅酸二钙等 |

> **【注意】**：普通玻璃是混合物，没有固定熔点，加热时逐渐软化（玻璃态），这是与晶体硅的本质区别。

随着科技发展，一批具有特殊结构和优异性能的新型无机非金属材料应运而生，它们是现代高新技术的重要物质基础。

## 【思想方法】本章核心思想方法总结

### 1. 价类二维图 —— 元素化合物学习的"导航地图"

价类二维图以**化合价**为纵轴、**物质类别**（单质、氧化物、酸、碱、盐）为横轴，将某一元素的常见物质定位在坐标系中。它的核心价值在于：

- **预测物质性质**：某一点的位置决定了其主要化学性质（如$+4$价硫既有氧化性又有还原性）。
- **梳理转化关系**：同价态不同类别之间转化通常是**非氧化还原反应**（酸碱盐之间的复分解、酸性氧化物与碱反应等）；不同价态之间的转化通常是**氧化还原反应**（需要氧化剂或还原剂）。
- **快速诊断陌生反应**：面对陌生情境时，先确定元素价态变化趋势，再寻找合适的氧化剂/还原剂及反应介质（酸碱性）。

### 2. 守恒思想 —— 定量计算的基石

- **原子守恒**：化学反应前后原子种类和数目不变。应用于多步反应计算、过量问题、混合物计算。例如，工业制硫酸中，1 mol S最终生成1 mol $H_2SO_4$，无论中间经历多少步骤。
- **电子守恒**：氧化还原反应中，氧化剂得电子总数 = 还原剂失电子总数。应用于氧化还原方程式配平、电化学计算、多元素复杂反应计算。例如，铜与硝酸反应中，铜失去的电子总数 = 氮元素得到的电子总数。
- **电荷守恒**：溶液中阳离子所带正电荷总数 = 阴离子所带负电荷总数。应用于离子浓度计算、溶液酸碱性判断。

> **典型应用**：铜与浓硝酸反应后溶液中，$n(NO_3^-) = n(H^+) + 2n(Cu^{2+})$（电荷守恒），结合电子守恒可快速计算气体产物量。

### 3. 工业条件优化思想 —— 化学原理走向工业应用的桥梁

化学反应原理（速率与平衡）指导工业生产，但工业实际条件的选择必须综合考量：

| 考量维度 | 具体问题 | 本章案例 |
|---------|---------|---------|
| **化学平衡** | 如何提高平衡转化率？ | 合成氨高压、接触法制硫酸用过量空气 |
| **反应速率** | 如何缩短达到平衡的时间？ | 合成氨、接触法制硫酸均使用催化剂 |
| **催化剂活性** | 催化剂最佳活性温度是多少？ | $V_2O_5$在400~500°C活性最高；合成氨铁触媒约500°C |
| **能耗与成本** | 极端条件是否经济？ | 接触法制硫酸用常压而非高压；合成氨分离液化$NH_3$而非加压到极高 |
| **设备与安全** | 材料能否承受？ | 高温高压对反应釜材质要求极高；浓硫酸用铁质容器需考虑钝化与腐蚀 |
| **循环利用** | 如何提高原子利用率？ | NO循环氧化、合成氨原料气循环利用 |
| **环境保护** | 如何处理尾气？ | $SO_2$用碱液吸收、氮氧化物用碱液吸收 |

> **核心理念**：工业生产追求的是**经济效益、社会效益和环境效益的统一**，而非单纯理论转化率的最大化。这是将化学知识转化为工程实践的关键思维模式。
