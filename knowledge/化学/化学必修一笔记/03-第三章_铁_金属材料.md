## 3.1 铁及其化合物

---

### 一、【来龙去脉】铁在人类文明发展中的历史地位

#### 1.1 从青铜时代到铁器时代

人类对铁的利用，显著改变了文明进程。

**陨铁时代**（约公元前4000年前）：人类最早接触的铁来自天外的陨铁（主要成分为铁镍合金）。由于陨铁在地表中分布稀少，古埃及人称其为"天石"，用于制作法老的陪葬品和宗教器物。

**青铜时代**（约公元前3300年—公元前1200年）：铜锡合金（青铜）的冶炼技术日趋成熟。但青铜有两个致命缺陷：一是锡矿资源稀缺，二是青铜硬度虽高却较脆，不适合制作大型农具和兵器。

**铁器时代**（约公元前1200年始）：铁的冶炼标志着人类文明发生重大转变。铁取代青铜成为主导金属材料，原因有三：

| 比较维度 | 铜/青铜 | 铁 |
|---------|--------|-----|
| 地壳丰度 | 铜约0.006%，锡更稀少 | 铁约5.1%，居金属元素第二位 |
| 矿石分布 | 分布集中，开采受限 | 广泛分布，赤铁矿、磁铁矿遍布全球 |
| 冶炼难度 | 较低（约1000°C即可） | 较高（需达到1538°C以上） |
| 机械性能 | 硬度高但脆性大 | 韧性好，强度可调（通过锻打、淬火） |
| 用途拓展 | 适合礼器、兵器 | 适合农具、工具、建筑，促进农业生产发展 |

> **化学视角**：铁的熔点（$1538^{\circ}C$）远高于铜（$1083^{\circ}C$），早期人类难以获得如此高温。直到鼓风技术成熟，炉温得以提升，铁器时代才正式开启。

#### 1.2 为什么铁在现代工业中仍然不可替代？

进入21世纪，铁（以钢的形式）年产量超过18亿吨，是产量最大的金属材料。其不可替代性源于：

**① 资源与成本的绝对优势**

铁是地壳中含量第四的元素（$O > Si > Al > Fe$），也是含量第二的金属元素。铁矿资源丰富，开采冶炼成本低于其他金属。

**② 优异的综合性能**

- 强度与韧性的平衡：通过合金化（加C、Mn、Cr、Ni等）和热处理，可以获得从极软到极硬的各种性能组合
- 磁性：铁是唯一室温下具有铁磁性的常见金属，是电机、变压器、磁存储的基础材料
- 可加工性：铸造、锻造、轧制、焊接等工艺成熟

**③ 可回收性与循环经济**

钢铁是目前回收率最高的金属材料。废钢回炉重炼能耗仅为从矿石冶炼的1/4，碳排放降低约75%，是实现"双碳"目标的关键材料。

**④ 某些领域的不可替代性**

| 应用领域 | 关键性能 | 替代可能性 |
|---------|---------|----------|
| 建筑钢筋 | 高强度、低成本、与混凝土结合好 | 短期内无替代方案 |
| 汽车车身 | 可吸收冲击能量（溃缩性） | 铝合金部分替代，但成本高 |
| 电力变压器铁芯 | 高磁导率、低矫顽力 | 硅钢片不可替代 |
| 磁悬浮/核磁共振 | 铁磁性 | 无替代材料 |

### 二、【基础精讲】铁单质的性质

#### 2.1 铁的原子结构与位置

铁（$Fe$，Iron）位于元素周期表**第四周期第VIII族**（过渡金属元素）。

- 原子序数：26
- 电子排布式：$1s^22s^22p^63s^23p^63d^64s^2$（或简写为$[Ar]3d^64s^2$）
- 常见化合价：$+2$价、$+3$价，另有$+6$价（高铁酸盐，如$K_2FeO_4$）

> **价电子分析**：Fe原子失去电子时，先失去能量较高的$4s$电子，再失去$3d$电子。失去2个电子形成$Fe^{2+}$（$3d^6$），再失去1个$3d$电子形成$Fe^{3+}$（$3d^5$）。由于$3d^5$是半充满的稳定结构，因此$Fe^{3+}$比$Fe^{2+}$更加稳定。

#### 2.2 铁的物理性质

| 物理性质 | 数据 |
|---------|------|
| 颜色、状态 | 银白色金属光泽，固体 |
| 密度 | $7.86 \, g/cm^3$ |
| 熔点 | $1538^{\circ}C$ |
| 沸点 | $2862^{\circ}C$ |
| 硬度 | 较软（纯铁），但含碳后硬度显著增大 |
| 导电性 | 良好（次于铜、银、金、铝） |
| 导热性 | 良好 |
| 延展性 | 良好（可拉成丝、压成薄片） |
| 磁性 | **铁磁性**（能被磁化，是铁的独特性质） |

> **注意**：纯铁质地较软，日常生活中接触到的"铁"大多是钢（铁碳合金），硬度远高于纯铁。

#### 2.3 铁的化学性质

铁的化学性质较活泼，但不如钠、钾等碱金属剧烈。铁的主要反应可归纳为：**与非金属反应、与酸反应、与盐溶液反应**。

##### （1）铁与非金属单质的反应

**① 铁与氧气反应**

铁在纯氧中剧烈燃烧，火星四射：

$$3Fe + 2O_2 \xrightarrow{点燃} Fe_3O_4$$

> **产物辨析**：产物是四氧化三铁（$Fe_3O_4$），不是氧化铁（$Fe_2O_3$）。$Fe_3O_4$可以看作$FeO \cdot Fe_2O_3$的复合氧化物，其中Fe显$+2$价和$+3$价（各1个$Fe^{3+}$和2个$Fe^{2+}$）。

铁在潮湿空气中缓慢氧化——**铁的锈蚀**：

$$4Fe + 3O_2 + 6H_2O = 4Fe(OH)_3 \quad （总反应，实际过程复杂）$$

最终生成的铁锈主要成分为$Fe_2O_3 \cdot nH_2O$（水合氧化铁），呈红褐色，结构疏松多孔，不能阻止内部铁继续被腐蚀。

**② 铁与氯气反应**

$$2Fe + 3Cl_2 \xrightarrow{点燃} 2FeCl_3$$

> **重要考点**：$Cl_2$是强氧化剂，能将Fe氧化至最高价态（$+3$价）。产物为$FeCl_3$，**不是**$FeCl_2$。这是判断氧化剂强弱的重要标志。

**③ 铁与硫反应**

$$Fe + S \xrightarrow{\Delta} FeS$$

> **对比分析**：S的氧化性远弱于$Cl_2$，只能将Fe氧化至$+2$价，产物为硫化亚铁（$FeS$）。

**④ 铁与碘反应**

$$Fe + I_2 \xrightarrow{\Delta} FeI_2$$

> **深化理解**：$I_2$的氧化性更弱，同样只能生成$FeI_2$。实际上，$Fe^{3+}$的氧化性强于$I_2$，所以即便生成$FeI_3$也会立即发生反应：$2Fe^{3+} + 2I^- = 2Fe^{2+} + I_2$。

##### （2）铁与酸的反应

**① 铁与非氧化性酸（盐酸、稀硫酸）反应**

$$Fe + 2HCl = FeCl_2 + H_2 \uparrow$$

离子方程式：

$$Fe + 2H^+ = Fe^{2+} + H_2 \uparrow$$

> **产物**：Fe被$H^+$（弱氧化剂）氧化为$Fe^{2+}$，生成$Fe^{2+}$盐和氢气。

**② 铁与氧化性酸（稀硝酸）反应**

$$Fe + 4HNO_3(稀) = Fe(NO_3)_3 + NO \uparrow + 2H_2O \quad （Fe少量）$$

$$3Fe + 8HNO_3(稀) = 3Fe(NO_3)_2 + 2NO \uparrow + 4H_2O \quad （Fe过量）$$

> **重要考点**：Fe与稀硝酸反应的产物与Fe的用量有关——这是"隐性考点"中的重点，详见后文【易错警示】。

**③ 铁与浓硫酸、浓硝酸的反应——钝化**

冷的浓硫酸或浓硝酸中，铁表面会形成一层致密的氧化物保护膜，阻止反应继续进行，这个现象称为**钝化**。

> **本质**：钝化不是"不反应"，而是发生了快速的氧化反应，在金属表面生成了一层极薄的、致密的氧化膜（主要成分为$Fe_3O_4$），这层膜将金属与酸隔离，反应终止。加热后氧化膜被破坏，反应继续进行。

##### （3）铁与盐溶液的反应

**① 铁与硫酸铜溶液反应（湿法炼铜）**

$$Fe + CuSO_4 = FeSO_4 + Cu$$

离子方程式：

$$Fe + Cu^{2+} = Fe^{2+} + Cu$$

> **应用原理**：利用Fe的还原性强于Cu，将$Cu^{2+}$还原为Cu单质。这是我国古代"湿法冶铜"的原理，《淮南万毕术》中就有"曾青得铁则化为铜"的记载（"曾青"即硫酸铜矿石）。

**② 铁与氯化铁溶液反应**

$$Fe + 2FeCl_3 = 3FeCl_2$$

离子方程式：

$$Fe + 2Fe^{3+} = 3Fe^{2+}$$

> **铁三角的重要一环**：这是Fe与$Fe^{3+}$之间的归中反应，体现了$Fe^{3+}$的氧化性。

### 三、【基础精讲】铁的氧化物

铁有三种常见的氧化物：氧化亚铁（FeO）、氧化铁（$Fe_2O_3$）和四氧化三铁（$Fe_3O_4$）。

| 性质 | FeO（氧化亚铁） | $Fe_2O_3$（氧化铁） | $Fe_3O_4$（四氧化三铁） |
|------|---------------|-------------------|---------------------|
| **俗名** | — | 铁红 | 磁性氧化铁 |
| **颜色、状态** | 黑色粉末 | 红棕色粉末 | 黑色晶体 |
| **Fe的价态** | $+2$价 | $+3$价 | $+2$价和$+3$价（混合） |
| **结构理解** | — | — | 可视为$FeO \cdot Fe_2O_3$ |
| **溶解性** | 不溶于水 | 不溶于水 | 不溶于水 |
| **与盐酸反应** | $FeO + 2HCl = FeCl_2 + H_2O$ | $Fe_2O_3 + 6HCl = 2FeCl_3 + 3H_2O$ | $Fe_3O_4 + 8HCl = FeCl_2 + 2FeCl_3 + 4H_2O$ |
| **与稀硝酸反应** | $3FeO + 10HNO_3 = 3Fe(NO_3)_3 + NO\uparrow + 5H_2O$ | $Fe_2O_3 + 6HNO_3 = 2Fe(NO_3)_3 + 3H_2O$ | 复杂（产物为$Fe^{3+}$） |
| **稳定性** | 不稳定，空气中加热被氧化 | 稳定 | 稳定 |
| **主要用途** | — | 红色颜料、炼铁原料 | 炼铁原料、磁性材料 |

#### 3.1 重要反应详解

**（1）$Fe_3O_4$与酸反应的特点**

$Fe_3O_4$与盐酸反应时，同时生成$Fe^{2+}$和$Fe^{3+}$两种盐：

$$Fe_3O_4 + 8HCl = FeCl_2 + 2FeCl_3 + 4H_2O$$

离子方程式：

$$Fe_3O_4 + 8H^+ = Fe^{2+} + 2Fe^{3+} + 4H_2O$$

> **检验方法**：向反应后的溶液中加入KSCN溶液，溶液变红色，证明有$Fe^{3+}$存在。

**（2）FeO与稀硝酸的反应——氧化还原反应**

$Fe^{2+}$具有还原性，遇到强氧化性的稀硝酸会被氧化：

$$3FeO + 10HNO_3(稀) = 3Fe(NO_3)_3 + NO \uparrow + 5H_2O$$

> **注意**：产物是$Fe(NO_3)_3$而非$Fe(NO_3)_2$，因为$HNO_3$是氧化性酸，将$Fe^{2+}$氧化为$Fe^{3+}$。同理，$Fe_3O_4$与稀硝酸反应也只生成$Fe^{3+}$的盐。

**（3）$Fe_2O_3$的还原——高炉炼铁原理**

$$Fe_2O_3 + 3CO \xrightarrow{高温} 2Fe + 3CO_2$$

或：

$$Fe_2O_3 + 2Al \xrightarrow{高温} 2Fe + Al_2O_3 \quad （铝热反应）$$

### 四、【基础精讲】铁的氢氧化物

铁的氢氧化物有两种：氢氧化亚铁（$Fe(OH)_2$）和氢氧化铁（$Fe(OH)_3$）。

| 性质 | $Fe(OH)_2$（氢氧化亚铁） | $Fe(OH)_3$（氢氧化铁） |
|------|-----------------------|---------------------|
| **颜色、状态** | 白色絮状沉淀 | 红褐色沉淀 |
| **溶解性** | 不溶于水 | 不溶于水 |
| **与酸反应** | $Fe(OH)_2 + 2H^+ = Fe^{2+} + 2H_2O$ | $Fe(OH)_3 + 3H^+ = Fe^{3+} + 3H_2O$ |
| **稳定性** | 极不稳定，易被氧化 | 较稳定，加热分解 |
| **热分解** | — | $2Fe(OH)_3 \xrightarrow{\Delta} Fe_2O_3 + 3H_2O$ |

#### 4.1 $Fe(OH)_2$的制备——实验重点

**（1）制备原理**

利用可溶性亚铁盐与强碱溶液反应：

$$FeSO_4 + 2NaOH = Fe(OH)_2 \downarrow + Na_2SO_4$$

离子方程式：

$$Fe^{2+} + 2OH^- = Fe(OH)_2 \downarrow$$

**（2）实验现象——"白色→灰绿色→红褐色"**

刚生成的$Fe(OH)_2$是**白色絮状沉淀**，但在空气中迅速变色：

$$4Fe(OH)_2 + O_2 + 2H_2O = 4Fe(OH)_3$$

> **现象描述**：白色沉淀 $\rightarrow$ 迅速变为灰绿色 $\rightarrow$ 最终变为红褐色

#### 4.2 为什么$Fe(OH)_2$白色沉淀会迅速变色？

**【深入分析】从电极电势看氧化还原趋势**

$Fe(OH)_2$之所以极易被氧化，根本原因在于$Fe^{2+}/Fe^{3+}$电对的标准电极电势较低：

$$E^{\theta}(Fe^{3+}/Fe^{2+}) = +0.77 \, V$$

而氧气在碱性条件下的电极电势：

$$O_2 + 2H_2O + 4e^- = 4OH^- \quad E^{\theta} = +0.40 \, V$$

两者之差$\Delta E^{\theta} = 0.40 - 0.77 = -0.37 \, V$看似不大，但实际上$Fe(OH)_2$的溶度积极小（$K_{sp} = 4.87 \times 10^{-17}$），其溶解产生的$Fe^{2+}$浓度极低，使得实际电极电势更低，远低于氧气的还原电势，因此氧化反应趋势很大。

**微观层面的理解**：

$Fe^{2+}$的$3d^6$电子构型比$Fe^{3+}$的半充满$3d^5$构型能量高、稳定性差。失去一个电子形成$Fe^{3+}$是热力学上有利的自发过程。氧气作为温和的氧化剂，即可将$Fe^{2+}$氧化。

#### 4.3 【实验思想】制备$Fe(OH)_2$的防氧化措施

教材中提到的多种防止$Fe(OH)_2$被氧化的实验操作，按防氧化效果可分类如下：

| 操作措施 | 防氧化原理 | 效果评价 |
|---------|----------|---------|
| **煮沸NaOH溶液** | 驱除溶解氧（$O_2$溶解度随温度升高降低） | 基础操作，不能完全除氧 |
| **使用新制FeSO₄溶液** | 避免$Fe^{2+}$久置被氧化（$4Fe^{2+} + O_2 + 4H^+ = 4Fe^{3+} + 2H_2O$） | 防止反应物已被氧化 |
| **滴管插入液面下** | 避免带氧气泡搅动液面，减少空气接触 | 中等效果 |
| **液面上加一层苯（或煤油）** | 隔绝空气（油封），物理隔离氧气 | 效果较好 |
| **通入惰性气体（如$N_2$）** | 排尽装置中的空气 | 效果最好 |

**综合实验方案**（以上措施的组合）：

1. 先向$FeSO_4$溶液和NaOH溶液中分别通入$N_2$排氧
2. 将NaOH溶液煮沸冷却
3. 用长胶头滴管吸取NaOH溶液，插入$FeSO_4$液面以下
4. 液面上覆盖一层苯或煤油
5. 挤压滴管，让NaOH与$FeSO_4$在液面下反应

这样可以观察到**持续较长时间的白色絮状沉淀**。

#### 4.4 $Fe(OH)_3$的性质

**（1）与酸反应**

$$Fe(OH)_3 + 3HCl = FeCl_3 + 3H_2O$$

**（2）受热分解**

$$2Fe(OH)_3 \xrightarrow{\Delta} Fe_2O_3 + 3H_2O$$

> 应用：工业上通过控制$Fe(OH)_3$的分解条件，制备不同晶型的$Fe_2O_3$颜料。

**（3）$Fe(OH)_3$胶体的制备**

向沸水中逐滴加入饱和$FeCl_3$溶液，继续煮沸至溶液呈红褐色：

$$FeCl_3 + 3H_2O \xrightarrow{\Delta} Fe(OH)_3(胶体) + 3HCl$$

> **注意**：这里生成的是**胶体**而非沉淀，因此方程式中不写"$\downarrow$"，而标注"(胶体)"。这是制备氢氧化铁胶体的常用方法。

### 五、【深入理解】铁三角——Fe、$Fe^{2+}$、$Fe^{3+}$的转化关系

铁三角是本章的主要知识框架，也是高考的高频考点。掌握铁三角的转化关系，关键在于理解：**什么条件下氧化，什么条件下还原，产物是什么**。

#### 5.1 铁三角转化关系图

```
                    强氧化剂
              Fe —————————→ Fe³⁺
              ↑ \              / ↑
              |  \   弱氧化  /  |
        还原剂|   \   剂   /   |氧化剂
              |    \      /    |
              |     Fe²⁺ ←———→|
              |          还原剂 |
              └───────────────┘
```

#### 5.2 详细转化路径

**路径一：Fe $\rightarrow$ $Fe^{2+}$（弱氧化剂氧化铁）**

| 氧化剂 | 反应方程式 | 条件 |
|--------|----------|------|
| $H^+$（非氧化性酸） | $Fe + 2H^+ = Fe^{2+} + H_2 \uparrow$ | 稀HCl、稀$H_2SO_4$ |
| $Cu^{2+}$ | $Fe + Cu^{2+} = Fe^{2+} + Cu$ | 可溶性铜盐 |
| $Fe^{3+}$ | $Fe + 2Fe^{3+} = 3Fe^{2+}$ | 可溶性铁盐 |
| S | $Fe + S \xrightarrow{\Delta} FeS$ | 加热 |
| $I_2$ | $Fe + I_2 \xrightarrow{\Delta} FeI_2$ | 加热 |

**路径二：Fe $\rightarrow$ $Fe^{3+}$（强氧化剂氧化铁）**

| 氧化剂 | 反应方程式 | 条件 |
|--------|----------|------|
| $Cl_2$ | $2Fe + 3Cl_2 \xrightarrow{点燃} 2FeCl_3$ | 点燃 |
| $Br_2$ | $2Fe + 3Br_2 = 2FeBr_3$ | 加热 |
| 稀$HNO_3$（过量） | $Fe + 4HNO_3 = Fe(NO_3)_3 + NO \uparrow + 2H_2O$ | — |
| 浓$H_2SO_4$（加热） | $2Fe + 6H_2SO_4(浓) \xrightarrow{\Delta} Fe_2(SO_4)_3 + 3SO_2 \uparrow + 6H_2O$ | 加热 |

**路径三：$Fe^{2+}$ $\rightarrow$ $Fe^{3+}$（$Fe^{2+}$被氧化）**

| 氧化剂 | 反应方程式 | 备注 |
|--------|----------|------|
| $Cl_2$ | $2Fe^{2+} + Cl_2 = 2Fe^{3+} + 2Cl^-$ | 最常用 |
| $Br_2$ | $2Fe^{2+} + Br_2 = 2Fe^{3+} + 2Br^-$ | — |
| $H_2O_2$（酸性） | $2Fe^{2+} + H_2O_2 + 2H^+ = 2Fe^{3+} + 2H_2O$ | 绿色氧化剂 |
| 稀$HNO_3$ | $3Fe^{2+} + 4H^+ + NO_3^- = 3Fe^{3+} + NO \uparrow + 2H_2O$ | — |
| $KMnO_4$（酸性） | $5Fe^{2+} + MnO_4^- + 8H^+ = 5Fe^{3+} + Mn^{2+} + 4H_2O$ | 常用于滴定分析 |
| $O_2$（空气） | $4Fe^{2+} + O_2 + 4H^+ = 4Fe^{3+} + 2H_2O$ | 缓慢氧化 |

> **关键理解**：$Fe^{2+}$既有氧化性又有还原性，但以**还原性为主**。上表中所有反应都体现了$Fe^{2+}$的还原性。$Fe^{2+}$被氧化时，产物一定是$Fe^{3+}$。

**路径四：$Fe^{3+}$ $\rightarrow$ $Fe^{2+}$（$Fe^{3+}$被还原）**

| 还原剂 | 反应方程式 | 备注 |
|--------|----------|------|
| Fe | $2Fe^{3+} + Fe = 3Fe^{2+}$ | 归中反应 |
| Cu | $2Fe^{3+} + Cu = 2Fe^{2+} + Cu^{2+}$ | 印刷电路板蚀刻原理 |
| Zn | $2Fe^{3+} + Zn = 2Fe^{2+} + Zn^{2+}$ | 活泼金属还原 |
| $H_2S$ | $2Fe^{3+} + H_2S = 2Fe^{2+} + S \downarrow + 2H^+$ | — |
| $I^-$ | $2Fe^{3+} + 2I^- = 2Fe^{2+} + I_2$ | $Fe^{3+}$氧化$I^-$ |
| $S^{2-}$（少量） | $2Fe^{3+} + S^{2-} = 2Fe^{2+} + S \downarrow$ | 注意量的关系 |

**路径五：$Fe^{3+}$ $\rightarrow$ Fe（$Fe^{3+}$被强还原剂还原）**

| 还原剂 | 反应方程式 | 条件 |
|--------|----------|------|
| Al | $Fe_2O_3 + 2Al \xrightarrow{高温} 2Fe + Al_2O_3$ | 铝热反应 |
| CO | $Fe_2O_3 + 3CO \xrightarrow{高温} 2Fe + 3CO_2$ | 高炉炼铁 |
| C | $2Fe_2O_3 + 3C \xrightarrow{高温} 4Fe + 3CO_2 \uparrow$ | 高温 |
| Zn（过量） | $2Fe^{3+} + 3Zn（过量）= 2Fe + 3Zn^{2+}$ | 金属过量 |

**路径六：$Fe^{2+}$ $\rightarrow$ Fe（$Fe^{2+}$被强还原剂还原）**

| 还原剂 | 反应方程式 |
|--------|----------|
| Zn | $Fe^{2+} + Zn = Fe + Zn^{2+}$ |
| Al | $3Fe^{2+} + 2Al = 3Fe + 2Al^{3+}$ |

#### 5.3 氧化剂强弱与Fe产物的关系——【隐性考点】

| 氧化剂 | 氧化性强弱 | Fe的产物 | 对应反应 |
|--------|----------|---------|---------|
| $Cl_2$、$Br_2$ | 很强 | $Fe^{3+}$ | $2Fe + 3Cl_2 = 2FeCl_3$ |
| 稀$HNO_3$、浓$H_2SO_4$（热） | 很强 | $Fe^{3+}$ | $Fe + 4HNO_3 = Fe(NO_3)_3 + NO \uparrow + 2H_2O$ |
| $H_2O_2$（酸性） | 较强 | $Fe^{3+}$ | $2Fe^{2+} + H_2O_2 + 2H^+ = 2Fe^{3+} + 2H_2O$ |
| $S$、$I_2$ | 较弱 | $Fe^{2+}$ | $Fe + S \xrightarrow{\Delta} FeS$ |
| $H^+$（非氧化性酸） | 弱 | $Fe^{2+}$ | $Fe + 2HCl = FeCl_2 + H_2 \uparrow$ |
| $Cu^{2+}$ | 弱 | $Fe^{2+}$ | $Fe + CuSO_4 = FeSO_4 + Cu$ |

> **规律总结**：$Cl_2$、$Br_2$、$HNO_3$等强氧化剂将Fe氧化至$Fe^{3+}$；$S$、$I_2$、$H^+$、$Cu^{2+}$等弱氧化剂只能将Fe氧化至$Fe^{2+}$

### 六、【基础精讲】$Fe^{2+}$与$Fe^{3+}$的检验

#### 6.1 $Fe^{3+}$的检验——KSCN溶液法

**原理**：$Fe^{3+}$与SCN$^-$（硫氰根离子）反应，生成**血红色的络合物**。

$$Fe^{3+} + 3SCN^- = Fe(SCN)_3$$

> **现象**：向待测溶液中滴加KSCN溶液，溶液立即变为**血红色**（或红色）。

**离子反应的本质**：$Fe^{3+}$有空轨道，$SCN^-$有孤对电子，两者通过配位键结合形成络离子$[Fe(SCN)]^{2+}$等，呈现特征的血红色。

**注意事项**：
- 该反应非常灵敏，微量$Fe^{3+}$即可检出
- 生成的$Fe(SCN)_3$是**络合物（配合物）**，不是沉淀，方程式中不打"$\downarrow$"
- 络合反应是可逆的，加入强还原剂（如Fe粉）可将$Fe^{3+}$还原，红色褪去：

$$2Fe(SCN)_3 + Fe = 3Fe^{2+} + 6SCN^-$$

#### 6.2 $Fe^{2+}$的检验

**方法一：先加KSCN，再加氧化剂**

步骤：
1. 取少量待测液，滴加KSCN溶液 $\rightarrow$ **无明显现象**（证明无$Fe^{3+}$）
2. 再滴加氯水（或$H_2O_2$） $\rightarrow$ **溶液变红色**（证明生成了$Fe^{3+}$，原溶液含$Fe^{2+}$）

涉及反应：

$$2Fe^{2+} + Cl_2 = 2Fe^{3+} + 2Cl^-$$

$$Fe^{3+} + 3SCN^- = Fe(SCN)_3$$

**方法二：加NaOH溶液法**

向待测液中加入NaOH溶液：
- 若生成**白色絮状沉淀**，迅速变为灰绿色，最终变为红褐色，则含$Fe^{2+}$

$$Fe^{2+} + 2OH^- = Fe(OH)_2 \downarrow \quad （白色）$$

$$4Fe(OH)_2 + O_2 + 2H_2O = 4Fe(OH)_3 \quad （红褐色）$$

**方法三：铁氰化钾$K_3[Fe(CN)_6]$法**

$Fe^{2+}$与$K_3[Fe(CN)_6]$反应生成**蓝色沉淀**（滕氏蓝）：

$$3Fe^{2+} + 2[Fe(CN)_6]^{3-} = Fe_3[Fe(CN)_6]_2 \downarrow$$

这是检验$Fe^{2+}$最灵敏、最专一的方法。

#### 6.3 $Fe^{3+}$与$Fe^{2+}$检验方法对比

| 检验方法 | $Fe^{3+}$ | $Fe^{2+}$ |
|---------|----------|----------|
| KSCN溶液 | 立即变红色 | 无明显变化 |
| NaOH溶液 | 红褐色沉淀 | 白色$\rightarrow$灰绿$\rightarrow$红褐 |
| $K_3[Fe(CN)_6]$ | 无明显变化 | 蓝色沉淀 |
| $K_4[Fe(CN)_6]$ | 蓝色沉淀（普鲁士蓝） | 无明显变化 |

> **拓展知识**：普鲁士蓝$Fe_4[Fe(CN)_6]_3$（$Fe^{3+}$与$[Fe(CN)_6]^{4-}$）和滕氏蓝$Fe_3[Fe(CN)_6]_2$（$Fe^{2+}$与$[Fe(CN)_6]^{3-}$）结构相同，是同一物质的不同名称。这两种蓝色颜料在工业上有重要用途。

### 七、【深入理解】$FeCl_3$蚀刻印刷电路板原理

#### 7.1 印刷电路板的制作

印刷电路板（PCB）是现代电子工业的基础。利用$FeCl_3$溶液蚀刻铜板的原理正是$Fe^{3+}$的氧化性：

$$2FeCl_3 + Cu = 2FeCl_2 + CuCl_2$$

离子方程式：

$$2Fe^{3+} + Cu = 2Fe^{2+} + Cu^{2+}$$

#### 7.2 工艺流程

1. **覆铜板准备**：在绝缘基板（玻璃纤维环氧树脂板）上覆一层薄铜
2. **感光成像**：涂覆感光胶，通过掩模版曝光、显影，保留需要的铜线路图案
3. **蚀刻**：将覆铜板浸入$FeCl_3$溶液中，未被保护的铜被腐蚀溶解
4. **去膜**：去除保护胶，露出铜线路
5. **回收**：蚀刻废液中含有$Cu^{2+}$和$Fe^{2+}$，可通过电解回收铜

#### 7.3 化学原理的分析

**为什么用$FeCl_3$而不是其他氧化剂？**

| 因素 | 分析 |
|------|------|
| 选择性 | $Fe^{3+}$能氧化Cu，但不能腐蚀基板（树脂） |
| 可控性 | 反应速率适中，便于控制蚀刻深度 |
| 经济性 | $FeCl_3$成本低，可部分回收再生 |
| 废液处理 | 废液中的铜可回收，铁盐可转化为净水剂 |

**$FeCl_3$蚀刻液的再生**：

蚀刻过程中$Fe^{3+}$被消耗，$Fe^{2+}$不断累积。可通过通入$Cl_2$或加入$H_2O_2$再生：

$$2Fe^{2+} + Cl_2 = 2Fe^{3+} + 2Cl^-$$

这样$FeCl_3$可以循环使用。

### 八、【知识串联】铁与初中化学的衔接

#### 8.1 金属活动性顺序的深化

初中学习的金属活动性顺序：

$$K > Ca > Na > Mg > Al > Zn > Fe > Sn > Pb > (H) > Cu > Hg > Ag > Pt > Au$$

**铁的"位置意义"**：
- Fe位于H之前：能与酸反应放出$H_2$
- Fe位于Cu之前：能置换铜盐溶液中的$Cu^{2+}$
- Fe不如Al活泼：Al能从铁的氧化物中还原出Fe（铝热反应）

#### 8.2 金属冶炼的本质——还原反应

所有金属冶炼的本质都是**还原反应**——将金属化合物中的金属离子还原为金属单质。还原方法的选择取决于金属的活泼性：

| 金属类型 | 代表金属 | 冶炼方法 | 原理 |
|---------|---------|---------|------|
| 极活泼金属 | K、Ca、Na、Mg、Al | 电解法 | 电解熔融盐或氧化物 |
| 中等活泼金属 | Zn、Fe、Sn、Pb | 热还原法 | CO、C、$H_2$、活泼金属作还原剂 |
| 不活泼金属 | Cu、Hg、Ag | 热分解法 | 加热分解氧化物 |
| 极不活泼金属 | Pt、Au | 物理分离法 | 自然界以单质存在 |

**铁的冶炼**属于热还原法，高炉中发生的主要反应：

$$3CO + Fe_2O_3 \xrightarrow{高温} 2Fe + 3CO_2$$

> **为什么是CO还原而不是C直接还原？**
> 
> 高炉中C与$O_2$先生成$CO_2$，$CO_2$再与炽热的C反应生成CO：
> $C + CO_2 \xrightarrow{高温} 2CO$
> CO是气体还原剂，能与固体矿石充分接触，还原效率更高。$CO_2$不能继续还原铁矿石。

#### 8.3 与氧化还原反应的联系

铁的多价态变化为氧化还原反应提供了系统化的研究对象：

| 氧化还原概念 | 铁元素中的体现 |
|------------|--------------|
| 氧化剂/还原剂 | $Fe^{3+}$是常见氧化剂，Fe、$Fe^{2+}$是常见还原剂 |
| 归中反应 | $Fe + 2Fe^{3+} = 3Fe^{2+}$（$0$价与$+3$价归中至$+2$价） |
| 歧化反应 | 铁元素一般不发生歧化（$Fe^{2+}$不歧化为Fe和$Fe^{3+}$） |
| 氧化性强弱比较 | 根据产物判断氧化剂强弱（$Cl_2 > S$） |

### 九、【隐性考点】深入分析

#### 隐性考点①：Fe与不同氧化剂反应产物不同

**Cl₂ → Fe³⁺，S → Fe²⁺**的本质原因：

$Cl_2$的氧化性很强，其标准电极电势$E^{\theta}(Cl_2/Cl^-) = +1.36 \, V$，远大于$E^{\theta}(Fe^{3+}/Fe^{2+}) = +0.77 \, V$，因此能将Fe从0价直接氧化至+3价。

$S$的氧化性较弱，其标准电极电势$E^{\theta}(S/S^{2-}) = -0.48 \, V$（碱性条件），只能将Fe氧化至+2价。即使尝试生成$Fe_2S_3$，$Fe^{3+}$的氧化性也足以将$S^{2-}$氧化。

#### 隐性考点②：Fe³⁺的氧化性表现

$Fe^{3+}$的氧化性在以下反应中得到充分体现：

| 被氧化物质 | 反应方程式 | 现象/应用 |
|-----------|----------|----------|
| Cu | $2Fe^{3+} + Cu = 2Fe^{2+} + Cu^{2+}$ | 蚀刻电路板 |
| Fe | $2Fe^{3+} + Fe = 3Fe^{2+}$ | 除去$FeCl_2$中的$FeCl_3$杂质 |
| $I^-$ | $2Fe^{3+} + 2I^- = 2Fe^{2+} + I_2$ | 淀粉-KI试纸变蓝 |
| $S^{2-}$ | $2Fe^{3+} + S^{2-} = 2Fe^{2+} + S \downarrow$ | — |
| $SO_3^{2-}$ | $2Fe^{3+} + SO_3^{2-} + H_2O = 2Fe^{2+} + SO_4^{2-} + 2H^+$ | — |

#### 隐性考点③：合金的熔点低于成分金属

合金的熔点一般低于各组分纯金属的熔点，其结构原因为：

纯金属中，原子排列规则有序（晶体），原子间作用力均匀。合金中不同大小的原子破坏了这种规则的晶格结构，使得原子间的结合力减弱。熔化时需要克服的能量壁垒降低，因此熔点下降。

例如：
- 纯铁熔点$1538^{\circ}C$，纯碳熔点$3550^{\circ}C$
- 生铁（含碳2%~4.3%）的熔点约$1100$~$1200^{\circ}C$
- 焊锡（Sn-Pb合金）熔点约$183^{\circ}C$，远低于Sn（$232^{\circ}C$）和Pb（$327^{\circ}C$）

### 十、【易错警示】从原理层面分析错误根源

#### 易错点①：Fe与稀硝酸反应产物与量有关

**错误认识**：Fe与稀硝酸反应一定生成$Fe(NO_3)_3$。

**正确理解**：

| Fe与稀硝酸的物质的量比 | 产物 |
|---------------------|------|
| $n(Fe) : n(HNO_3) \leq 1 : 4$ | 生成$Fe(NO_3)_3$ |
| $n(Fe) : n(HNO_3) \geq 3 : 8$ | 生成$Fe(NO_3)_2$ |
| $1 : 4 < n(Fe) : n(HNO_3) < 3 : 8$ | $Fe(NO_3)_3$和$Fe(NO_3)_2$都有 |

**反应分两步进行**：

第一步（Fe少量）：

$$Fe + 4HNO_3(稀) = Fe(NO_3)_3 + NO \uparrow + 2H_2O$$

第二步（Fe过量，与生成的$Fe^{3+}$继续反应）：

$$Fe + 2Fe(NO_3)_3 = 3Fe(NO_3)_2$$

总反应（Fe过量）：

$$3Fe + 8HNO_3(稀) = 3Fe(NO_3)_2 + 2NO \uparrow + 4H_2O$$

> **本质原因**：$Fe^{3+}$的氧化性使它能继续被Fe还原为$Fe^{2+}$。因此当Fe过量时，产物是$Fe^{2+}$盐而非$Fe^{3+}$盐。类似的，Cu与$Fe^{3+}$反应也只生成$Fe^{2+}$，不会继续还原为Fe。

#### 易错点②：$Fe^{3+}$和SCN⁻是络合反应，不是沉淀

**错误写法**：

$$Fe^{3+} + 3SCN^- = Fe(SCN)_3 \downarrow \quad \times$$

**正确写法**：

$$Fe^{3+} + 3SCN^- = Fe(SCN)_3 \quad （溶液变红，无沉淀）$$

> **本质**：$Fe(SCN)_3$是**络合物（配合物）**，以分子或络离子形式存在于溶液中，使溶液呈现血红色，并不会产生沉淀。方程式中不应打"$\downarrow$"。

#### 易错点③：铝是两性金属（与酸碱都反应）

**错误认识**：铝既能与酸反应又能与碱反应，所以铝是两性元素。

**正确理解**：
- 铝是**两性金属单质**，不是两性氧化物或两性氢氧化物
- 铝与酸反应体现金属性：$2Al + 6HCl = 2AlCl_3 + 3H_2 \uparrow$
- 铝与碱反应的本质是铝先与水反应生成$Al(OH)_3$和$H_2$，$Al(OH)_3$再与NaOH反应：

$$2Al + 6H_2O = 2Al(OH)_3 + 3H_2 \uparrow$$

$$Al(OH)_3 + NaOH = NaAlO_2 + 2H_2O$$

**总反应**：

$$2Al + 2NaOH + 2H_2O = 2NaAlO_2 + 3H_2 \uparrow$$

> **关键理解**：铝与碱反应中，水也是反应物。NaOH的作用是溶解生成的$Al(OH)_3$，促进反应持续进行。铝与水直接反应其实也能发生，只是生成的$Al(OH)_3$覆盖在表面阻止了反应。

#### 易错点④：钝化不是不反应

**错误认识**：铁、铝在冷的浓硫酸或浓硝酸中不反应。

**正确理解**：
- 钝化是**发生了快速氧化反应**的结果
- 金属表面生成了一层极薄的（几纳米厚）、致密的氧化膜
- 这层氧化膜将金属与酸隔离，反应终止
- 钝化是金属表面形成保护性氧化膜的物理化学过程
- 加热会破坏氧化膜，反应会重新进行
- 钝化后的铁、铝容器可以安全盛放冷的浓硫酸、浓硝酸

> **本质方程式**：
> $2Fe + 6H_2SO_4(浓,冷) \xrightarrow{快速} Fe_2O_3 + 6SO_2 \uparrow + 6H_2O \quad （表面氧化膜）$

### 二、【基础精讲】合金的概念与性质

#### 2.1 合金的定义

**合金**是由两种或两种以上的金属（或金属与非金属）熔合而成的具有金属特性的物质。

> **关键词解读**：
> - "熔合"：合金通过熔化混合制备，不是简单混合
> - "金属特性"：保持金属光泽、导电导热性、延展性等
> - "金属与非金属"：如钢（Fe-C）、硅钢（Fe-Si）中的C、Si都是非金属

#### 2.2 合金的基本特征

| 特征 | 解释 | 实例 |
|------|------|------|
| **一定是混合物** | 合金中各成分保持各自的化学性质 | 黄铜中的Cu和Zn各自可以反应 |
| **至少含一种金属** | 合金以金属为主体 | 钢中的Fe是主体 |
| **具有金属特性** | 金属键仍存在，有自由电子 | 合金都能导电（但导电性一般低于纯金属） |
| **熔点低于成分金属** | 异种原子破坏了规则晶格 | 焊锡熔点$183^{\circ}C$低于Sn和Pb |
| **硬度大于成分金属** | 异种原子造成晶格畸变，阻碍位错移动 | 黄铜硬度大于纯铜和纯锌 |
| **机械性能可调** | 改变成分比例和热处理条件 | 钢可从很软调到很硬 |

#### 2.3 合金为什么优于纯金属？——【深入分析】

从微观角度分析，合金性能优于纯金属的原因：

**（1）固溶强化**

将直径不同的原子（溶质）融入基体金属（溶剂）的晶格中，造成晶格畸变。这种畸变增加了原子间的相互作用力，使金属变形时需要更大的外力，从而提高了强度和硬度。

**（2）弥散强化**

在基体金属中加入高硬度、高熔点的第二相颗粒（如碳化物、氧化物），这些颗粒均匀弥散分布，阻碍了晶体的滑移变形，从而提高合金的强度和硬度。

**（3）细晶强化**

合金化可以细化晶粒。晶粒越细小，晶界越多，位错运动越困难，材料的强度和韧性同时提高。

**微观机理解析**：
- 纯金属：原子呈规则周期性排列（晶格），位错滑移阻力小，变形抗力低
> - 合金：异种原子散布其中，阻碍位错移动

### 三、【基础精讲】铁合金——钢和生铁

#### 3.1 生铁与钢的比较

| 性质 | 生铁 | 钢 |
|------|------|-----|
| **含碳量** | $2\%$~$4.3\%$ | $0.03\%$~$2\%$ |
| **其他杂质** | 较多Si、Mn、S、P | 较少（经精炼去除） |
| **熔点** | 较低（约$1100$~$1200^{\circ}C$） | 较高（约$1400$~$1500^{\circ}C$） |
| **硬度** | 硬而脆 | 硬而韧（可调节） |
| **机械加工性** | 可铸不可锻 | 可铸、可锻、可轧 |
| **用途** | 炼钢原料、铸造件 | 机械零件、建筑、工具 |

> **规律**：含碳量越高，硬度越大，但脆性也越大。生铁含碳量高，所以硬而脆；钢含碳量适中，所以强度和韧性兼顾。

#### 3.2 钢的分类

**（1）按含碳量分类**

| 类型 | 含碳量 | 特点 | 用途 |
|------|--------|------|------|
| 低碳钢 | $< 0.3\%$ | 韧性、焊接性好 | 建筑钢筋、钢板、钢管 |
| 中碳钢 | $0.3\%$~$0.6\%$ | 强度与韧性兼顾 | 机械零件、轴类 |
| 高碳钢 | $> 0.6\%$ | 硬度高、耐磨 | 刀具、弹簧、轴承 |

**（2）按化学成分分类**

- **碳素钢**：只含Fe、C及少量Si、Mn、S、P
- **合金钢**：特意加入一种或多种合金元素

| 合金钢类型 | 加入元素 | 主要用途 | 性能特点 |
|-----------|---------|---------|---------|
| 锰钢 | Mn | 钢轨、挖掘机铲斗 | 耐磨性好 |
| 不锈钢 | Cr、Ni | 医疗器械、餐具 | 耐腐蚀（Cr形成致密氧化膜） |
| 硅钢 | Si | 变压器铁芯 | 高磁导率、低磁损耗 |
| 钨钢 | W | 高速切削刀具 | 高温下保持硬度 |
| 镍铬钢 | Ni、Cr | 航空发动机叶片 | 耐高温、耐腐蚀 |

#### 3.3 高炉炼铁——工业制铁的主要方法

**高炉结构**（自上而下）：

```
炉喉 → 加入铁矿石、焦炭、石灰石
  ↓
炉身 → 预热区：矿石被CO部分还原
  ↓
炉腰 → 主要反应区：$Fe_2O_3 \rightarrow Fe_3O_4 \rightarrow FeO \rightarrow Fe$
  ↓
炉腹 → 高温区（约$1500^{\circ}C$）：C燃烧生成CO
  ↓
炉缸 → 铁水和炉渣分层，分别排出
```

**主要反应方程式**：

① 焦炭燃烧提供热量：

$$C + O_2 \xrightarrow{点燃} CO_2 \quad \Delta H < 0$$

② 二氧化碳被还原为一氧化碳（还原剂）：

$$CO_2 + C \xrightarrow{高温} 2CO$$

③ 一氧化碳还原铁矿石（逐步还原）：

$$3CO + Fe_2O_3 \xrightarrow{高温} 2Fe + 3CO_2$$

④ 石灰石分解造渣（除去脉石$SiO_2$）：

$$CaCO_3 \xrightarrow{高温} CaO + CO_2 \uparrow$$

$$CaO + SiO_2 \xrightarrow{高温} CaSiO_3 \quad （炉渣）$$

**产物**：
- **生铁**：含碳量$2\%$~$4.3\%$，密度大沉于炉缸底部
- **炉渣**：$CaSiO_3$等，密度小浮于铁水上方，可用于制水泥

#### 3.4 铝热反应——野外焊接钢轨

**反应原理**：

$$Fe_2O_3 + 2Al \xrightarrow{高温} 2Fe + Al_2O_3 \quad \Delta H = -851.5 \, kJ/mol$$

**反应特点**：
- 放出大量热，温度可达$2500^{\circ}C$以上
- 生成的Fe呈熔融状态
- 反应一旦引发，不需要持续加热即可自发进行

**工业应用**：

| 应用 | 具体做法 |
|------|---------|
| **焊接钢轨** | 在钢轨接口处放置铝热剂，点燃后熔融铁水流入缝隙 |
| **冶炼难熔金属** | 冶炼V、Cr、Mn等高熔点金属 |
| **火箭推进剂** | 利用铝粉与金属氧化物反应的高温 |

> **实验注意事项**：
> - 铝热反应非常剧烈，需在安全距离外操作
> - 使用镁条引燃，氯酸钾助燃
> - 反应会产生耀眼的白光，必须佩戴护目镜
> - 生成的熔融铁温度极高，注意防火

### 四、【基础精讲】铝和铝合金

#### 4.1 铝的原子结构与性质

铝（$Al$，Aluminum）位于元素周期表第三周期第IIIA族。

- 原子序数：13
- 电子排布式：$1s^22s^22p^63s^23p^1$（或$[Ne]3s^23p^1$）
- 常见化合价：$+3$价

**铝的物理性质**：

| 性质 | 数据 |
|------|------|
| 颜色、状态 | 银白色金属光泽，固体 |
| 密度 | $2.70 \, g/cm^3$（约为铁的1/3） |
| 熔点 | $660^{\circ}C$ |
| 沸点 | $2519^{\circ}C$ |
| 导电性 | 良好（次于银、铜、金，居第四位） |
| 延展性 | 良好（可制成0.01mm的铝箔） |

#### 4.2 铝的化学性质

**（1）铝与非金属反应**

$$4Al + 3O_2 \xrightarrow{\Delta} 2Al_2O_3$$

$$2Al + 3Cl_2 \xrightarrow{点燃} 2AlCl_3$$

$$2Al + 3S \xrightarrow{\Delta} Al_2S_3$$

> **注意**：常温下铝表面即被空气中的氧气氧化，形成一层致密的$Al_2O_3$薄膜（厚度约4nm），这层膜阻止了铝的进一步氧化。因此铝具有良好的耐腐蚀性。

**（2）铝与酸反应**

与非氧化性酸（如稀盐酸）：

$$2Al + 6HCl = 2AlCl_3 + 3H_2 \uparrow$$

离子方程式：

$$2Al + 6H^+ = 2Al^{3+} + 3H_2 \uparrow$$

**（3）铝与碱反应——铝的两性**

$$2Al + 2NaOH + 2H_2O = 2NaAlO_2 + 3H_2 \uparrow$$

离子方程式：

$$2Al + 2OH^- + 2H_2O = 2AlO_2^- + 3H_2 \uparrow$$

> **反应机理**：铝与NaOH溶液反应分两步进行：
> ① $2Al + 6H_2O = 2Al(OH)_3 + 3H_2 \uparrow$（铝置换水中的氢）
> ② $Al(OH)_3 + NaOH = NaAlO_2 + 2H_2O$（两性氢氧化物与碱反应）
> 
> NaOH的作用是溶解覆盖在铝表面的$Al(OH)_3$，使铝能持续与水反应。

**（4）铝热反应**（详见3.2.3节）

#### 4.3 氧化铝（$Al_2O_3$）的两性

$Al_2O_3$是典型的**两性氧化物**——既能与酸反应，又能与碱反应。

**与酸反应**（表现碱性氧化物的性质）：

$$Al_2O_3 + 6HCl = 2AlCl_3 + 3H_2O$$

$$Al_2O_3 + 6H^+ = 2Al^{3+} + 3H_2O$$

**与碱反应**（表现酸性氧化物的性质）：

$$Al_2O_3 + 2NaOH = 2NaAlO_2 + H_2O$$

$$Al_2O_3 + 2OH^- = 2AlO_2^- + H_2O$$

> **重要用途**：
> - 高纯度的$Al_2O_3$（刚玉）硬度极高，可用作磨料、轴承
> - 含微量杂质的$Al_2O_3$可呈不同颜色：红宝石（含$Cr^{3+}$）、蓝宝石（含$Fe^{2+}$、$Ti^{4+}$）
> - 氧化铝薄膜（阳极氧化）可保护铝制品

#### 4.4 氢氧化铝（$Al(OH)_3$）的两性

$Al(OH)_3$是典型的**两性氢氧化物**。

**电离方式**：$Al(OH)_3$存在两种电离方式：

$$Al^{3+} + 3OH^- \rightleftharpoons Al(OH)_3 \rightleftharpoons H^+ + AlO_2^- + H_2O$$

$$\quad \quad 碱式电离 \quad \quad \quad 酸式电离$$

**与酸反应**（碱式电离方向移动）：

$$Al(OH)_3 + 3HCl = AlCl_3 + 3H_2O$$

**与碱反应**（酸式电离方向移动）：

$$Al(OH)_3 + NaOH = NaAlO_2 + 2H_2O$$

**制备**：用氨水与铝盐反应：

$$AlCl_3 + 3NH_3 \cdot H_2O = Al(OH)_3 \downarrow + 3NH_4Cl$$

> **为什么用氨水不用NaOH？**
> 
> 因为$Al(OH)_3$能溶于过量的NaOH溶液，如果用NaOH且过量，则生成的$Al(OH)_3$会被溶解。氨水是弱碱，即使过量也不会溶解$Al(OH)_3$。

**受热分解**：

$$2Al(OH)_3 \xrightarrow{\Delta} Al_2O_3 + 3H_2O$$

#### 4.5 铝合金

| 合金名称 | 主要成分 | 特点 | 应用 |
|---------|---------|------|------|
| 硬铝 | Al-Cu-Mg-Mn | 强度高、密度小 | 飞机、火箭、船舶 |
| 防锈铝 | Al-Mn、Al-Mg | 耐腐蚀、塑性好 | 油箱、管道、容器 |
| 超硬铝 | Al-Cu-Mg-Zn | 强度接近钢 | 航空结构件 |
| 铸造铝 | Al-Si | 铸造性能好 | 发动机零件 |
| 钎焊铝 | Al-Si | 熔点低 | 焊接材料 |

> **铝的优势**：
> - 密度小（$2.70 \, g/cm^3$，约为铁的1/3），轻量化首选
> - 导电性好，仅次于铜，常用于高压输电线
> - 耐腐蚀，表面$Al_2O_3$膜提供保护
> - 易加工，可回收，是循环经济的重要材料

### 五、【基础精讲】新型合金

#### 5.1 储氢合金

**问题背景**：氢能是未来清洁能源的重要方向，但氢气的储存和运输是瓶颈。高压气态储氢不安全，液态储氢需要$-253^{\circ}C$的超低温，能耗巨大。

**解决思路**：利用某些金属合金能可逆地吸收和释放氢气的特性。

**典型代表**：LaNi₅H₆（镧镍合金氢化物）

$$LaNi_5 + 3H_2 \underset{加热}{\stackrel{室温,加压}{\rightleftharpoons}} LaNi_5H_6$$

**储氢原理**：
- 加压或降温时，$H_2$分子在合金表面解离为H原子，进入金属晶格间隙中
- 加热或降压时，H原子从晶格中脱出，重新结合为$H_2$分子释放

**特点**：储氢密度高、安全、可逆循环

#### 5.2 钛合金

| 特性 | 说明 |
|------|------|
| 密度小 | $4.51 \, g/cm^3$，约为钢的60% |
| 强度高 | 比强度（强度/密度）在金属材料中居首位 |
| 耐腐蚀 | 表面形成致密$TiO_2$保护膜 |
| 生物相容性好 | 不引起人体排异反应 |

**应用**：航空发动机、航天器、人工关节、牙科植入体

#### 5.3 形状记忆合金

**原理**：某些合金在特定温度下发生相变，使其能"记忆"原始形状。加热到一定温度（相变温度）时，即使被严重变形也能恢复到原始形状。

**典型代表**：镍钛合金（NiTi，Nitinol）

**应用**：
- 医疗器械：心血管支架（低温下压缩送入血管，到达位置后升温展开）
- 航天：卫星天线、管接头
- 日常生活：眼镜框架、手机天线

#### 5.4 其他新型合金材料

| 新型合金 | 特点 | 应用 |
|---------|------|------|
| 高温合金 | 在高温下保持强度和抗氧化性 | 航空发动机叶片 |
| 非晶合金（金属玻璃） | 原子排列无序，强度高、耐腐蚀 | 变压器铁芯、体育器材 |
| 纳米晶合金 | 晶粒尺寸在纳米级，性能优异 | 永磁材料、催化 |
| 高熵合金 | 多种元素等比例混合 | 结构材料、耐磨涂层 |

### 七、【思想方法】化学学科核心素养在本章的体现

#### 7.1 价类二维图——铁元素系统认识的工具

价类二维图是以**化合价**为纵轴、**物质类别**为横轴，系统梳理某一元素及其化合物之间转化关系的思维工具。

**铁的价类二维图**：

```
化合价
  +3  |        FeCl₃    Fe₂O₃    Fe(OH)₃    Fe₂(SO₄)₃
      |         |         |         |           |
  +2  |        FeCl₂    FeO      Fe(OH)₂    FeSO₄
      |         |         |         |           |
   0  |        Fe（单质）
      |_____________________________________________
              盐      氧化物    氢氧化物     盐
                     物质类别
```

**价类二维图的应用**：

| 应用场景 | 分析方法 |
|---------|---------|
| 判断反应能否发生 | 同类别物质可在不同价态间转化（氧化还原） |
| 推断未知反应 | 根据已知物质的类别和价态，推测反应产物 |
| 系统记忆 | 将方程式按逻辑关系整理为系统化的知识网络 |
| 解题策略 | 框图推断题的重要突破口 |

**示例**：已知A是Fe，B是FeCl₃，C是FeCl₂，D是Fe(OH)₃，E是Fe(OH)₂，请写出它们之间的转化关系。

解题思路：在价类二维图上标出各物质的位置，然后按相邻关系连线即可得到转化路径。

#### 7.2 氧化还原思想——贯穿铁三角的主线

铁三角的所有转化本质上都是氧化还原反应。掌握这一思想，可以从本质上理解反应规律：

- **升价失电子被氧化**（作还原剂）：Fe $\rightarrow$ $Fe^{2+}$ $\rightarrow$ $Fe^{3+}$
- **降价得电子被还原**（作氧化剂）：$Fe^{3+}$ $\rightarrow$ $Fe^{2+}$ $\rightarrow$ Fe

**氧化还原思想的解题应用**：

例：向含$amol \, FeCl_3$、$bmol \, CuCl_2$的混合溶液中加入铁粉，分析反应顺序。

分析：由于$Fe^{3+}$的氧化性强于$Cu^{2+}$，Fe先与$Fe^{3+}$反应：

$$2Fe^{3+} + Fe = 3Fe^{2+}$$

待$Fe^{3+}$完全反应后，Fe再与$Cu^{2+}$反应：

$$Cu^{2+} + Fe = Fe^{2+} + Cu$$

这就是利用"强者先反应"的氧化还原规律解题的典型例子。

#### 7.3 宏微结合——从宏观现象到微观本质

| 宏观现象 | 微观解释 |
|---------|---------|
| 铁在纯氧中火星四射 | Fe原子失去电子变成$Fe^{2+}$和$Fe^{3+}$，与$O^{2-}$结合生成$Fe_3O_4$，同时释放大量能量 |
| $Fe(OH)_2$白色变红褐色 | $Fe^{2+}$（$3d^6$）失去电子变为更稳定的$Fe^{3+}$（$3d^5$半充满），与OH⁻重新结合 |
| 钢比纯铁硬 | 碳原子进入铁晶格的间隙，造成晶格畸变，阻碍位错滑移 |
| 合金熔点降低 | 异种原子破坏规则晶格，原子间作用力减弱 |

#### 7.4 分类思想——合金的系统认识

合金的分类方法：

| 分类标准 | 类型 | 举例 |
|---------|------|------|
| **按基体金属** | 铁合金、铝合金、铜合金 | 钢、硬铝、黄铜 |
| **按组成元素** | 二元合金、三元合金 | Fe-C、Fe-Cr-Ni |
| **按用途** | 结构合金、功能合金 | 建筑钢、形状记忆合金 |
| **按性能** | 高强合金、耐蚀合金、耐热合金 | 钛合金、不锈钢、镍基合金 |

#### 7.5 守恒思想——化学计算的基本方法

在涉及铁及其化合物的计算中，守恒思想是最高效的解题工具：

| 守恒类型 | 应用场景 | 实例 |
|---------|---------|------|
| **质量守恒** | 反应前后总质量不变 | 铁与酸反应后溶液质量的增减 |
| **元素守恒** | 某元素在反应前后总量不变 | Fe元素守恒：$n(Fe)_{总} = n(Fe^{2+}) + n(Fe^{3+})$ |
| **电子守恒** | 氧化还原反应中得失电子相等 | Fe与$HNO_3$反应中Fe失电子数 = N得电子数 |
| **电荷守恒** | 溶液中阴阳离子电荷总数相等 | 混合盐溶液中离子浓度关系的建立 |

### 八、【实验思想】本章重要实验总结

#### 实验一：Fe²⁺与Fe³⁺的检验实验

**实验目的**：掌握$Fe^{2+}$和$Fe^{3+}$的检验方法

**实验原理**：
- $Fe^{3+}$与SCN⁻反应生成红色络合物
- $Fe^{2+}$无此反应，但可被氧化为$Fe^{3+}$后再检验

**实验步骤与现象**：

| 操作步骤 | 实验现象 | 结论 |
|---------|---------|------|
| 取待测液，加KSCN溶液 | 溶液变红色 | 含$Fe^{3+}$ |
| 取待测液，加KSCN溶液 | 无明显变化 | 不含$Fe^{3+}$ |
| 再加氯水（或$H_2O_2$） | 溶液变红色 | 含$Fe^{2+}$（被氧化为$Fe^{3+}$） |

**实验注意事项**：
1. 若同时检验$Fe^{2+}$和$Fe^{3+}$，应先加KSCN检验$Fe^{3+}$（直接观察），再加氧化剂检验$Fe^{2+}$
2. 氯水要逐滴加入，过量氯水可能进一步氧化SCN⁻，导致红色褪去
3. 不能用酸性$KMnO_4$代替氯水，因为紫色会干扰红色的观察

#### 实验二：制备Fe(OH)₂白色沉淀

**实验原理**：

$$Fe^{2+} + 2OH^- = Fe(OH)_2 \downarrow$$

**实验装置改进思路**：

```
方案一：液封法
        苯层（隔绝空气）
    ─────────────────────
    FeSO₄溶液 + NaOH（滴管插入液面下）

方案二：氢气保护法
    Zn + 稀H₂SO₄ ──→ H₂排尽空气 ──→ 关闭活塞产生H₂压 ──→
    将FeSO₄和NaOH溶液压入同一区域反应
```

**实验操作要点**：

| 要点 | 操作 | 目的 |
|------|------|------|
| 除氧 | 煮沸NaOH溶液 | 驱除溶解氧 |
| 防氧化 | 滴管插入液面下滴加 | 避免滴加过程带入空气 |
| 隔离 | 液面上覆盖一层苯 | 物理隔绝空气 |
| 新鲜配制 | 使用新制备的FeSO₄溶液 | 防止Fe²⁺已被氧化 |

#### 实验三：铝热反应

**实验装置**：

```
    镁条（引燃）
       |
    ┌──┴──┐
    │氯酸钾│  （助燃剂）
    ├─────┤
    │铝热剂│  （Al粉 + Fe₂O₃粉末，质量比约1:3）
    ├─────┤
    │ 沙子 │  （隔热、防止炸裂容器）
    └─────┘
       蒸发皿（或耐火容器）
```

**操作步骤**：
1. 将铝粉和$Fe_2O_3$粉末按质量比约1:3混合均匀
2. 在混合物上方铺一层氯酸钾（助燃剂）
3. 插入镁条作为引信
4. 在容器底部铺一层干沙（隔热、防止容器炸裂）
5. 点燃镁条，迅速退至安全距离

**实验现象**：
- 镁条剧烈燃烧，发出耀眼白光
- 铝热剂被引燃，反应剧烈，火星四射
- 生成大量熔融的铁珠，落入底部的沙坑中
- 放出大量热，温度可达$2500^{\circ}C$

**安全注意事项**：
- 必须在通风良好的环境中进行
- 操作人员必须佩戴护目镜和防护手套
- 保持足够的安全距离
- 反应容器下方必须铺沙隔热
- 产生的熔融铁温度极高，注意防火防烫伤

### 九、【隐性考点】深度总结

#### 隐性考点①：Fe与不同氧化剂反应产物不同（再强调）

**规律**：氧化剂的氧化性越强，Fe被氧化的价态越高。

| 氧化剂 | 氧化性强弱 | Fe产物 |
|--------|----------|--------|
| $Cl_2$、$Br_2$、$HNO_3$、浓$H_2SO_4$、$KMnO_4$ | 强 | $Fe^{3+}$ |
| $S$、$I_2$、$H^+$（非氧化性酸）、$Cu^{2+}$ | 弱 | $Fe^{2+}$ |

**判断方法**：比较两个电对的标准电极电势。若氧化剂的电势高于$E^{\theta}(Fe^{3+}/Fe^{2+}) = +0.77 \, V$，则可将Fe氧化至$+3$价；若只高于$E^{\theta}(Fe^{2+}/Fe) = -0.44 \, V$但低于$+0.77 \, V$，则只能氧化至$+2$价。

#### 隐性考点②：Fe³⁺与S²⁻反应与量有关

$Fe^{3+}$与$S^{2-}$反应时，存在**氧化还原反应**和**复分解反应**的竞争：

- $Fe^{3+}$具有氧化性，$S^{2-}$具有还原性 → 发生氧化还原反应
- $Fe^{3+}$和$S^{2-}$也可能形成$Fe_2S_3$沉淀 → 复分解反应

**实际情况**：由于$Fe^{3+}$的氧化性较强，主要发生氧化还原反应：

$$2Fe^{3+} + S^{2-} = 2Fe^{2+} + S \downarrow$$

当$S^{2-}$过量时，生成的$Fe^{2+}$会与过量的$S^{2-}$形成FeS沉淀：

$$Fe^{2+} + S^{2-} = FeS \downarrow$$

#### 隐性考点③：Fe³⁺不能氧化Cl⁻、Br⁻，但能氧化I⁻

判断依据是比较标准电极电势：

$$E^{\theta}(Fe^{3+}/Fe^{2+}) = +0.77 \, V$$
$$E^{\theta}(I_2/I^-) = +0.54 \, V$$
$$E^{\theta}(Br_2/Br^-) = +1.07 \, V$$
$$E^{\theta}(Cl_2/Cl^-) = +1.36 \, V$$

由于$+0.77 > +0.54$，所以$Fe^{3+}$能氧化$I^-$：

$$2Fe^{3+} + 2I^- = 2Fe^{2+} + I_2$$

由于$+0.77 < +1.07$且$+0.77 < +1.36$，所以$Fe^{3+}$**不能**氧化$Br^-$和$Cl^-$。

#### 隐性考点④：铁元素不表现+1价

Fe的常见化合价为0、+2、+3。在某些特殊化合物中还可表现+4、+6价（如$Na_2FeO_4$中Fe为+6价），但**不存在稳定的+1价化合物**。这与铜（有+1价）不同。

#### 隐性考点⑤：Fe(OH)₃胶体的制备与性质

制备要点：
- 向**沸水**中滴加饱和$FeCl_3$溶液（不是NaOH溶液！）
- 继续煮沸至溶液呈**红褐色**即停止加热
- 方程式中标注"(胶体)"，不写"$\downarrow$"

$$FeCl_3 + 3H_2O \xrightarrow{\Delta} Fe(OH)_3(胶体) + 3HCl$$

**不能持续加热的原因**：持续加热会使胶体发生**聚沉**，变成沉淀。

#### 隐性考点⑥：检验Fe²⁺时氧化剂的选择

检验$Fe^{2+}$时需要先加氧化剂将其氧化为$Fe^{3+}$，再用KSCN检验。选择氧化剂时应注意：

| 氧化剂 | 是否适合 | 原因 |
|--------|---------|------|
| 氯水 | 适合 | 氧化性适中，无色，不干扰 |
| $H_2O_2$ | 适合 | 绿色氧化剂，产物是水，不引入杂质 |
| 稀$HNO_3$ | 不适合 | 可能引入$NO_3^-$，且可能有颜色干扰 |
| 酸性$KMnO_4$ | 不适合 | 紫色会干扰红色的观察 |
