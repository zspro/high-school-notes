# 第二章 海水中的重要元素——钠和氯

---

## 【来龙去脉】为什么从"钠和氯"开始学元素化合物？

### 一、海水的启示

海洋中溶解有大量化学物质，海水中盐类平均每千克约含35克，其中氯化钠（$NaCl$）占比高达77.7%。早在远古时代，人类就从海水中晒盐、从盐湖中提取碱——但这些只是经验层面的利用。进入近代化学之后，科学家们通过电解熔融氯化钠制得金属钠，通过电解饱和食盐水获得氯气——这两种活泼的元素从此走进人类文明的视野。





教材选择"钠和氯"作为元素化合物学习的开篇，有着深刻的逻辑考量：

| 维度 | 钠（$Na$） | 氯（$Cl$） |
|------|-----------|-----------|
| 原子结构 | 第三周期IA族，最外层1个电子 | 第三周期VIIA族，最外层7个电子 |
| 元素性质 | 典型的金属性，强还原剂 | 典型的非金属性，强氧化剂 |
| 代表物质 | $Na$、$Na_2O_2$、$Na_2CO_3$、$NaHCO_3$ | $Cl_2$、$HCl$、$HClO$、$NaClO$ |
| 化学特征 | "活泼金属"的典型代表 | "活泼非金属"的典型代表 |
| 社会价值 | 制碱工业、焰火、钠灯 | 漂白消毒、制盐酸、农药、塑料 |

钠和氯分别代表了**金属元素**和**非金属元素**的极端——一个极易失电子，一个极易得电子。它们形成的离子化合物$NaCl$正是离子晶体的典型代表。以这两种元素为切入点，既能深入理解元素周期律的初步框架（同周期元素性质的递变），又能系统学习元素化合物的知识网络，还能自然引出"物质的量"这一化学定量分析的核心工具。

### 二、物质的量——微观粒子数与宏观可测量之间的定量关系

化学研究的对象是原子、分子等微观粒子，而实验操作和工业生产中测量的却是宏观质量、体积。如何在这两个世界之间建立联系？

12克碳-12中所含的碳原子数约为$6.02 \times 10^{23}$个——这个数字被定义为阿伏伽德罗常数（$N_A$）。物质的量是以阿伏伽德罗常数为计数单位的物理量，符号为$n$，单位为mol（摩尔），1 mol = $6.02 \times 10^{23}$个粒子。这一物理量的引入实现了微观粒子数与宏观可测量之间的定量转换：

- 从质量求粒子数：$n = \frac{m}{M}$，$N = n \cdot N_A$
- 从气体体积求粒子数（标准状况下）：$n = \frac{V}{V_m}$（$V_m = 22.4\,L/mol$）
- 从溶液浓度求粒子数：$n = c \cdot V$

物质的量的引入标志着高中化学从"定性描述"进入"定量计算"阶段，是后续所有化学计算的基础。

## 2.1 钠及其化合物

---

### 【来龙去脉】钠——从戴维的电火花到现代工业

1807年，英国化学家汉弗莱·戴维（Humphry Davy）通过电解熔融氢氧化钠，首次分离出金属钠。银白色的金属钠暴露在空气中时迅速失去光泽，其极强的化学活泼性使戴维感到惊奇。

钠的发现具有里程碑意义：它是人类历史上**第一个通过电解法制得的金属元素**，证明了电化学方法的有效性，也标志着碱金属元素系统研究的开始。

为什么钠如此活泼？让我们从原子结构说起。

---

### 【基础精讲】一、钠的原子结构与物理性质

#### 1. 钠的原子结构

$$_{11}Na: \quad 1s^2 2s^2 2p^6 3s^1$$

钠位于元素周期表第三周期第IA族（碱金属族），原子核外有11个电子，排布为2、8、1三层结构。**最外层仅有1个电子**，且该电子距离原子核较远（第三电子层），原子核对它的束缚力很弱。因此，钠原子极易失去这个电子，形成稳定的$Na^+$离子：

$$Na - e^- \rightarrow Na^+ \quad \text{（还原剂——失去电子，被氧化）}$$

#### 2. 钠的物理性质

| 性质 | 数据/描述 | 本质解释 |
|------|----------|---------|
| 颜色 | 银白色金属光泽 | 自由电子对可见光的反射 |
| 密度 | $0.97\,g/cm^3$ | 小于水（$1.0\,g/cm^3$），大于煤油（$\approx 0.8\,g/cm^3$） |
| 熔点 | $97.8\,^\circ C$ | 金属键较弱（原子半径大，价电子少） |
| 硬度 | 很软（可用小刀切割） | 金属键不强，原子层间易滑动 |
| 导电/导热性 | 良好 | 自由电子的定向移动和能量传递 |

**重要应用**：由于钠的密度介于煤油和水的密度之间，且钠不与煤油反应，实验室中常将钠保存在煤油中以隔绝空气和水蒸气。

---

### 【基础精讲】二、钠的化学性质——强还原性的全面体现

#### 1. 钠与氧气的反应

**（1）常温下——缓慢氧化**

将刚切开的钠块暴露在空气中，银白色表面迅速变暗：

$$4Na + O_2 = 2Na_2O \quad \text{（氧化钠，白色固体）}$$

**（2）加热或点燃——剧烈燃烧**

将钠放在坩埚中加热，钠先熔化（熔点低），然后燃烧，发出**黄色火焰**，生成**淡黄色固体**：

$$2Na + O_2 \xrightarrow{\Delta} Na_2O_2 \quad \text{（过氧化钠，淡黄色固体）}$$

**产物差异的本质**：温度升高，氧气分子的活化程度增大，$O_2$不再只是简单地接受电子形成$O^{2-}$（在$Na_2O$中），而是形成过氧根离子$O_2^{2-}$（在$Na_2O_2$中，两个氧原子通过共用一对电子结合在一起，整体带2个单位负电荷）。

#### 2. 钠与水的反应——经典实验

$$2Na + 2H_2O = 2NaOH + H_2 \uparrow$$





**实验现象——"浮、熔、游、响、红"五步特征**：

| 现象 | 解释 |
|------|------|
| **浮**——钠浮在水面上 | 钠的密度（$0.97\,g/cm^3$）小于水 |
| **熔**——钠熔化成闪亮的小球 | 反应放热 + 钠熔点低（$97.8\,^\circ C$） |
| **游**——小球在水面四处游动 | 反应产生的$H_2$推动钠球运动 |
| **响**——发出"嘶嘶"的响声 | $H_2$气泡破裂及气体与水面的摩擦 |
| **红**——滴加酚酞后溶液变红 | 生成$NaOH$，溶液呈碱性 |

**实验安全**：钠与水反应剧烈，需控制钠的用量（绿豆大小），在烧杯中进行，并用玻璃片半遮盖。

#### 3. 钠与盐溶液的反应

**核心规律**：钠投入盐溶液中，**钠先与水反应**，生成的$NaOH$再与盐反应。

**（1）钠与$CuSO_4$溶液**：

$$2Na + 2H_2O = 2NaOH + H_2 \uparrow$$

$$2NaOH + CuSO_4 = Cu(OH)_2 \downarrow \text{（蓝色沉淀）} + Na_2SO_4$$

总反应：

$$2Na + 2H_2O + CuSO_4 = Cu(OH)_2 \downarrow + Na_2SO_4 + H_2 \uparrow$$

**现象**：浮、熔、游、响，同时产生**蓝色沉淀**。

**注意**：不能置换出铜单质！因为$H_2O$中的$H^+$比$Cu^{2+}$更容易被还原（$H_2O$的氧化性更强）。

**（2）钠与$NH_4Cl$溶液**：

$$2Na + 2NH_4Cl = 2NaCl + 2NH_3 \uparrow + H_2 \uparrow$$

反应更加剧烈，因为$NH_4^+$水解使溶液呈酸性。

#### 4. 钠与酸的反应

钠与酸反应比与水反应更剧烈，因为酸中$H^+$浓度更高：

$$2Na + 2HCl = 2NaCl + H_2 \uparrow$$

---

### 【深度理解】钠的还原性为何如此之强？

从能量角度分析，钠原子失去一个电子所需的电离能（$496\,kJ/mol$）虽然不算最低（锂为$520\,kJ/mol$），但综合考虑以下因素：

1. **电离能较低**：最外层仅1个电子，有效核电荷较小
2. **离子水合能高**：$Na^+$离子半径小，水合时放出大量能量
3. **产物稳定性高**：$Na^+$具有稀有气体（Ne）电子构型，极为稳定

这三者共同决定了钠的强还原性。在金属活动性顺序表中，钠排在第三位（$K$、$Ca$、$Na$），是极为活泼的金属。

---

### 【易错警示】钠与盐溶液反应的误区

| 错误认识 | 正确理解 |
|----------|---------|
| 钠能置换盐溶液中的金属 | 钠先与水反应，不能置换出金属 |
| 钠与饱和食盐水不反应 | 照样反应，只是产物$NaOH$使$NaCl$析出 |
| 钠可以保存在水中 | 钠与水反应，不能保存在水中 |
| 大块钠反应更安全 | 大块钠反应更剧烈，可能爆炸 |

---

### 【基础精讲】三、钠的氧化物

#### 1. 氧化钠（$Na_2O$）

| 项目 | 内容 |
|------|------|
| 颜色状态 | 白色固体 |
| 氧元素化合价 | $-2$价 |
| 类别 | 碱性氧化物 |
| 与$H_2O$反应 | $Na_2O + H_2O = 2NaOH$（常温进行） |
| 与$CO_2$反应 | $Na_2O + CO_2 = Na_2CO_3$ |
| 与酸反应 | $Na_2O + 2HCl = 2NaCl + H_2O$ |

#### 2. 过氧化钠（$Na_2O_2$）——重点物质

| 项目 | 内容 |
|------|------|
| 颜色状态 | 淡黄色固体 |
| 氧元素化合价 | $-1$价（过氧根$O_2^{2-}$） |
| 类别 | 过氧化物（不是碱性氧化物！） |
| 与$H_2O$反应 | $2Na_2O_2 + 2H_2O = 4NaOH + O_2 \uparrow$ |
| 与$CO_2$反应 | $2Na_2O_2 + 2CO_2 = 2Na_2CO_3 + O_2$ |
| 与酸反应 | $2Na_2O_2 + 4HCl = 4NaCl + 2H_2O + O_2 \uparrow$ |

**【隐性考点】过氧化钠与$H_2O$、$CO_2$反应的电子转移分析**：

以$Na_2O_2$与$CO_2$反应为例：

$$2Na_2O_2 + 2CO_2 = 2Na_2CO_3 + O_2$$

- $Na_2O_2$中氧为$-1$价，反应后一部分变为$Na_2CO_3$中的$-2$价（被还原），另一部分变为$O_2$中的$0$价（被氧化）
- 这是一个**歧化反应**（同种元素既被氧化又被还原）
- 电子转移：$2\,mol\,Na_2O_2$反应，转移$2\,mol$电子

**规律**：$2\,mol\,Na_2O_2$与足量$H_2O$或$CO_2$反应，均转移$2\,mol$电子，生成$1\,mol\,O_2$。

**重要应用**：过氧化钠可用于呼吸面具和潜水艇中作为供氧剂——它能同时吸收$CO_2$并放出$O_2$。

---

### 【知识串联】钠→氧化钠→过氧化钠→氢氧化钠→碳酸钠→碳酸氢钠 转化链

$$Na \xrightarrow{O_2\text{（常温）}} Na_2O \xrightarrow{O_2\text{（加热）}} Na_2O_2 \xrightarrow{H_2O} NaOH$$

$$Na \xrightarrow{H_2O} NaOH \xrightarrow{CO_2\text{（少量）}} Na_2CO_3 \xrightarrow{CO_2\text{（过量）}+H_2O} 2NaHCO_3$$

$$2NaHCO_3 \xrightarrow{\Delta} Na_2CO_3 + H_2O + CO_2 \uparrow$$

掌握这条转化链，就能系统把握钠及其化合物的核心反应。

---

### 【基础精讲】四、碳酸钠与碳酸氢钠

#### 1. 物理性质对比

| 性质 | 碳酸钠（$Na_2CO_3$） | 碳酸氢钠（$NaHCO_3$） |
|------|-------------------|---------------------|
| 俗名 | 纯碱、苏打 | 小苏打 |
| 颜色状态 | 白色粉末 | 白色细小晶体 |
| 溶解性 | 易溶于水（$21.5\,g/100g\,H_2O$，$20\,^\circ C$） | 可溶于水（$9.6\,g/100g\,H_2O$，$20\,^\circ C$） |
| 水溶液酸碱性 | 碱性较强（$pH \approx 12$） | 碱性较弱（$pH \approx 8.3$） |

#### 2. 化学性质对比

| 性质 | $Na_2CO_3$ | $NaHCO_3$ |
|------|-----------|-----------|
| 与酸反应 | $Na_2CO_3 + 2HCl = 2NaCl + H_2O + CO_2 \uparrow$（较慢） | $NaHCO_3 + HCl = NaCl + H_2O + CO_2 \uparrow$（较快） |
| 热稳定性 | 很稳定（$851\,^\circ C$熔化但不分解） | 不稳定，受热分解：$2NaHCO_3 \xrightarrow{\Delta} Na_2CO_3 + H_2O + CO_2 \uparrow$ |
| 与$NaOH$ | 不反应（同阳离子） | $NaHCO_3 + NaOH = Na_2CO_3 + H_2O$ |
| 与$Ca(OH)_2$ | $Na_2CO_3 + Ca(OH)_2 = CaCO_3 \downarrow + 2NaOH$ | $2NaHCO_3 + Ca(OH)_2 = CaCO_3 \downarrow + Na_2CO_3 + 2H_2O$（$NaHCO_3$过量时） |
| 与$CaCl_2$ | $Na_2CO_3 + CaCl_2 = CaCO_3 \downarrow + 2NaCl$ | 不反应（不生成沉淀） |

#### 3. 相互转化

$$Na_2CO_3 \xrightarrow{CO_2 + H_2O} 2NaHCO_3$$

$$2NaHCO_3 \xrightarrow{\Delta} Na_2CO_3 + H_2O + CO_2 \uparrow$$

$$NaHCO_3 + NaOH = Na_2CO_3 + H_2O$$

#### 4. 鉴别方法

| 方法 | $Na_2CO_3$ | $NaHCO_3$ |
|------|-----------|-----------|
| 加热 | 不分解 | 分解产生$CO_2$（使澄清石灰水变浑浊） |
| 加$CaCl_2$ | 白色沉淀 | 无沉淀 |
| 逐滴加稀盐酸 | 开始无明显现象，后产生气泡 | 立即产生气泡 |
| pH试纸 | 碱性较强 | 碱性较弱 |

---

### 【深度理解】碳酸钠碱性为何强于碳酸氢钠？

碳酸钠溶于水时，$CO_3^{2-}$发生水解：

$$CO_3^{2-} + H_2O \rightleftharpoons HCO_3^- + OH^- \quad K_{h1} = \frac{K_w}{K_{a2}} \approx 2.1 \times 10^{-4}$$

$$HCO_3^- + H_2O \rightleftharpoons H_2CO_3 + OH^- \quad K_{h2} = \frac{K_w}{K_{a1}} \approx 2.3 \times 10^{-8}$$

碳酸氢钠溶液中，$HCO_3^-$既能水解（显碱性）又能电离（显酸性）：

$$HCO_3^- \rightleftharpoons H^+ + CO_3^{2-} \quad K_{a2} = 5.6 \times 10^{-11}$$

$$HCO_3^- + H_2O \rightleftharpoons H_2CO_3 + OH^- \quad K_h = 2.3 \times 10^{-8}$$

由于$K_h > K_{a2}$，$HCO_3^-$的水解程度大于电离程度，溶液呈碱性，但碱性远弱于$Na_2CO_3$。

---

### 【隐性考点】碳酸氢钠与碱反应的量的关系

$NaHCO_3$与$Ca(OH)_2$反应时，产物与二者的物质的量之比有关：

**（1）$NaHCO_3$不足**：

$$NaHCO_3 + Ca(OH)_2 = CaCO_3 \downarrow + NaOH + H_2O$$

**（2）$NaHCO_3$过量**：

$$2NaHCO_3 + Ca(OH)_2 = CaCO_3 \downarrow + Na_2CO_3 + 2H_2O$$

**判断技巧**：看哪个物质少——$OH^-$多时，产物中有$NaOH$；$HCO_3^-$多时，产物中有$Na_2CO_3$。

---

### 【实验思想】碳酸钠与碳酸氢钠热稳定性实验

**实验设计**：将$NaHCO_3$放在小试管中，$Na_2CO_3$放在大试管中，加热大试管，将产生的气体通入澄清石灰水。

**实验原理**：利用"套管实验"——外管温度更高。若外管（装$Na_2CO_3$）中物质不分解而内管（装$NaHCO_3$）中物质分解，则可证明$Na_2CO_3$热稳定性更强。

**实验现象**：小试管中的$NaHCO_3$分解，产生的气体使澄清石灰水变浑浊；大试管中的$Na_2CO_3$不分解。

**结论**：$Na_2CO_3$热稳定性 > $NaHCO_3$热稳定性。

### 【基础精讲】五、焰色试验

#### 1. 原理

某些金属或它们的化合物在灼烧时，会使火焰呈现特殊的颜色。这是由于金属原子中的电子吸收能量后从基态跃迁到激发态，当电子从激发态回到基态时，以光的形式释放能量。不同金属元素的电子跃迁能量不同，因此发出不同波长的光。

#### 2. 操作步骤

（1）将铂丝（或光洁无锈的铁丝）蘸取浓盐酸，在酒精灯外焰上灼烧至**火焰无色**（除去杂质）。

（2）用洁净的铂丝蘸取待测样品（固体或溶液），在酒精灯外焰上灼烧。

（3）观察火焰颜色。

（4）用盐酸洗净铂丝，再灼烧至无色，检验下一种样品。

#### 3. 常见金属的焰色

| 金属元素 | 焰色 |
|---------|------|
| 钠（$Na$） | **黄色** |
| 钾（$K$） | **紫色**（透过蓝色钴玻璃观察，滤去钠的黄光） |
| 钙（$Ca$） | 砖红色 |
| 锶（$Sr$） | 洋红色 |
| 钡（$Ba$） | 黄绿色 |
| 铜（$Cu$） | 绿色 |

#### 4. 要点说明

- **焰色试验是物理变化**，不是化学变化——本质是电子的能级跃迁，没有新物质生成
- 检验钾元素时必须**透过蓝色钴玻璃**——因为钾盐中常混有钠盐，钠的黄色光会掩盖钾的紫色光
- 可以用铁丝代替铂丝（铁丝灼烧时火焰无色），但不能用铜丝或镍丝（本身有焰色）
- 用盐酸洗涤铂丝而不是硫酸：盐酸易挥发，不会残留；硫酸高沸点，不易挥发

---

### 【易错警示】焰色试验常见误区

| 错误认识 | 正确理解 |
|----------|---------|
| 焰色试验是化学变化 | 电子跃迁是物理过程，属于物理变化 |
| 只有金属单质有焰色 | 化合物也有焰色（如$NaCl$、$Na_2CO_3$焰色均为黄色） |
| 所有金属都有焰色 | 只有部分金属元素有特征焰色（主要是碱金属和部分碱土金属） |
| 检验钾时不用蓝色钴玻璃也可以 | 必须透过蓝色钴玻璃滤去黄色光 |
| 用硫酸代替盐酸洗涤铂丝 | 应用盐酸，硫酸不易挥发会残留 |

---

### 【思想方法】分类思想与类比思想

#### 1. 碱金属性质的递变规律

将钠的性质与锂（$Li$）、钾（$K$）比较，可以发现碱金属性质的递变规律：

| 性质 | $Li$ → $Na$ → $K$ → $Rb$ → $Cs$ |
|------|-------------------------------|
| 原子半径 | 逐渐增大 |
| 最外层电子 | 均为1个 |
| 失电子能力 | 逐渐增强 |
| 金属性（还原性） | 逐渐增强 |
| 与水反应 | 越来越剧烈（$K$反应放热可使$H_2$燃烧甚至爆炸） |
| 熔点 | 逐渐降低 |
| 密度 | 总体增大（$Na$、$K$例外） |

#### 2. 类比思想的应用

- $Na$的性质可类比推断$K$的性质，但要注意递变性（$K$更活泼）
- $Na_2O_2$的性质可类比推断其他过氧化物（如$K_2O_2$、$CaO_2$）的性质
- $Na_2CO_3$和$NaHCO_3$的性质对比可类比到其他多元酸的盐（如$Na_2SO_3$和$NaHSO_3$）

## 2.2 氯及其化合物

---

### 【来龙去脉】氯——从发现到现代化工应用

1774年，瑞典化学家卡尔·威廉·舍勒（Carl Wilhelm Scheele）将浓盐酸与二氧化锰混合加热，产生了一种黄绿色的刺激性气体。他将其称为"脱燃素盐酸气"，因为当时流行的"燃素说"无法解释这种气体的性质。

1810年，英国化学家汉弗莱·戴维通过实验证明了这种气体是一种新的化学元素，并将其命名为"Chlorine"（氯），源自希腊语"chloros"，意为"黄绿色"。

氯气的发现意义深远：它是元素周期表中第17号元素，属于卤族元素，是化学工业最重要的基础原料之一。从漂白粉到聚氯乙烯（PVC），从农药到制药，氯的化合物无处不在。

---

### 【基础精讲】一、氯的原子结构与非金属性

#### 1. 氯的原子结构

$$_{17}Cl: \quad 1s^2 2s^2 2p^6 3s^2 3p^5$$

氯位于元素周期表第三周期第VIIA族（卤族），原子核外有17个电子，排布为2、8、7三层结构。**最外层有7个电子**，仅需获得1个电子即可达到8电子稳定结构。因此，氯原子具有强烈的得电子倾向：

$$Cl + e^- \rightarrow Cl^- \quad \text{（氧化剂——得到电子，被还原）}$$

#### 2. 氯气的物理性质

| 性质 | 描述 |
|------|------|
| 颜色 | 黄绿色气体 |
| 气味 | 刺激性气味（有毒！） |
| 密度 | 比空气大（相对分子质量71 > 29） |
| 溶解性 | 可溶于水（$1:2$体积比，常温常压），易溶于有机溶剂 |
| 液化 | 易液化（加压或降温），液氯呈黄绿色 |

**安全提示**：氯气有毒，吸入少量会刺激呼吸道，大量吸入可致死。实验室中若有氯气泄漏，应用碱液（如$NaOH$溶液）吸收或用湿毛巾捂住口鼻逃离。

---

### 【基础精讲】二、氯气的化学性质——强氧化性的全面体现

氯气的化学性质非常活泼，表现出**强氧化性**，能与金属、非金属、水、碱等多种物质反应。

#### 1. 与金属反应

氯气能与绝大多数金属反应，生成金属氯化物：

**（1）与钠反应（点燃）**：

$$2Na + Cl_2 \xrightarrow{点燃} 2NaCl$$

现象：剧烈燃烧，产生白烟（$NaCl$固体小颗粒），发出黄色火焰。

**（2）与铁反应（点燃）**：

$$2Fe + 3Cl_2 \xrightarrow{点燃} 2FeCl_3$$

**关键注意**：氯气的氧化性很强，能将铁氧化到$+3$价（生成$FeCl_3$），而不是$+2$价（$FeCl_2$）。这是氯气强氧化性的重要体现。

现象：剧烈燃烧，产生**棕褐色烟**。

**（3）与铜反应（点燃）**：

$$Cu + Cl_2 \xrightarrow{点燃} CuCl_2$$

现象：剧烈燃烧，产生**棕黄色烟**（无水$CuCl_2$为棕黄色）。

#### 2. 与非金属反应

**（1）与氢气反应**：

$$H_2 + Cl_2 \xrightarrow{点燃或光照} 2HCl$$

- **点燃**：氢气在氯气中安静燃烧，发出**苍白色火焰**，瓶口有白雾（$HCl$气体遇水蒸气形成盐酸小液滴）
- **光照（或混合后强光照射）**：**爆炸**反应！

**【实验思想】氢气与氯气光照爆炸实验**：将$H_2$和$Cl_2$按体积比1:1混合，用镁条燃烧发出的强光照射，混合气体瞬间爆炸。这是因为光能提供了反应活化能，一旦引发链式反应，反应速率急剧增大。

**（2）与磷反应**：

$$2P + 3Cl_2 \xrightarrow{点燃} 2PCl_3 \quad \text{（三氯化磷，无色液体）}$$

$$2P + 5Cl_2 \xrightarrow{点燃（Cl_2过量）} 2PCl_5 \quad \text{（五氯化磷，白色固体）}$$

#### 3. 与水的反应——氯水的形成

$$Cl_2 + H_2O \rightleftharpoons HCl + HClO$$

这是一个**可逆反应**，氯气部分溶于水并与水反应。

**氯水的成分分析（三分子、四离子）**：

| 类别 | 粒子 | 来源 |
|------|------|------|
| 分子 | $Cl_2$ | 溶解的氯气分子 |
| 分子 | $H_2O$ | 水分子（大量） |
| 分子 | $HClO$ | 反应生成的次氯酸 |
| 离子 | $H^+$ | $HCl$和$HClO$电离 |
| 离子 | $Cl^-$ | $HCl$电离 |
| 离子 | $ClO^-$ | $HClO$部分电离 |
| 离子 | $OH^-$ | 水电离（极少量） |

#### 4. 与碱的反应——漂白粉的制备

**（1）与氢氧化钠反应**：

$$Cl_2 + 2NaOH = NaCl + NaClO + H_2O$$

该反应用于**尾气吸收**——实验室用$NaOH$溶液吸收多余的氯气。

**（2）与石灰乳反应（制备漂白粉）**：

$$2Cl_2 + 2Ca(OH)_2 = CaCl_2 + Ca(ClO)_2 + 2H_2O$$

漂白粉的主要成分是$CaCl_2$和$Ca(ClO)_2$，**有效成分是$Ca(ClO)_2$**（次氯酸钙）。

**漂白原理**：次氯酸钙与空气中的$CO_2$和$H_2O$反应，生成次氯酸：

$$Ca(ClO)_2 + CO_2 + H_2O = CaCO_3 \downarrow + 2HClO$$

次氯酸（$HClO$）具有强氧化性，能氧化有机色素使其褪色，起到漂白作用。

---

### 【深度理解】氯水的成分分析与性质

#### 1. 氯水的多重性质

| 性质 | 对应的成分 | 实验验证 |
|------|----------|---------|
| 黄绿色 | $Cl_2$分子 | 观察颜色 |
| 酸性 | $H^+$（$HCl$、$HClO$电离） | 使紫色石蕊试纸先变红 |
| 漂白性 | $HClO$ | 使红色石蕊试纸褪色 |
| 强氧化性 | $Cl_2$、$HClO$ | 氧化$KI$、$Fe^{2+}$等 |
| 杀菌消毒 | $HClO$ | 自来水消毒 |

#### 2. 次氯酸（$HClO$）的性质

**（1）不稳定性**：

$$2HClO \xrightarrow{光照} 2HCl + O_2 \uparrow$$

次氯酸见光易分解，因此氯水应**避光保存**，且久置后失去漂白能力。

**（2）弱酸性**：

次氯酸是弱酸（比碳酸还弱），不能完全电离：

$$HClO \rightleftharpoons H^+ + ClO^- \quad K_a \approx 2.9 \times 10^{-8}$$

酸性：$H_2CO_3 > HClO > HCO_3^-$

**（3）强氧化性**：

$HClO$中氯为$+1$价，具有较强的得电子能力，能氧化多种还原性物质。

#### 3. 氯水久置的变化

新制氯水 $\rightarrow$ 久置氯水 $\rightarrow$ 稀盐酸

- 颜色：黄绿色 $\rightarrow$ 无色
- 成分：含$Cl_2$、$HClO$ $\rightarrow$ 主要为$HCl$和$H_2O$
- 漂白性：有 $\rightarrow$ 无
- 酸性：较弱 $\rightarrow$ 较强（$HClO$分解产生$HCl$）

---

### 【实验思想】氯气的实验室制法

#### 1. 反应原理

利用强氧化剂将浓盐酸中的$Cl^-$氧化为$Cl_2$：

$$MnO_2 + 4HCl\text{（浓）} \xrightarrow{\Delta} MnCl_2 + Cl_2 \uparrow + 2H_2O$$

**为什么必须用浓盐酸？**

- 该反应需要$H^+$和$Cl^-$浓度都较高才能进行
- 稀盐酸中$Cl^-$浓度低，还原性弱，不足以被$MnO_2$氧化
- 随着反应进行，盐酸浓度降低，反应会逐渐停止

**氧化剂选择**：除了$MnO_2$，还可以用$KMnO_4$、$KClO_3$、$Ca(ClO)_2$等强氧化剂：

$$2KMnO_4 + 16HCl\text{（浓）} = 2KCl + 2MnCl_2 + 5Cl_2 \uparrow + 8H_2O$$

此反应**不需要加热**，$KMnO_4$氧化性比$MnO_2$更强。

#### 2. 实验装置

| 装置部分 | 作用 | 具体选择 |
|---------|------|---------|
| 发生装置 | 制取$Cl_2$ | 固液加热型（圆底烧瓶+分液漏斗+酒精灯） |
| 净化装置 | 除去$HCl$和水蒸气 | 先通过饱和食盐水除$HCl$，再通过浓硫酸干燥 |
| 收集装置 | 收集$Cl_2$ | 向上排空气法（密度比空气大）或排饱和食盐水法 |
| 尾气处理 | 吸收多余$Cl_2$ | 用$NaOH$溶液吸收 |

**为什么用饱和食盐水除$HCl$？**

- $HCl$在饱和食盐水中溶解度很大（$Cl^-$浓度高，抑制$HCl$电离，促进溶解）
- $Cl_2$在饱和食盐水中溶解度很小（同离子效应——$Cl^-$浓度高，抑制$Cl_2 + H_2O \rightleftharpoons H^+ + Cl^- + HClO$平衡向右移动）

#### 3. 实验操作要点

（1）检查装置气密性
（2）先加浓盐酸于分液漏斗中，$MnO_2$放于圆底烧瓶中
（3）先微热，再逐滴加入浓盐酸
（4）收集时，导气管应伸入集气瓶底部
（5）实验结束后，先停止加热，继续通入气体至装置冷却

#### 4. 实验装置的拓展

**【知识串联】实验室制取气体的装置选择思路**：

| 发生装置类型 | 适用条件 | 典型气体 |
|-------------|---------|---------|
| 固体加热型 | 固体反应物，需加热 | $O_2$（$KMnO_4$分解）、$NH_3$ |
| 固液加热型 | 固体+液体，需加热 | $Cl_2$、$HCl$ |
| 固液不加热型 | 固体+液体，不需加热 | $H_2$、$CO_2$、$O_2$（$H_2O_2$分解） |

---

### 【基础精讲】三、氯离子的检验

#### 检验方法

**试剂**：稀硝酸（$HNO_3$）+ 硝酸银溶液（$AgNO_3$）

**步骤**：
1. 取少量待测液于试管中
2. 先加入**稀硝酸**酸化（排除$CO_3^{2-}$、$SO_3^{2-}$等干扰）
3. 再加入$AgNO_3$溶液
4. 观察是否产生白色沉淀

**原理**：

$$Ag^+ + Cl^- = AgCl \downarrow \text{（白色沉淀，不溶于稀硝酸）}$$

#### 为什么必须用稀硝酸酸化？

| 可能存在的干扰离子 | 与$Ag^+$反应 | 加稀硝酸后的变化 |
|-------------------|-------------|-----------------|
| $CO_3^{2-}$ | $Ag_2CO_3 \downarrow$（白色） | $Ag_2CO_3 + 2HNO_3 = 2AgNO_3 + H_2O + CO_2 \uparrow$，沉淀溶解 |
| $SO_3^{2-}$ | $Ag_2SO_3 \downarrow$（白色） | 被$HNO_3$氧化，沉淀变化 |
| $OH^-$ | $AgOH \rightarrow Ag_2O \downarrow$（褐色） | 被中和 |

**注意**：不能用盐酸酸化（引入$Cl^-$，造成假阳性）；不能用硫酸酸化（$Ag_2SO_4$微溶，可能造成浑浊）。

---

### 【知识串联】卤族元素的递变规律

氯元素属于卤族元素（第VIIA族），该族元素性质的递变：

| 性质 | $F_2$ | $Cl_2$ | $Br_2$ | $I_2$ |
|------|-------|--------|--------|-------|
| 颜色 | 淡黄绿色 | 黄绿色 | 深红棕色 | 紫黑色 |
| 状态 | 气体 | 气体 | 液体 | 固体 |
| 与水反应 | 剧烈（$2F_2 + 2H_2O = 4HF + O_2$） | 可逆 | 缓慢 | 极弱 |
| 氧化性 | 最强 | 强 | 中等 | 较弱 |
| 与$H_2$化合难易 | 暗处爆炸 | 光照爆炸 | 加热 | 持续加热 |
| 单质活泼性 | 极强 | 很活泼 | 较活泼 | 一般 |

**递变规律**：从上到下，原子半径增大，得电子能力减弱，非金属性减弱，单质氧化性减弱。

---

### 【思想方法】氧化还原反应的配平技巧——氯元素的歧化反应

氯气与水、碱反应时，$Cl_2$既被氧化又被还原（一部分变为$Cl^-$，一部分变为$ClO^-$或$ClO_3^-$），这类反应称为**歧化反应**。

**配平思路——电子守恒法**：

以$Cl_2$与热浓$NaOH$溶液反应为例：

$$3Cl_2 + 6NaOH \xrightarrow{\Delta} 5NaCl + NaClO_3 + 3H_2O$$

分析：
- $Cl_2 \rightarrow NaCl$：$Cl$从$0$价降至$-1$价，每个$Cl$得1个电子
- $Cl_2 \rightarrow NaClO_3$：$Cl$从$0$价升至$+5$价，每个$Cl$失5个电子
- 得失电子守恒：生成5个$Cl^-$（得5e-），对应生成1个$ClO_3^-$（失5e-）

---

### 【易错警示】氯及其化合物常见误区

| 错误认识 | 正确理解 |
|----------|---------|
| $Cl_2$有漂白性 | $Cl_2$本身无漂白性，其漂白作用是通过与水反应生成的$HClO$实现的 |
| 氯水能使干燥的有色布条褪色 | 干燥的氯气不能使干燥的有色布条褪色（无水则无法生成$HClO$） |
| $Fe$与$Cl_2$反应生成$FeCl_2$ | $Cl_2$氧化性强，生成$FeCl_3$（$+3$价） |
| 用$pH$试纸测定氯水的$pH$ | 氯水有漂白性，会使$pH$试纸褪色，应用$pH$计 |
| 漂白粉在空气中长期放置不变质 | 漂白粉会与空气中$CO_2$和$H_2O$反应而变质 |
| 实验室制$Cl_2$可用稀盐酸 | 必须用浓盐酸，稀盐酸不与$MnO_2$反应 |
| 检验$Cl^-$可用盐酸酸化 | 不能用盐酸（引入$Cl^-$），必须用稀硝酸酸化 |

## 2.3 物质的量

---

### 【来龙去脉】为什么需要"物质的量"这个物理量？

#### 一、微观世界与宏观世界的鸿沟

化学研究的核心对象是原子、分子、离子等微观粒子。这些粒子极其微小——一个水分子的质量约为$3 \times 10^{-23}\,g$，一个碳原子的直径约为$1.5 \times 10^{-10}\,m$。在实验室中，我们无法直接称量或计数这些微观粒子。

然而，化学实验和工业生产中，我们测量的都是宏观量——质量（克）、体积（升）、浓度（摩尔/升）。**如何在微观粒子数与宏观可测量之间建立联系？** 这就是引入"物质的量"这一物理量的原因。

#### 二、物质的量的定义原理

微观粒子（原子、分子、离子等）由于其质量和体积极小，无法直接计数。化学上引入物质的量（$n$）这一物理量，以阿伏伽德罗常数（$N_A \approx 6.02 \times 10^{23}\,mol^{-1}$）为计数基准，将微观粒子数与宏观可测量（质量、体积等）定量联系起来。物质的量的单位为摩尔（mol），1 mol任何粒子集合体所含的粒子数均等于$N_A$。

**物质的量的本质**：以$N_A$为基准的粒子计数系统，使微观粒子数可通过质量或体积等宏观测量间接确定。

#### 三、阿伏伽德罗常数的由来

意大利化学家阿伏伽德罗（Amedeo Avogadro）在1811年提出了著名的"阿伏伽德罗假说"：在同温同压下，相同体积的任何气体含有相同数目的分子。为了纪念他的贡献，人们将$0.012\,kg$（12克）碳-12中所含的碳原子数命名为"阿伏伽德罗常数"，符号为$N_A$。

$$N_A \approx 6.02 \times 10^{23}\,mol^{-1}$$

为什么是12克碳-12？因为碳-12是国际上定义相对原子质量的基准，选用它便于统一标准。

---

### 【基础精讲】一、物质的量（$n$）

#### 1. 定义

物质的量是一个物理量，表示含有一定数目粒子的集合体，符号为$n$，单位为**摩尔**（简称"摩"），符号为$mol$。

**使用规则**：
- 必须指明微粒种类：1 mol $H_2O$ √，1 mol 水 ×
- 可以是原子、分子、离子、电子、质子、中子等微观粒子
- 不能用于宏观物体：1 mol 大米 ×

#### 2. 物质的量与粒子数的关系

$$n = \frac{N}{N_A}$$

其中：
- $N$：粒子数目（个）
- $N_A$：阿伏伽德罗常数，$6.02 \times 10^{23}\,mol^{-1}$

**变形公式**：

$$N = n \cdot N_A$$

**示例**：0.5 mol $H_2O$中含有的水分子数：

$$N = 0.5 \times 6.02 \times 10^{23} = 3.01 \times 10^{23} \text{ 个}$$

---

### 【基础精讲】二、摩尔质量（$M$）

#### 1. 定义

单位物质的量的物质所具有的质量叫做**摩尔质量**，符号为$M$，单位为$g/mol$（或$g \cdot mol^{-1}$）。

#### 2. 数值关系

**当以$g/mol$为单位时，摩尔质量在数值上等于该粒子的相对原子质量、相对分子质量或式量**。

| 物质 | 相对分子质量 | 摩尔质量 |
|------|------------|---------|
| $Na$ | 23 | $23\,g/mol$ |
| $H_2O$ | 18 | $18\,g/mol$ |
| $NaCl$ | 58.5 | $58.5\,g/mol$ |
| $H_2SO_4$ | 98 | $98\,g/mol$ |
| $Na_2CO_3$ | 106 | $106\,g/mol$ |

#### 3. 物质的量、质量与摩尔质量的关系

$$n = \frac{m}{M}$$

**变形公式**：

$$m = n \cdot M$$

$$M = \frac{m}{n}$$

#### 4. 计算示例

**例1**：4.6 g金属钠的物质的量是多少？

$$n(Na) = \frac{m}{M} = \frac{4.6\,g}{23\,g/mol} = 0.2\,mol$$

**例2**：配制500 mL $0.1\,mol/L$ $NaOH$溶液，需要$NaOH$多少克？





$$n(NaOH) = c \cdot V = 0.1\,mol/L \times 0.5\,L = 0.05\,mol$$

$$m(NaOH) = n \cdot M = 0.05\,mol \times 40\,g/mol = 2.0\,g$$

### 【基础精讲】三、气体摩尔体积（$V_m$）

#### 1. 物质的体积决定因素

物质的体积由三个因素决定：

（1）**粒子数目**（$N$）—— 粒子越多，体积越大
（2）**粒子大小**（$d$）—— 粒子越大，体积越大
（3）**粒子间距**（$l$）—— 间距越大，体积越大

#### 2. 固体、液体与气体的体积差异

| 状态 | 粒子间距 | 体积主要取决于 | 结论 |
|------|---------|--------------|------|
| 固体 | 很小 | 粒子数目和粒子大小 | 不同物质1 mol体积不同 |
| 液体 | 较小 | 粒子数目和粒子大小 | 不同物质1 mol体积不同 |
| 气体 | 很大（约为粒子直径的10倍） | **粒子数目**和**粒子间距** | 同温同压下，1 mol任何气体体积近似相等 |

#### 3. 气体摩尔体积的定义

单位物质的量的气体所占的体积叫做**气体摩尔体积**，符号为$V_m$，单位为$L/mol$。

$$V_m = \frac{V}{n}$$

#### 4. 标准状况下的气体摩尔体积

**标准状况**（Standard Temperature and Pressure，简称STP）指：
- 温度：$0\,^\circ C$（$273.15\,K$）
- 压强：$101\,kPa$（1个标准大气压）

在标准状况下，**任何气体**的摩尔体积约为：

$$V_m = 22.4\,L/mol$$

**重要公式**：

$$n = \frac{V}{V_m} = \frac{V}{22.4\,L/mol} \quad \text{（标准状况，气体）}$$

#### 5. 影响气体摩尔体积的因素

根据理想气体状态方程 $PV = nRT$，可得：

$$V_m = \frac{V}{n} = \frac{RT}{P}$$

- **温度升高**，$V_m$增大（热胀）
- **压强增大**，$V_m$减小（冷缩）
- 同温同压下，$V_m$为定值，与气体种类无关

#### 6. 计算示例

**例3**：标准状况下，5.6 L $O_2$的物质的量是多少？

$$n(O_2) = \frac{5.6\,L}{22.4\,L/mol} = 0.25\,mol$$

**例4**：标准状况下，0.5 mol $CO_2$的质量和体积各是多少？

$$m(CO_2) = n \cdot M = 0.5\,mol \times 44\,g/mol = 22\,g$$

$$V(CO_2) = n \cdot V_m = 0.5\,mol \times 22.4\,L/mol = 11.2\,L$$

### 【隐性考点】阿伏伽德罗常数的"陷阱"

关于阿伏伽德罗常数$N_A$的考题中，常见的陷阱有：

| 陷阱类型 | 错误表述 | 正确分析 |
|---------|---------|---------|
| **状态陷阱** | "标准状况下，$22.4\,L\,H_2O$含有$N_A$个分子" | $H_2O$在标况下是液体，不是气体，不能用$22.4\,L/mol$ |
| **状态陷阱** | "常温常压下，$22.4\,L\,O_2$含有$N_A$个分子" | 常温常压不是标准状况，$V_m \neq 22.4\,L/mol$ |
| **状态陷阱** | "标准状况下，$22.4\,L\,CCl_4$..." | $CCl_4$标况下是液体 |
| **分子结构** | "$1\,mol\,CH_4$含$4N_A$个原子" | 错误！$CH_4$含5个原子，应为$5N_A$ |
| **可逆反应** | "$1\,mol\,Cl_2$与$H_2O$反应转移$N_A$个电子" | 反应可逆，不能完全进行 |
| **水解** | "$1\,L\,0.1\,mol/L\,Na_2CO_3$含$0.1N_A$个$CO_3^{2-}$" | $CO_3^{2-}$水解，实际$CO_3^{2-}$少于$0.1N_A$ |
| **气体混合物** | "标准状况下，$22.4\,L$空气含$N_A$个分子" | 正确。同温同压下，气体总体积与总物质的量成正比 |
| **电子数** | "$1\,mol\,OH^-$含$10N_A$个电子" | 正确。$O$有8个+$H$有1个+1个负电荷=$10$个电子 |

**常见物质在标况下的状态**：

| 标况下为液体的物质 | 标况下为固体的物质 |
|-------------------|-------------------|
| $H_2O$、$H_2O_2$ | $I_2$、$S$、$P$、$NaCl$ |
| $Br_2$（唯一液态非金属单质） | $Fe$、$Na$等金属 |
| $CCl_4$、$CHCl_3$、$CS_2$ | 所有离子化合物 |
| $SO_3$（标况下为固体，熔点$16.8\,^\circ C$） | $SiO_2$、$Al_2O_3$等共价晶体 |

| 错误用法 | 正确用法 |
|---------|---------|
| 用$22.4\,L/mol$计算常温常压下的气体体积 | $22.4\,L/mol$只适用于**标准状况**（$0\,^\circ C$、$101\,kPa$） |

### 【思想方法】守恒思想在化学计算中的应用

#### 1. 原子守恒

化学反应前后，各元素的原子数目保持不变。

**例**：$NH_4HCO_3$分解：

$$NH_4HCO_3 \xrightarrow{\Delta} NH_3 \uparrow + H_2O + CO_2 \uparrow$$

反应前$N:H:C:O = 1:5:1:3$，反应后各产物中原子总数相等。

#### 2. 电子守恒

氧化还原反应中，氧化剂得电子总数 = 还原剂失电子总数。

**例**：$Cl_2$与$Fe$反应：

$$2Fe + 3Cl_2 = 2FeCl_3$$

$2\,mol\,Fe$失去$6\,mol$电子，$3\,mol\,Cl_2$得到$6\,mol$电子。

#### 3. 质量守恒

$$m_{\text{反应物}} = m_{\text{生成物}}$$

#### 4. 电荷守恒

溶液中阳离子所带正电荷总数 = 阴离子所带负电荷总数。

**例**：在$NaCl$溶液中：

$$c(Na^+) + c(H^+) = c(Cl^-) + c(OH^-)$$

### 【基础精讲】四、物质的量浓度（$c$）

#### 1. 定义

单位体积溶液中所含溶质的物质的量，叫做**物质的量浓度**，符号为$c$（或$c_B$），单位为$mol/L$（或$mol \cdot L^{-1}$）。

$$c = \frac{n}{V}$$

其中：
- $n$：溶质的物质的量（$mol$）
- $V$：溶液的体积（$L$）

**注意**：是**溶液体积**，不是**溶剂体积**！

#### 2. 与质量分数（$w$）的换算

已知溶液密度$\rho$（$g/mL$或$g/cm^3$）和质量分数$w$：

$$c = \frac{1000 \cdot \rho \cdot w}{M}$$

推导：取1 L（1000 mL）溶液，
- 溶液质量 = $1000\rho$（$g$）
- 溶质质量 = $1000\rho \cdot w$（$g$）
- 溶质的物质的量 = $\frac{1000\rho w}{M}$（$mol$）
- 物质的量浓度 = $\frac{1000\rho w}{M}$（$mol/L$）

**例5**：质量分数为98%的浓硫酸，密度为$1.84\,g/cm^3$，求其物质的量浓度。

$$c(H_2SO_4) = \frac{1000 \times 1.84 \times 0.98}{98} = 18.4\,mol/L$$

#### 3. 溶液的稀释与混合

**（1）稀释定律**：

$$c_1V_1 = c_2V_2$$

稀释前后溶质的物质的量不变。

**（2）等体积混合**（忽略体积变化）：

$$c_{\text{混}} = \frac{c_1V + c_2V}{2V} = \frac{c_1 + c_2}{2}$$

**（3）溶液中离子浓度的计算**：

对于强电解质完全电离的情况：

| 溶质 | 浓度关系 |
|------|---------|
| $NaCl$ | $c(Na^+) = c(Cl^-) = c(NaCl)$ |
| $Na_2SO_4$ | $c(Na^+) = 2c(SO_4^{2-}) = 2c(Na_2SO_4)$ |
| $MgCl_2$ | $c(Mg^{2+}) = \frac{1}{2}c(Cl^-) = c(MgCl_2)$ |
| $Al_2(SO_4)_3$ | $c(Al^{3+}) = \frac{2}{3}c(SO_4^{2-}) = 2c[Al_2(SO_4)_3]$ |

### 【基础精讲】五、一定物质的量浓度溶液的配制

#### 1. 实验仪器

| 仪器 | 作用 | 使用注意事项 |
|------|------|-------------|
| 容量瓶 | 准确配制一定体积、一定浓度的溶液 | **不能加热、不能溶解、不能长期储存** |
| 托盘天平 | 称量固体质量 | 左物右码，精确到0.1 g |
| 量筒 | 量取液体体积 | 选择合适规格，读数平视 |
| 烧杯 | 溶解固体（或稀释浓溶液） | 用玻璃棒搅拌加速溶解 |
| 玻璃棒 | 搅拌、引流 | 转移溶液时用玻璃棒引流 |
| 胶头滴管 | 定容时逐滴加水 | 垂直悬空，不能伸入瓶中 |

#### 2. 容量瓶的规格与标识

常见规格：$100\,mL$、$250\,mL$、$500\,mL$、$1000\,mL$

瓶身标有：
- **容积**（如$500\,mL$）
- **温度**（$20\,^\circ C$）——容量瓶在标定温度下才准确
- **刻度线**——一条环形标线

#### 3. 实验步骤（以配制$500\,mL\,0.1\,mol/L\,NaOH$溶液为例）

**步骤一：计算**

$$n(NaOH) = c \cdot V = 0.1\,mol/L \times 0.5\,L = 0.05\,mol$$

$$m(NaOH) = n \cdot M = 0.05\,mol \times 40\,g/mol = 2.0\,g$$

**步骤二：称量**

用托盘天平称取2.0 g $NaOH$固体。

**注意**：$NaOH$易潮解且腐蚀性强，应在**烧杯**或**表面皿**上称量（不能直接放在称量纸上）。

**步骤三：溶解**

将$NaOH$固体放入烧杯，加入适量蒸馏水（约$200\,mL$），用玻璃棒搅拌溶解。

**注意**：$NaOH$溶解放热，应冷却至室温后再转移。不能在容量瓶中直接溶解！

**步骤四：转移**

将冷却后的溶液沿玻璃棒注入$500\,mL$容量瓶中。

**注意**：烧杯内壁要洗涤2~3次，洗涤液一并转入容量瓶（确保溶质全部转移）。

**步骤五：洗涤**

用少量蒸馏水洗涤烧杯和玻璃棒2~3次，洗涤液全部注入容量瓶。

**步骤六：定容**

向容量瓶中加蒸馏水至液面离刻度线1~2 cm处，改用胶头滴管逐滴加蒸馏水至**凹液面最低点与刻度线相切**。

**注意**：
- 视线要与刻度线平齐
- 加至接近刻度线时改换胶头滴管
- **不能仰视或俯视**（仰视加水偏多，浓度偏低；俯视加水偏少，浓度偏高）

**步骤七：摇匀**

盖好瓶塞，反复颠倒摇匀。

**注意**：摇匀后若液面低于刻度线，**不能补加水**（瓶塞沾有溶液，属于正常现象）。

**步骤八：装瓶贴签**

将配好的溶液倒入洁净的试剂瓶中，贴上标签。

#### 4. 实验流程图

```
计算 → 称量 → 溶解 → 冷却 → 转移 → 洗涤 → 定容 → 摇匀 → 装瓶
```

#### 5. 如果用浓溶液配制稀溶液

**例**：用$18.4\,mol/L$浓硫酸配制$500\,mL\,0.5\,mol/L$稀硫酸。

**步骤一：计算**

$$c_1V_1 = c_2V_2$$

$$18.4\,mol/L \times V_1 = 0.5\,mol/L \times 500\,mL$$

$$V_1 = \frac{0.5 \times 500}{18.4} \approx 13.6\,mL$$

**步骤二：量取**

用量筒量取$13.6\,mL$浓硫酸。

**步骤三：稀释**

将浓硫酸沿烧杯壁**缓缓注入**蒸馏水中，并不断搅拌。

**注意**：**不能把水倒入浓硫酸中**！浓硫酸密度大，溶于水放热剧烈，若将水倒入浓硫酸，水会浮在硫酸表面沸腾溅出，造成危险。

后续步骤同上（冷却→转移→洗涤→定容→摇匀→装瓶）。

### 【实验思想】一定物质的量浓度溶液配制的误差分析

误差分析的核心依据：

$$c = \frac{n}{V}$$

- 若$n$偏大（溶质偏多），则$c$偏高
- 若$n$偏小（溶质偏少），则$c$偏低
- 若$V$偏大（加水偏多），则$c$偏低
- 若$V$偏小（加水偏少），则$c$偏高

#### 常见误差分析一览表

| 操作 | 对$n$的影响 | 对$V$的影响 | 对$c$的影响 |
|------|------------|------------|------------|
| 砝码生锈（质量变大） | $n$偏大 | — | **偏高** |
| 左码右物（称量$NaCl$） | $n$偏小 | — | **偏低** |
| 称量$NaOH$时间过长（潮解） | $n$偏小 | — | **偏低** |
| 量筒洗涤后量取浓溶液 | $n$偏大 | — | **偏高** |
| 量取浓溶液时仰视读数 | $n$偏大 | — | **偏高** |
| 量取浓溶液时俯视读数 | $n$偏小 | — | **偏低** |
| 溶解后未冷却就转移 | — | $V$偏小 | **偏高** |
| 转移时溶液溅出 | $n$偏小 | — | **偏低** |
| 未洗涤烧杯和玻璃棒 | $n$偏小 | — | **偏低** |
| 定容时仰视刻度线 | — | $V$偏大 | **偏低** |
| 定容时俯视刻度线 | — | $V$偏小 | **偏高** |
| 定容后液面下降补加水 | — | $V$偏大 | **偏低** |
| 容量瓶中原有少量蒸馏水 | — | — | **无影响** |
| 砝码缺角 | $n$偏小 | — | **偏低** |

#### 误差分析的核心记忆法

- **仰视** → 加水多 → $V$大 → $c$**偏低**
- **俯视** → 加水少 → $V$小 → $c$**偏高**

记忆要点：仰视时视线低于刻度线，继续加水至液面与视线平齐，导致实际液面高于刻度线（加水偏多）；俯视时视线高于刻度线，提前停止加水，导致实际液面低于刻度线（加水偏少）。

### 【知识串联】物质的量——化学计算的中心物理量

物质的量是建立微观粒子数与宏观可测量之间定量关系的中心物理量，掌握以下关系网络至关重要：

```
                    粒子数 N
                   ↗       ↘
          N = n·N_A          n = N/N_A
                 ↗    n    ↘
           m/M = n            n = c·V
                 ↘            ↗
                  质量 m ———— 溶液体积 V
                            (aq)
                           ↗
                     n = V(gas)/V_m
                           
                    气体体积 V(gas)
```

**核心公式汇总**：

| 公式 | 适用条件 |
|------|---------|
| $n = \frac{N}{N_A}$ | 任何粒子 |
| $n = \frac{m}{M}$ | 任何物质 |
| $n = \frac{V_{\text{气}}}{V_m}$ | 标准状况下的气体 |
| $n = c \cdot V_{\text{液}}$ | 溶液中的溶质 |
| $c_1V_1 = c_2V_2$ | 溶液稀释 |

### 【思想方法】定量思想与宏观微观结合

#### 1. "见量化摩"法

化学计算中，先将已知量（质量、气体体积等）转换为物质的量，再进行后续计算，这是化学定量分析的基本方法。

**例6**：标准状况下，$11.2\,L\,HCl$气体溶于水配成$500\,mL$溶液，求物质的量浓度。

$$n(HCl) = \frac{11.2\,L}{22.4\,L/mol} = 0.5\,mol$$

$$c(HCl) = \frac{0.5\,mol}{0.5\,L} = 1.0\,mol/L$$

#### 2. "化学方程式计算"三步法

**第一步**：写出配平的化学方程式

**第二步**：标出已知量和未知量的物质的量之比

**第三步**：列比例式求解

**例7**：5.4 g铝与足量氢氧化钠溶液反应，求生成的$H_2$在标准状况下的体积。

解：

$$2Al + 2NaOH + 2H_2O = 2NaAlO_2 + 3H_2 \uparrow$$

$$n(Al) = \frac{5.4\,g}{27\,g/mol} = 0.2\,mol$$

由方程式可知：$2\,mol\,Al$生成$3\,mol\,H_2$

设生成$H_2$的物质的量为$x$：

$$\frac{2}{3} = \frac{0.2}{x}$$

$$x = 0.3\,mol$$

$$V(H_2) = 0.3\,mol \times 22.4\,L/mol = 6.72\,L$$

### 【易错警示】物质的量相关计算常见误区

| 错误认识 | 正确理解 |
|----------|---------|
| 摩尔质量就是相对分子质量 | 摩尔质量单位为$g/mol$，相对分子质量无单位；二者数值相等 |
| $N_A$就是$6.02 \times 10^{23}$ | $6.02 \times 10^{23}$只是近似值，精确值为$0.012\,kg\,^{12}C$中的碳原子数 |
| 1 mol $H_2O$含有$N_A$个$H$原子 | 应为$2N_A$个$H$原子，$N_A$个$O$原子 |
| 标准状况下，1 mol $H_2O$体积为$22.4\,L$ | $H_2O$标况下是液体，不适用气体摩尔体积 |
| 常温常压下$V_m = 22.4\,L/mol$ | 只适用于标准状况（$0\,^\circ C$、$101\,kPa$） |
| 将溶质溶于1 L水中，浓度为$c$ | 应是配成1 L**溶液**，不是溶于1 L**水** |
| 容量瓶可配制任意体积的溶液 | 只能配制与容量瓶规格一致的体积（如$100\,mL$、$250\,mL$等） |
| 容量瓶可以加热溶解固体 | **不能加热、不能溶解**，只能用于定容 |
| 定容时仰视读数，浓度偏高 | 仰视加水多，$V$偏大，$c$**偏低** |
| 摇匀后液面下降，补加水 | 不能补加，否则$V$偏大，$c$偏低 |
| 容量瓶使用温度为$25\,^\circ C$ | 标注温度为$20\,^\circ C$ |
| 配制$450\,mL$溶液用$450\,mL$容量瓶 | 没有$450\,mL$规格，应选用$500\,mL$容量瓶 |

### 【隐性考点】物质的量浓度计算的难点突破

#### 1. 溶液混合后浓度的计算

**例8**：将$100\,mL\,0.3\,mol/L$ $Na_2SO_4$溶液与$50\,mL\,0.2\,mol/L$ $Al_2(SO_4)_3$溶液混合（忽略体积变化），求混合溶液中$SO_4^{2-}$的物质的量浓度。

解：

$$n_1(SO_4^{2-}) = 0.1\,L \times 0.3\,mol/L = 0.03\,mol$$

$$n_2(SO_4^{2-}) = 0.05\,L \times 0.2\,mol/L \times 3 = 0.03\,mol$$

$$c(SO_4^{2-}) = \frac{0.03 + 0.03}{0.1 + 0.05} = \frac{0.06}{0.15} = 0.4\,mol/L$$

#### 2. 气体溶于水后溶液浓度的计算

**例9**：标准状况下，$a\,L\,HCl$气体溶于$1000\,g$水中，得到密度为$\rho\,g/cm^3$的盐酸，求该盐酸的物质的量浓度。

解：

$$n(HCl) = \frac{a}{22.4}\,mol$$

$$m(HCl) = \frac{a}{22.4} \times 36.5\,g$$

$$m_{\text{溶液}} = \frac{a \times 36.5}{22.4} + 1000\,g$$

$$V_{\text{溶液}} = \frac{m_{\text{溶液}}}{\rho} = \frac{\frac{36.5a}{22.4} + 1000}{1000\rho}\,L$$

$$c(HCl) = \frac{n}{V} = \frac{\frac{a}{22.4}}{\frac{\frac{36.5a}{22.4} + 1000}{1000\rho}} = \frac{1000\rho a}{36.5a + 22400}\,mol/L$$
