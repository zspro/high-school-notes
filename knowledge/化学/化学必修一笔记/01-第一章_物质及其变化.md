# 第一章 物质及其变化

> **本章地位**：本章是高中化学的方法论基础。物质分类为后续学习提供系统的认知框架，离子反应和氧化还原反应是化学反应的两大核心研究维度。本章学习的三种核心思想——分类思想、微粒观、守恒观——将贯穿整个高中化学乃至大学化学的学习。

## 【来龙去脉】为什么要重新学习"物质分类"和"化学反应分类"？

### 一、从初中到高中：认知视角的跃迁

初中化学提供了初步认识化学世界的分类方法：物质分为纯净物和混合物，化学反应分为化合、分解、置换、复分解四大基本反应类型。这套分类体系简单直观，帮助我们快速入门。但随着学习的深入，这种分类方法在处理更复杂的化学问题时显示出局限性：

**场景1**：铁生锈 $4Fe + 3O_2 = 2Fe_2O_3$ 属于化合反应——但这只是表面分类。铜在潮湿空气中生锈生成铜绿 $Cu_2(OH)_2CO_3$，这个反应的本质是什么？

**场景2**：盐酸和氢氧化钠反应 $HCl + NaOH = NaCl + H_2O$ 属于复分解反应——但在溶液中实际发生的是什么？$HCl$ 和 $NaOH$ 在水中以什么形式存在？反应的实质是 $H^+$ 和 $OH^-$ 结合生成水，那为什么方程式中要写 $HCl + NaOH$ 而不是 $H^+ + OH^-$？

**场景3**：$Fe + CuSO_4 = FeSO_4 + Cu$ 既是置换反应，同时也是铁失电子、铜离子得电子的过程——如何用统一的语言描述这种电子转移？

### 二、两个新的分类维度

高中化学引入了两个全新的分类维度：

| 分类维度 | 核心问题 | 对应章节 |
|---------|---------|---------|
| **是否有离子参加** | 反应在水溶液中是如何发生的？哪些微粒真正参与了反应？ | 1.2 离子反应 |
| **是否有电子转移** | 元素的化合价为什么会变化？谁在得电子、谁在失电子？ | 1.3 氧化还原反应 |

这两个分类维度不是对初中分类的否定，而是**从更深层的微观本质进行的重新分类**。四大基本反应是按"反应物和生成物的种类/数量"这一**外在形式**分类的；而离子反应和氧化还原反应是按**反应机制和电子行为**这一**内在本质**分类的。二者是"交叉关系"而非"从属关系"——一个反应可以同时属于"置换反应"和"氧化还原反应"，也可以属于"复分解反应"和"离子反应"。

## 1.1 物质的分类及转化

### 【来龙去脉】分类——人类认识世界的基本方法

人类认识世界始于命名和分类。古希腊哲学家亚里士多德将世界万物分为"实体""数量""性质"等十大范畴；中国古代将物质分为"金木水火土"五行。近代化学的发展史，是物质分类不断精细化的历史：

- **17-18世纪**：波义耳提出"元素"概念，化学开始从炼金术中独立
- **19世纪**：门捷列夫发现元素周期律，元素分类进入系统化时代
- **20世纪**：化学键理论的发展，使分类深入到微粒间相互作用的层面

化学中为什么要学分类？因为已知物质超过**1亿种**，没有科学的分类方法，化学知识将缺乏系统性。分类的本质是找出事物之间的**共性**和**差异性**，建立层次化的认知结构。

### 【基础精讲】一、物质分类的方法

#### 1. 树状分类法（层级分类法）

树状分类法是按照某种层级标准，将物质逐层细分，形成层级结构。核心特征是：**同一层级用同一标准，下层类别互不重叠、完全穷尽**。

```
                    ┌─── 金属单质（Fe, Cu, Na）
          ┌─ 单质 ──┤
          │         └─── 非金属单质（O₂, S, C）
物质 ─────┤
          │         ┌─── 氧化物（CO₂, CaO）
          │         │
          └─ 纯净物─┼─── 酸（HCl, H₂SO₄）
            │       │
            │       ├─── 碱（NaOH, Ca(OH)₂）
            │       │
            │       ├─── 盐（NaCl, Na₂CO₃）
            │       │
            │       └─── 其他（如氢化物 NH₃）
            │
            └─── 混合物（溶液、胶体、浊液、空气等）
```

> **注意**：上图中"酸、碱、盐"的分类是初中常见的无机化合物分类方式。在高中，我们还会学习有机化合物（烃、醇、羧酸等），它们属于另一大分支。

#### 2. 交叉分类法（多维度分类）

交叉分类法是**同时从多个角度**对物质进行分类，不同维度之间可以"交叉"，形成的类别之间有重叠。

**示例：从"阳离子种类"和"阴离子种类"两个维度对盐进行分类**

| 阳离子＼阴离子 | $Cl^-$ | $SO_4^{2-}$ | $CO_3^{2-}$ |
|:---:|:---:|:---:|:---:|
| $Na^+$ | 氯化钠 $NaCl$ | 硫酸钠 $Na_2SO_4$ | 碳酸钠 $Na_2CO_3$ |
| $K^+$ | 氯化钾 $KCl$ | 硫酸钾 $K_2SO_4$ | 碳酸钾 $K_2CO_3$ |
| $NH_4^+$ | 氯化铵 $NH_4Cl$ | 硫酸铵 $(NH_4)_2SO_4$ | 碳酸铵 $(NH_4)_2CO_3$ |
| $Mg^{2+}$ | 氯化镁 $MgCl_2$ | 硫酸镁 $MgSO_4$ | 碳酸镁 $MgCO_3$ |

通过交叉分类，我们可以：
- 预测未知盐的某些性质（含 $Na^+$ 的盐通常可溶于水；含 $CO_3^{2-}$ 的盐遇酸产生 $CO_2$）
- 系统记忆大量盐类的性质
- 理解"正盐、酸式盐、碱式盐"等概念（这是从"酸的氢是否被完全中和"这一维度进行的分类）

#### 3. 氧化物的重要分类（高中新增视角）

氧化物看似种类繁杂，但从化学性质角度可分为几大类：

| 类型 | 定义 | 实例 | 性质特征 |
|------|------|------|---------|
| **酸性氧化物** | 能与碱反应生成盐和水的氧化物（大多是非金属氧化物） | $CO_2, SO_2, SO_3, SiO_2$ | $CO_2 + 2NaOH = Na_2CO_3 + H_2O$ |
| **碱性氧化物** | 能与酸反应生成盐和水的氧化物（都是金属氧化物） | $CaO, Fe_2O_3, Na_2O, CuO$ | $CaO + 2HCl = CaCl_2 + H_2O$ |
| **两性氧化物** | 既能与酸反应，又能与碱反应生成盐和水的氧化物 | $Al_2O_3$ | 详见第三章 |
| **不成盐氧化物** | 不能与酸或碱反应生成盐的氧化物 | $CO, NO$ | 又称"中性氧化物" |
| **过氧化物** | 含有过氧键—O—O—的氧化物 | $Na_2O_2, H_2O_2$ | 具有强氧化性 |

> **深层理解**：酸性氧化物与碱性氧化物的分类依据，本质上是看氧化物对应的水化物是酸还是碱。例如 $CO_2$ 对应 $H_2CO_3$（酸），所以 $CO_2$ 是酸性氧化物；$CaO$ 对应 $Ca(OH)_2$（碱），所以 $CaO$ 是碱性氧化物。

> **注意**：
> - 金属氧化物不一定是碱性氧化物（如 $Mn_2O_7$ 是酸性氧化物，$Al_2O_3$ 是两性氧化物）
> - 非金属氧化物不一定是酸性氧化物（如 $CO, NO$ 是不成盐氧化物）
> - **酸性氧化物与碱、碱性氧化物与酸的反应，本质上属于复分解反应（或非氧化还原反应）**

### 【基础精讲】二、分散系及其分类

#### 1. 分散系的定义

**分散系** = **分散质**（被分散的物质） + **分散剂**（起分散作用的物质）

分散系不一定是"溶液"——溶液只是分散系的一种。分散系的分类依据是**分散质粒子的直径大小**。

#### 2. 三种分散系的本质区别

| 分散系 | 分散质粒子直径 | 外观特征 | 稳定性 | 能否透过滤纸 | 能否透过半透膜 |
|--------|--------------|---------|--------|------------|-------------|
| **溶液** | $<1\text{nm}$ | 均一、透明 | 稳定 | 能 | 能 |
| **胶体** | $1\text{nm} \sim 100\text{nm}$ | 均一、较透明（有的有颜色） | 较稳定 | 能 | **不能** |
| **浊液** | $>100\text{nm}$ | 不均一、不透明、浑浊 | 不稳定，静置分层/沉降 | **不能** | 不能 |

> **核心结论**：三种分散系最本质的区别是**分散质粒子的大小不同**。这个尺寸范围恰好对应着微观世界的几个重要尺度：
> - 小于 $1\text{nm}$：粒子直径接近小分子/离子级别，光线通过时不发生明显散射
> - $1\text{nm} \sim 100\text{nm}$：粒子尺寸接近可见光波长（400-700nm），对光产生**散射**（丁达尔效应）
> - 大于 $100\text{nm}$：粒子太大，阻挡光线，发生**反射或吸收**

#### 3. 胶体的本质特征

胶体的本质特征是**分散质粒子直径在 $1\text{nm} \sim 100\text{nm}$ 之间**，这一尺寸赋予了胶体许多独特的性质。

**（1）丁达尔效应——胶体的鉴别特征**

当一束光线通过胶体时，由于胶体粒子对光的散射，从侧面可以观察到一条光亮的"通路"。溶液没有丁达尔效应，浊液由于不透明也看不到。丁达尔效应是**区分胶体和溶液的最简便方法**。

> **微观解释**：可见光波长约 400-700 nm，胶体粒子直径（1-100 nm）小于可见光波长。当光照射到胶体粒子上时，粒子中的电子在光的电磁场作用下做受迫振动，成为次级波源，向各个方向发射散射光（瑞利散射）。由于胶体粒子密度适中，散射光叠加形成可见的"光路"。溶液中粒子太小，散射光极弱；浊液中粒子太大，主要是反射和吸收。

**（2）胶体的电泳**

在外加电场作用下，胶体粒子向某一电极方向移动的现象叫**电泳**。这说明胶体粒子带有**同种电荷**。

> **常见胶体粒子的带电情况**：
> - 金属氧化物/氢氧化物胶体粒子（如 $Fe(OH)_3$ 胶体）：一般带**正电**
> - 非金属氧化物/硫化物胶体粒子（如 $As_2S_3$ 胶体、硅酸胶体）：一般带**负电**
> - 淀粉胶体、蛋白质胶体：通常不带电（高分子胶体）

> **思考**：胶体粒子为什么带电？
> 胶体粒子具有很大的比表面积，容易吸附溶液中的离子而带上电荷。例如 $Fe(OH)_3$ 胶体粒子在制备过程中吸附了溶液中的 $Fe^{3+}$ 或 $FeO^+$ 而带正电。

**（3）胶体的聚沉**

使胶体粒子聚集成较大颗粒，从而沉降下来的过程叫**聚沉**。聚沉的方法有：
- 加入**电解质**（中和胶粒电荷）
- 加入**带相反电荷的胶体**（电荷中和）
- 加热（增加粒子动能，碰撞机会增多）
- 搅拌（物理作用促使聚沉）

> **生活实例**：
> - 卤水点豆腐：豆浆是蛋白质胶体，加入 $MgCl_2$（卤水）或 $CaSO_4$（石膏）使蛋白质聚沉
> - 江河入海口三角洲的形成：河水携带的泥沙胶体遇到海水中的 $NaCl, MgCl_2$ 等电解质而聚沉
> - 血液透析：利用半透膜分离血液中的有害小分子（血液本身是胶体）

#### 4. $Fe(OH)_3$ 胶体的制备实验

**实验原理**：$FeCl_3$ 在沸水中发生水解反应，生成 $Fe(OH)_3$ 胶体：

$$FeCl_3 + 3H_2O \xrightarrow{\Delta} Fe(OH)_3(\text{胶体}) + 3HCl$$

**操作要点**：
1. 取 $25\text{mL}$ 蒸馏水加热至**沸腾**
2. 逐滴加入**5-6滴**饱和 $FeCl_3$ 溶液
3. 继续加热至溶液呈**红褐色**
4. 停止加热

**关键注意事项**：
- 必须用**蒸馏水**（自来水中含电解质，会导致胶体聚沉）
- $FeCl_3$ 溶液要**少量逐滴加入**（过量会导致聚沉生成沉淀）
- 加热至**红褐色即停止**，不可过度加热（过度加热也会使胶体聚沉）
- 不可搅拌（搅拌会破坏胶体结构）
- 方程式中注明"胶体"二字，不能写"$\downarrow$"沉淀符号

**误差分析**：
- 若出现浑浊：可能是 $FeCl_3$ 加入过多，或加热过度，或使用了自来水
- 若颜色过浅：可能是 $FeCl_3$ 浓度太低或加入量太少

### 【深度理解】三、物质的转化关系

#### 1. 单质、氧化物、酸、碱、盐之间的转化关系

这是化学中最核心的"物质转化网络"，后续学习元素化合物知识时，各类反应都可以归入这一框架：

**（1）单质 $\rightarrow$ 氧化物**

$$2Mg + O_2 \xrightarrow{\text{点燃}} 2MgO$$

$$C + O_2 \xrightarrow{\text{点燃}} CO_2$$

> **说明**：并非所有单质都能直接转化为氧化物。例如，$Cu$ 与 $S$ 反应生成 $Cu_2S$（硫化物）而非氧化物。

**（2）氧化物 $\rightarrow$ 酸/碱（氧化物的水化）**

$$SO_3 + H_2O = H_2SO_4$$

$$CaO + H_2O = Ca(OH)_2$$

> **说明**：能直接与水反应生成酸/碱的氧化物是有限的。例如 $SiO_2$ 不溶于水，不能直接生成硅酸，需要先与碱反应生成硅酸盐，再加酸制得硅酸。

**（3）酸 $\rightarrow$ 盐**

$$2HCl + Na_2CO_3 = 2NaCl + H_2O + CO_2 \uparrow$$

$$H_2SO_4 + BaCl_2 = BaSO_4 \downarrow + 2HCl$$

> **酸的通性**：酸 + 金属 $\rightarrow$ 盐 + 氢气；酸 + 金属氧化物 $\rightarrow$ 盐 + 水；酸 + 碱 $\rightarrow$ 盐 + 水；酸 + 盐 $\rightarrow$ 新酸 + 新盐

**（4）碱 $\rightarrow$ 盐**

$$2NaOH + CO_2 = Na_2CO_3 + H_2O$$

$$Ca(OH)_2 + Na_2CO_3 = CaCO_3 \downarrow + 2NaOH$$

**（5）盐 $\rightarrow$ 新盐**

$$Na_2CO_3 + CaCl_2 = CaCO_3 \downarrow + 2NaCl$$

#### 2. 转化关系的应用——物质的制备

利用物质转化关系，可以设计物质的制备路线。例如由铜制备硫酸铜：

$$\text{路线1}：Cu \xrightarrow{+O_2} CuO \xrightarrow{+H_2SO_4} CuSO_4 + H_2O$$

$$\text{路线2}：Cu + 2H_2SO_4(\text{浓}) \xrightarrow{\Delta} CuSO_4 + SO_2 \uparrow + 2H_2O$$

> **评价**：路线1更优，因为产物纯净、无污染气体 $SO_2$ 生成、硫酸利用率高。这体现了绿色化学思想。

### 【思想方法】分类思想

分类思想是化学研究的基本方法。本章学习了两种分类方法：

| 分类方法 | 特点 | 应用 |
|---------|------|------|
| **树状分类法** | 同一层级同一标准，层次递进 | 物质按组成分类（纯净物→单质/化合物→...） |
| **交叉分类法** | 多维度交叉，类别可重叠 | 盐按阳离子和阴离子双重分类 |

**分类的基本原则**：
1. **每次分类只有一个标准**（树状分类法）
2. **分类标准要明确**（不能模棱两可）
3. **分类后的子项互不重叠**（树状分类法）
4. **分类要穷尽所有对象**

> **实例分析**：请判断下列分类是否正确——"氧化物分为金属氧化物和非金属氧化物"？
> 
> **分析**：这一分类标准是"组成元素是否为金属"，分类本身没有错误。但如果目的是研究氧化物的**化学性质**，那么按"酸性/碱性/两性/不成盐氧化物"分类更有价值。**分类标准的选择应服务于研究目的**。

## 1.2 离子反应

### 【来龙去脉】为什么需要"离子反应"这个概念？

初中化学告诉我们：盐酸和氢氧化钠反应生成氯化钠和水，$HCl + NaOH = NaCl + H_2O$。这是一个复分解反应。但这个方程式真的描述了反应的本质吗？

让我们追问几个"为什么"：

**问题1**：将 $HCl$ 溶液和 $NaOH$ 溶液混合，反应发生得极快，几乎是瞬间完成。而氢气和氮气合成氨的反应，在高温高压催化剂条件下还需要很长时间。为什么溶液中的酸碱反应这么快？

**问题2**：如果将 $NaOH$ 溶液分别与 $HCl$ 溶液和 $HNO_3$ 溶液反应，现象完全相同——都没有沉淀、没有气体、只是温度升高。如何理解这种"反应的共性"？

**问题3**：书写化学方程式时，为什么要按化学式写 $HCl$？$HCl$ 在水中以什么形式存在？

19世纪末，瑞典化学家**阿伦尼乌斯**（Arrhenius）提出电离理论，回答了这些问题。他发现，$NaCl, HCl, NaOH$ 等物质溶解于水时，会分解成**带电的离子**。溶液中的反应，实际上是离子之间的反应。这就是离子反应概念的由来。

> **历史意义**：阿伦尼乌斯的电离理论（1884年提出）是化学史上的里程碑，它首次从微观角度揭示了溶液中化学反应的本质。阿伦尼乌斯因此获得1903年诺贝尔化学奖。

### 【基础精讲】一、电解质与非电解质

#### 1. 核心概念

| 概念 | 定义 | 关键要求 | 实例 |
|------|------|---------|------|
| **电解质** | 在水溶液中或熔融状态下**能导电的化合物** | ①必须是**化合物**；②满足一个条件即可 | $NaCl, HCl, NaOH, BaSO_4$ |
| **非电解质** | 在水溶液中和熔融状态下**都不能导电的化合物** | ①必须是**化合物**；②两个条件都不满足 | $CO_2, NH_3, C_2H_5OH, C_6H_{12}O_6$（葡萄糖） |

#### 2. 从定义中挖掘的深层信息

**（1）电解质导电的实质是产生"自由移动的离子"**

电解质导电 ≠ 电解质本身有电。电解质之所以能在水溶液中或熔融状态下导电，是因为在这些条件下，电解质分子或晶体中的离子变成了**可以自由移动的离子**，在外加电场作用下定向移动形成电流。

**（2）"或"字的深意**

定义中用的是"**或**"而不是"**和**"，意味着只需满足其中一个条件即可。例如 $HCl$ 在液态（纯）时不导电（没有自由离子），但溶于水后能导电，所以 $HCl$ 是电解质。$NaCl$ 在水溶液中和熔融状态下都能导电。$BaSO_4$ 虽然难溶于水，但熔融状态下能导电，所以也是电解质。

**（3）导电只是判断的"现象标准"，不是本质**

电解质溶于水后溶液的导电性强弱，与电解质的**电离程度**和**溶液浓度**都有关。不能简单地说"导电强的就是强电解质"，因为一个很稀的强电解质溶液可能比一个浓的弱电解质溶液导电性还弱。

#### 3. 强电解质与弱电解质

| 类别 | 定义 | 电离程度 | 溶液中微粒形态 | 实例 |
|------|------|---------|--------------|------|
| **强电解质** | 在水溶液中**完全电离**的电解质 | 接近100% | 只有离子（没有溶质分子） | 强酸：$HCl, H_2SO_4, HNO_3$；强碱：$NaOH, KOH, Ba(OH)_2, Ca(OH)_2$；绝大多数盐（包括难溶盐） |
| **弱电解质** | 在水溶液中**部分电离**的电解质 | 远小于100% | 既有离子，又有大量未电离的分子 | 弱酸：$CH_3COOH, H_2CO_3, HClO$；弱碱：$NH_3 \cdot H_2O$；水：$H_2O$ |

> **本质区别**：强电解质在水中完全电离为离子；弱电解质在水中部分电离，溶液中同时存在未电离的分子和离子。

#### 4. 【隐性考点】电解质强弱的判断——与溶解性无关！

| 物质 | 溶解性 | 电解质类型 | 原因 |
|------|--------|-----------|------|
| $BaSO_4$ | 难溶 | **强电解质** | 溶于水的部分**完全电离** |
| $CaCO_3$ | 难溶 | **强电解质** | 溶于水的部分**完全电离** |
| $AgCl$ | 难溶 | **强电解质** | 溶于水的部分**完全电离** |
| $CH_3COOH$ | 易溶 | **弱电解质** | 溶于水的部分**仅部分电离** |
| $NH_3 \cdot H_2O$ | 易溶 | **弱电解质** | 溶于水的部分**仅部分电离** |

> **核心结论**：电解质的强弱取决于**电离程度**，而不是**溶解度**。强电解质可能是难溶物（如 $BaSO_4$），弱电解质可能是易溶物（如醋酸）。

### 【易错警示】单质和混合物既不是电解质也不是非电解质

| 物质类别 | 是否为电解质 | 原因分析 |
|---------|------------|---------|
| $Cu$（单质） | **既不是电解质也不是非电解质** | 电解质必须是**化合物** |
| $Cl_2$（单质） | **既不是电解质也不是非电解质** | 同上 |
| $NaCl$溶液（混合物） | **既不是电解质也不是非电解质** | 电解质必须是**化合物**。$NaCl$是电解质，$NaCl$溶液不是 |
| 盐酸（混合物） | **既不是电解质也不是非电解质** | $HCl$是电解质，盐酸是$HCl$的水溶液（混合物） |
| $CO_2$（化合物） | **非电解质** | $CO_2$溶于水生成的$H_2CO_3$能导电，但导电的是$H_2CO_3$不是$CO_2$ |
| $NH_3$（化合物） | **非电解质** | $NH_3$溶于水生成的$NH_3 \cdot H_2O$能导电，但导电的是$NH_3 \cdot H_2O$不是$NH_3$ |

> **判断流程**：
> 1. 先看是否为**化合物**——单质、混合物直接排除
> 2. 再看是否在水溶液中或熔融状态下能导电
> 3. 注意 $CO_2, SO_2, NH_3$ 等物质的"迷惑性"——它们的水溶液能导电，但不是它们本身导电

### 【基础精讲】二、电离

#### 1. 电离的定义

电离：电解质溶于水或受热熔化时，离解成**自由移动的离子**的过程。

$$NaCl \xrightarrow{溶于水} Na^+ + Cl^-$$

$$HCl \xrightarrow{溶于水} H^+ + Cl^-$$

$$NaOH \xrightarrow{溶于水} Na^+ + OH^-$$

#### 2. 电离方程式书写规则

**强电解质**：用 "$=$" 连接，一步完全电离。

$$H_2SO_4 = 2H^+ + SO_4^{2-}$$

$$Ba(OH)_2 = Ba^{2+} + 2OH^-$$

$$Na_2CO_3 = 2Na^+ + CO_3^{2-}$$

$$Fe_2(SO_4)_3 = 2Fe^{3+} + 3SO_4^{2-}$$

**弱电解质**：用 "$\rightleftharpoons$" 连接，表示可逆电离。

$$CH_3COOH \rightleftharpoons CH_3COO^- + H^+$$

$$NH_3 \cdot H_2O \rightleftharpoons NH_4^+ + OH^-$$

$$H_2O \rightleftharpoons H^+ + OH^-$$

**多元弱酸**：分步电离，以第一步为主（选修内容）。

$$H_2CO_3 \rightleftharpoons H^+ + HCO_3^- \quad(\text{主要})$$

$$HCO_3^- \rightleftharpoons H^+ + CO_3^{2-} \quad(\text{次要})$$

#### 3. 电离方程式中的守恒关系

**质量守恒**：方程式左边和右边各元素的原子个数相等。

**电荷守恒**：阳离子所带正电荷总数 = 阴离子所带负电荷总数。

> 例如：$Na_2CO_3 = 2Na^+ + CO_3^{2-}$，左边总电荷为0，右边 $2 \times (+1) + (-2) = 0$。
>
> 再如：$Fe_2(SO_4)_3 = 2Fe^{3+} + 3SO_4^{2-}$，右边 $2 \times (+3) + 3 \times (-2) = 6 - 6 = 0$。

### 【深度理解】三、离子反应

#### 1. 离子反应的定义

**离子反应**：有离子参加或生成的反应。

#### 2. 离子反应发生的条件（复分解反应型）

复分解型的离子反应发生的条件是：反应中有**难溶物**、**难电离物质**或**挥发性物质**生成。用更专业的术语说，即生成**沉淀**、**气体**或**弱电解质**（如水）。

| 反应条件 | 实例 | 离子方程式 |
|---------|------|----------|
| 生成沉淀 | $NaCl + AgNO_3$ | $Ag^+ + Cl^- = AgCl \downarrow$ |
| 生成气体 | $Na_2CO_3 + HCl$ | $CO_3^{2-} + 2H^+ = H_2O + CO_2 \uparrow$ |
| 生成弱电解质 | $NaOH + HCl$ | $H^+ + OH^- = H_2O$ |

#### 3. 离子方程式的定义

**离子方程式**：用实际参加反应的离子符号表示反应的式子。离子方程式不仅能表示一个具体的反应，还能表示**同一类型的所有反应**。

例如：$H^+ + OH^- = H_2O$ 不仅表示 $HCl + NaOH$ 的反应，还表示 $HNO_3 + KOH$、$H_2SO_4 + NaOH$ 等所有强酸与强碱反应生成可溶性盐和水的反应。

---

### 【基础精讲】四、离子方程式的书写——"写、拆、删、查"四步法

#### 第一步：写出正确的化学方程式

$$Na_2CO_3 + 2HCl = 2NaCl + H_2O + CO_2 \uparrow$$

#### 第二步：拆——将可溶性强电解质拆成离子形式

**拆的原则**：
- **可溶性强酸、强碱、可溶性盐** → 拆成离子
- **单质、氧化物、气体、沉淀、弱电解质、非电解质** → 不拆，保留化学式
- **微溶物**：作为反应物时，若是澄清溶液则拆，若是悬浊液则不拆；作为生成物时不拆，写化学式并标"$\downarrow$"

**常见的不可拆物质总结**：

| 类别 | 具体物质 | 原因 |
|------|---------|------|
| 单质 | $Fe, Cu, Cl_2, H_2, O_2$ 等 | 不是化合物 |
| 氧化物 | $CO_2, CaO, Fe_2O_3, H_2O$ 等 | 不是电解质或弱电解质 |
| 气体 | $CO_2, SO_2, NH_3, H_2S$ 等 | 分子形式存在 |
| 沉淀 | $AgCl, BaSO_4, CaCO_3, Fe(OH)_3$ 等 | 难溶物 |
| 弱酸 | $CH_3COOH, H_2CO_3, HClO$ 等 | 弱电解质，主要分子形式 |
| 弱碱 | $NH_3 \cdot H_2O$ 等 | 弱电解质 |
| 水 | $H_2O$ | 极弱电解质 |
| 非电解质 | $C_2H_5OH, C_6H_{12}O_6$ 等 | 不电离 |

**特别提醒**：$Ca(OH)_2$ 是微溶物——澄清石灰水（$Ca(OH)_2$ 溶液）中拆为 $Ca^{2+} + 2OH^-$；石灰乳（$Ca(OH)_2$ 悬浊液）中不拆，保留 $Ca(OH)_2$。

将上例拆开后：

$$2Na^+ + CO_3^{2-} + 2H^+ + 2Cl^- = 2Na^+ + 2Cl^- + H_2O + CO_2 \uparrow$$

#### 第三步：删——删去方程式两边相同的离子（ spectator ions，旁观离子）

删去两边的 $2Na^+$ 和 $2Cl^-$：

$$CO_3^{2-} + 2H^+ = H_2O + CO_2 \uparrow$$

> **概念**：被删去的 $Na^+$ 和 $Cl^-$ 称为"旁观离子"，它们在反应前后没有变化，实际并未参与反应。

#### 第四步：查——检查守恒关系

1. **原子守恒**：左右两边各元素原子个数相等
2. **电荷守恒**：左边电荷总数 = 右边电荷总数
   - 上例：左边 $(-2) + 2 \times (+1) = 0$，右边 $0 + 0 = 0$
3. **配平系数**：化为最简整数比

---

### 【隐性考点】离子方程式"拆与不拆"的深层规则

#### 规则1：酸式盐的处理

酸式盐（如 $NaHSO_4, NaHCO_3$）在书写离子方程式时要区别处理：

| 酸式盐 | 在水溶液中 | 离子方程式中的写法 |
|--------|----------|-----------------|
| $NaHSO_4$ | 完全电离为 $Na^+ + H^+ + SO_4^{2-}$ | **拆为 $H^+$**（水溶液中视为强酸的酸式盐） |
| $NaHCO_3$ | 电离为 $Na^+ + HCO_3^-$（$HCO_3^-$ 不完全电离） | **不拆 $HCO_3^-$**，保留 $HCO_3^-$ |
| $NaHSO_3$ | 类似 $NaHCO_3$ | **保留 $HSO_3^-$** |

> **对比**：
> - $NaHSO_4 + NaOH$：$H^+ + OH^- = H_2O$（$NaHSO_4$ 中的 $H^+$ 参与反应）
> - $NaHCO_3 + NaOH$：$HCO_3^- + OH^- = CO_3^{2-} + H_2O$（$HCO_3^-$ 整体参与反应）

> **注意**：$NaHSO_4$ 在**熔融状态**下电离为 $Na^+ + HSO_4^-$，此时 $HSO_4^-$ 不能拆。

#### 规则2：过量与少量问题

当反应物过量或少量时，离子方程式可能不同。

**例：$NaHCO_3$ 溶液与 $Ca(OH)_2$ 溶液反应**

- $NaHCO_3$ 少量：$HCO_3^- + Ca^{2+} + OH^- = CaCO_3 \downarrow + H_2O$
- $Ca(OH)_2$ 少量：$2HCO_3^- + Ca^{2+} + 2OH^- = CaCO_3 \downarrow + CO_3^{2-} + 2H_2O$

> **解题策略**："少量定1法"——将少量物质的系数定为1，按化学式中离子比例书写，过量物质根据需要补足。

#### 规则3：隐含条件（酸性/碱性环境）

某些反应方程式中隐含了酸碱环境，需要补充 $H^+$ 或 $OH^-$ 使方程式配平。

**例：酸性条件下 $MnO_4^-$ 氧化 $Fe^{2+}$**

$$MnO_4^- + 5Fe^{2+} + 8H^+ = Mn^{2+} + 5Fe^{3+} + 4H_2O$$

> 这里 $H^+$ 没有单独写出来源（如 $H_2SO_4$ 提供），而是直接出现在离子方程式中，表示"酸性条件"。

---

### 【易错警示】离子方程式书写常见错误

| 错误类型 | 错例 | 正例 | 错误原因 |
|---------|------|------|---------|
| 弱酸拆了 | $CH_3COOH + OH^-$ 写成 $H^+ + OH^- = H_2O$ | $CH_3COOH + OH^- = CH_3COO^- + H_2O$ | $CH_3COOH$ 是弱酸，不能拆为 $H^+$ |
| 该拆的没拆 | $Na_2CO_3 + 2H^+ = H_2O + CO_2 \uparrow + 2Na^+$ 写成 $Na_2CO_3$ 未拆 | $CO_3^{2-} + 2H^+ = H_2O + CO_2 \uparrow$ | 可溶性盐应拆为离子 |
| 电荷不守恒 | $Fe + Fe^{3+} = 2Fe^{2+}$ | $Fe + 2Fe^{3+} = 3Fe^{2+}$ | 左边电荷 $+3$，右边 $+4$，不守恒 |
| 原子不守恒 | $Cu + Ag^+ = Cu^{2+} + Ag$ | $Cu + 2Ag^+ = Cu^{2+} + 2Ag$ | 左右 $Ag$ 原子数不等 |
| 微溶物处理错误 | 澄清石灰水参与反应时 $Ca(OH)_2$ 未拆 | 澄清石灰水中应拆为 $Ca^{2+} + 2OH^-$ | 澄清石灰水属于溶液，应拆 |

> **电荷守恒检查法**：这是检查离子方程式正误的可靠方法。写出离子方程式后，计算左右两边的总电荷，若不相等则方程式一定有误。

### 【实验思想】离子反应的实验探究

#### 实验：盐酸与氢氧化钠反应的本质探究

**问题提出**：$HCl$ 和 $NaOH$ 反应的实质是什么？

**实验设计**：

| 实验步骤 | 操作 | 现象 | 分析 |
|---------|------|------|------|
| 1 | 向 $NaOH$ 溶液中滴加酚酞 | 溶液变红 | 溶液中存在 $OH^-$，显碱性 |
| 2 | 逐滴加入 $HCl$ 溶液 | 红色逐渐变浅 | $OH^-$ 浓度降低 |
| 3 | 继续滴加至恰好无色 | 红色恰好褪去 | $OH^-$ 与 $H^+$ 恰好完全反应 |
| 4 | 蒸发反应后溶液 | 得到白色固体 $NaCl$ | 产物是 $NaCl$ |

**微观解释**：

$HCl$ 在水中电离：$HCl = H^+ + Cl^-$

$NaOH$ 在水中电离：$NaOH = Na^+ + OH^-$

混合后，$H^+$ 和 $OH^-$ 结合生成难电离的 $H_2O$ 分子：$H^+ + OH^- = H_2O$

而 $Na^+$ 和 $Cl^-$ 在反应前后没有变化，是**旁观离子**。

**结论**：酸碱中和反应的本质是 $H^+ + OH^- = H_2O$，所有强酸与强碱反应生成可溶性盐和水的反应，都可以用这个离子方程式表示。

## 1.3 氧化还原反应

### 【来龙去脉】从"得氧失氧"到"电子转移"——氧化还原概念的三次跃迁

#### 第一阶段：古典氧化还原（18世纪）

1774年，拉瓦锡提出"氧化"概念，认为物质与**氧**结合的过程叫氧化，从氧化物中夺取氧的过程叫还原。这是氧化还原的原始定义。

$$2Cu + O_2 \xrightarrow{\Delta} 2CuO \quad \text{（铜被氧化，氧被还原——不对，当时不说氧被还原）}$$

$$CuO + H_2 \xrightarrow{\Delta} Cu + H_2O \quad \text{（}CuO\text{ 被还原，}H_2\text{ 被氧化）}$$

这套定义直观，但存在局限性：
- 很多反应没有氧参加，但也存在类似 $CuO + H_2$ 反应中的"电子转移"过程
- 无法解释 $Cl_2 + 2Na = 2NaCl$ 这类没有氧参与的反应

#### 第二阶段：化合价视角（19世纪末）

随着化合价概念的发展，化学家发现：氧化还原反应中元素的**化合价一定会发生变化**。

| 反应 | 化合价变化 | 结论 |
|------|----------|------|
| $CuO + H_2 \xrightarrow{\Delta} Cu + H_2O$ | $Cu: +2 \to 0$，$H: 0 \to +1$ | 化合价有变化 |
| $Cl_2 + 2Na = 2NaCl$ | $Cl: 0 \to -1$，$Na: 0 \to +1$ | 化合价有变化 |
| $Zn + 2HCl = ZnCl_2 + H_2 \uparrow$ | $Zn: 0 \to +2$，$H: +1 \to 0$ | 化合价有变化 |
| $NaOH + HCl = NaCl + H_2O$ | 所有元素化合价不变 | **非氧化还原反应** |

由此得到新的判断标准：**有元素化合价升降的反应就是氧化还原反应**。

> **进步意义**：不再局限于"氧"的参与，只要是化合价变化的反应都可以纳入氧化还原的范畴。化合价的变化是氧化还原反应的**判断依据**。

#### 第三阶段：电子转移视角（20世纪，高中核心）

化合价为什么会变化？追根溯源，是因为原子之间发生了**电子的转移**（得失或偏移）。这才是氧化还原反应的**本质**。

$$2Na + Cl_2 = 2NaCl$$

- $Na$ 原子失去1个电子变成 $Na^+$（化合价从0升到+1）→ 被**氧化**
- $Cl$ 原子得到1个电子变成 $Cl^-$（化合价从0降到-1）→ 被**还原**

**核心认识**：

> **氧化还原反应的本质是电子的转移（得失或偏移），化合价的升降是电子转移的外在表现。**

---

### 【基础精讲】一、氧化还原反应的基本概念

#### 1. 核心概念网

氧化还原反应中有6对核心概念，它们之间有严格的对应关系：

| 概念对 | 定义 | 记忆口诀 |
|--------|------|---------|
| **氧化反应** vs **还原反应** | 元素化合价**升高**（失电子）的过程叫氧化反应；元素化合价**降低**（得电子）的过程叫还原反应 | "升失氧，降得还" |
| **氧化剂** vs **还原剂** | 在反应中使其他物质**氧化**（自身被还原）的物质叫氧化剂；使其他物质**还原**（自身被氧化）的物质叫还原剂 | "剂性一致"——氧化剂具有氧化性，还原剂具有还原性 |
| **氧化产物** vs **还原产物** | 还原剂被**氧化**后得到的产物；氧化剂被**还原**后得到的产物 | "产物相反"——还原剂 → 氧化产物，氧化剂 → 还原产物 |
| **氧化性** vs **还原性** | 物质**得电子**的能力（氧化能力）；物质**失电子**的能力（还原能力） | 得电子能力强 → 氧化性强；失电子能力强 → 还原性强 |

> **理解口诀"升失氧还，降得还氧"**：
> - **升**（化合价升高）→ **失**（失电子）→ **氧**（被氧化）→ **还**（本身是还原剂）
> - **降**（化合价降低）→ **得**（得电子）→ **还**（被还原）→ **氧**（本身是氧化剂）

#### 2. 概念关系图

```
        氧化剂 ──────→ 还原产物
           ↓ 得电子（被还原） ↑
           │ 化合价降低        │
           │                   │
           └──── 电子转移 ────┘
           │                   │
           │ 化合价升高        │
           ↓ 失电子（被氧化） ↓
        还原剂 ──────→ 氧化产物
```

**氧化还原反应的电子转移方向**：
- **还原剂**失电子 → 化合价升高 → 被氧化 → 生成**氧化产物**
- **氧化剂**得电子 → 化合价降低 → 被还原 → 生成**还原产物**

#### 3. 典型分析示例

**例：$CuO + H_2 \xrightarrow{\Delta} Cu + H_2O$**

| 物质 | $CuO$ | $H_2$ |
|------|-------|-------|
| 元素化合价变化 | $Cu: +2 \to 0$（降低） | $H: 0 \to +1$（升高） |
| 电子得失 | 得电子 | 失电子 |
| 发生何反应 | 被还原（还原反应） | 被氧化（氧化反应） |
| 是何"剂" | **氧化剂** | **还原剂** |
| 产物名称 | **还原产物** $Cu$ | **氧化产物** $H_2O$ |

> **注意**：一个氧化还原反应中，氧化剂和还原剂**可能是同种物质**（歧化反应，后续学习），也可能是**不同物质**。在上述反应中，$CuO$ 是氧化剂，$H_2$ 是还原剂。

### 【基础精讲】二、电子转移的表示方法

#### 1. 双线桥法

**特征**：从反应物出发，两条线分别指向产物，一条表示失电子（氧化），一条表示得电子（还原）。

**写法规范**：
1. 箭头由反应物中变价元素**指向**产物中对应元素
2. 桥上标明"得/失"电子数、"被氧化/被还原"
3. 每条线标明化合价变化情况

$$\overset{+2}{Cu}O + \overset{0}{H}_2 \xrightarrow{\Delta} \overset{0}{Cu} + \overset{+1}{H}_2O$$

双线桥表示：
- $Cu$：$\overset{+2}{Cu} \xrightarrow{\text{得}2e^- \text{，被还原}} \overset{0}{Cu}$
- $H$：$\overset{0}{H}_2 \xrightarrow{\text{失}2 \times e^- \text{，被氧化}} \overset{+1}{H}_2$（在 $H_2O$ 中）

**$Cu$ 线**：从 $CuO$ 中的 $Cu$ 指向 $Cu$ 单质，标"得 $2e^-$，被还原"（化合价+2→0，得2个电子）

**$H$ 线**：从 $H_2$ 中的 $H$ 指向 $H_2O$ 中的 $H$，标"失 $2 \times e^-$，被氧化"（每个 $H$ 从0→+1，失1个电子，2个 $H$ 共失2个电子）

> **双线桥法的特点**：
> - 能清晰显示**谁被氧化、谁被还原**
> - 每条线上标明**得失电子的具体数目**
> - 适用于分析**单个元素**的氧化还原过程

#### 2. 单线桥法

**特征**：只用一条线，从还原剂（失电子方）指向氧化剂（得电子方），表示电子的转移方向和总数。

$$\overset{+2}{Cu}O + \overset{0}{H}_2 \xrightarrow{\Delta} \overset{0}{Cu} + H_2\overset{+1}{O}$$

单线桥表示：

$$\overset{2e^-}{H_2 \longrightarrow CuO}$$

即从 $H_2$ 指向 $CuO$，桥上标"$2e^-$"，表示 $H_2$ 将2个电子转移给 $CuO$。

> **单线桥法的特点**：
> - 只标**电子转移方向和总数**，不标"得/失""氧化/还原"
> - 箭头方向就是**电子转移方向**（从失电子方指向得电子方）
> - 简洁直观，适用于表示**电子转移的总数**
> - 不涉及 $H, O$ 等不变价元素

#### 3. 双线桥法与单线桥法的对比

| 比较项目 | 双线桥法 | 单线桥法 |
|---------|---------|---------|
| 线的数量 | 两条（分别表示氧化和还原） | 一条（表示电子转移） |
| 箭头方向 | 反应物 $\to$ 产物（各自变化） | 还原剂 $\to$ 氧化剂（电子转移方向） |
| 标注内容 | "得/失 $ne^-$"、"被氧化/被还原" | 只标转移电子总数 $ne^-$ |
| 优点 | 清晰显示各元素的氧化还原过程 | 简洁，直接显示电子转移总量 |
| 适用场景 | 初学分析、复杂反应逐个分析 | 快速判断电子转移数、配平方程式 |

### 【深度理解】三、氧化还原反应与四大基本反应的关系

#### 1. 交叉关系图

```
                    化学反应
                   /        \
              氧化还原反应   非氧化还原反应
             /     |    \
        置换反应  部分化合  部分分解
        （全部）  （部分）  （部分）
```

#### 2. 详细对应关系

| 反应类型 | 是否一定是氧化还原反应 | 分析 |
|---------|---------------------|------|
| **置换反应** | **一定是** | 单质（0价）→ 化合物（非0价），必有化合价变化 |
| **化合反应** | **不一定是** | 有单质参加的是（如 $2H_2 + O_2 = 2H_2O$）；没有单质参加的一般不是（如 $CaO + H_2O = Ca(OH)_2$） |
| **分解反应** | **不一定是** | 有单质生成的是（如 $2KClO_3 \xrightarrow{MnO_2} 2KCl + 3O_2 \uparrow$）；没有单质生成的一般不是（如 $CaCO_3 \xrightarrow{高温} CaO + CO_2 \uparrow$） |
| **复分解反应** | **一定不是** | 反应前后各元素化合价均不变，只是离子交换组合 |

#### 3. 重要结论

- **置换反应 $\subset$ 氧化还原反应**（所有置换反应都是氧化还原反应）
- **复分解反应 $\cap$ 氧化还原反应 $= \varnothing$**（二者没有交集）
- **化合反应和分解反应与氧化还原反应部分交叉**

**记忆口诀**："置全是，复全否，化合分解看单质"

### 【基础精讲】四、常见的氧化剂和还原剂

#### 1. 常见氧化剂（反应中化合价降低，得电子）

| 类别 | 典型物质 | 常见化合价变化 | 实例 |
|------|---------|-------------|------|
| 活泼非金属单质 | $O_2, O_3, Cl_2, Br_2, F_2$ | $O: 0 \to -2$；$Cl: 0 \to -1$ | $2Na + Cl_2 = 2NaCl$ |
| 高价金属离子 | $Fe^{3+}, Cu^{2+}, Ag^+$ | $Fe^{3+} \to Fe^{2+}$ 或 $Fe$；$Cu^{2+} \to Cu$ | $2Fe^{3+} + Fe = 3Fe^{2+}$ |
| 高价含氧化合物 | $KMnO_4, K_2Cr_2O_7, HNO_3$, 浓 $H_2SO_4$ | $Mn: +7 \to +2$；$Cr: +6 \to +3$ | 酸性 $KMnO_4$ 氧化 $Fe^{2+}$ |
| 过氧化物 | $H_2O_2, Na_2O_2$ | $O: -1 \to -2$ | $2H_2O_2 \xrightarrow{MnO_2} 2H_2O + O_2 \uparrow$ |

#### 2. 常见还原剂（反应中化合价升高，失电子）

| 类别 | 典型物质 | 常见化合价变化 | 实例 |
|------|---------|-------------|------|
| 活泼金属单质 | $Na, Mg, Al, Zn, Fe$ | $0 \to$ 正价 | $Zn + 2HCl = ZnCl_2 + H_2 \uparrow$ |
| 某些非金属单质 | $H_2, C, CO$ | $H: 0 \to +1$；$C: 0 \to +2/+4$ | $CuO + H_2 \xrightarrow{\Delta} Cu + H_2O$ |
| 低价金属离子 | $Fe^{2+}, Cu^+$ | $Fe^{2+} \to Fe^{3+}$；$Cu^+ \to Cu^{2+}$ | $2Fe^{2+} + Cl_2 = 2Fe^{3+} + 2Cl^-$ |
| 低价含氧化合物 | $SO_2, H_2SO_3, Na_2SO_3$ | $S: +4 \to +6$ | $SO_2 + Cl_2 + 2H_2O = H_2SO_4 + 2HCl$ |

### 【隐性考点】氧化还原反应中电子转移数目的计算

#### 计算方法：化合价变化法

**核心公式**：

$$\text{转移电子总数} = n(\text{变价原子}) \times |\Delta \text{化合价}| \times N_A$$

或简化为（计算物质的量时）：

$$n(e^-) = n(\text{变价原子}) \times |\Delta \text{化合价}|$$

#### 典型例题

**例1：$2Na + Cl_2 = 2NaCl$**

- 分析：每个 $Na$ 从0→+1，失1个电子；每个 $Cl$ 从0→-1，得1个电子
- 2 mol $Na$ 反应，转移电子 = $2 \times 1 = 2$ mol
- 或：1 mol $Cl_2$ 反应，转移电子 = $2 \times 1 = 2$ mol（1个 $Cl_2$ 分子含2个 $Cl$ 原子）

**例2：$2KMnO_4 + 16HCl = 2KCl + 2MnCl_2 + 5Cl_2 \uparrow + 8H_2O$**

- $Mn$：$+7 \to +2$，每个 $Mn$ 得5个电子
- 2 mol $KMnO_4$ 反应，$Mn$ 得电子 = $2 \times 5 = 10$ mol
- $Cl$：部分从 $-1 \to 0$（生成 $Cl_2$），生成5 mol $Cl_2$ 需要10 mol $Cl^-$ 失电子
- $Cl$ 失电子 = $10 \times 1 = 10$ mol
- **转移电子总数为10 mol**（得失电子守恒）

> **注意**：此反应中16 mol $HCl$ 只有10 mol $Cl^-$ 被氧化（生成 $Cl_2$），另外6 mol $Cl^-$ 没有变价（在 $KCl$ 和 $MnCl_2$ 中）。这是**部分氧化/还原**的典型例子。

**例3：$3Cu + 8HNO_3(\text{稀}) = 3Cu(NO_3)_2 + 2NO \uparrow + 4H_2O$**

- $Cu$：$0 \to +2$，3 mol $Cu$ 失电子 = $3 \times 2 = 6$ mol
- $N$：部分从 $+5 \to +2$（生成 $NO$），2 mol $NO$ 生成，得电子 = $2 \times 3 = 6$ mol
- 8 mol $HNO_3$ 中只有2 mol 被还原（生成 $NO$），另外6 mol $HNO_3$ 起酸的作用（提供 $NO_3^-$ 与 $Cu^{2+}$ 结合）
- **转移电子总数为6 mol**

> **关键理解**：在部分氧化还原反应中，**氧化剂（或还原剂）中只有一部分**实际参与了电子转移。计算时必须准确找出"变价的部分"。

### 【易错警示】氧化还原反应常见错误

#### 易错点1：氧化剂/还原剂的判断方向搞反

**错误认知**："化合价升高 → 氧化剂"

**正确理解**：
- 化合价**升高** → 失电子 → 被**氧化** → 本身是**还原剂**
- 化合价**降低** → 得电子 → 被**还原** → 本身是**氧化剂**

> **逻辑推导**：
> - 失去电子 → 化合价升高 → 被氧化 → 该物质是还原剂
> - 得到电子 → 化合价降低 → 被还原 → 该物质是氧化剂

#### 易错点2：歧化反应中的角色混淆

**歧化反应**：同种元素在同一反应中既升高又降低。

$$Cl_2 + 2NaOH = NaCl + NaClO + H_2O$$

分析：$Cl_2$ 中 $Cl$ 为0价
- 部分 $Cl \to NaCl$ 中 $Cl$（-1价）：化合价**降低**→ 得电子 → 被还原 → $Cl_2$ 作**氧化剂**
- 部分 $Cl \to NaClO$ 中 $Cl$（+1价）：化合价**升高**→ 失电子 → 被氧化 → $Cl_2$ 作**还原剂**

**结论**：$Cl_2$ 既是氧化剂，又是还原剂！

#### 易错点3：部分氧化/还原中转移电子数计算错误

如例3中 $Cu$ 与稀 $HNO_3$ 的反应，8 mol $HNO_3$ 只有2 mol 作氧化剂，不能直接用8 mol 计算！

#### 易错点4：认为氧化还原反应必须有氧参与

这是初中"得氧失氧"观念的残留。氧化还原反应的本质是电子转移，完全可以没有氧元素参与：

$$Fe + CuSO_4 = FeSO_4 + Cu \quad \text{（$Fe$ 失电子给 $Cu^{2+}$，典型的氧化还原反应，无氧参与）}$$

## 【思想方法】本章提炼的化学思维

### 一、分类思想

**分类**是将复杂事物系统化的基本方法。化学中面对数以万计的物质和反应，没有分类就无法学习。

**树状分类法**：强调层级和标准的一致性
- 例：化合物 $\to$ 无机化合物/有机化合物 $\to$ 无机化合物分为酸、碱、盐、氧化物

**交叉分类法**：强调多维度视角
- 例：碳酸钠既是钠盐，又是碳酸盐，还是正盐——三个维度同时适用

**分类的相对性**：分类标准不同，归属不同
- $Na_2CO_3$ 从阳离子角度是钠盐，从阴离子角度是碳酸盐
- 同一反应从不同角度可归入不同类型

### 二、守恒思想

守恒思想是化学计算和方程式书写的核心。

| 守恒类型 | 应用场景 | 示例 |
|---------|---------|------|
| **质量守恒** | 化学方程式配平 | 反应前后各元素原子数相等 |
| **电荷守恒** | 离子方程式检查、电化学 | 离子方程式左右电荷总数相等 |
| **电子守恒** | 氧化还原计算、原电池 | 氧化剂得电子数 = 还原剂失电子数 |
| **物料守恒** | 溶液中离子浓度关系（后续学习） | 某元素的各种存在形式总量不变 |

**守恒思想的本质**：化学反应是原子的重新组合，原子本身不会凭空产生或消失，电子也不会凭空产生或消失。守恒是自然界的基本规律。

### 三、宏微结合思想

化学研究的特点是"从宏观到微观，再从微观到宏观"：

```
宏观现象 ────→ 微观本质 ────→ 宏观应用
   │              │              │
   ↓              ↓              ↓
丁达尔效应    胶粒大小接近     鉴别胶体和溶液
              可见光波长
   │              │              │
导电性实验    自由移动的离子    判断电解质类型
              存在与否
   │              │              │
化合价变化    电子得失/偏移     氧化还原反应
              引起电荷变化       方程式的配平
```

> **学习要求**：看到宏观现象，要能联想到微观粒子层面的解释；掌握了微观规律，要能预测和解释宏观现象。

### 四、证据推理思想

化学是一门以实验为基础的学科。从实验现象出发，经过推理分析，得出化学结论，这就是证据推理。

**示例**：如何证明 $NaCl$ 在水中电离成了离子？
- 证据1：$NaCl$ 固体不导电，但 $NaCl$ 溶液导电 → 推理：溶液中产生了能自由移动的带电粒子
- 证据2：$NaCl$ 溶液的导电性随浓度增大而增强 → 推理：离子浓度越高，导电性越强
- 证据3：$NaCl$ 熔融状态也能导电 → 推理：导电的本质是 $Na^+$ 和 $Cl^-$ 的自由移动，而非水的作用

## 【隐性考点】高考常考但教材轻描淡写的细节

### 隐性考点1：电解质强弱与溶解性无关

| 常见误区 | 正确理解 | 典型反例 |
|---------|---------|---------|
| "难溶物是非电解质或弱电解质" | 电解质的强弱取决于**电离程度**，与溶解性无关 | $BaSO_4$：难溶，但溶于水的部分完全电离，是**强电解质** |
| "易溶物是强电解质" | 溶解性和电离程度是两个独立的概念 | $CH_3COOH$：易溶，但仅部分电离，是**弱电解质** |

**判断强电解质的依据**：
1. 强酸（$HCl, H_2SO_4, HNO_3, HBr, HI, HClO_4$ 等）
2. 强碱（$NaOH, KOH, Ba(OH)_2, Ca(OH)_2$ 等）
3. **绝大多数盐**（包括难溶盐如 $AgCl, BaSO_4, CaCO_3$）

> **记忆口诀**：强酸强碱和大多数盐，溶不溶都可能强。

### 隐性考点2：$CO_2, SO_2, NH_3$ 等物质属于非电解质

| 物质 | 水溶液能否导电 | 本身是否为电解质 | 原因 |
|------|--------------|----------------|------|
| $CO_2$ | 能（生成碳酸） | **非电解质** | 导电的是 $H_2CO_3$，不是 $CO_2$ |
| $SO_2$ | 能（生成亚硫酸） | **非电解质** | 导电的是 $H_2SO_3$，不是 $SO_2$ |
| $NH_3$ | 能（生成氨水） | **非电解质** | 导电的是 $NH_3 \cdot H_2O$，不是 $NH_3$ |

> **判断方法**：把该物质溶于水，看是它本身电离出离子，还是它与水反应的产物电离出离子。如果是后者，该物质就是非电解质。

### 隐性考点3：酸式盐在离子方程式中的处理

| 酸式盐 | 水溶液中 | 熔融状态 |
|--------|---------|---------|
| $NaHSO_4$ | 拆为 $Na^+ + H^+ + SO_4^{2-}$ | 电离为 $Na^+ + HSO_4^-$（$HSO_4^-$ 不拆） |
| $NaHCO_3$ | 拆为 $Na^+ + HCO_3^-$（$HCO_3^-$ 不拆） | $Na^+ + HCO_3^-$ |

> **区分关键**：$H_2SO_4$ 是二元强酸，其酸式酸根 $HSO_4^-$ 在水中几乎完全电离；$H_2CO_3$ 是二元弱酸，其酸式酸根 $HCO_3^-$ 在水中仅部分电离。

### 隐性考点4：氧化还原反应中的电子转移计算——"部分参与"问题

在某些反应中，氧化剂（或还原剂）并非全部被还原（或被氧化），只有一部分参与了氧化还原过程。

**例：$MnO_2 + 4HCl(\text{浓}) \xrightarrow{\Delta} MnCl_2 + Cl_2 \uparrow + 2H_2O$**

- $Mn$：$+4 \to +2$，得2个电子
- $Cl$：4 mol $HCl$ 中只有2 mol $Cl^-$ 被氧化为 $Cl_2$（失2个电子）
- 另外2 mol $Cl^-$ 没有变价，存在于 $MnCl_2$ 中
- **转移电子 = 2 mol**（不是4 mol！）
- 浓盐酸既表现**还原性**（提供被氧化的 $Cl^-$），又表现**酸性**（提供 $Cl^-$ 与 $Mn^{2+}$ 结合成盐）

### 隐性考点5：$Na_2O_2$ 与 $H_2O$、$CO_2$ 反应——歧化反应

$$2Na_2O_2 + 2H_2O = 4NaOH + O_2 \uparrow$$

- $Na_2O_2$ 中 $O$ 为 -1 价
- 部分 $O \to O_2$ 中 $O$（0价）：化合价升高 → 被氧化
- 部分 $O \to NaOH$ 中 $O$（-2价）：化合价降低 → 被还原
- $Na_2O_2$ **既是氧化剂，又是还原剂**
- 每2 mol $Na_2O_2$ 反应，转移电子 = **2 mol**（不是4 mol！）

> **计算方法**：2 mol $Na_2O_2$ 含4 mol -1价 $O$，其中2 mol 变为0价（生成1 mol $O_2$），失2 mol 电子；另外2 mol 变为-2价，得2 mol 电子。转移电子总数为2 mol。

## 【易错警示】全章易错点汇总

### 易错点1：单质和混合物既不是电解质也不是非电解质

**常见错误**："铁能导电，所以铁是电解质"或"食盐溶液能导电，所以食盐溶液是电解质"

**正确理解**：
- 电解质和非电解质都必须是**化合物**
- 单质（如 $Fe, Cu, Cl_2$）不属于电解质/非电解质的范畴
- 混合物（如食盐水、盐酸）也不属于电解质/非电解质的范畴
- 应该说"$NaCl$ 是电解质"，而不是"食盐水是电解质"

### 易错点2：离子方程式中电荷不守恒

**错例**：$Fe + Fe^{3+} = 2Fe^{2+}$

分析：左边电荷 = $0 + (+3) = +3$；右边电荷 = $2 \times (+2) = +4$。电荷不守恒！

**正解**：$Fe + 2Fe^{3+} = 3Fe^{2+}$

左边电荷 = $0 + 2 \times (+3) = +6$；右边电荷 = $3 \times (+2) = +6$。电荷守恒

### 易错点3：把"被氧化"和"氧化剂"搞混

| 错误说法 | 正确说法 |
|---------|---------|
| "$H_2$ 在反应中被还原" | "$H_2$ 在反应中被**氧化**"（化合价0→+1，失电子） |
| "$CuO$ 是还原剂" | "$CuO$ 是**氧化剂**"（$Cu$ 化合价+2→0，得电子） |
| "还原剂具有氧化性" | "还原剂具有**还原性**"（还原剂失电子的能力） |
| "氧化产物是氧化剂得到的" | "氧化产物是**还原剂**被氧化后得到的" |

### 易错点4：误认为氧化还原反应一定有氧元素参与

这是初中"得氧失氧"概念的残留影响。氧化还原反应的本质是**电子转移**，完全可以没有氧元素参与：

$$Zn + 2HCl = ZnCl_2 + H_2 \uparrow \quad \text{（典型的氧化还原反应，无氧元素）}$$

$$Cl_2 + 2NaBr = 2NaCl + Br_2 \quad \text{（典型的氧化还原反应，无氧元素）}$$

### 易错点5：$NaHSO_4$ 与 $NaHCO_3$ 在离子方程式中混淆

| 物质 | 离子方程式写法 | 与 $NaOH$ 反应的离子方程式 |
|------|--------------|----------------------|
| $NaHSO_4$ | $Na^+ + H^+ + SO_4^{2-}$ | $H^+ + OH^- = H_2O$ |
| $NaHCO_3$ | $Na^+ + HCO_3^-$ | $HCO_3^- + OH^- = CO_3^{2-} + H_2O$ |

### 易错点6：计算电子转移数时漏乘系数

**错例**：$2Na + Cl_2 = 2NaCl$ 中，认为1 mol $Cl_2$ 反应转移1 mol 电子。

**正解**：每个 $Cl$ 原子从0→-1，得1个电子；1 mol $Cl_2$ 含2 mol $Cl$ 原子，共转移 **2 mol** 电子。

## 【实验思想】本章实验方法总结

### 实验1：$Fe(OH)_3$ 胶体的制备与性质

| 项目 | 内容 |
|------|------|
| **实验原理** | $FeCl_3 + 3H_2O \xrightarrow{\Delta} Fe(OH)_3(\text{胶体}) + 3HCl$ |
| **操作要点** | 沸水 + 逐滴加饱和 $FeCl_3$（5-6滴）+ 加热至红褐色 + 停止加热 |
| **成功标志** | 液体呈透明的红褐色，无浑浊 |
| **丁达尔效应** | 用激光笔照射，侧面可见光亮通路 |
| **注意事项** | ①用蒸馏水；②$FeCl_3$ 不能过量；③不可过度加热；④不可搅拌；⑤注明"胶体"不写"$\downarrow$" |
| **失败原因** | $FeCl_3$ 过量→聚沉；自来水含电解质→聚沉；搅拌→破坏胶体结构 |

### 实验2：溶液导电性实验

| 项目 | 内容 |
|------|------|
| **实验目的** | 探究不同物质水溶液的导电性差异 |
| **实验现象** | 盐酸、$NaOH$ 溶液、$NaCl$ 溶液 → 灯泡亮；醋酸溶液 → 灯泡暗；蔗糖溶液、乙醇溶液 → 灯泡不亮 |
| **微观解释** | 强电解质 → 大量自由离子 → 导电性强；弱电解质 → 少量自由离子 → 导电性弱；非电解质 → 无自由离子 → 不导电 |
| **注意** | 溶液导电性强弱与**离子浓度**和**离子所带电荷数**有关，不能直接等同于电解质的强弱 |

### 实验3：离子反应的实验探究

| 项目 | 内容 |
|------|------|
| **实验设计** | 利用指示剂（酚酞）观察中和反应的过程；利用沉淀的生成/溶解观察离子反应 |
| **核心方法** | 对比实验——对比同一反应以化学方程式和离子方程式表示时的差异 |
| **结论** | 离子反应的本质是某些离子浓度的减小（生成沉淀、气体或弱电解质） |

## 本章核心公式/规律速记

1. **电解质判断**：化合物 + 水溶液中或熔融状态下能导电
2. **强电解质**：强酸、强碱、绝大多数盐（完全电离，用"$=$"）
3. **弱电解质**：弱酸、弱碱、水（部分电离，用"$\rightleftharpoons$"）
4. **离子方程式四步法**：写 $\to$ 拆 $\to$ 删 $\to$ 查
5. **拆与不拆**：强酸强碱可溶性盐拆；单质氧化物气体沉淀弱电解质不拆
6. **氧化还原判断口诀**：升失氧还，降得还氧
7. **双线桥vs单线桥**：双线桥（反应物$\to$产物，标得失）；单线桥（还原剂$\to$氧化剂，标总数）
8. **四大反应与氧化还原**：置全是，复全否，化合分解看单质
9. **电子转移计算**：$n(e^-) = n(\text{变价原子}) \times |\Delta \text{化合价}|$
10. **部分氧化还原注意**：找准实际变价的原子数，不能直接用化学计量数
