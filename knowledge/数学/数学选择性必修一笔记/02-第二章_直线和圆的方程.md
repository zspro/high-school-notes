# 第二章 直线和圆的方程

---

## 2.1 直线的倾斜角与斜率

### 【来龙去脉】

解析几何的诞生是数学史上最具革命性的转折之一。1637年，笛卡尔（René Descartes）在其著作《方法论》的附录《几何学》中首次系统地阐述了用代数方法研究几何问题的思想。几乎同一时期，费马（Pierre de Fermat）也独立发展了类似的坐标方法。这一思想的核心在于：**建立平面上的点与有序实数对之间的一一对应**，从而将几何图形的性质转化为代数方程的性质来研究。

在笛卡尔之前，几何与代数是两个相对独立的数学分支。古希腊的欧几里得几何以公理化方法研究图形的形状、大小和位置关系，而代数则主要处理数与方程的问题。解析几何的建立彻底打破了这一壁垒，使得几何问题可以通过计算来解决，代数方程可以获得几何解释。

直线的倾斜角与斜率是解析几何中最基础的概念。为什么要引入倾斜角？因为在平面直角坐标系中，直线相对于$x$轴的"倾斜程度"是一个基本的几何特征，需要用数量来刻画。而斜率正是这一几何特征的代数化表达，它建立了直线的方向信息与代数运算之间的桥梁。

倾斜角的定义具有明确的几何直观：取$x$轴正向与直线向上方向之间的夹角。这一定义要求角度范围在$[0, \pi)$内，保证了每条直线有唯一的倾斜角。斜率的定义$k = \tan\alpha$则将这一角度信息转化为可计算的实数，使得直线的方向可以被精确量化。

### 【基础精讲】

**定义2.1.1（直线的倾斜角）**

在平面直角坐标系中，对于一条与$x$轴相交的直线$l$，把$x$轴正向绕交点按逆时针方向旋转到与直线$l$首次重合时所转过的最小正角，称为直线$l$的倾斜角（angle of inclination）。

当直线$l$与$x$轴平行或重合时，规定其倾斜角为$0$。

倾斜角的取值范围为$[0, \pi)$。

**定义2.1.2（直线的斜率）**

设直线$l$的倾斜角为$\alpha$，当$\alpha \neq \frac{\pi}{2}$时，称$k = \tan\alpha$为直线$l$的斜率（slope）。

当$\alpha = \frac{\pi}{2}$时，即直线垂直于$x$轴时，直线的斜率不存在。

**定理2.1.1（斜率公式）**

已知直线$l$经过两点$P_1(x_1, y_1)$和$P_2(x_2, y_2)$，且$x_1 \neq x_2$，则直线$l$的斜率为：

$$k = \frac{y_2 - y_1}{x_2 - x_1}$$

**证明**：设直线$l$的倾斜角为$\alpha$。过$P_1$作$x$轴的平行线，过$P_2$作$y$轴的平行线，两线交于点$Q$，则$Q$的坐标为$(x_2, y_1)$。

在直角三角形$P_1QP_2$中：
- 当$\alpha$为锐角时，$\tan\alpha = \frac{|QP_2|}{|P_1Q|} = \frac{y_2 - y_1}{x_2 - x_1}$
- 当$\alpha$为钝角时，$\tan\alpha = -\tan(\pi - \alpha) = -\frac{|QP_2|}{|P_1Q|} = -\frac{y_2 - y_1}{x_1 - x_2} = \frac{y_2 - y_1}{x_2 - x_1}$

综上，$k = \tan\alpha = \frac{y_2 - y_1}{x_2 - x_1}$。$\square$

### 【深度理解】

**1. 倾斜角范围的严格性**

倾斜角的取值范围规定为$[0, \pi)$而非其他区间，是基于以下考量：

首先，直线的方向是双向的，即直线$l$没有"起点"和"终点"的区分。如果倾斜角范围取$[0, 2\pi)$，那么同一直线上的两个相反方向将对应不同的角度，这与直线作为整体几何对象的本质不符。

其次，取$x$轴"正向"与直线"向上方向"之间的夹角，这一约定使得每条直线对应唯一的倾斜角，建立了直线方向到角度集合$[0, \pi)$的一一对应。

**2. 斜率不存在的本质原因**

当$\alpha = \frac{\pi}{2}$时，$\tan\alpha$无定义，因此垂直于$x$轴的直线不存在斜率。这一现象的深层原因在于：

从几何上看，垂直于$x$轴的直线（即$x = a$形式的直线）与$x$轴正方向的夹角为$90°$，此时直线的"倾斜程度"无法用有限实数来度量——无论$y$坐标如何变化，$x$坐标始终保持不变，比值$\frac{\Delta y}{\Delta x}$趋于无穷。

从代数上看，斜率公式$k = \frac{y_2 - y_1}{x_2 - x_1}$在$x_1 = x_2$时分母为零，表达式无意义。这对应于$x = a$形式的直线不能用$y = kx + b$的形式表示。

**3. 斜率的几何意义**

斜率$k = \tan\alpha$的绝对值$|k|$反映了直线的"陡峭程度"：$|k|$越大，直线越"陡"；$|k|$越小，直线越"平"。当$k = 0$时，直线水平；当$k > 0$时，直线"上升"（$y$随$x$增大而增大）；当$k < 0$时，直线"下降"。

### 【知识串联】

- **与一次函数的关联**：一次函数$y = kx + b$（$k \neq 0$）的图象是一条斜率为$k$、在$y$轴上截距为$b$的直线。注意：一次函数要求$k \neq 0$，而直线的斜截式方程允许$k = 0$，这是两者的区别。
- **与空间解析几何的过渡**：在平面上用$(x, y)$确定点的位置，推广到空间中则用$(x, y, z)$。平面上直线的斜率概念在空间中将推广为方向向量。
- **与导数概念的衔接**：斜率$k = \frac{\Delta y}{\Delta x}$是平均变化率的几何表示，当$\Delta x \to 0$时即得到导数，即切线的斜率。

### 【隐性考点】

**1. 三点共线的斜率判定**

若$A$、$B$、$C$三点共线，则$k_{AB} = k_{AC}$（前提是斜率均存在）。这一结论常用于解析几何中验证点的共线性，也是某些高考题的核心突破口。

**2. 斜率的范围问题**

已知点$P(x, y)$在某曲线上运动，求$\frac{y - y_0}{x - x_0}$的范围。这类问题的几何意义是：连接定点$(x_0, y_0)$与曲线上动点$(x, y)$的直线的斜率范围。

**3. 倾斜角与斜率的单调性关系**

在$\alpha \in [0, \frac{\pi}{2})$上，$k = \tan\alpha$单调递增；在$\alpha \in (\frac{\pi}{2}, \pi)$上，$k = \tan\alpha$也单调递增。但整个区间$[0, \pi)$上不是单调的，在$\alpha = \frac{\pi}{2}$处发生间断（从$+\infty$跳变到$-\infty$）。

### 【易错警示】

**易错点1：忽略斜率不存在的情况**

在使用斜率解决问题时，必须先判断斜率是否存在。对于涉及直线$l$过定点$P$且与某图形有交点的问题，若直接用点斜式设$y - y_0 = k(x - x_0)$，则遗漏了斜率不存在（即$x = x_0$）的情况。

**纠正策略**：凡是涉及斜率的问题，先考虑斜率不存在的情形是否满足条件，再设斜率存在时进行求解。

**易错点2：倾斜角与斜率的符号混淆**

当$\alpha \in (\frac{\pi}{2}, \pi)$时，$k = \tan\alpha < 0$。学生常误认为倾斜角为钝角时斜率为正。

**纠正**：$\tan\alpha$在第二象限为负值，这是三角函数的基本性质。

### 【思想方法】

**坐标法思想**

倾斜角与斜率的定义本身就是坐标法思想的体现：将直线的几何特征（倾斜程度）转化为代数运算（正切函数值），使得直线的方向可以被精确计算和比较。这是整个解析几何的方法论基础。

## 2.2 直线的方程

### 【来龙去脉】

直线是平面几何中最简单的曲线（实际上不是"曲"的，而是一维的）。在建立了平面直角坐标系之后，自然的问题就是：如何用代数方程来描述一条直线？

从不同的几何条件出发，可以得到不同形式的直线方程。这些形式看似不同，但本质上都描述了同一个几何对象——直线。不同形式各有其适用的场景：已知点和斜率时用点斜式最为方便；涉及$y$轴截距时用斜截式更为直观；涉及坐标轴截距时用截距式更为简洁。

直线的方程最终可以统一为一般式$Ax + By + C = 0$，这体现了代数形式的统一性。而一般式中系数$A$、$B$、$C$的几何意义（如方向向量、法向量等）则揭示了代数形式背后的几何本质。

### 【基础精讲】

#### 2.2.1 点斜式

**定理2.2.1（点斜式方程）**

过点$P_0(x_0, y_0)$且斜率为$k$的直线$l$的方程为：

$$y - y_0 = k(x - x_0)$$

**推导**：设$P(x, y)$是直线$l$上异于$P_0$的任意一点，由斜率公式：

$$k = \frac{y - y_0}{x - x_0}$$

两边同乘$(x - x_0)$即得$y - y_0 = k(x - x_0)$。

$P_0(x_0, y_0)$显然也满足该方程。$\square$

**适用范围**：斜率存在的直线。斜率不存在的直线（垂直于$x$轴的直线）不能用点斜式表示。

#### 2.2.2 斜截式

**定义2.2.1（直线的纵截距）**

直线$l$与$y$轴的交点的纵坐标称为直线$l$在$y$轴上的截距，简称纵截距，通常记为$b$。

**定理2.2.2（斜截式方程）**

斜率为$k$且在$y$轴上的截距为$b$的直线的方程为：

$$y = kx + b$$

**推导**：直线过点$(0, b)$且斜率为$k$，代入点斜式：

$$y - b = k(x - 0) \Rightarrow y = kx + b \quad \square$$

**适用范围**：斜率存在的直线。

#### 2.2.3 两点式

**定理2.2.3（两点式方程）**

过两点$P_1(x_1, y_1)$和$P_2(x_2, y_2)$（其中$x_1 \neq x_2$且$y_1 \neq y_2$）的直线的方程为：

$$\frac{y - y_1}{y_2 - y_1} = \frac{x - x_1}{x_2 - x_1}$$

**推导**：由斜率公式，$k = \frac{y_2 - y_1}{x_2 - x_1}$。代入点斜式（以$P_1$为定点）：

$$y - y_1 = \frac{y_2 - y_1}{x_2 - x_1}(x - x_1)$$

两边同除以$(y_2 - y_1)$即得。$\square$

**适用范围**：不与坐标轴平行的直线（即$x_1 \neq x_2$且$y_1 \neq y_2$）。

#### 2.2.4 截距式

**定义2.2.2（直线的横截距）**

直线$l$与$x$轴的交点的横坐标称为直线$l$在$x$轴上的截距，简称横截距，通常记为$a$。

**定理2.2.4（截距式方程）**

在$x$轴上的截距为$a$、在$y$轴上的截距为$b$（$a \neq 0$且$b \neq 0$）的直线的方程为：

$$\frac{x}{a} + \frac{y}{b} = 1$$

**推导**：直线过点$(a, 0)$和$(0, b)$，由两点式：

$$\frac{y - 0}{b - 0} = \frac{x - a}{0 - a}$$

即$\frac{y}{b} = -\frac{x - a}{a} = -\frac{x}{a} + 1$，整理得$\frac{x}{a} + \frac{y}{b} = 1$。$\square$

**适用范围**：不过原点且不与坐标轴平行的直线（即$a \neq 0$且$b \neq 0$且$a$、$b$均存在）。

#### 2.2.5 一般式

**定理2.2.5（一般式方程）**

平面直角坐标系中，任何直线都可以表示为关于$x$、$y$的二元一次方程：

$$Ax + By + C = 0$$

其中$A$、$B$不同时为零。反之，任何二元一次方程都表示一条直线。

**证明**：

（必要性）设直线$l$为平面上任意直线。
- 若$l$垂直于$x$轴，方程为$x = a$，即$x - a = 0$，此为$A = 1, B = 0, C = -a$的一般式。
- 若$l$不垂直于$x$轴，则存在斜率$k$和截距$b$，方程为$y = kx + b$，即$kx - y + b = 0$，此为$A = k, B = -1, C = b$的一般式。

（充分性）设$Ax + By + C = 0$且$A$、$B$不同时为零。
- 若$B = 0$，则$A \neq 0$，方程化为$x = -\frac{C}{A}$，表示垂直于$x$轴的直线。
- 若$B \neq 0$，方程化为$y = -\frac{A}{B}x - \frac{C}{B}$，即斜率为$-\frac{A}{B}$、截距为$-\frac{C}{B}$的直线。$\square$

**一般式的几何意义**：
- 当$B \neq 0$时，斜率$k = -\frac{A}{B}$
- 向量$(A, B)$是直线的法向量（垂直于直线的向量）
- 当$B = 0$时，直线垂直于$x$轴

### 【深度理解】

**1. 直线方程的本质**

直线方程的本质是：**直线上所有点的坐标$(x, y)$所满足的充要条件**。即：

$$P(x, y) \in l \Leftrightarrow Ax + By + C = 0$$

这意味着方程$Ax + By + C = 0$的解集与直线$l$上的点集之间存在一一对应关系。

**2. 五种方程形式的统一性**

五种形式看似不同，但本质等价：

| 方程形式 | 所需条件 | 适用范围 | 核心参数 |
|:---:|:---:|:---:|:---:|
| 点斜式 | 一点$(x_0, y_0)$+斜率$k$ | $k$存在 | 方向+位置 |
| 斜截式 | 斜率$k$+纵截距$b$ | $k$存在 | 方向+$y$轴交点 |
| 两点式 | 两点$P_1, P_2$ | 不平行坐标轴 | 两点确定直线 |
| 截距式 | 横截距$a$+纵截距$b$ | $a \neq 0, b \neq 0$ | 两轴交点 |
| 一般式 | 系数$A, B, C$ | 所有直线 | 代数标准形 |

一般式是最具一般性的形式，因为任何直线都可以表示为一般式，且二元一次方程的代数性质研究最为成熟。

**3. 法向量的几何意义**

对于直线$Ax + By + C = 0$，向量$\vec{n} = (A, B)$是该直线的法向量。这是因为：若$P_1(x_1, y_1)$和$P_2(x_2, y_2)$在直线上，则$Ax_1 + By_1 + C = 0$且$Ax_2 + By_2 + C = 0$，两式相减得$A(x_2 - x_1) + B(y_2 - y_1) = 0$，即$\vec{n} \cdot \overrightarrow{P_1P_2} = 0$，故$\vec{n} \perp \overrightarrow{P_1P_2}$。

法向量的概念将在距离公式和位置关系中发挥核心作用。

### 【知识串联】

- **与向量知识的联系**：直线的方向向量为$(1, k)$或$(B, -A)$，法向量为$(A, B)$。方向向量与斜率一一对应：$k = \frac{B_1}{A_1}$（方向向量为$(A_1, B_1)$）。
- **与集合语言的联系**：直线可以表示为满足特定条件的点的集合：$l = \{(x, y) \in \mathbb{R}^2 \mid Ax + By + C = 0\}$。
- **与不等式的联系**：不等式$Ax + By + C > 0$表示直线某一侧的半平面，这是线性规划的基础。

### 【隐性考点】

**1. 过定点直线系**

方程$y - y_0 = k(x - x_0)$（$k \in \mathbb{R}$）表示过定点$(x_0, y_0)$的所有直线（斜率不存在者除外）。

更一般地，若直线方程含参数$\lambda$，可改写为$f(x, y) + \lambda g(x, y) = 0$的形式，则该直线系过$f(x, y) = 0$与$g(x, y) = 0$的交点。

**2. 平行直线系与垂直直线系**

与$Ax + By + C = 0$平行的直线可设为$Ax + By + C' = 0$（$C' \neq C$）；
与$Ax + By + C = 0$垂直的直线可设为$Bx - Ay + C' = 0$。

**3. 含参直线过定点问题**

对于含参数的直线方程，如$(2 + \lambda)x + (1 - \lambda)y + 3 = 0$，求其过定点的方法：按参数$\lambda$整理，令各项系数为零，解方程组。

### 【易错警示】

**易错点1：截距与距离的混淆**

截距是坐标值（可正可负可为零），不是距离。例如直线$y = 2x - 3$在$y$轴上的截距为$-3$，不是$3$。

**易错点2：忽略截距为零时不能用截距式**

当直线过原点时，横截距和纵截距均为$0$，此时不能用截距式$\frac{x}{a} + \frac{y}{b} = 1$表示。应使用$y = kx$或一般式。

**易错点3：混淆截距式的前提条件**

截距式要求$a \neq 0$且$b \neq 0$，即直线不能过原点，也不能平行于任一坐标轴。使用截距式时必须先验证这些条件。

### 【思想方法】

**参数思想**

直线方程的不同形式引入了不同的参数（$k$、$b$、$a$等），选择合适的参数可以简化问题。例如，已知直线过定点时，以斜率$k$为参数最为方便；涉及坐标轴截距的问题，以$a$、$b$为参数更为直观。

参数思想的本质是：用尽可能少的独立变量来描述几何对象，通过参数的取值范围控制几何对象的全体。

## 2.3 直线的交点坐标与距离公式

### 【来龙去脉】

在解析几何的框架下，两条直线的位置关系（相交、平行、重合）完全可以通过其方程的代数性质来判断。这一转化的核心思想是：**两条直线的交点坐标同时满足两个直线方程**，因此交点问题就是方程组的求解问题。

距离是几何学的基本概念之一。在坐标系中，两点之间的距离可以通过勾股定理导出。点到直线的距离则是更为复杂但也更为重要的概念，它在判断直线与圆的位置关系、求圆的切线等问题中具有核心作用。

### 【基础精讲】

#### 2.3.1 两条直线的交点

**定理2.3.1（两直线交点）**

设两条直线$l_1: A_1x + B_1y + C_1 = 0$和$l_2: A_2x + B_2y + C_2 = 0$，则它们的交点坐标是方程组

$$\begin{cases} A_1x + B_1y + C_1 = 0 \\ A_2x + B_2y + C_2 = 0 \end{cases}$$

的解。

**定理2.3.2（两直线位置关系的判定）**

设$l_1: A_1x + B_1y + C_1 = 0$，$l_2: A_2x + B_2y + C_2 = 0$，记$D = A_1B_2 - A_2B_1$，则：

| 条件 | 位置关系 |
|:---:|:---:|
| $D \neq 0$ | 相交（有唯一交点） |
| $D = 0$且$A_1C_2 \neq A_2C_1$ | 平行（无交点） |
| $D = 0$且$A_1C_2 = A_2C_1$ | 重合（无数交点） |

**证明**：方程组有唯一解$\Leftrightarrow D = A_1B_2 - A_2B_1 \neq 0$（由克莱姆法则）。

当$D = 0$时，$A_1B_2 = A_2B_1$，即$\frac{A_1}{A_2} = \frac{B_1}{B_2}$（比例存在时），两直线法向量平行，故直线平行或重合。再比较$C$的关系即可判断。$\square$

#### 2.3.2 两点间距离公式

**定理2.3.3（两点间距离公式）**

平面上两点$P_1(x_1, y_1)$和$P_2(x_2, y_2)$之间的距离为：

$$|P_1P_2| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

**推导**：由勾股定理，$|P_1P_2|^2 = |x_2 - x_1|^2 + |y_2 - y_1|^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2$。$\square$

#### 2.3.3 点到直线的距离公式

**定理2.3.4（点到直线的距离公式）**

点$P(x_0, y_0)$到直线$l: Ax + By + C = 0$的距离为：

$$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$

**证明**（向量法）：设$Q(x_1, y_1)$是直线$l$上任意一点，则$Ax_1 + By_1 + C = 0$，即$C = -Ax_1 - By_1$。

向量$\overrightarrow{QP} = (x_0 - x_1, y_0 - y_1)$，直线$l$的法向量$\vec{n} = (A, B)$。

点$P$到直线$l$的距离等于$\overrightarrow{QP}$在$\vec{n}$方向上的投影的绝对值：

$$d = \frac{|\overrightarrow{QP} \cdot \vec{n}|}{|\vec{n}|} = \frac{|A(x_0 - x_1) + B(y_0 - y_1)|}{\sqrt{A^2 + B^2}}$$

$$= \frac{|Ax_0 + By_0 - (Ax_1 + By_1)|}{\sqrt{A^2 + B^2}} = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}} \quad \square$$

#### 2.3.4 两条平行直线间的距离

**定理2.3.5（平行直线间距离公式）**

两条平行直线$l_1: Ax + By + C_1 = 0$和$l_2: Ax + By + C_2 = 0$（$C_1 \neq C_2$）之间的距离为：

$$d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$$

**推导**：在$l_1$上任取一点，如令$x = 0$，得$y = -\frac{C_1}{B}$（设$B \neq 0$），即点$P(0, -\frac{C_1}{B})$。由点到直线距离公式：

$$d = \frac{|A \cdot 0 + B \cdot (-\frac{C_1}{B}) + C_2|}{\sqrt{A^2 + B^2}} = \frac{|-C_1 + C_2|}{\sqrt{A^2 + B^2}} = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}} \quad \square$$

### 【深度理解】

**1. 点到直线距离公式的几何本质**

点到直线的距离公式$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$中：
- 分子$|Ax_0 + By_0 + C|$反映的是点$P$相对于直线的"有向距离"（不考虑单位化）
- 分母$\sqrt{A^2 + B^2}$是法向量的模，起到归一化作用
- 整个公式可以理解为：将点$P$到直线上某定点的向量投影到法向量方向上的长度

**2. 距离公式的符号意义**

表达式$Ax_0 + By_0 + C$的符号具有几何意义：当$Ax_0 + By_0 + C > 0$时，点$P$在法向量$(A, B)$所指的一侧；当$Ax_0 + By_0 + C < 0$时，点$P$在法向量相反的一侧。这一性质在判断点与直线的位置关系以及线性规划中具有重要作用。

**3. 两平行直线距离公式的条件**

使用$d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$的前提是两条直线的$x$、$y$系数完全相同（即$A_1 = A_2 = A$且$B_1 = B_2 = B$）。如果仅平行但系数不成比例，必须先化为标准形式（使$A$、$B$相同）。

### 【知识串联】

- **与一次方程组的联系**：两直线交点问题本质上是二元一次方程组的求解问题，可以用行列式（克莱姆法则）来研究。
- **与线性代数的联系**：$D = A_1B_2 - A_2B_1$是两直线法向量构成的行列式，$D \neq 0$意味着法向量线性无关。
- **与圆锥曲线的联系**：点到直线的距离公式是后续研究圆锥曲线焦点、准线、离心率等概念的基础。

### 【隐性考点】

**1. 过两直线交点的直线系**

过$l_1: A_1x + B_1y + C_1 = 0$与$l_2: A_2x + B_2y + C_2 = 0$交点的直线系方程为：

$$A_1x + B_1y + C_1 + \lambda(A_2x + B_2y + C_2) = 0$$

（该直线系不包含$l_2$本身，若要包含$l_2$，需另外讨论$\lambda = \infty$的情形）

这一结论可避免求交点坐标，直接写出过交点的直线方程。

**2. 对称问题**

求点$P(x_0, y_0)$关于直线$l: Ax + By + C = 0$的对称点$P'(x', y')$的方法：
- $PP' \perp l$：$\frac{y' - y_0}{x' - x_0} \cdot (-\frac{A}{B}) = -1$（斜率之积为$-1$）
- $PP'$的中点在$l$上：$A \cdot \frac{x_0 + x'}{2} + B \cdot \frac{y_0 + y'}{2} + C = 0$

联立求解即得$P'$的坐标。

**3. 最值问题——距离之和最小**

在直线$l$上找一点$P$，使$|PA| + |PB|$最小的问题：
- 若$A$、$B$在$l$两侧，则$P$为$AB$与$l$的交点
- 若$A$、$B$在$l$同侧，则先求$A$关于$l$的对称点$A'$，$P$为$A'B$与$l$的交点

### 【易错警示】

**易错点1：使用平行线距离公式前未统一系数**

如求$l_1: 2x + 3y + 1 = 0$与$l_2: 4x + 6y - 5 = 0$的距离，不能直接用$\frac{|1 - (-5)|}{\sqrt{2^2 + 3^2}}$，而应先将$l_2$化为$2x + 3y - \frac{5}{2} = 0$，再计算$d = \frac{|1 - (-\frac{5}{2})|}{\sqrt{13}} = \frac{7}{2\sqrt{13}}$。

**易错点2：判断两直线垂直时遗漏斜率不存在的情况**

当一条直线斜率为$0$（水平），另一条斜率不存在（垂直）时，两直线也垂直。用斜率判断垂直（$k_1 \cdot k_2 = -1$）的前提是斜率均存在。更准确的方法是：$A_1A_2 + B_1B_2 = 0$。

**易错点3：距离公式中忘记绝对值**

点到直线距离是长度（非负），公式中有绝对值。忘记绝对值会导致符号错误。

### 【思想方法】

**数形结合**

直线的交点、距离等问题既是代数问题也是几何问题。在解析几何中，应养成"双向转化"的思维方式：看到代数方程就联想其几何图形，看到几何关系就尝试建立代数方程。数形结合的核心在于利用几何直观指导代数运算，利用代数运算精确描述几何关系。

## 2.4 圆的方程

### 【来龙去脉】

圆是平面几何中最基本的曲线之一，古希腊人将其视为"最完美的图形"。在解析几何的框架下，圆作为到定点距离等于定长的点的轨迹，其代数表达式具有特别简洁的形式。

从标准方程$(x - a)^2 + (y - b)^2 = r^2$到一般方程$x^2 + y^2 + Dx + Ey + F = 0$，圆的方程经历了从几何特征直接表达到代数标准形的过程。标准方程直接揭示了圆心$(a, b)$和半径$r$这两个决定圆的基本要素；一般方程则在代数处理上更为方便，尤其是在涉及方程组求解和判别式分析的问题中。

圆的方程的研究不仅具有自身的理论价值，更是后续研究椭圆、双曲线、抛物线等圆锥曲线的基础。圆可以看作椭圆的特殊情形（离心率为$0$），其方程形式和对称性质都是圆锥曲线的特例。

### 【基础精讲】

#### 2.4.1 圆的标准方程

**定义2.4.1（圆）**

平面上到定点$C$的距离等于定长$r$（$r > 0$）的点的轨迹称为圆。定点$C$称为圆心，定长$r$称为半径。

**定理2.4.1（圆的标准方程）**

圆心为$(a, b)$，半径为$r$（$r > 0$）的圆的方程为：

$$(x - a)^2 + (y - b)^2 = r^2$$

**推导**：设$P(x, y)$是圆上任意一点，由定义，$|PC| = r$，即$\sqrt{(x - a)^2 + (y - b)^2} = r$。两边平方即得标准方程。$\square$

**特别地**，圆心在原点$(0, 0)$、半径为$r$的圆的方程为：

$$x^2 + y^2 = r^2$$

#### 2.4.2 圆的一般方程

**定理2.4.2（圆的一般方程）**

方程$x^2 + y^2 + Dx + Ey + F = 0$（$D^2 + E^2 - 4F > 0$）表示圆，其圆心为$(-\frac{D}{2}, -\frac{E}{2})$，半径为$r = \frac{\sqrt{D^2 + E^2 - 4F}}{2}$。

**推导**：将一般方程配方：

$$x^2 + Dx + y^2 + Ey + F = 0$$

$$(x + \frac{D}{2})^2 - \frac{D^2}{4} + (y + \frac{E}{2})^2 - \frac{E^2}{4} + F = 0$$

$$(x + \frac{D}{2})^2 + (y + \frac{E}{2})^2 = \frac{D^2 + E^2 - 4F}{4}$$

当$D^2 + E^2 - 4F > 0$时，右端为正，方程表示圆心$(-\frac{D}{2}, -\frac{E}{2})$、半径$r = \frac{\sqrt{D^2 + E^2 - 4F}}{2}$的圆。

当$D^2 + E^2 - 4F = 0$时，方程表示一个点$(-\frac{D}{2}, -\frac{E}{2})$。

当$D^2 + E^2 - 4F < 0$时，方程无实数解，不表示任何图形。$\square$

**定义2.4.2（点圆与虚圆）**

当$D^2 + E^2 - 4F = 0$时，方程$x^2 + y^2 + Dx + Ey + F = 0$表示一个点，称为点圆。

当$D^2 + E^2 - 4F < 0$时，方程在实平面上无图形，称为虚圆。

#### 2.4.3 确定圆的方程的条件

**定理2.4.3（确定圆的条件）**

不共线的三点确定唯一的圆。

**推导**：设圆的方程为$x^2 + y^2 + Dx + Ey + F = 0$，将三点坐标代入，得到关于$D$、$E$、$F$的三元一次方程组。由于三点不共线，方程组有唯一解。$\square$

### 【深度理解】

**1. 圆的几何特征与代数表达**

圆的方程$(x - a)^2 + (y - b)^2 = r^2$的几何特征是：到定点$(a, b)$的距离恒为$r$。这一特征在代数上表现为：

- 方程关于$x$和$y$都是二次的，且$x^2$和$y^2$的系数相等（均为$1$）
- 不含$xy$交叉项（这是圆区别于一般二次曲线的重要标志）
- 一般方程中$x^2$和$y^2$系数相等且$xy$项系数为零，是方程表示圆的必要条件

**2. 判别式$\Delta = D^2 + E^2 - 4F$的几何意义**

判别式$\Delta = D^2 + E^2 - 4F$的几何意义是：它决定了圆心到原点的距离与半径之间的关系。更本质地，$\Delta > 0$保证了半径为正的实数，从而方程表示一个真实的圆。

从配方过程可以看出：$\Delta = 4r^2$，即$\Delta$与半径的平方成正比。

**3. 圆方程的参数个数**

圆的标准方程含有三个独立参数$(a, b, r)$，一般方程也含有三个独立参数$(D, E, F)$。这意味着确定一个圆需要三个独立条件，"不共线的三点确定一个圆"正是这一结论的几何表述。

### 【知识串联】

- **与二次函数的联系**：圆的上半部分$y = b + \sqrt{r^2 - (x - a)^2}$和下半部分$y = b - \sqrt{r^2 - (x - a)^2}$都是函数（单个$x$对应唯一的$y$），但整个圆的方程不是函数。
- **与三角函数的联系**：圆的参数方程为$x = a + r\cos\theta$，$y = b + r\sin\theta$，其中$\theta \in [0, 2\pi)$。这一表示将在后续学习参数方程时深入讨论。
- **与圆锥曲线的联系**：圆是离心率$e = 0$的圆锥曲线，也是椭圆在$a = b = r$时的特例。

### 【隐性考点】

**1. 圆系方程**

过两圆$C_1: x^2 + y^2 + D_1x + E_1y + F_1 = 0$与$C_2: x^2 + y^2 + D_2x + E_2y + F_2 = 0$交点的圆系方程为：

$$x^2 + y^2 + D_1x + E_1y + F_1 + \lambda(x^2 + y^2 + D_2x + E_2y + F_2) = 0$$

当$\lambda = -1$时，退化为两圆的公共弦所在直线方程。

**2. 阿波罗尼斯圆**

到两定点$A$、$B$的距离之比为常数$\lambda$（$\lambda > 0$且$\lambda \neq 1$）的点的轨迹是圆。设$A(-c, 0)$、$B(c, 0)$，则由$\frac{|PA|}{|PB|} = \lambda$可得：

$$(x + c)^2 + y^2 = \lambda^2[(x - c)^2 + y^2]$$

整理得圆的标准方程。这一结论在高考中时有出现。

**3. 圆的切线方程**

圆$x^2 + y^2 = r^2$上一点$P(x_0, y_0)$处的切线方程为$x_0x + y_0y = r^2$。

圆$(x - a)^2 + (y - b)^2 = r^2$上一点$P(x_0, y_0)$处的切线方程为$(x_0 - a)(x - a) + (y_0 - b)(y - b) = r^2$。

**推导**：切线垂直于半径$OP$，故切线的法向量为$(x_0 - a, y_0 - b)$，由点法式即得。

### 【易错警示】

**易错点1：忽略圆方程中$x^2$和$y^2$系数必须相等**

方程$2x^2 + y^2 + 3x - 4y + 1 = 0$不表示圆，因为$x^2$和$y^2$系数不等。必须先将$x^2$和$y^2$的系数化为$1$。

**易错点2：配方时符号错误**

将$x^2 + Dx$配方时，应为$(x + \frac{D}{2})^2 - \frac{D^2}{4}$。注意是"加$\frac{D}{2}$"而非"减$\frac{D}{2}$"，常因符号错误导致圆心坐标出错。

**易错点3：将方程表示的点圆误认为圆**

当$D^2 + E^2 - 4F = 0$时，方程只表示一个点，不是圆（半径为零）。在求满足某条件的圆的方程时，需检验判别式是否为正。

### 【思想方法】

**待定系数法**

确定圆的方程是待定系数法的典型应用。根据题设条件设出圆的方程（标准式或一般式），代入已知条件建立关于待定系数的方程组，求解即得。选择标准式还是一般式取决于已知条件的类型：已知圆心和半径时用标准式；已知圆上点时，用一般式更为方便（避免根号）。

## 2.5 直线与圆、圆与圆的位置关系

### 【来龙去脉】

直线与圆的位置关系是平面几何的经典问题。在欧氏几何中，这些关系通过公共点的个数来分类：相离（无公共点）、相切（一个公共点）、相交（两个公共点）。

解析几何将这些几何分类转化为代数判别：联立方程组，通过解的个数来判断位置关系。同时，几何量（如圆心到直线的距离与半径的比较）也提供了直观的判断方法。这两种方法的结合，使得位置关系问题既有几何直观又有代数精确。

### 【基础精讲】

#### 2.5.1 直线与圆的位置关系

设直线$l: Ax + By + C = 0$，圆$C: (x - a)^2 + (y - b)^2 = r^2$（$r > 0$），圆心到直线的距离为$d = \frac{|Aa + Bb + C|}{\sqrt{A^2 + B^2}}$。

**定理2.5.1（直线与圆位置关系的判定）**

| 条件 | 位置关系 | 公共点个数 |
|:---:|:---:|:---:|
| $d > r$ | 相离 | $0$ |
| $d = r$ | 相切 | $1$ |
| $d < r$ | 相交 | $2$ |

**证明**：圆心到直线的距离$d$是圆上点到直线距离的最小值（或最大值）。当$d > r$时，圆上所有点到直线的距离都大于零，无交点；当$d = r$时，圆心到直线的垂足恰在圆上，为一个交点；当$d < r$时，垂足在圆内，直线穿过圆，有两个交点。$\square$

**判别方法II（代数法）**：联立$\begin{cases} Ax + By + C = 0 \\ (x - a)^2 + (y - b)^2 = r^2 \end{cases}$，消元得到一元二次方程，由判别式$\Delta$判断：

| 条件 | 位置关系 |
|:---:|:---:|
| $\Delta < 0$ | 相离 |
| $\Delta = 0$ | 相切 |
| $\Delta > 0$ | 相交 |

#### 2.5.2 圆的切线

**定理2.5.2（过圆上一点的切线）**

圆$(x - a)^2 + (y - b)^2 = r^2$上一点$P(x_0, y_0)$处的切线方程为：

$$(x_0 - a)(x - a) + (y_0 - b)(y - b) = r^2$$

特别地，圆$x^2 + y^2 = r^2$上一点$P(x_0, y_0)$处的切线方程为$x_0x + y_0y = r^2$。

**证明**：半径$CP \perp$切线，$\overrightarrow{CP} = (x_0 - a, y_0 - b)$为切线的法向量。由点法式：

$$(x_0 - a)(x - x_0) + (y_0 - b)(y - y_0) = 0$$

展开并利用$(x_0 - a)^2 + (y_0 - b)^2 = r^2$整理即得。$\square$

**定理2.5.3（过圆外一点的切线）**

过圆外一点$P(x_0, y_0)$作圆的切线，可用以下方法：

方法一：设切线斜率为$k$，写出点斜式方程，利用圆心到切线距离等于半径列方程求$k$。

方法二：设切点为$(x_1, y_1)$，则$(x_1 - a)(x_0 - a) + (y_1 - b)(y_0 - b) = r^2$，且$(x_1 - a)^2 + (y_1 - b)^2 = r^2$，联立求解切点。

#### 2.5.3 圆的弦

**定理2.5.4（弦长公式）**

直线$l$与圆$C$相交于$A$、$B$两点，圆心到直线的距离为$d$，圆的半径为$r$，则弦长为：

$$|AB| = 2\sqrt{r^2 - d^2}$$

**推导**：设$M$为$AB$中点，则$CM \perp AB$，$|CM| = d$。在直角三角形$CMA$中，$|AM| = \sqrt{r^2 - d^2}$，故$|AB| = 2|AM| = 2\sqrt{r^2 - d^2}$。$\square$

#### 2.5.4 圆与圆的位置关系

设两圆圆心距为$d = |C_1C_2|$，半径分别为$R$和$r$（$R \geq r > 0$）。

**定理2.5.5（两圆位置关系的判定）**

| 条件 | 位置关系 | 公共点个数 |
|:---:|:---:|:---:|
| $d > R + r$ | 外离 | $0$ |
| $d = R + r$ | 外切 | $1$ |
| $R - r < d < R + r$ | 相交 | $2$ |
| $d = R - r$ | 内切 | $1$ |
| $0 \leq d < R - r$ | 内含 | $0$ |

### 【深度理解】

**1. 几何法与代数法的比较**

判断直线与圆位置关系有两种方法：

- **几何法**：比较$d$与$r$。优点是计算简便，几何意义明确；缺点是只适用于圆（对其他二次曲线没有直接对应）。
- **代数法**：联立方程看判别式。优点是适用范围广（可推广到任意二次曲线）；缺点是计算量大，对参数讨论复杂。

对于直线与圆的问题，**优先使用几何法**，这是圆的特有性质所决定的。

**2. 弦长公式的几何本质**

弦长公式$|AB| = 2\sqrt{r^2 - d^2}$来源于垂径定理的解析几何表达。其核心思想是：圆心到弦的垂线平分弦。这一几何性质使得弦长问题转化为简单的勾股定理计算。

由此公式还可以看出：当$d = 0$（直线过圆心）时，弦长最大为$2r$（直径）；当$d \to r$时，弦长趋于$0$。

**3. 两圆相交的公共弦**

两圆$C_1: x^2 + y^2 + D_1x + E_1y + F_1 = 0$和$C_2: x^2 + y^2 + D_2x + E_2y + F_2 = 0$相交时，公共弦所在直线的方程为两圆方程相减：

$$(D_1 - D_2)x + (E_1 - E_2)y + (F_1 - F_2) = 0$$

这是因为两圆交点的坐标同时满足两个圆的方程，故也满足两方程之差。

### 【知识串联】

- **与平面几何的联系**：垂径定理、切线性质、弦切角定理等平面几何结论在解析几何中都有对应的代数表达。
- **与导数的联系**：圆的切线斜率也可以用隐函数求导得到。对$x^2 + y^2 = r^2$两边关于$x$求导得$2x + 2yy' = 0$，即$y' = -\frac{x}{y}$，故点$(x_0, y_0)$处切线斜率为$-\frac{x_0}{y_0}$。
- **与物理学的联系**：光的反射定律（入射角等于反射角）可以用对称点的方法求解，圆的性质在光学中有广泛应用。

### 【隐性考点】

**1. 圆上的点到直线的距离的最值**

圆$C$上的点到直线$l$的距离的最大值为$d + r$，最小值为$|d - r|$（其中$d$为圆心到直线的距离）。

当直线与圆相离时，最小值为$d - r$；当直线与圆相交时，最小值为$0$。

**2. 圆的切线长公式**

从圆外一点$P(x_0, y_0)$到圆$(x - a)^2 + (y - b)^2 = r^2$的切线长为：

$$L = \sqrt{(x_0 - a)^2 + (y_0 - b)^2 - r^2}$$

这是由勾股定理直接得到的：$L^2 + r^2 = |PC|^2$。

**3. 相交圆的公共弦长**

两圆相交时，公共弦长可以通过以下步骤求解：
- 求出公共弦所在直线方程（两圆方程相减）
- 任选一圆心到该直线的距离$d$
- 用弦长公式$2\sqrt{r^2 - d^2}$计算

### 【易错警示】

**易错点1：过圆外一点求切线时遗漏斜率不存在的情况**

过圆外一点作圆的切线，设点斜式$y - y_0 = k(x - x_0)$求切线时，可能遗漏斜率不存在的切线（垂直于$x$轴的直线）。应检验$x = x_0$是否满足切线条件。

**易错点2：两圆位置关系中忽略$R \geq r$的约定**

在使用$d = R - r$判断内切时，必须确保$R \geq r$。若未约定大小，内切条件应写为$d = |R - r|$。

**易错点3：混淆"内含"与"内切"**

内含（$d < R - r$）与内切（$d = R - r$）的区别在于公共点个数：内含无公共点，内切有一个公共点。当$d = 0$且$R > r$时为同心圆，是内含的特例。

**易错点4：弦长公式中$d$的含义**

弦长公式中的$d$是**圆心到直线的距离**，不是弦到某点的距离。混淆这一概念会导致错误。

### 【思想方法】

**坐标法思想的综合运用**

直线与圆的位置关系问题是坐标法思想的综合运用。其核心流程是：

1. **建系**：建立适当的坐标系（通常利用已知对称性）
2. **设点**：用坐标$(x, y)$表示所求点
3. **列式**：根据几何条件建立方程或不等式
4. **求解**：用代数方法求解
5. **回译**：将代数结果翻译回几何结论

这一"几何—代数—几何"的循环是解析几何方法论的核心，也是处理更复杂曲线（椭圆、双曲线、抛物线）的基本范式。

## 本章小结与思想方法提炼

### 一、核心知识结构

本章围绕"直线和圆的方程"展开，构建了平面解析几何的基础框架：

```
坐标法
  |-- 直线的倾斜角与斜率（方向量化）
  |-- 直线的方程（几何→代数）
  |       |-- 点斜式、斜截式、两点式、截距式、一般式
  |-- 位置关系与度量（代数→几何）
  |       |-- 交点坐标、距离公式
  |-- 圆的方程（曲线代数化）
  |       |-- 标准方程、一般方程
  |-- 位置关系（综合应用）
          |-- 直线与圆、圆与圆
```

### 二、数学思想方法

**1. 坐标法（解析法）**

坐标法是整个解析几何的核心方法论。其基本思想是：通过建立坐标系，将几何问题转化为代数问题；利用代数运算求解后，再将结果翻译回几何结论。

坐标法的三个步骤：
- 建立适当的坐标系
- 用坐标表示几何对象，用方程表示几何关系
- 通过代数运算解决几何问题

**2. 数形结合**

数形结合不是简单的"看图说话"，而是指代数与几何之间的双向转化能力。一方面，几何直观可以指导代数运算的方向和策略；另一方面，代数运算的结果需要回到几何图形中验证和解释。

**3. 参数思想**

直线方程$y - y_0 = k(x - x_0)$中的$k$、圆的标准方程中的$(a, b, r)$都是参数。参数思想的核心是：用适当数量的独立参数描述几何对象的全体，通过参数的约束条件来刻画几何对象的特定性质。

**4. 待定系数法**

待定系数法是确定曲线方程的通用方法。其逻辑是：先设出含待定系数的方程形式，再根据已知条件建立方程组求解系数。这一方法从直线推广到圆，再推广到一般的二次曲线。

### 三、关键公式汇总

| 公式名称 | 表达式 | 适用条件 |
|:---:|:---:|:---:|
| 斜率公式 | $k = \frac{y_2 - y_1}{x_2 - x_1}$ | $x_1 \neq x_2$ |
| 两点距离 | $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ | 任意两点 |
| 点线距离 | $\frac{\|Ax_0 + By_0 + C\|}{\sqrt{A^2 + B^2}}$ | 任意点与直线 |
| 平行线距离 | $\frac{\|C_1 - C_2\|}{\sqrt{A^2 + B^2}}$ | $A, B$相同 |
| 圆的标准方程 | $(x - a)^2 + (y - b)^2 = r^2$ | $r > 0$ |
| 圆的一般方程 | $x^2 + y^2 + Dx + Ey + F = 0$ | $D^2 + E^2 - 4F > 0$ |
| 弦长公式 | $2\sqrt{r^2 - d^2}$ | 直线与圆相交 |

### 四、本章思维要点

1. **斜率是核心**：斜率$k$是描述直线方向的唯一参数，几乎所有直线问题的求解都围绕斜率展开。

2. **一般式是归宿**：直线方程的五种形式最终都可以统一到一般式$Ax + By + C = 0$，这是因为二元一次方程的代数理论最为完备。

3. **距离是关键**：点到直线的距离公式是判断位置关系、求切线、求弦长等问题的枢纽。

4. **几何法优先**：涉及圆的问题，应优先使用几何性质（如垂径定理、切线性质），其次考虑代数方法。

5. **分类讨论意识**：斜率是否存在、判别式的符号、圆方程中判别式的正负等，都需要分类讨论。
