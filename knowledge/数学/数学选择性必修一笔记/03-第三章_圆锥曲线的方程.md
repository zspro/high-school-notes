# 第三章 圆锥曲线的方程

---

## 【来龙去脉】

### 一、历史渊源：从古希腊到近代科学

#### 1. 起源——梅内克穆斯（Menaechmus, 公元前380–前320）

圆锥曲线的研究始于古希腊数学家梅内克穆斯。为解决古希腊三大几何难题之一的"倍立方问题"（即给定一个立方体，构造体积为其两倍的立方体），梅内克穆斯系统研究了三类曲线：

- **齐曲线**（parabola，即抛物线）：用一个垂直于圆锥母线的平面截直圆锥所得；
- **超曲线**（hyperbola，即双曲线的一支）：用平行于圆锥轴的平面截取所得；
- **亏曲线**（ellipse，即椭圆）：用倾斜平面截取所得。

梅内克穆斯发现，倍立方问题等价于求两个平均比例项，即给定 $a$ 和 $b$，求 $x, y$ 使得 $a : x = x : y = y : b$。这可以转化为两条圆锥曲线的交点问题。

#### 2. 集大成——阿波罗尼奥斯（Apollonius of Perga, 公元前262–前190）

阿波罗尼奥斯在其八卷巨著《圆锥曲线论》（$\textit{Conics}$）中，首次从**同一个直圆锥**出发，用不同位置的平面截取，系统得到了椭圆、抛物线、双曲线三类曲线，并证明其几何性质。这是圆锥曲线作为"同一对象的不同截面"这一统一视角的最早确立。

阿波罗尼奥斯的关键贡献：
- 引入齐曲线、亏曲线、超曲线的命名，分别对应现代术语 parabola、ellipse、hyperbola（其希腊语原义为"不足"、"恰好"、"超出"，指 $y^2$ 与 $px$ 相比的大小关系）；
- 证明了焦点-切线性质（光学性质的雏形）；
- 建立了用"纵线"和"横线"描述曲线的方法，相当于现代坐标方法的雏形。

#### 3. 从天文学到物理学——开普勒与牛顿

1609年，开普勒（Johannes Kepler）发表《新天文学》，提出**行星运动第一定律**：行星绕太阳运行的轨道是**椭圆**，太阳位于椭圆的一个焦点上。这一发现彻底改变了人类对宇宙的认知——天体轨道不是古希腊哲学所崇尚的"正圆"，而是圆锥曲线。

1687年，牛顿（Isaac Newton）在《自然哲学的数学原理》中证明：在万有引力 $F \propto \frac{1}{r^2}$ 作用下，质点的运动轨道恰好是圆锥曲线，其具体类型由**总机械能**决定：
- 负总能量 $\Rightarrow$ 椭圆轨道（束缚运动）
- 零总能量 $\Rightarrow$ 抛物线轨道（恰好逃逸）
- 正总能量 $\Rightarrow$ 双曲线轨道（散射运动）

这正是本章将学习的核心结论：**离心率 $e$ 决定曲线类型**，而 $e$ 的物理本质是系统总能量与角动量的比值。

#### 4. 解析几何的创立——笛卡尔与费马

17世纪，笛卡尔（Ren\'e Descartes）和费马（Pierre de Fermat）创立解析几何，将几何问题转化为代数方程。圆锥曲线由此获得了统一的代数描述——二元二次方程 $Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0$ 在 $B^2 - 4AC < 0, = 0, > 0$ 时分别表示椭圆型、抛物线型、双曲线型曲线。

### 二、为什么要统一研究三类曲线

教材将椭圆、双曲线、抛物线放在同一章，并非简单的编排便利，而是基于深刻的内在统一性：

| 统一视角 | 具体内容 |
|---------|---------|
| 几何统一 | 同一圆锥的不同截面 |
| 定义统一 | 焦点-准线统一定义（第二定义） |
| 代数统一 | 二元二次方程的一般形式 |
| 物理统一 | 平方反比力场中的运动轨道 |
| 参数统一 | 离心率 $e$ 作为连续参数控制曲线形态 |

理解这种统一性，是掌握本章内容的关键。

## 3.1 椭圆

### 【基础精讲】

#### 1. 第一定义（焦点定义）

**定义 3.1**（椭圆的第一定义）设 $F_1, F_2$ 为平面内两个定点，且 $|F_1F_2| = 2c > 0$。平面上到两定点距离之和为常数 $2a$（其中 $2a > 2c$）的点的轨迹称为**椭圆**。即：

$$P = \{M \in \mathbb{R}^2 : |MF_1| + |MF_2| = 2a\}$$

其中 $F_1, F_2$ 称为椭圆的**焦点**，$2c$ 称为**焦距**，$2a$ 称为**长轴长**。

**定义的有效性条件**：必须要求 $2a > 2c$（即 $a > c$）。
- 若 $2a = 2c$，则轨迹退化为线段 $F_1F_2$；
- 若 $2a < 2c$，则轨迹为空集 $\varnothing$。

#### 2. 标准方程的推导

**定理 3.1**（椭圆的标准方程）设椭圆中心在原点，焦点在 $x$ 轴上，坐标为 $F_1(-c, 0)$，$F_2(c, 0)$，长轴长为 $2a$（$a > c > 0$）。则椭圆上任意一点 $M(x, y)$ 满足：

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

其中 $b = \sqrt{a^2 - c^2}$，称为**半短轴长**。

**证明**：

由定义，$|MF_1| + |MF_2| = 2a$，即：

$$\sqrt{(x+c)^2 + y^2} + \sqrt{(x-c)^2 + y^2} = 2a$$

移项得 $\sqrt{(x+c)^2 + y^2} = 2a - \sqrt{(x-c)^2 + y^2}$，两边平方：

$$(x+c)^2 + y^2 = 4a^2 - 4a\sqrt{(x-c)^2 + y^2} + (x-c)^2 + y^2$$

展开并整理：

$$x^2 + 2cx + c^2 = 4a^2 - 4a\sqrt{(x-c)^2 + y^2} + x^2 - 2cx + c^2$$

$$4cx - 4a^2 = -4a\sqrt{(x-c)^2 + y^2}$$

$$a\sqrt{(x-c)^2 + y^2} = a^2 - cx$$

再次平方：

$$a^2[(x-c)^2 + y^2] = (a^2 - cx)^2 = a^4 - 2a^2cx + c^2x^2$$

$$a^2x^2 - 2a^2cx + a^2c^2 + a^2y^2 = a^4 - 2a^2cx + c^2x^2$$

$$a^2x^2 + a^2y^2 - c^2x^2 = a^4 - a^2c^2$$

$$(a^2 - c^2)x^2 + a^2y^2 = a^2(a^2 - c^2)$$

令 $b^2 = a^2 - c^2$（由 $a > c > 0$ 知 $b > 0$），两边除以 $a^2b^2$：

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

**证毕。**

#### 3. 几何性质

设椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$（$a > b > 0$），其几何性质如下：

| 性质 | 内容 |
|------|------|
| 范围 | $-a \leq x \leq a$，$-b \leq y \leq b$ |
| 对称性 | 关于 $x$ 轴、$y$ 轴、原点均对称 |
| 顶点 | $A_1(-a, 0)$，$A_2(a, 0)$，$B_1(0, -b)$，$B_2(0, b)$ |
| 长轴 | $\|A_1A_2\| = 2a$，在 $x$ 轴上 |
| 短轴 | $\|B_1B_2\| = 2b$，在 $y$ 轴上 |
| 焦点 | $F_1(-c, 0)$，$F_2(c, 0)$，其中 $c = \sqrt{a^2 - b^2}$ |
| 焦距 | $\|F_1F_2\| = 2c$ |
| 离心率 | $e = \frac{c}{a} = \sqrt{1 - \frac{b^2}{a^2}}$，$0 < e < 1$ |
| 准线 | $l_1: x = -\frac{a^2}{c}$，$l_2: x = \frac{a^2}{c}$ |

#### 4. 焦点在 $y$ 轴上的椭圆

若焦点在 $y$ 轴上，焦点为 $F_1(0, -c)$，$F_2(0, c)$，则标准方程为：

$$\frac{y^2}{a^2} + \frac{x^2}{b^2} = 1 \quad (a > b > 0)$$

此时长轴在 $y$ 轴上，$a$ 始终表示半长轴，$b$ 始终表示半短轴。

#### 5. 椭圆的通径

**定义**：过焦点且垂直于长轴的弦称为椭圆的**通径**（或正焦弦、latus rectum）。

**定理**：椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 的通径长为 $\frac{2b^2}{a}$。

**证明**：通径过焦点 $F_2(c, 0)$ 且垂直于 $x$ 轴，故其端点横坐标为 $x = c$。代入椭圆方程：

$$\frac{c^2}{a^2} + \frac{y^2}{b^2} = 1 \Rightarrow \frac{y^2}{b^2} = 1 - \frac{c^2}{a^2} = \frac{a^2-c^2}{a^2} = \frac{b^2}{a^2}$$

$$y = \pm \frac{b^2}{a}$$

通径端点为 $\left(c, \frac{b^2}{a}\right)$ 和 $\left(c, -\frac{b^2}{a}\right)$，故通径长为 $\frac{2b^2}{a}$。

**证毕。**

通径长 $\frac{2b^2}{a} = 2a(1-e^2) = \frac{2b^2}{a}$ 是刻画椭圆"胖瘦"的重要指标。当 $e \to 1$ 时，通径长 $\to 0$；当 $e \to 0$ 时，通径长 $\to 2a$（即圆的直径）。

#### 6. 焦半径公式

**定理**（椭圆的焦半径公式）：设 $M(x_0, y_0)$ 为椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 上一点，则：

$|MF_1| = a + ex_0$，$|MF_2| = a - ex_0$

其中 $F_1(-c, 0)$ 为左焦点，$F_2(c, 0)$ 为右焦点。

**证明**：由椭圆的第二定义（见后文），$\frac{|MF_2|}{d(M, l_2)} = e$，其中 $l_2: x = \frac{a^2}{c}$ 为右准线。

$$|MF_2| = e \cdot d(M, l_2) = e\left(\frac{a^2}{c} - x_0\right) = \frac{a^2e}{c} - ex_0 = a - ex_0$$

（利用 $\frac{c}{a} = e$ 即 $\frac{a}{e} = \frac{a^2}{c}$）

同理 $|MF_1| = a + ex_0$。

**证毕。**

由焦半径公式可知：
- 最大焦半径（远地点距离）：$a + c = a(1+e)$，在左顶点取得
- 最小焦半径（近地点距离）：$a - c = a(1-e)$，在右顶点取得

### 【深度理解】

#### 离心率 $e$ 的几何意义

椭圆的离心率 $e = \frac{c}{a} = \sqrt{1 - \frac{b^2}{a^2}}$ 满足 $0 < e < 1$。

- 当 $e \to 0$（即 $c \to 0$，$b \to a$）时，椭圆趋近于**圆**；
- 当 $e \to 1$（即 $c \to a$，$b \to 0$）时，椭圆变得极度扁平，趋近于**线段**。

因此，$e$ 刻画了椭圆的"扁平程度"：$e$ 越大，椭圆越扁；$e$ 越小，椭圆越圆。

#### 椭圆定义中 $2a > 2c$ 的本质

第一定义要求 $2a > 2c$，即三角形两边之和大于第三边。这是**三角不等式**的直接要求：对于任意点 $M$，$|MF_1| + |MF_2| \geq |F_1F_2| = 2c$，等号当且仅当 $M$ 在线段 $F_1F_2$ 上时成立。因此，若 $2a = 2c$，轨迹退化为线段；若 $2a < 2c$，则不存在满足条件的点。

## 3.2 双曲线

### 【基础精讲】

#### 1. 第一定义（焦点定义）

**定义 3.2**（双曲线的第一定义）设 $F_1, F_2$ 为平面内两个定点，且 $|F_1F_2| = 2c > 0$。平面上到两定点距离之差的绝对值为常数 $2a$（其中 $0 < 2a < 2c$）的点的轨迹称为**双曲线**。即：

$$P = \{M \in \mathbb{R}^2 : \|MF_1| - |MF_2\| = 2a\}$$

**定义的有效性条件**：必须要求 $0 < 2a < 2c$（即 $0 < a < c$）。
- 若 $2a = 2c$，则轨迹为以 $F_1, F_2$ 为端点的两条射线（不含线段内部）；
- 若 $2a > 2c$，则轨迹为空集 $\varnothing$；
- 若 $a = 0$，则轨迹为线段 $F_1F_2$ 的垂直平分线。

**重要说明**：$\|MF_1| - |MF_2\| = 2a$ 等价于两条分支：
- $|MF_1| - |MF_2| = 2a$：靠近 $F_2$ 的**右支**
- $|MF_2| - |MF_1| = 2a$：靠近 $F_1$ 的**左支**

#### 2. 标准方程的推导

**定理 3.2**（双曲线的标准方程）设双曲线中心在原点，焦点在 $x$ 轴上，坐标为 $F_1(-c, 0)$，$F_2(c, 0)$，实轴长为 $2a$（$0 < a < c$）。则双曲线的标准方程为：

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$

其中 $b = \sqrt{c^2 - a^2}$，称为**半虚轴长**。

**证明**：

由定义，$\|MF_1| - |MF_2\| = 2a$。考虑右支（$|MF_1| - |MF_2| = 2a$）：

$$\sqrt{(x+c)^2 + y^2} - \sqrt{(x-c)^2 + y^2} = 2a$$

（对于右支上的点，$|MF_1| > |MF_2|$，故 $x > 0$）

移项并平方，过程与椭圆类似，最终可得：

$$(c^2 - a^2)x^2 - a^2y^2 = a^2(c^2 - a^2)$$

令 $b^2 = c^2 - a^2$（由 $c > a > 0$ 知 $b > 0$），两边除以 $a^2b^2$：

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$

**证毕。**

#### 3. 几何性质

设双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$（$a > 0, b > 0$），其几何性质如下：

| 性质 | 内容 |
|------|------|
| 范围 | $x \leq -a$ 或 $x \geq a$，$y \in \mathbb{R}$ |
| 对称性 | 关于 $x$ 轴、$y$ 轴、原点均对称 |
| 顶点 | $A_1(-a, 0)$，$A_2(a, 0)$ |
| 实轴 | $\|A_1A_2\| = 2a$，在 $x$ 轴上 |
| 虚轴 | 长度为 $2b$，端点为 $(0, \pm b)$（非曲线上的点） |
| 焦点 | $F_1(-c, 0)$，$F_2(c, 0)$，其中 $c = \sqrt{a^2 + b^2}$ |
| 焦距 | $\|F_1F_2\| = 2c$ |
| 离心率 | $e = \frac{c}{a} = \sqrt{1 + \frac{b^2}{a^2}}$，$e > 1$ |
| 准线 | $l_1: x = -\frac{a^2}{c}$，$l_2: x = \frac{a^2}{c}$ |
| 渐近线 | $y = \pm \frac{b}{a}x$ |

#### 4. 焦点在 $y$ 轴上的双曲线

若焦点在 $y$ 轴上，焦点为 $F_1(0, -c)$，$F_2(0, c)$，则标准方程为：

$$\frac{y^2}{a^2} - \frac{x^2}{b^2} = 1 \quad (a > 0, b > 0)$$

此时实轴在 $y$ 轴上，渐近线为 $y = \pm \frac{a}{b}x$。

#### 5. 渐近线的严格推导

**定理 3.3**（双曲线的渐近线）双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 有两条渐近线，方程为 $y = \pm \frac{b}{a}x$。

**证明**：考虑双曲线在第一象限的部分 $y = \frac{b}{a}\sqrt{x^2 - a^2}$（$x \geq a$）。考察该曲线与直线 $y = \frac{b}{a}x$ 的纵向距离：

$$d(x) = \frac{b}{a}x - \frac{b}{a}\sqrt{x^2 - a^2} = \frac{b}{a}\left(x - \sqrt{x^2 - a^2}\right)$$

有理化：

$$d(x) = \frac{b}{a} \cdot \frac{a^2}{x + \sqrt{x^2 - a^2}} = \frac{ab}{x + \sqrt{x^2 - a^2}}$$

当 $x \to +\infty$ 时，$d(x) \to 0$。因此直线 $y = \frac{b}{a}x$ 是双曲线在第一象限的渐近线。由对称性，$y = -\frac{b}{a}x$ 也是渐近线。

**证毕。**

**渐近线的几何意义**：渐近线刻画了双曲线在无穷远处的"走向"。双曲线虽然向两个方向无限延伸，但其延伸方向被渐近线所"约束"——双曲线无限接近但永不相交于渐近线。

#### 6. 等轴双曲线

当 $a = b$ 时，双曲线 $\frac{x^2}{a^2} - \frac{y^2}{a^2} = 1$ 称为**等轴双曲线**（或等边双曲线、直角双曲线）。其性质：
- 渐近线为 $y = \pm x$，互相垂直；
- 离心率 $e = \sqrt{2}$；
- 方程可写为 $x^2 - y^2 = a^2$。

若将等轴双曲线旋转 $45°$，可得其另一种形式 $xy = k$（$k \neq 0$），这是反比例函数的图像。

#### 7. 共轭双曲线

**定义**：双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 与 $\frac{y^2}{b^2} - \frac{x^2}{a^2} = 1$ 互为**共轭双曲线**。

共轭双曲线的性质：
- 它们有相同的渐近线 $y = \pm \frac{b}{a}x$；
- 它们的四个焦点在同一圆 $x^2 + y^2 = a^2 + b^2$ 上；
- 一个双曲线的实轴恰好是另一个的虚轴。

#### 8. 双曲线的通径

**定理**：双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 的通径（过焦点且垂直于实轴的弦）长为 $\frac{2b^2}{a}$。

**证明**：通径过焦点 $F_2(c, 0)$ 且垂直于 $x$ 轴，$x = c$。代入双曲线方程：

$$\frac{c^2}{a^2} - \frac{y^2}{b^2} = 1 \Rightarrow \frac{y^2}{b^2} = \frac{c^2}{a^2} - 1 = \frac{c^2-a^2}{a^2} = \frac{b^2}{a^2}$$

$$y = \pm \frac{b^2}{a}$$

通径长为 $\frac{2b^2}{a}$。

**证毕。**

### 【深度理解】

#### 渐近线方程的记忆方法（基于结构）

双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 的渐近线方程为 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 0$，即 $y = \pm \frac{b}{a}x$。

**本质理解**：将标准方程右边的"$1$"替换为"$0$"，即将双曲线方程的等号右侧常数项归零，所得方程即为渐近线方程。这一操作的数学含义是：渐近线描述了双曲线在无穷远处的"主导项"行为——当 $|x|, |y| \to \infty$ 时，双曲线方程中的常数项相对可以忽略，曲线行为由二次齐次部分 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 0$ 决定。

#### 双曲线离心率 $e > 1$ 的本质

双曲线离心率 $e = \frac{c}{a} = \sqrt{1 + \frac{b^2}{a^2}} > 1$。与椭圆不同，双曲线的离心率没有上界：
- 当 $e \to 1^+$（即 $b \to 0$）时，双曲线开口变得极"窄"，趋近于两条射线；
- 当 $e \to +\infty$（即 $b \gg a$）时，双曲线开口变得极"宽"，渐近线趋近于 $y$ 轴。

## 3.3 抛物线

### 【基础精讲】

#### 1. 定义

**定义 3.3**（抛物线的定义）设 $F$ 为平面内一定点（**焦点**），$l$ 为平面内一定直线（**准线**），且 $F \notin l$。平面上到定点 $F$ 与到定直线 $l$ 距离相等的点的轨迹称为**抛物线**。即：

$$P = \{M \in \mathbb{R}^2 : |MF| = d(M, l)\}$$

其中 $d(M, l)$ 表示点 $M$ 到直线 $l$ 的距离。

#### 2. 标准方程的推导

**定理 3.4**（抛物线的标准方程）设抛物线的焦点为 $F\left(\frac{p}{2}, 0\right)$，准线为 $l: x = -\frac{p}{2}$（$p > 0$）。则抛物线的标准方程为：

$$y^2 = 2px$$

**证明**：设 $M(x, y)$ 为抛物线上任一点。由定义 $|MF| = d(M, l)$：

$$\sqrt{\left(x - \frac{p}{2}\right)^2 + y^2} = \left|x + \frac{p}{2}\right|$$

两边平方：

$$\left(x - \frac{p}{2}\right)^2 + y^2 = \left(x + \frac{p}{2}\right)^2$$

$$x^2 - px + \frac{p^2}{4} + y^2 = x^2 + px + \frac{p^2}{4}$$

$$y^2 = 2px$$

**证毕。**

#### 3. 几何性质

抛物线 $y^2 = 2px$（$p > 0$）的几何性质：

| 性质 | 内容 |
|------|------|
| 范围 | $x \geq 0$，$y \in \mathbb{R}$ |
| 对称性 | 关于 $x$ 轴对称 |
| 顶点 | $O(0, 0)$ |
| 焦点 | $F\left(\frac{p}{2}, 0\right)$ |
| 准线 | $l: x = -\frac{p}{2}$ |
| 离心率 | $e = 1$ |
| 通径 | 过焦点且垂直于对称轴的弦，长为 $2p$ |

#### 4. 四种标准方程形式

根据抛物线开口方向的不同，有四种标准方程形式：

| 方程 | 开口方向 | 焦点 | 准线 | 对称轴 |
|------|---------|------|------|--------|
| $y^2 = 2px$（$p > 0$） | 向右 | $\left(\frac{p}{2}, 0\right)$ | $x = -\frac{p}{2}$ | $x$ 轴 |
| $y^2 = -2px$（$p > 0$） | 向左 | $\left(-\frac{p}{2}, 0\right)$ | $x = \frac{p}{2}$ | $x$ 轴 |
| $x^2 = 2py$（$p > 0$） | 向上 | $\left(0, \frac{p}{2}\right)$ | $y = -\frac{p}{2}$ | $y$ 轴 |
| $x^2 = -2py$（$p > 0$） | 向下 | $\left(0, -\frac{p}{2}\right)$ | $y = \frac{p}{2}$ | $y$ 轴 |

### 【深度理解】

#### 参数 $p$ 的几何意义

抛物线标准方程中的参数 $p$ 有明确的几何意义：$p$ 是**焦点到准线的距离**。对于 $y^2 = 2px$，焦点 $F\left(\frac{p}{2}, 0\right)$ 到准线 $x = -\frac{p}{2}$ 的距离恰为 $p$。

$p$ 决定了抛物线的"开口宽窄"：
- $p$ 越大，抛物线开口越宽；
- $p$ 越小，抛物线开口越窄。

通径（过焦点垂直于对称轴的弦）的长度为 $2p$，这是 $p$ 的直接几何度量。

#### 抛物线的焦半径公式

设 $M(x_0, y_0)$ 为抛物线 $y^2 = 2px$ 上一点，则焦半径：

$$|MF| = x_0 + \frac{p}{2}$$

这是由抛物线定义直接得到的：$|MF| = d(M, l) = x_0 - \left(-\frac{p}{2}\right) = x_0 + \frac{p}{2}$。

## 【深度理解】统一定义与圆锥曲线的本质统一性

### 一、第二定义（焦点-准线定义）

**定义 3.4**（圆锥曲线的统一定义/第二定义）设 $F$ 为平面内一定点（焦点），$l$ 为平面内一定直线（准线），$F \notin l$。平面上到定点 $F$ 的距离与到定直线 $l$ 的距离之比为常数 $e$（$e > 0$）的点的轨迹称为**圆锥曲线**。即：

$$P = \{M \in \mathbb{R}^2 : \frac{|MF|}{d(M, l)} = e\}$$

**定理 3.5**（离心率与曲线类型的关系）在统一定义中：
- 当 $0 < e < 1$ 时，轨迹为**椭圆**；
- 当 $e = 1$ 时，轨迹为**抛物线**；
- 当 $e > 1$ 时，轨迹为**双曲线**。

**证明**：建立坐标系，设焦点 $F(c, 0)$，准线 $l: x = \frac{c}{e^2}$（此取法使得后续推导简洁）。对任意点 $M(x, y)$：

$$\frac{\sqrt{(x-c)^2 + y^2}}{\left|x - \frac{c}{e^2}\right|} = e$$

平方得：

$$(x-c)^2 + y^2 = e^2\left(x - \frac{c}{e^2}\right)^2$$

$$x^2 - 2cx + c^2 + y^2 = e^2x^2 - \frac{2cx}{e} + \frac{c^2}{e^2}$$

令 $a = \frac{c}{e}$（注意此代换），则 $c = ae$，代入：

$$x^2 - 2aex + a^2e^2 + y^2 = e^2x^2 - 2aex + a^2$$

$$(1 - e^2)x^2 + y^2 = a^2(1 - e^2)$$

**情形 1**：$0 < e < 1$。令 $b^2 = a^2(1 - e^2) = a^2 - c^2 > 0$，则：

$$(1 - e^2)x^2 + y^2 = a^2(1 - e^2)$$

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

此为椭圆。

**情形 2**：$e = 1$。方程变为 $y^2 = 2cx$，此为抛物线。

**情形 3**：$e > 1$。令 $b^2 = a^2(e^2 - 1) = c^2 - a^2 > 0$，则：

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$

此为双曲线。

**证毕。**

### 二、为什么离心率 $e$ 决定曲线类型

统一定义 $\frac{|MF|}{d(M, l)} = e$ 揭示了圆锥曲线类型的连续变化：

- 当 $e < 1$ 时，点到焦点的距离"小于"点到准线距离的 $e$ 倍，曲线被"束缚"在焦点附近，形成**闭合的椭圆**；
- 当 $e = 1$ 时，点到焦点距离"恰好等于"到准线距离，曲线既不被束缚也不发散，形成**开放的抛物线**——这是椭圆与双曲线的"临界状态"；
- 当 $e > 1$ 时，点到焦点的距离"大于"点到准线距离的 $e$ 倍，曲线向远处"发散"，形成**开放的双曲线**。

从物理角度看，这对应平方反比力场中质点能量的三种状态：
- $E < 0$（束缚态）$\Leftrightarrow$ $e < 1$（椭圆）
- $E = 0$（临界态）$\Leftrightarrow$ $e = 1$（抛物线）
- $E > 0$（散射态）$\Leftrightarrow$ $e > 1$（双曲线）

这正是圆锥曲线统一性的深刻物理根源。

### 三、圆锥曲线的光学性质

**定理 3.6**（椭圆的光学性质）从椭圆一个焦点发出的光线（或声波），经椭圆反射后必经过另一个焦点。

**定理 3.7**（双曲线的光学性质）从双曲线一个焦点发出的光线，经双曲线反射后，其反向延长线经过另一个焦点。

**定理 3.8**（抛物线的光学性质）从抛物线焦点发出的光线，经抛物线反射后变为平行于对称轴的平行光；反之，平行于对称轴的平行光经抛物线反射后汇聚于焦点。

**原理说明（以椭圆为例）**：

光学性质的本质是**反射定律**（入射角等于反射角）与椭圆的几何性质的结合。设 $M$ 为椭圆上一点，过 $M$ 的切线为 $l$。光学性质等价于：切线 $l$ 与 $MF_1$ 的夹角等于切线 $l$ 与 $MF_2$ 的夹角。

**严格证明**：设椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$，点 $M(x_0, y_0)$ 在椭圆上。过 $M$ 的切线方程为 $\frac{x_0 x}{a^2} + \frac{y_0 y}{b^2} = 1$。该切线的法向量为 $\vec{n} = \left(\frac{x_0}{a^2}, \frac{y_0}{b^2}\right)$。

向量 $\vec{MF_1} = (-c - x_0, -y_0)$，$\vec{MF_2} = (c - x_0, -y_0)$。

光学性质等价于 $\vec{n}$ 平分 $\angle F_1MF_2$，即 $\vec{n}$ 与 $\vec{MF_1}$ 和 $\vec{MF_2}$ 的夹角相等。这等价于：

$$\frac{\vec{n} \cdot \vec{MF_1}}{|\vec{n}||\vec{MF_1}|} = \frac{\vec{n} \cdot \vec{MF_2}}{|\vec{n}||\vec{MF_2}|}$$

即 $\frac{\vec{n} \cdot \vec{MF_1}}{|\vec{MF_1}|} = \frac{\vec{n} \cdot \vec{MF_2}}{|\vec{MF_2}|}$。

计算 $\vec{n} \cdot \vec{MF_1} = -\frac{cx_0}{a^2} - \frac{x_0^2}{a^2} - \frac{y_0^2}{b^2} = -\frac{cx_0}{a^2} - 1$

$$\vec{n} \cdot \vec{MF_2} = \frac{cx_0}{a^2} - \frac{x_0^2}{a^2} - \frac{y_0^2}{b^2} = \frac{cx_0}{a^2} - 1$$

由焦半径公式 $|\vec{MF_1}| = a + ex_0 = a + \frac{cx_0}{a}$，$|\vec{MF_2}| = a - ex_0 = a - \frac{cx_0}{a}$。

代入验证：

$$\frac{-\frac{cx_0}{a^2} - 1}{a + \frac{cx_0}{a}} = \frac{-\frac{cx_0 + a^2}{a^2}}{\frac{a^2 + cx_0}{a}} = -\frac{1}{a}$$

$$\frac{\frac{cx_0}{a^2} - 1}{a - \frac{cx_0}{a}} = \frac{\frac{cx_0 - a^2}{a^2}}{\frac{a^2 - cx_0}{a}} = -\frac{1}{a}$$

两式相等，故切线平分 $\angle F_1MF_2$ 的外角，即入射角等于反射角。椭圆的光学性质得证。

**更本质的理解**：椭圆的切线是到两焦点距离之和为 $2a$ 的点的"等值线"。由费马原理（光沿极值路径传播），切线方向是光程取极值的方向，因此入射角等于反射角。

### 二、直线与圆锥曲线的位置关系

设直线 $y = kx + m$ 与圆锥曲线 $F(x, y) = 0$ 联立，消去 $y$ 得到关于 $x$ 的一元二次方程 $Ax^2 + Bx + C = 0$。

| 判别式 | 位置关系 | 交点个数 |
|--------|---------|---------|
| $\Delta > 0$ | 相交 | 2个 |
| $\Delta = 0$ | 相切 | 1个 |
| $\Delta < 0$ | 相离 | 0个 |

$$\|AB\| = \sqrt{1 + k^2} \cdot \sqrt{(x_1 + x_2)^2 - 4x_1x_2} = \sqrt{1 + k^2} \cdot \frac{\sqrt{\Delta}}{|A|}$$

其中 $\Delta$ 为联立方程的判别式，$A$ 为二次项系数。

   - $\Delta < 0$：椭圆型（包括椭圆、点、空集）
   - $\Delta = 0$：抛物线型（包括抛物线、两条平行线等）
   - $\Delta > 0$：双曲线型（包括双曲线、两条相交直线）

2. **坐标变换**：通过平移和旋转化简二次曲线方程，消去一次项和交叉项。

3. **不变量理论**：$I_1 = A + C$，$I_2 = \Delta = B^2 - 4AC$ 等不变量完全决定了二次曲线的度量性质。

4. **参数方程**：椭圆的参数方程 $x = a\cos\theta$，$y = b\sin\theta$ 是参数方程思想的典型应用。

## 【隐性考点】

### 一、焦点三角形问题

**焦点三角形**：椭圆（或双曲线）上一点 $M$ 与两个焦点 $F_1, F_2$ 构成的三角形 $\triangle MF_1F_2$。

#### 椭圆焦点三角形

设 $M$ 为椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 上一点，$\angle F_1MF_2 = \theta$。则：

**面积公式**：$S_{\triangle MF_1F_2} = b^2 \tan\frac{\theta}{2}$

**推导**：设 $\|MF_1\| = r_1$，$\|MF_2\| = r_2$。由椭圆定义 $r_1 + r_2 = 2a$，$\|F_1F_2\| = 2c$。

由余弦定理：$(2c)^2 = r_1^2 + r_2^2 - 2r_1r_2\cos\theta = (r_1+r_2)^2 - 2r_1r_2(1+\cos\theta) = 4a^2 - 2r_1r_2(1+\cos\theta)$

解得 $r_1r_2 = \frac{2b^2}{1+\cos\theta}$，因此：

$$S = \frac{1}{2}r_1r_2\sin\theta = \frac{b^2\sin\theta}{1+\cos\theta} = b^2 \tan\frac{\theta}{2}$$

#### 双曲线焦点三角形

设 $M$ 为双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 右支上一点，$\angle F_1MF_2 = \theta$。则：

**面积公式**：$S_{\triangle MF_1F_2} = b^2 \cot\frac{\theta}{2}$

**推导**：设 $\|MF_1\| = r_1$，$\|MF_2\| = r_2$。由双曲线定义 $r_1 - r_2 = 2a$（右支），$\|F_1F_2\| = 2c$。

由余弦定理：$(2c)^2 = r_1^2 + r_2^2 - 2r_1r_2\cos\theta = (r_1-r_2)^2 + 2r_1r_2(1-\cos\theta) = 4a^2 + 2r_1r_2(1-\cos\theta)$

解得 $r_1r_2 = \frac{2b^2}{1-\cos\theta}$，因此：

$$S = \frac{1}{2}r_1r_2\sin\theta = \frac{b^2\sin\theta}{1-\cos\theta} = b^2 \cot\frac{\theta}{2}$$

### 二、弦中点问题（点差法）

**问题类型**：已知椭圆（或双曲线）的一条弦 $AB$，求弦中点 $M$ 的坐标与弦斜率之间的关系。

**点差法**：设 $A(x_1, y_1)$，$B(x_2, y_2)$ 在椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 上，弦中点 $M(x_0, y_0)$。

由 $\frac{x_1^2}{a^2} + \frac{y_1^2}{b^2} = 1$ 和 $\frac{x_2^2}{a^2} + \frac{y_2^2}{b^2} = 1$，相减得：

$$\frac{(x_1+x_2)(x_1-x_2)}{a^2} + \frac{(y_1+y_2)(y_1-y_2)}{b^2} = 0$$

$$\frac{2x_0(x_1-x_2)}{a^2} + \frac{2y_0(y_1-y_2)}{b^2} = 0$$

$$\frac{y_1-y_2}{x_1-x_2} = -\frac{b^2x_0}{a^2y_0}$$

即弦的斜率 $k_{AB} = -\frac{b^2x_0}{a^2y_0}$。这一关系在解决弦中点轨迹问题时极为有效。

**注意**：点差法的使用前提是弦存在（即 $\Delta > 0$），需要在最后验证。

### 三、最值问题

圆锥曲线中的最值问题常见类型：

1. **距离最值**：椭圆上点到定点的距离的最大/最小值。利用参数方程转化为三角函数的最值问题。

2. **焦半径最值**：椭圆焦半径 $r = a \pm ex_0$（$|x_0| \leq a$），因此：
   - 最大焦半径：$a + c$（对应左顶点到左焦点距离）
   - 最小焦半径：$a - c$（对应右顶点到右焦点距离）

3. **角度最值**：焦点三角形中 $\angle F_1MF_2$ 的最大值，在短轴端点处取得。此时 $\cos\theta = \frac{2b^2-a^2}{a^2} = 1 - 2e^2$。

### 四、统一定义的应用

利用第二定义，可以将到焦点的距离转化为到准线的距离，从而简化某些最值问题。

**典型问题**：求椭圆上一点 $M$ 到焦点 $F$ 的距离与到某定直线距离之和的最小值。

由 $\frac{|MF|}{d(M, l)} = e$，得 $|MF| = e \cdot d(M, l)$。将问题转化为单纯的距离问题。

### 五、离心角的本质含义

椭圆参数方程 $x = a\cos\theta$，$y = b\sin\theta$ 中，参数 $\theta$ 称为**离心角**。需要明确区分两个概念：

**离心角 $\theta$**：以原点 $O$ 为圆心、$a$ 为半径作辅助圆（大辅助圆），从 $x$ 轴正半轴到辅助圆上对应半径的夹角即为离心角。

**旋转角 $\varphi$**：原点 $O$ 到椭圆上点 $P$ 的连线与 $x$ 轴正半轴的夹角，满足 $\tan\varphi = \frac{y}{x} = \frac{b\sin\theta}{a\cos\theta} = \frac{b}{a}\tan\theta$。

一般情况下 $\theta \neq \varphi$（圆是特例，此时 $a = b$，$\theta = \varphi$）。离心角 $\theta$ 的优势在于：椭圆上任意一点都可以用单一参数 $\theta$ 完整描述，且 $\theta$ 的取值范围恰好是 $[0, 2\pi)$，与点的位置一一对应。

## 【易错警示】

### 一、焦点位置的判断

**易错点**：看到方程 $\frac{x^2}{m} + \frac{y^2}{n} = 1$ 就默认焦点在 $x$ 轴上。

**正确做法**：
- 若 $m > n > 0$，则焦点在 $x$ 轴上；
- 若 $n > m > 0$，则焦点在 $y$ 轴上；
- 若 $m = n > 0$，则为圆；
- 若 $m, n$ 异号，则为双曲线（正号对应实轴方向）。

**核心原则**：$a$ 永远对应**较大分母**的方向。对于椭圆，$a^2$ 是两个分母中较大的那个；对于双曲线，$a^2$ 是正分母所对应的方向。

### 二、双曲线渐近线方程的记忆

**易错点**：混淆 $y = \pm \frac{b}{a}x$ 和 $y = \pm \frac{a}{b}x$。

**正确记忆**：
- 双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$（实轴在 $x$ 轴）：渐近线 $y = \pm \frac{b}{a}x$
- 双曲线 $\frac{y^2}{a^2} - \frac{x^2}{b^2} = 1$（实轴在 $y$ 轴）：渐近线 $y = \pm \frac{a}{b}x$

**不记分数的方法**：将标准方程右边的 $1$ 改为 $0$，解出 $y$ 即可。即：

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 0 \Rightarrow \frac{y^2}{b^2} = \frac{x^2}{a^2} \Rightarrow y = \pm \frac{b}{a}x$$

### 三、抛物线标准方程的四种形式

**易错点**：混淆焦点位置与方程形式。

| 方程 | 一次项 | 焦点位置 | 开口方向 |
|------|--------|---------|---------|
| $y^2 = 2px$ | $x$ 一次项 | $x$ 轴正半轴 | 向右 |
| $y^2 = -2px$ | $x$ 一次项 | $x$ 轴负半轴 | 向左 |
| $x^2 = 2py$ | $y$ 一次项 | $y$ 轴正半轴 | 向上 |
| $x^2 = -2py$ | $y$ 一次项 | $y$ 轴负半轴 | 向下 |

**记忆口诀（基于结构）**：谁是一次项，焦点就在谁轴上；系数正负定方向。

### 四、双曲线定义中的绝对值

**易错点**：忽略定义中的绝对值符号，遗漏双曲线的一支。

双曲线定义 $\|MF_1| - |MF_2\| = 2a$ 包含两条分支：
- $|MF_1| - |MF_2| = 2a > 0$：右支（靠近 $F_2$）
- $|MF_2| - |MF_1| = 2a > 0$：左支（靠近 $F_1$）

若题目仅给出 $|MF_1| - |MF_2| = 2a$ 而没有绝对值，则只表示右支。

### 五、直线与圆锥曲线相交时的判别式

**易错点**：联立方程后忘记检验判别式 $\Delta \geq 0$。

**纠正**：直线与圆锥曲线联立后，必须要求 $\Delta > 0$（相交于两点）或 $\Delta = 0$（相切）。$\Delta < 0$ 表示直线与曲线无交点。

### 六、混淆 $a, b, c$ 的关系

**易错点**：将椭圆的关系 $a^2 = b^2 + c^2$ 与双曲线的关系 $c^2 = a^2 + b^2$ 混淆。

**区分方法**：
- 椭圆中 $a$ 最大，$a^2 = b^2 + c^2$
- 双曲线中 $c$ 最大，$c^2 = a^2 + b^2$

记忆：椭圆中 $a$ 是半长轴（老大），双曲线中 $c$ 比 $a$ 和 $b$ 都大（焦距最大）。

## 【思想方法】

### 一、定义法思想

**核心**：圆锥曲线的定义不仅是判断一个轨迹是什么曲线的依据，更是**解决问题的重要工具**。

**应用场景**：
1. **求轨迹方程**：直接利用定义写出等量关系，比用坐标法更简洁；
2. **转化距离**：将到焦点的距离与到准线的距离相互转化（第二定义）；
3. **几何性质的推导**：如焦半径公式 $|MF| = a \pm ex_0$ 可由第二定义直接导出。

**例**：椭圆焦半径公式的推导

设 $M(x_0, y_0)$ 在椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 上，$F(c, 0)$ 为右焦点，右准线 $l: x = \frac{a^2}{c}$。

由第二定义 $\frac{|MF|}{d(M, l)} = e = \frac{c}{a}$：

$$|MF| = e \cdot d(M, l) = \frac{c}{a}\left(\frac{a^2}{c} - x_0\right) = a - \frac{c}{a}x_0 = a - ex_0$$

同理，左焦半径 $|MF_1| = a + ex_0$。

### 二、数形结合思想

**核心**：将几何直观与代数运算有机结合，既用图形辅助理解代数关系，又用代数方法精确刻画几何性质。

**在本章的体现**：
1. 通过图形理解 $a, b, c$ 的几何意义（半长轴、半短轴、半焦距）；
2. 利用图形对称性简化计算；
3. 通过图形判断直线与曲线的位置关系。

### 三、参数方程思想

**核心**：引入参数表示曲线上点的坐标，将二元问题转化为一元参数问题。

**椭圆的参数方程**：

$$\begin{cases} x = a\cos\theta \\ y = b\sin\theta \end{cases} \quad (\theta \in [0, 2\pi))$$

其中参数 $\theta$ 称为**离心角**（注意：不是点与原点连线和 $x$ 轴的夹角）。

**应用**：
1. 求椭圆上点到定点的距离最值：
   
   设 $P(a\cos\theta, b\sin\theta)$ 为椭圆上一点，$A(x_A, y_A)$ 为定点。则：
   
   $\|PA\|^2 = (a\cos\theta - x_A)^2 + (b\sin\theta - y_A)^2$
   
   这是关于 $\theta$ 的三角函数，可用辅助角公式求最值。

2. 求椭圆上点使某角度最大的问题；
3. 计算弧长、面积等几何量。

### 四、坐标法思想

**核心**：用坐标系将几何问题转化为代数方程，通过代数运算解决几何问题。

**在本章的体现**：
1. 建立适当的坐标系推导标准方程；
2. 利用坐标运算证明几何性质（如光学性质）；
3. 用判别式判断位置关系。

### 五、等价转化思想

**核心**：将复杂问题转化为简单问题，将未知问题转化为已知问题。

**在本章的体现**：
1. 一般位置圆锥曲线 $\to$ 标准位置（平移坐标系）；
2. 非标准方程 $\to$ 标准方程（配方、换元）；
3. 焦点距离 $\leftrightarrow$ 准线距离（第二定义转化）。

### 六、分类讨论思想

**核心**：根据问题的不同情形分别讨论。

**在本章的体现**：
1. 焦点在 $x$ 轴还是 $y$ 轴；
2. 双曲线的一支还是两支；
3. 直线斜率存在与不存在；
4. 抛物线开口的四种方向。

## 【补充】圆锥曲线的统一极坐标方程

在以焦点为极点、以指向最近顶点的方向为极轴的极坐标系中，三类圆锥曲线有统一的极坐标方程：

$$\rho = \frac{ep}{1 - e\cos\theta}$$

其中：
- $e$ 为离心率
- $p$ 为焦点到准线的距离
- 当 $e < 1$ 时为椭圆
- 当 $e = 1$ 时为抛物线
- 当 $e > 1$ 时为双曲线（右支）

**推导**：由统一定义 $\frac{|MF|}{d(M, l)} = e$，设焦点 $F$ 为极点，准线 $l$ 在 $F$ 左侧距离 $p$ 处。则 $d(M, l) = p + \rho\cos\theta$，由 $\frac{\rho}{p + \rho\cos\theta} = e$ 解得上述方程。

这一方程在天体力学中尤为重要——开普勒行星运动定律的数学表达即基于此形式。
