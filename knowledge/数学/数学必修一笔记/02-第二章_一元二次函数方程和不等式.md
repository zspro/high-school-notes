# 第二章 一元二次函数、方程和不等式

## 一、本章概览与来龙去脉

### 1.1 从初中到高中：为什么把"函数、方程、不等式"放在一起学？

初中阶段，分别学习了：
- **一元二次方程** $ax^2 + bx + c = 0$（$a \neq 0$）——求根公式、判别式、韦达定理；
- **二次函数** $y = ax^2 + bx + c$ ——图像、顶点、最值；
- **不等式** ——仅涉及一元一次不等式（组）的解法。

三者具有紧密的代数联系。高中的核心任务，是将这三者纳入统一的函数视角，形成"三个二次"的理论框架。

> **为什么要统一？**
> 
> 方程 $f(x) = 0$ 的根，即函数 $y = f(x)$ 图像与 $x$ 轴交点的横坐标；
> 不等式 $f(x) > 0$ 的解集，即函数 $y = f(x)$ 图像在 $x$ 轴上方对应 $x$ 的取值范围。
> 
> 方程给出了不等式解集的边界，函数为方程和不等式提供了统一的分析工具。通过函数图像分析，可以将解不等式转化为对函数图像的系统研究。这是高中数学"数形结合"思想的集中体现。

此外，本章引入的**基本不等式** $\frac{a+b}{2} \geq \sqrt{ab}$，是高中阶段第一个重要的求最值工具。赵爽弦图从几何角度证明了该不等式，为后续学习基本不等式链、柯西不等式及导数求最值奠定基础。

## 2.1 等式性质与不等式性质

### 2.1.1 不等关系的现实来源

现实世界中的大量关系可用不等式描述：高速公路限速（$v \leq 120$ km/h）、三角形两边之和大于第三边（$a + b > c$）、海拔高度差异、温度变化范围等。等式刻画的是精确等价关系，不等式刻画的是范围约束。从数的角度看，数轴上的点有左右之分，实数天然具有大小顺序，这是不等式得以建立的根基。

### 2.1.2 实数大小比较的基本事实（理论基础）

**【基本事实】** 对于任意两个实数 $a, b$，下列三种关系有且仅有一种成立：

$$
a > b, \quad a = b, \quad a < b
$$

这是实数的三歧性（trichotomy），是不等式所有性质的逻辑起点。

**【比较原理】** 在数轴上，点 $a$ 位于点 $b$ 的右侧 $\Leftrightarrow a > b$；两点重合 $\Leftrightarrow a = b$。代数上等价于：

$$
a > b \Leftrightarrow a - b > 0; \quad a = b \Leftrightarrow a - b = 0; \quad a < b \Leftrightarrow a - b < 0
$$

> **来龙去脉**：为什么可以用"作差"来比较大小？因为实数集是有序域，正数的概念（大于0）是原始概念。判断 $a$ 与 $b$ 的大小，等价于判断 $a-b$ 的符号。这种归约到0的思想贯穿整个不等式理论的证明。

### 2.1.3 不等式的基本性质

设 $a, b, c, d$ 为实数，则：

| 性质 | 内容 | 名称/备注 |
|:---|:---|:---|
| 对称性 | $a > b \Leftrightarrow b < a$ | 不等号方向改变 |
| 传递性 | $a > b, b > c \Rightarrow a > c$ | 可用于放缩比较 |
| 可加性 | $a > b \Leftrightarrow a + c > b + c$ | 两边同加（减）一个数，不等号方向不变 |
| 可乘性（正） | $a > b, c > 0 \Rightarrow ac > bc$ | 两边同乘正数，不等号方向不变 |
| 可乘性（负） | $a > b, c < 0 \Rightarrow ac < bc$ | 两边同乘负数，不等号方向改变 |
| 同向可加 | $a > b, c > d \Rightarrow a + c > b + d$ | 同向不等式可相加 |
| 同向同正可乘 | $a > b > 0, c > d > 0 \Rightarrow ac > bd$ | 仅当各数均为正数时不等式可乘 |
| 乘方性质（正） | $a > b > 0 \Rightarrow a^n > b^n$（$n \in \mathbb{N}^*, n \geq 2$） | 只对正数成立 |
| 开方性质（正） | $a > b > 0 \Rightarrow \sqrt[n]{a} > \sqrt[n]{b}$（$n \in \mathbb{N}^*, n \geq 2$） | 只对正数成立 |

#### 深度理解：性质的证明与内在逻辑

**性质3（可加性）的证明：**

$$
a > b \Rightarrow a - b > 0 \Rightarrow (a + c) - (b + c) = a - b > 0 \Rightarrow a + c > b + c
$$

由数轴上点的平移不变性，加（减）同一实数不改变两点之间的相对位置关系。

**性质5（可乘性——负数）的证明：**

$$
a > b \Rightarrow a - b > 0, \quad c < 0 \Rightarrow ac - bc = (a - b)c < 0 \Rightarrow ac < bc
$$

乘负数相当于数轴关于原点的对称变换，因此不等号方向改变。这是初学者最易出错之处。

**性质7（同向同正可乘）的说明：**

若缺少"同正"条件，结论不一定成立。例如 $a = 1, b = -2, c = 1, d = -2$，虽有 $a > b$ 且 $c > d$，但 $ac = 1 < 4 = bd$。

### 2.1.4 作差法比较大小——不等式证明的基本方法

**【方法概述】** 要比较两个数（或式）$M$ 与 $N$ 的大小：
1. 作差：计算 $M - N$；
2. 变形：因式分解、配方、通分、有理化等，将差化为可判断符号的形式；
3. 定号：判断差的正负；
4. 结论：$M - N > 0 \Rightarrow M > N$，等等。

**【典型示例】** 比较 $(x+1)(x+5)$ 与 $(x+3)^2$ 的大小。

**解：**

$$
\begin{aligned}
&(x+1)(x+5) - (x+3)^2 \\
&= (x^2 + 6x + 5) - (x^2 + 6x + 9) \\
&= -4 < 0
\end{aligned}
$$

故 $(x+1)(x+5) < (x+3)^2$ 对任意实数 $x$ 恒成立。

**【另一示例】** 已知 $a > b > 0$，比较 $\frac{a}{b^2}$ 与 $\frac{b}{a^2}$ 的大小。

**解：**

$$
\frac{a}{b^2} - \frac{b}{a^2} = \frac{a^3 - b^3}{a^2 b^2} = \frac{(a-b)(a^2+ab+b^2)}{a^2 b^2}
$$

由 $a > b > 0$ 知 $a - b > 0$，$a^2 + ab + b^2 > 0$，$a^2 b^2 > 0$，所以差 $> 0$，即 $\frac{a}{b^2} > \frac{b}{a^2}$。

> **思想方法**：作差法的本质是将两个数的大小比较（二元问题），转化为判断一个数与0的关系（一元问题）。这是化归思想的典型应用。

## 2.2 基本不等式

### 2.2.1 基本不等式的内容

**【定理】** 若 $a > 0, b > 0$，则

$$
\frac{a+b}{2} \geq \sqrt{ab}
$$

当且仅当 $a = b$ 时，等号成立。

其中：
- $\frac{a+b}{2}$ 称为 $a, b$ 的算术平均数（Arithmetic Mean，简称AM）
- $\sqrt{ab}$ 称为 $a, b$ 的几何平均数（Geometric Mean，简称GM）

因此，基本不等式也被称为 AM-GM 不等式（二元情形），其内涵为：算术平均数不小于几何平均数。

### 2.2.2 几何证明：赵爽弦图（面积法）

**【构造】** 取两个边长分别为 $a$ 和 $b$ 的正方形（$a \geq b > 0$），将它们并排放置，构造如下图形：

以 $a + b$ 为边长作一个大正方形。在大正方形内部，构造四个全等的直角三角形，每个直角三角形的两条直角边分别为 $a$ 和 $b$，斜边为 $\sqrt{a^2 + b^2}$。

更经典的构造是：作一个半圆，直径 $AB = a + b$。在直径上取点 $C$，使 $AC = a, CB = b$。过 $C$ 作直径的垂线，交半圆于点 $D$。由射影定理（或相似三角形），$CD = \sqrt{ab}$。而半圆的半径为 $\frac{a+b}{2}$。由 $CD \leq$ 半径，即 $\sqrt{ab} \leq \frac{a+b}{2}$。当 $C$ 位于圆心时（即 $a = b$），$CD$ 等于半径，等号成立。

**【赵爽弦图法（代数几何结合）】**

将两个正方形（边长 $a, b$）的面积和 $a^2 + b^2$ 与以 $a+b$ 为边长的大正方形面积 $(a+b)^2 = a^2 + 2ab + b^2$ 对比：

作边长为 $a+b$ 的正方形，其面积为 $(a+b)^2$。内部用四个直角边为 $a, b$ 的直角三角形和一个边长为 $|a-b|$ 的小正方形拼成。则：

$$
(a+b)^2 = 4 \cdot \frac{1}{2}ab + (a-b)^2 = 2ab + (a-b)^2
$$

即 $(a+b)^2 - 4ab = (a-b)^2 \geq 0$，整理得 $(a+b)^2 \geq 4ab$。两边开方（均为正），得 $a+b \geq 2\sqrt{ab}$，即 $\frac{a+b}{2} \geq \sqrt{ab}$。

等号成立当且仅当 $(a-b)^2 = 0$，即 $a = b$。

> **来龙去脉**：赵爽弦图出自中国古代数学经典《周髀算经》，是勾股定理的经典证法。此处借用其"大正方形面积 = 若干部分面积之和"的思想，从几何角度证明了代数不等式。这是中国古代数学"形数结合"思想的体现，表明基本不等式具有明确的几何来源。

### 2.2.3 代数证明：从完全平方出发

**【证明】** 由实数平方的非负性，对任意实数 $a, b$：

$$
(a-b)^2 \geq 0
$$

展开得：

$$
a^2 - 2ab + b^2 \geq 0 \Rightarrow a^2 + b^2 \geq 2ab
$$

这是基本不等式的平方形式。若 $a > 0, b > 0$，令 $a = \sqrt{m}, b = \sqrt{n}$（其中 $m > 0, n > 0$），代入得：

$$
m + n \geq 2\sqrt{mn} \Rightarrow \frac{m+n}{2} \geq \sqrt{mn}
$$

将 $m, n$ 换回 $a, b$，即得基本不等式。

> **深度理解**：代数证明的起点是 $(a-b)^2 \geq 0$，这是实数最基本的性质之一。整个推导仅需"平方非负"和"代入换元"，逻辑链条简短。值得注意的是，$(a-b)^2 \geq 0$ 对所有实数成立，因此 $a^2 + b^2 \geq 2ab$ 不要求 $a, b$ 为正；但变到 $\frac{a+b}{2} \geq \sqrt{ab}$ 时，由于出现了 $\sqrt{ab}$，必须要求 $a > 0, b > 0$。

### 2.2.4 "一正二定三相等"的缺一不可

基本不等式 $\frac{a+b}{2} \geq \sqrt{ab}$ 的应用，必须同时满足三个条件：

| 条件 | 内容 | 原因 | 不满足的后果 |
|:---|:---|:---|:---|
| 一正 | $a > 0, b > 0$（两数均为正） | 若 $a, b$ 中有负数，$\sqrt{ab}$ 可能无意义；若均负，不等号方向反转 | 误用导致错解 |
| 二定 | $a + b$（或 $ab$）为定值 | 基本不等式提供的是下界或上界，只有定值才能确定最值 | 虽有不等关系，但无法求最值 |
| 三相等 | 等号能够取到，即 $a = b$ 在可行域内 | 若等号取不到，则界不可达，需用其他方法（如函数单调性）求最值 | 误将不可达的上界当作最大值 |

#### 深度剖析：三个条件的内在逻辑

1. **"一正"——定义域的约束**

   $\sqrt{ab}$ 要求 $ab \geq 0$。若 $a, b$ 一正一负，$\sqrt{ab}$ 在实数范围内无意义；若 $a, b$ 均为负数，虽然 $ab > 0$，但 $\frac{a+b}{2} < 0$，$\sqrt{ab} > 0$，此时 $\frac{a+b}{2} \geq \sqrt{ab}$ 不成立（实际是 $\frac{a+b}{2} \leq -\sqrt{ab}$）。

2. **"二定"——最值的前提**

   基本不等式的核心用途是求最值。例如，若 $a + b = S$（定值），则 $ab \leq \left(\frac{S}{2}\right)^2$，当 $a = b = \frac{S}{2}$ 时 $ab$ 取最大值 $\frac{S^2}{4}$；若 $ab = P$（定值），则 $a + b \geq 2\sqrt{P}$，当 $a = b = \sqrt{P}$ 时 $a+b$ 取最小值 $2\sqrt{P}$。

   但如果 $a + b$ 不是定值，比如 $a + b = x$（变量），则 $ab \leq \frac{x^2}{4}$ 给出的上界本身也在变化，无法确定 $ab$ 的最大值。

3. **"三相等"——等号成立条件**

   这是最易被忽视的条件。例如：求 $f(x) = x + \frac{1}{x}$ 在 $x > 2$ 时的最小值。若直接用基本不等式，$x + \frac{1}{x} \geq 2\sqrt{x \cdot \frac{1}{x}} = 2$，等号当 $x = 1$ 时成立。但 $x = 1$ 不在定义域 $x > 2$ 内，因此最小值不是 $2$。实际上，$f(x)$ 在 $(2, +\infty)$ 上单调递增，最小值为 $f(2) = 2.5$（在 $x = 2$ 处取到，但 $x > 2$ 是开区间，所以 $2.5$ 是下确界而非最小值）。

   > **易错警示**："等号取不到"是基本不等式应用中最隐蔽的问题。不能只看代数推导的形式正确，必须验证等号成立条件是否在题目给定的约束范围内。


### 2.2.5 基本不等式的变形与拓展

**【变形1】** $a^2 + b^2 \geq 2ab$（$a, b \in \mathbb{R}$，不要求正）

**【变形2】** $a + b \geq 2\sqrt{ab}$（$a, b > 0$）

**【变形3】** $ab \leq \left(\frac{a+b}{2}\right)^2$（$a, b > 0$，积的最大值形式）

**【变形4】** $\frac{a}{b} + \frac{b}{a} \geq 2$（$a, b$ 同号，因为 $\frac{a}{b} > 0$）

**【变形5】** $a^2 + b^2 \geq \frac{(a+b)^2}{2}$（$a, b \in \mathbb{R}$，平方平均数 $\geq$ 算术平均数）

**【拓展——基本不等式链】** 对 $a > 0, b > 0$：

$$
\frac{2}{\frac{1}{a}+\frac{1}{b}} \leq \sqrt{ab} \leq \frac{a+b}{2} \leq \sqrt{\frac{a^2+b^2}{2}}
$$

即：调和平均数 $\leq$ 几何平均数 $\leq$ 算术平均数 $\leq$ 平方平均数（简称：调几算方，依次增大）。等号均当且仅当 $a = b$ 时成立。

> **知识串联**：该不等式链在选修课程中会进一步学习（如柯西不等式、排序不等式），展示了不同平均概念之间的层次关系，是理解统计学中各类均值联系的重要基础。

### 2.2.6 典型应用举例

**【类型1】和定积最大**

已知 $x > 0, y > 0$，且 $x + y = 10$，求 $xy$ 的最大值。

**解：** 由基本不等式：

$$
xy \leq \left(\frac{x+y}{2}\right)^2 = \left(\frac{10}{2}\right)^2 = 25
$$

当且仅当 $x = y = 5$ 时取等号。故 $xy$ 的最大值为 $25$。

**【类型2】积定和最小**

已知 $x > 0$，求 $x + \frac{4}{x}$ 的最小值。

**解：** 由基本不等式：

$$
x + \frac{4}{x} \geq 2\sqrt{x \cdot \frac{4}{x}} = 2\sqrt{4} = 4
$$

当且仅当 $x = \frac{4}{x}$，即 $x^2 = 4, x = 2$（$x > 0$）时取等号。故最小值为 $4$。

**【类型3】凑配技巧**

已知 $x > 1$，求 $y = x + \frac{4}{x-1}$ 的最小值。

**解：** 注意到 $x - 1 > 0$，令 $t = x - 1 > 0$，则 $x = t + 1$，代入得：

$$
y = (t+1) + \frac{4}{t} = t + \frac{4}{t} + 1 \geq 2\sqrt{t \cdot \frac{4}{t}} + 1 = 4 + 1 = 5
$$

当且仅当 $t = \frac{4}{t}$，即 $t = 2, x = 3$ 时取等号。故最小值为 $5$。

> **要点**：凑配技巧的核心是构造乘积为定值。通过加一项、减一项、乘一个系数等手段，把表达式变形为可以直接套用基本不等式的形式。这种配凑能力是后续学习导数求最值、数列求和（裂项相消）的重要基础。


### 2.2.7 隐性考点——"1的代换"技巧

**【技法介绍】** "1的代换"（也称为"常数代换"或"乘1法"），是指在已知条件和待求式之间，利用某个等于1的表达式进行代换，从而构造出基本不等式可用的形式。这是基本不等式应用中技巧性较强的一类问题。

**【典型题型】** 已知正数 $a, b$ 满足 $\frac{1}{a} + \frac{2}{b} = 1$，求 $2a + b$ 的最小值。

**分析：** 条件是"倒数和为1"，目标是"线性组合的最小值"。直接展开关联性不强，但若将目标式乘以"1"（即条件式的左边），则可建立联系。

**解：**

$$
\begin{aligned}
2a + b &= (2a + b) \cdot 1 = (2a + b) \cdot \left(\frac{1}{a} + \frac{2}{b}\right) \\
&= 2a \cdot \frac{1}{a} + 2a \cdot \frac{2}{b} + b \cdot \frac{1}{a} + b \cdot \frac{2}{b} \\
&= 2 + \frac{4a}{b} + \frac{b}{a} + 2 \\
&= 4 + \frac{4a}{b} + \frac{b}{a}
\end{aligned}
$$

由于 $a > 0, b > 0$，故 $\frac{4a}{b} > 0, \frac{b}{a} > 0$，可用基本不等式：

$$
\frac{4a}{b} + \frac{b}{a} \geq 2\sqrt{\frac{4a}{b} \cdot \frac{b}{a}} = 2\sqrt{4} = 4
$$

所以 $2a + b \geq 4 + 4 = 8$。

**等号成立条件：** $\frac{4a}{b} = \frac{b}{a}$，即 $b^2 = 4a^2, b = 2a$（取正）。代入条件 $\frac{1}{a} + \frac{2}{b} = 1$：

$$
\frac{1}{a} + \frac{2}{2a} = \frac{1}{a} + \frac{1}{a} = \frac{2}{a} = 1 \Rightarrow a = 2, b = 4
$$

$a = 2, b = 4$ 均为正数，满足条件。故最小值为 $8$。

> **深度理解**："1的代换"的本质是将条件式嵌入目标式——通过乘以1的方式将条件 $\frac{1}{a} + \frac{2}{b} = 1$ 引入目标式，从而创造出积为定值的结构。这体现了一种主动构造的数学思维方式。

**【变式】** 已知 $a > 0, b > 0$，且 $a + b = 1$，求 $\frac{1}{a} + \frac{1}{b}$ 的最小值。

**解：**

$$
\frac{1}{a} + \frac{1}{b} = \left(\frac{1}{a} + \frac{1}{b}\right)(a+b) = 1 + \frac{b}{a} + \frac{a}{b} + 1 = 2 + \frac{b}{a} + \frac{a}{b} \geq 2 + 2 = 4
$$

当 $a = b = \frac{1}{2}$ 时取等号。

## 2.3 二次函数与一元二次方程、不等式

### 2.3.1 "三个二次"的统一框架

高中阶段，将初中分散学习的三个对象——二次函数、一元二次方程、一元二次不等式——纳入统一视角，是本章核心的认知升级。

设二次函数 $y = ax^2 + bx + c$（$a \neq 0$），对应的方程为 $ax^2 + bx + c = 0$，对应的不等式为 $ax^2 + bx + c > 0$（或 $< 0, \geq 0, \leq 0$）。三者通过函数图像建立有机联系：

| 研究对象 | 代数表达 | 几何意义 |
|:---|:---|:---|
| 二次函数 | $y = ax^2 + bx + c$ | 抛物线 $y = ax^2 + bx + c$ 的图像 |
| 一元二次方程 | $ax^2 + bx + c = 0$ | 抛物线与 $x$ 轴交点的横坐标 |
| 一元二次不等式 | $ax^2 + bx + c > 0$ | 抛物线在 $x$ 轴上方部分的横坐标范围 |

> **来龙去脉**：方程的根和不等式的解集可以通过函数图像分析得出，因为引入了函数这一工具。函数 $y = f(x)$ 是一个映射，它的图像展示了输出值 $y$ 随输入值 $x$ 的变化关系。方程 $f(x) = 0$ 即求解输出为0时对应的输入值，即图像与横轴的交点；不等式 $f(x) > 0$ 即求解输出为正时对应的输入值范围，即图像在横轴上方的部分。这种通过函数图像分析问题的能力，是高中数学区别于初中数学的重要特征。

### 2.3.2 判别式 $\Delta$ 的几何意义

**【定义】** 对于一元二次方程 $ax^2 + bx + c = 0$（$a \neq 0$），判别式定义为

$$
\Delta = b^2 - 4ac
$$

判别式的符号直接决定了方程根的个数和性质：

| $\Delta$ 的符号 | 方程根的情况 | 二次函数图像与 $x$ 轴的位置关系 | 几何特征 |
|:---|:---|:---|:---|
| $\Delta > 0$ | 两个不等实根 $x_1, x_2$ | 与 $x$ 轴有两个不同交点 | 抛物线与 $x$ 轴相交 |
| $\Delta = 0$ | 两个相等实根 $x_1 = x_2 = -\frac{b}{2a}$ | 与 $x$ 轴有一个交点（相切） | 抛物线与 $x$ 轴相切于顶点 |
| $\Delta < 0$ | 无实根（有两个共轭复根） | 与 $x$ 轴无交点 | 抛物线完全在 $x$ 轴上方或下方 |

#### 深度理解：判别式的本质

判别式 $\Delta = b^2 - 4ac$ 的几何本质，可以从配方过程中直接读出：

$$
y = ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 + \frac{4ac - b^2}{4a} = a\left(x + \frac{b}{2a}\right)^2 - \frac{\Delta}{4a}
$$

顶点坐标为 $\left(-\frac{b}{2a}, -\frac{\Delta}{4a}\right)$。

- 当 $\Delta > 0$ 时，$-\frac{\Delta}{4a}$ 与 $a$ 异号（顶点纵坐标与开口方向相反），抛物线与 $x$ 轴有两个交点；
- 当 $\Delta = 0$ 时，顶点纵坐标为 $0$，抛物线与 $x$ 轴相切于顶点；
- 当 $\Delta < 0$ 时，$-\frac{\Delta}{4a}$ 与 $a$ 同号（顶点纵坐标与开口方向相同），抛物线完全在 $x$ 轴一侧。

> **数形结合**：判别式的符号，本质上是在比较顶点纵坐标与 $0$ 的关系。配方公式将抛物线的关键信息集中于顶点坐标。

### 2.3.3 "三个二次"关系图谱——解不等式的根本方法

解一元二次不等式的标准步骤为：先求根，再分析图像，最后写出解集。具体来说：

**【情况1】$a > 0$（开口向上）**

| 不等式 | $\Delta > 0$（两根 $x_1 < x_2$） | $\Delta = 0$（重根 $x_0$） | $\Delta < 0$（无实根） |
|:---|:---|:---|:---|
| $ax^2+bx+c > 0$ | $\{x \vert x < x_1 \text{ 或 } x > x_2\}$ | $\{x \vert x \neq x_0\}$ | $\mathbb{R}$（全体实数） |
| $ax^2+bx+c \geq 0$ | $\{x \vert x \leq x_1 \text{ 或 } x \geq x_2\}$ | $\mathbb{R}$ | $\mathbb{R}$ |
| $ax^2+bx+c < 0$ | $\{x \vert x_1 < x < x_2\}$ | $\varnothing$（空集） | $\varnothing$ |
| $ax^2+bx+c \leq 0$ | $\{x \vert x_1 \leq x \leq x_2\}$ | $\{x_0\}$（单点集） | $\varnothing$ |

记忆口诀（$a > 0$ 时）：
- **大于取两边**：$> 0$ 的解集在两根之外；
- **小于取中间**：$< 0$ 的解集在两根之间。

**【情况2】$a < 0$（开口向下）**

原则：先化为 $a > 0$ 的情形，或在图像上直接观察。

例如 $-x^2 + 3x - 2 > 0$，等价于 $x^2 - 3x + 2 < 0$（两边同乘 $-1$，不等号变向）。

也可直接分析：开口向下时，抛物线在 $x$ 轴上方的部分，对应两根之间的区间（与开口向上时相反）。

> **易错警示**：解二次不等式时，开口方向是最容易被忽视的因素。"大于取两边，小于取中间"仅对 $a > 0$ 成立。若 $a < 0$，结论正好相反（大于取中间，小于取两边）。正确做法是：要么先两边同乘 $-1$ 化为 $a > 0$，要么通过图像分析判断。


### 2.3.4 解一元二次不等式的规范步骤

**【步骤】**
1. **标准化**：确保二次项系数为正。若 $a < 0$，两边同乘 $-1$，同时改变不等号方向。
2. **求判别式**：计算 $\Delta = b^2 - 4ac$。
3. **求根**：若 $\Delta \geq 0$，求出对应方程的根 $x_1, x_2$（可用求根公式或因式分解）。
4. **定解集**：结合二次项系数的符号（即开口方向），写出不等式的解集。
5. **检验**：取解集内外的特殊值代入验证。

**【示例】** 解不等式 $-2x^2 + 5x - 3 \leq 0$。

**解：**

**第一步：标准化**
两边同乘 $-1$，不等号方向改变：

$$
2x^2 - 5x + 3 \geq 0
$$

**第二步：求判别式**

$$
\Delta = (-5)^2 - 4 \cdot 2 \cdot 3 = 25 - 24 = 1 > 0
$$

**第三步：求根**

$$
x = \frac{5 \pm \sqrt{1}}{4} = \frac{5 \pm 1}{4}
$$

得 $x_1 = \frac{4}{4} = 1, \quad x_2 = \frac{6}{4} = \frac{3}{2}$。

**第四步：定解集**

由于二次项系数 $2 > 0$（开口向上），$\geq 0$ 对应图像在 $x$ 轴上方及交点处，即两根之外：

$$
x \leq 1 \quad \text{或} \quad x \geq \frac{3}{2}
$$

**第五步：检验**
取 $x = 0$（$x < 1$ 范围内）：$-2(0)^2 + 5(0) - 3 = -3 \leq 0$，满足。
取 $x = 1.25$（$1 < x < 1.5$ 之间）：$-2(1.25)^2 + 5(1.25) - 3 = -3.125 + 6.25 - 3 = 0.125 > 0$，不满足，说明中间部分不在解集中，验证正确。

### 2.3.5 含参一元二次不等式的分类讨论——本章最难关口

当不等式中含有参数（如 $ax^2 + bx + c > 0$ 中的 $a, b, c$ 含字母），解集的形式会随参数的取值而变化。分类讨论是解决这类问题的唯一通用方法。讨论的三个维度是：

1. **开口方向**（二次项系数的符号，是否为零）
2. **判别式的符号**（有无实根，根的个数）
3. **根的大小关系**（若有多个根，谁大谁小）

#### 分类讨论的标准流程

以解不等式 $ax^2 - (a+1)x + 1 > 0$ 为例：

**【第一步：判断类型——是否为二次？】**

二次项系数为 $a$，需要讨论：

- **Case 1：$a = 0$**（退化为一次不等式）
  
  原不等式变为 $-x + 1 > 0$，即 $x < 1$。

- **Case 2：$a \neq 0$**（确为二次不等式）

**【第二步：分解因式（或配方），分析根的情况】**

尝试因式分解：$ax^2 - (a+1)x + 1 = (ax - 1)(x - 1)$。

验证：$(ax-1)(x-1) = ax^2 - ax - x + 1 = ax^2 - (a+1)x + 1$。成立。

所以方程 $ax^2 - (a+1)x + 1 = 0$ 的两根为 $x_1 = \frac{1}{a}, x_2 = 1$。

**【第三步：按开口方向分类，结合根的大小】**

**Case 2a：$a > 0$（开口向上）**

此时需要比较 $\frac{1}{a}$ 与 $1$ 的大小：

- **Case 2a(i)：$a > 1$**，则 $0 < \frac{1}{a} < 1$。不等式 $(ax-1)(x-1) > 0$，即 $a(x-\frac{1}{a})(x-1) > 0$。由于 $a > 0$，等价于 $(x-\frac{1}{a})(x-1) > 0$。"大于取两边"，解集为 $x < \frac{1}{a}$ 或 $x > 1$。

- **Case 2a(ii)：$a = 1$**，则 $\frac{1}{a} = 1 = x_2$。方程有等根 $x = 1$。不等式化为 $(x-1)^2 > 0$，解集为 $\{x \vert x \neq 1\}$。

- **Case 2a(iii)：$0 < a < 1$**，则 $\frac{1}{a} > 1$。解集为 $x < 1$ 或 $x > \frac{1}{a}$。

**Case 2b：$a < 0$（开口向下）**

两根 $\frac{1}{a}$ 与 $1$：由于 $a < 0$，$\frac{1}{a} < 0 < 1$，所以 $\frac{1}{a} < 1$ 恒成立。

不等式 $(ax-1)(x-1) > 0$，展开得 $a(x-\frac{1}{a})(x-1) > 0$。由于 $a < 0$，两边除以 $a$（负数），不等号方向改变：

$$
(x - \frac{1}{a})(x - 1) < 0
$$

"小于取中间"，且 $\frac{1}{a} < 1$，解集为 $\frac{1}{a} < x < 1$。

**【汇总】**

| $a$ 的范围 | 解集 |
|:---|:---|
| $a < 0$ | $\frac{1}{a} < x < 1$ |
| $a = 0$ | $x < 1$ |
| $0 < a < 1$ | $x < 1$ 或 $x > \frac{1}{a}$ |
| $a = 1$ | $x \neq 1$ |
| $a > 1$ | $x < \frac{1}{a}$ 或 $x > 1$ |

> **思想方法——分类讨论**：含参问题的分类讨论，关键在于找到分类的分界点。本例中，分界点是 $a = 0$（是否二次）和 $a = 1$（两根大小关系的转折点）。分类讨论须满足完备性与互斥性：覆盖所有可能情形，且各情形之间互不重叠。这一方法在后续解析几何（直线斜率是否存在）、导数（单调区间分界点）等问题中广泛应用。

### 2.3.6 恒成立问题——参数范围的求解

**【问题类型】** 求参数 $a$ 的范围，使得不等式对所有实数 $x$（或对某个区间内所有 $x$）恒成立。

**【类型1】$ax^2 + bx + c > 0$ 对所有 $x \in \mathbb{R}$ 恒成立**

分析：二次函数图像始终在 $x$ 轴上方。

- 若 $a = 0$：退化为 $bx + c > 0$，不可能对所有 $x$ 恒成立（一次函数图像是一条直线，必穿过 $x$ 轴）。
- 若 $a \neq 0$：必须满足 $\begin{cases} a > 0 \quad \text{（开口向上）} \\ \Delta < 0 \quad \text{（与 }x\text{ 轴无交点）} \end{cases}$

**【类型2】$ax^2 + bx + c \geq 0$ 对所有 $x \in \mathbb{R}$ 恒成立**

- 若 $a = 0$：需 $bx + c \geq 0$ 恒成立，仅当 $b = 0$ 且 $c \geq 0$ 时成立。
- 若 $a \neq 0$：必须满足 $\begin{cases} a > 0 \\ \Delta \leq 0 \end{cases}$

**【类型3】$ax^2 + bx + c > 0$ 对 $x \in [m, n]$ 恒成立**

此时转化为区间上的最值问题：二次函数在区间 $[m, n]$ 上的最小值大于 $0$。

求最小值需考虑对称轴 $x = -\frac{b}{2a}$ 与区间的位置关系：

| 对称轴位置 | 最小值位置 | 最小值 |
|:---|:---|:---|
| $-\frac{b}{2a} < m$（对称轴在区间左侧） | 在 $x = m$ 处取到 | $f(m)$ |
| $m \leq -\frac{b}{2a} \leq n$（对称轴在区间内） | 在顶点处取到 | $f(-\frac{b}{2a}) = \frac{4ac - b^2}{4a}$ |
| $-\frac{b}{2a} > n$（对称轴在区间右侧） | 在 $x = n$ 处取到 | $f(n)$ |

> **隐性考点**：区间上的恒成立问题，最容易出错的是忽略对称轴的位置，直接套用"$\Delta < 0$"的结论。$\Delta < 0$ 保证的是"对所有实数恒成立"，但在有限区间上，即使 $\Delta > 0$（有实根），只要实根不在区间内，函数在区间上仍可能恒正。例如 $f(x) = x^2 - 3x + 2 = (x-1)(x-2)$，在区间 $[3, 4]$ 上 $f(x) > 0$ 恒成立，尽管 $\Delta = 1 > 0$。

### 2.3.7 二次函数在闭区间上的最值

二次函数 $f(x) = ax^2 + bx + c$（$a \neq 0$）在闭区间 $[m, n]$ 上的最值，由顶点位置与区间位置共同决定：

**【开口向上（$a > 0$）】**

| 对称轴位置 | 最大值 | 最小值 |
|:---|:---|:---|
| $-\frac{b}{2a} \leq \frac{m+n}{2}$（对称轴在中点左侧或重合） | $f(n)$ | 顶点处或端点 |
| $-\frac{b}{2a} > \frac{m+n}{2}$（对称轴在中点右侧） | $f(m)$ | 顶点处或端点 |

实际上更简洁的记忆：
- **最小值**：若对称轴在区间内，最小值为顶点值 $f(-\frac{b}{2a})$；否则为离对称轴较近的端点值。
- **最大值**：开口向上时，最大值总在离对称轴较远的端点处取到。

**【开口向下（$a < 0$）】**

- **最大值**：若对称轴在区间内，最大值为顶点值；否则为离对称轴较近的端点值。
- **最小值**：总在离对称轴较远的端点处取到。

> **知识串联**：二次函数在闭区间上的最值，是高中数学含参讨论的经典模型。后续学习三角函数在区间上的最值、导数求最值时，核心思路一致：确定临界点（对称轴、导数为零的点），比较临界点与端点的函数值。

## 四、知识串联——本章与前后知识的关联

### 4.1 基本不等式与后续求最值的统一性

**【二次函数顶点最值 vs. 基本不等式最值】**

二次函数在顶点处取最值（$x = -\frac{b}{2a}$ 时 $y_{\min} = \frac{4ac-b^2}{4a}$），与基本不等式"和定积最大、积定和最小"是两套不同的工具，但二者在本质上是统一的。

考虑 $y = x + \frac{k}{x}$（$k > 0, x > 0$）：
- **基本不等式法**：$x + \frac{k}{x} \geq 2\sqrt{k}$，当 $x = \sqrt{k}$ 时取等。
- **导数法**（高二学）：$y' = 1 - \frac{k}{x^2} = 0 \Rightarrow x = \sqrt{k}$，此时 $y_{\min} = 2\sqrt{k}$。
- **函数图像**：这是"对勾函数"，在 $x = \sqrt{k}$ 处有唯一的极小值点。

> **本质揭示**：基本不等式给出了对勾函数极值点的坐标。当等号成立条件 $x = \frac{k}{x}$（即 $x = \sqrt{k}$）满足时，基本不等式给出的下界恰好是函数的真实最小值。如果等号取不到，说明最低点不在定义域内，此时需要用函数的单调性（或导数）来判断最值。

### 4.2 三个二次与后续课程的关联

| 后续课程 | 关联内容 |
|:---|:---|
| 集合（第一章） | 不等式的解集用集合或区间表示；空集、全集的概念 |
| 函数概念（第三章） | 函数 $y = f(x)$ 是三个二次的统一载体；定义域、值域 |
| 指数对数函数（第四章） | 指数不等式、对数不等式的求解，最终转化为二次不等式 |
| 三角函数（第五章） | 三角函数在区间上的最值，思路与二次函数完全一致 |
| 数列（选择性必修） | 等差等比数列的最值问题，常用基本不等式 |
| 导数（选择性必修） | 求函数最值的核心工具；极值点与基本不等式等号条件的联系 |
| 解析几何（选择性必修） | 圆锥曲线的最值问题，常用基本不等式或二次函数求最值 |

### 4.3 不等式性质与逻辑推理

不等式的传递性（$a > b, b > c \Rightarrow a > c$）是数学证明中放缩法的逻辑基础。后续证明不等式、估计数列通项的范围、判断级数收敛性等，都依赖不等关系的传递。

## 五、隐性考点深度剖析

### 5.1 隐性考点①：基本不等式的"1的代换"（已详述于2.2.7）

**补充说明**："1的代换"还有更隐蔽的形式。例如：

已知 $x > 0, y > 0$，且 $x + 2y = 1$，求 $\frac{1}{x} + \frac{1}{y}$ 的最小值。

**解：**

$$
\frac{1}{x} + \frac{1}{y} = \left(\frac{1}{x} + \frac{1}{y}\right)(x + 2y) = 1 + \frac{2y}{x} + \frac{x}{y} + 2 = 3 + \frac{2y}{x} + \frac{x}{y}
$$

由基本不等式：

$$
\frac{2y}{x} + \frac{x}{y} \geq 2\sqrt{\frac{2y}{x} \cdot \frac{x}{y}} = 2\sqrt{2}
$$

所以 $\frac{1}{x} + \frac{1}{y} \geq 3 + 2\sqrt{2}$。

等号成立当 $\frac{2y}{x} = \frac{x}{y}$，即 $x^2 = 2y^2, x = \sqrt{2}y$。代入 $x + 2y = 1$：$\sqrt{2}y + 2y = 1, y = \frac{1}{2+\sqrt{2}} = \frac{2-\sqrt{2}}{2}, x = \frac{\sqrt{2}(2-\sqrt{2})}{2} = \sqrt{2} - 1$。均为正数，条件满足。

### 5.2 隐性考点②：含参二次不等式的"三维度分类"

再次强调，含参二次不等式的分类讨论必须系统、完整。最容易遗漏的是：

**（1）忘记讨论二次项系数是否为0**

例如解 $kx^2 + 2x + 1 > 0$，若直接当二次不等式处理，会漏掉 $k = 0$ 时退化为一次不等式 $2x + 1 > 0$ 的情形。

**（2）能因式分解时漏看根的大小**

例如 $(x-a)(x-2a) > 0$，两根为 $a$ 和 $2a$。当 $a > 0$ 时，$a < 2a$，解集为 $x < a$ 或 $x > 2a$；当 $a < 0$ 时，$a > 2a$，解集为 $x < 2a$ 或 $x > a$。若不做此分类，直接写"$x < a$ 或 $x > 2a$"就错了。

**（3）判别式等于0时的解集写法**

$(x-a)^2 > 0$ 的解集是 $\{x \vert x \neq a\}$，不是"$x > a$ 或 $x < a$"（虽然等价，但要理解本质），更不是"全体实数"。

### 5.3 隐性考点③：恒成立问题的区间端点陷阱

**问题**：$x^2 + ax + 1 \geq 0$ 对所有 $x \in [0, 2]$ 恒成立，求 $a$ 的取值范围。

**常见错误**：直接用 $\Delta \leq 0$，得 $a^2 - 4 \leq 0$，$-2 \leq a \leq 2$。

**错误原因**：$\Delta \leq 0$ 保证的是"对所有实数 $x$ 恒成立"，但题目只要求在区间 $[0, 2]$ 上恒成立。后者条件更宽松，$a$ 的范围应该更大。

**正确解法：**

令 $f(x) = x^2 + ax + 1$，对称轴 $x = -\frac{a}{2}$。

**Case 1：$-\frac{a}{2} \leq 0$（即 $a \geq 0$）**

$f(x)$ 在 $[0, 2]$ 上单调递增，最小值为 $f(0) = 1 \geq 0$，恒满足。故 $a \geq 0$ 均可。

**Case 2：$0 < -\frac{a}{2} < 2$（即 $-4 < a < 0$）**

最小值在顶点处：$f(-\frac{a}{2}) = (-\frac{a}{2})^2 + a(-\frac{a}{2}) + 1 = \frac{a^2}{4} - \frac{a^2}{2} + 1 = 1 - \frac{a^2}{4} \geq 0$。

解得 $a^2 \leq 4$，即 $-2 \leq a \leq 2$。结合 $-4 < a < 0$，得 $-2 \leq a < 0$。

**Case 3：$-\frac{a}{2} \geq 2$（即 $a \leq -4$）**

$f(x)$ 在 $[0, 2]$ 上单调递减，最小值为 $f(2) = 4 + 2a + 1 = 5 + 2a \geq 0$。

解得 $a \geq -\frac{5}{2} = -2.5$。但与 $a \leq -4$ 矛盾，无解。

**综上**：$a \geq -2$。

对比错误答案 $[-2, 2]$，正确答案应为 $[-2, +\infty)$。

> **隐性考点**：在区间上恒成立的问题，核心是把"恒成立"转化为"最小值 $\geq 0$"，然后分类讨论对称轴位置求最小值。直接用判别式是在加强条件，得到的范围会偏小。

## 六、易错警示——从认知层面剖析错误根源

### 6.1 易错点①：基本不等式等号取不到时强行使用

**【典型错误】** 求 $f(x) = x + \frac{1}{x}$ 在 $x \in (2, +\infty)$ 上的最小值。

**错误解法**：$f(x) = x + \frac{1}{x} \geq 2\sqrt{x \cdot \frac{1}{x}} = 2$，所以最小值为 $2$。

**错误根源**：基本不等式给出的"$\geq 2$"是正确的下界估计，但等号成立条件是 $x = \frac{1}{x}$，即 $x = 1$。而 $x = 1$ 不在定义域 $(2, +\infty)$ 内。因此 $2$ 是下界，但不可达，不是最小值。

**正确解法**：$f(x)$ 在 $(2, +\infty)$ 上单调递增（可用定义证明：设 $x_1 > x_2 > 2$，则 $f(x_1) - f(x_2) = (x_1 - x_2)(1 - \frac{1}{x_1 x_2}) > 0$，因为 $x_1 x_2 > 4 > 1$）。所以 $f(x) > f(2) = 2.5$。函数在 $(2, +\infty)$ 上没有最小值，只有下确界 $2.5$（若区间是闭区间 $[2, +\infty)$，则最小值为 $2.5$）。

> **认知纠偏**：使用基本不等式后，必须验证三个条件：一正满足吗？二定满足吗？等号能取到吗？任何一个不满足，结论就不能直接使用。

### 6.2 易错点②：解二次不等式时忽视开口方向

**【典型错误】** 解不等式 $-x^2 + x + 6 > 0$。

**错误解法**：因式分解得 $-(x-3)(x+2) > 0$，即 $(x-3)(x+2) > 0$（此处错误，漏掉了不等号变向），解得 $x < -2$ 或 $x > 3$。

**正确解法**：

方法一：先标准化

$$
-x^2 + x + 6 > 0 \Leftrightarrow x^2 - x - 6 < 0 \Leftrightarrow (x-3)(x+2) < 0
$$

解得 $-2 < x < 3$。

方法二：直接分析
$-x^2 + x + 6 = -(x-3)(x+2) > 0$，即 $(x-3)(x+2) < 0$。

> **认知纠偏**：解二次不等式的基本原则是——永远先让二次项系数为正。这不仅是习惯的养成，更是逻辑上的安全保障。一旦二次项系数为正，"大于取两边，小于取中间"的口诀才严格成立。

### 6.3 易错点③：区间端点的开闭判断

**【典型错误】** 解不等式 $x^2 - 4x + 4 \leq 0$。

**错误写法**：$(x-2)^2 \leq 0$，解集为 $(-\infty, 2] \cup [2, +\infty)$。

**正确理解**：$(x-2)^2 \leq 0$ 且 $(x-2)^2 \geq 0$（平方非负），所以只能是 $(x-2)^2 = 0$，即 $x = 2$。解集为 $\{2\}$，也可写为 $[2, 2]$（单点区间）。

**【另一典型错误】** 解不等式 $\frac{x-1}{x-2} \geq 0$（虽非二次不等式，但端点判断思想一致）。

**错误解法**：化为 $(x-1)(x-2) \geq 0$，解得 $x \leq 1$ 或 $x \geq 2$。

**错误根源**：$x = 2$ 使分母为零，不在定义域内，不能用等号。

**正确解集**：$x \leq 1$ 或 $x > 2$（$x = 2$ 处是开区间）。

> **认知纠偏**：区间端点的开闭，取决于该点是否满足原始不等式。若不等式含等号（$\geq$ 或 $\leq$），且该点代入后等号成立、表达式有意义，则取闭区间；若不等式是严格不等（$>$ 或 $<$），或该点使表达式无意义（分母为零、根号内为负等），则取开区间。

### 6.4 易错点④：解集写成不等式而非集合/区间

**【规范写法】**

- 解集必须用集合 $\{x \vert \dots\}$ 或区间表示。
- 不等式 $x^2 - 3x + 2 < 0$ 的解集是 $\{x \vert 1 < x < 2\}$ 或区间 $(1, 2)$。
- 不能直接写 "$1 < x < 2$"作为答案（虽然意思对，但这不是解集的规范形式）。

### 6.5 易错点⑤：含参讨论时遗漏边界情况

**【典型错误】** 讨论 $ax^2 + x + 1 > 0$ 时，只分 $a > 0$ 和 $a < 0$ 两种情况，忘记 $a = 0$。

**根源**：二次不等式的"二次"二字，本身就预设了 $a \neq 0$。但含参时，参数可能恰好使二次项系数为零。"参数化导致类型退化"是含参问题的核心难点，需要在讨论的一开始就检验退化情形。

## 七、数学思想方法提炼

### 7.1 数形结合思想

**【核心内涵】** 把代数问题与几何图形相互转化，以几何直观辅助代数分析，以代数精确性刻画几何性质。

**【本章体现】**
- 二次不等式的解集 $\Leftrightarrow$ 二次函数图像在 $x$ 轴上方/下方的横坐标范围；
- 方程的根 $\Leftrightarrow$ 函数图像与 $x$ 轴的交点横坐标；
- 判别式 $\Delta$ 的符号 $\Leftrightarrow$ 抛物线与 $x$ 轴交点的个数。

**【操作步骤】** 画抛物线草图，标出与 $x$ 轴的交点（若有），观察所需区域（上方或下方），将横坐标范围转化为解集。

### 7.2 分类讨论思想

**【核心内涵】** 当问题包含可变因素（参数）时，按照某种标准划分若干类别，在每一类中分别求解，最后汇总。

**【本章体现】**
- 含参二次不等式的讨论：按开口方向、判别式、根的大小分类；
- 二次函数在区间上的最值：按对称轴与区间的位置关系分类。

**【分类原则】**
1. **标准统一**：同一层级的分类使用同一标准；
2. **不重不漏**：各类别之间互斥，且覆盖所有可能；
3. **层次清晰**：复杂问题可分多级讨论，如先按 $a = 0$ 与 $a \neq 0$ 分，再在 $a \neq 0$ 下按 $\Delta$ 的符号分。

### 7.3 转化与化归思想

**【核心内涵】** 将待解决的问题，通过某种变换，转化为已经解决或较易解决的问题。

**【本章体现】**
- 解不等式 $\Leftrightarrow$ 解方程 + 函数图像分析（不等式转化为方程+函数）；
- 含参不等式恒成立 $\Leftrightarrow$ 函数在区间上的最值问题（不等式转化为函数）；
- 作差法比较大小 $\Leftrightarrow$ 判断差的符号（二元问题转化为一元问题）；
- 二次项系数为负 $\Leftrightarrow$ 两边同乘 $-1$ 化为正（非标准形式转化为标准形式）。

### 7.4 函数与方程思想

**【核心内涵】** 用函数的观点看方程和不等式，方程的根是函数的零点，不等式的解集是函数值满足某种条件的自变量范围。

**【本章体现】** "三个二次"的统一正是这一思想的典型应用。本章之后，解任何不等式的基本套路都是：构造函数 $\rightarrow$ 找零点 $\rightarrow$ 分析单调性/符号变化 $\rightarrow$ 确定解集。这一方法将在指数对数不等式、三角不等式、导数不等式中反复使用。

### 7.5 配方法——贯穿始终的代数技巧

配方不仅是推导求根公式、判别式的工具，更是一种构造性的代数思想：

$$
ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 + \frac{4ac-b^2}{4a}
$$

配方将一般二次式转化为"完全平方 + 常数"的形式，使顶点位置、最值、判别式的符号一目了然。后续学习圆的方程、椭圆方程、二次型标准化等，配方都是核心手段。

        └────────────┬──────────────┬───────────────┘

$$
\text{不等式性质} \xrightarrow{\text{作差法}} \text{基本不等式} \xrightarrow{\text{求最值}} \text{函数最值问题} \xleftarrow{\text{数形结合}} \text{二次函数图像}
$$

"三个二次"将函数、方程、不等式三者统一于抛物线图像之上，是高中数学"数形结合"思想的集中体现。

## 九、核心公式与结论速查

| 公式/结论 | 条件 | 内容 |
|:---|:---|:---|
| 实数比较 | $a, b \in \mathbb{R}$ | $a > b \Leftrightarrow a - b > 0$ |
| 基本不等式 | $a > 0, b > 0$ | $\frac{a+b}{2} \geq \sqrt{ab}$，等号 $\Leftrightarrow a = b$ |
| 平方形式 | $a, b \in \mathbb{R}$ | $a^2 + b^2 \geq 2ab$ |
| 倒数形式 | $a, b$ 同号 | $\frac{a}{b} + \frac{b}{a} \geq 2$ |
| 求根公式 | $a \neq 0, \Delta \geq 0$ | $x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$ |
| 判别式 | $a \neq 0$ | $\Delta = b^2 - 4ac$；$\Delta > 0 \Leftrightarrow$ 两不等实根；$\Delta = 0 \Leftrightarrow$ 两等实根；$\Delta < 0 \Leftrightarrow$ 无实根 |
| 韦达定理 | $\Delta \geq 0$ | $x_1 + x_2 = -\frac{b}{a}, \quad x_1 x_2 = \frac{c}{a}$ |
| 顶点坐标 | $a \neq 0$ | $\left(-\frac{b}{2a}, \frac{4ac-b^2}{4a}\right)$ |
| 二次不等式（$a > 0$） | $\Delta > 0$，根 $x_1 < x_2$ | $> 0$ 取两边 $(-\infty, x_1) \cup (x_2, +\infty)$；$< 0$ 取中间 $(x_1, x_2)$ |

> 2. **会算**：熟练运用基本不等式求最值，严格检验"一正二定三相等"；
> 3. **会讨论**：面对含参问题，心中有一张清晰的分类讨论路线图；
