# 第八章 成对数据的统计分析
---

## 一、来龙去脉：相关分析的历史源流

### 1.1 相关概念的诞生：高尔顿与优生学研究

19世纪后半叶，英国科学家弗朗西斯·高尔顿（Francis Galton, 1822–1911）在研究人类遗传现象时，首次系统性地引入了"相关"（correlation）这一统计概念。高尔顿致力于优生学（eugenics）研究，试图量化亲代与子代之间身体特征的关联程度。他收集了大量家庭身高数据，发现父母的身高与子女的身高之间存在某种数量上的伴随关系，但这种关系并非确定性的函数关系——高个父母的子女平均而言仍较高，却未必更高；矮个父母的子女平均而言仍较矮，却未必更矮。这种既非完全确定、又非完全独立的数量关系，促使高尔顿提出了"相关"的概念来描述两个变量之间伴随变化的趋势。

高尔顿最初采用的方法是基于中位数和四分位数的图形分析法，但他逐渐意识到需要一种精确的数值度量来刻画变量间线性关联的强弱。1888年，高尔顿在论文《相关及其主要来自人体的度量》中，首次给出了相关系数的雏形——他将其命名为"指数"（index），定义为两个变量离差乘积的平均值与各自离差平方和几何平均之比。这一工作奠定了线性相关分析的基础。

高尔顿的学生卡尔·皮尔逊（Karl Pearson, 1857–1936）在此基础上进行了严格的数学化处理。1896年，皮尔逊正式提出了积矩相关系数（product-moment correlation coefficient）的公式：

$$r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \sum_{i=1}^{n}(y_i - \bar{y})^2}}$$

这一公式至今仍是统计学中最常用的相关系数定义。皮尔逊不仅完善了计算体系，更重要的是建立了相关的数学理论框架，将其纳入了正态分布理论与大样本理论的体系之中，使相关分析从描述性工具转变为严格的统计推断方法。

### 1.2 "回归"一词的起源：高尔顿的"向均值回归"现象

"回归"（regression）一词在统计学中的含义与日常用语中的"倒退"或"退回"有本质不同。该术语源于高尔顿1886年的经典研究《世代身高中向平庸的回归》。高尔顿在分析父母身高与子女身高的关系时，发现了一个引人注目的现象：当父母身高显著高于群体平均值时，其子女的平均身高虽然也高于群体平均，但相对于父母而言"回落"了；反之，当父母身高显著低于群体平均值时，其子女的平均身高虽然也低于群体平均，但相对于父母而言"回升"了。

高尔顿将这一现象命名为"向均值回归"（regression toward the mean）。其产生的原因在于：身高是多基因遗传性状，子代的身高不仅受父母遗传因素影响，还受大量随机因素（其他基因组合、营养、环境等）的综合作用。从概率论角度看，设亲代身高为$X$，子代身高为$Y$，若$(X, Y)$服从二元正态分布，则条件期望$E(Y|X=x)$满足：

$$E(Y|X=x) = \mu_Y + \rho \frac{\sigma_Y}{\sigma_X}(x - \mu_X)$$

其中$|\rho| < 1$（假设不完全相关），故当$x > \mu_X$时，$E(Y|X=x) < x$（假设$\sigma_X \approx \sigma_Y$），即表现出向均值的"回归"。

此后，英国遗传学家兼统计学家尤尔（G. Udny Yule）在1897年将"回归"一词推广至一般统计语境，用以描述一个变量对另一个变量的条件期望的线性依赖关系。英国生物统计学家皮尔逊及其合作者韦尔登（W. F. R. Weldon）进一步发展了回归线的计算方法，使回归分析成为独立于相关分析的统计方法论体系。

### 1.3 最小二乘法的历史：勒让德与高斯之争

最小二乘法（method of least squares）是求解线性回归参数估计的核心算法，其历史可追溯至18世纪末的法国数学家阿德里安-马里·勒让德（Adrien-Marie Legendre, 1752–1833）。1805年，勒让德在其著作《计算彗星轨道的新方法》附录中，首次公开发表了最小二乘法。他在处理由多余观测方程（overdetermined system）导致的矛盾方程组时，提出了以"残差平方和最小"为准则来确定未知参数的思想。勒让德明确指出："在所有原理中，我认为应当优先考虑使误差平方和最小的原理。"他运用这一方法成功计算了彗星轨道参数。

然而，最小二乘法的优先权争议成为科学史上著名的公案。德国数学家卡尔·弗里德里希·高斯（Carl Friedrich Gauss, 1777–1855）声称自己早在1794年（时年17岁）就已发现该方法，并于1795年开始在天文计算中系统使用，但直至1809年才在著作《天体运动论》（*Theoria Motus Corporum Coelestium*）中公开发表。高斯不仅重新陈述了最小二乘法，更重要的是为其提供了概率论基础——他证明了在误差服从正态分布的假设下，最小二乘估计等价于最大似然估计，从而赋予该方法以统计最优性。

1809年至1812年间，拉普拉斯（Pierre-Simon Laplace）从中心极限定理出发，证明了最小二乘估计在大样本下的优良性质，进一步巩固了该方法在数理统计学中的核心地位。19世纪末，俄国数学家马尔可夫（Andrey Markov）在1900年前后完成了高斯-马尔可夫定理（Gauss-Markov theorem）的严格证明：在经典线性回归模型的基本假设下（误差零均值、同方差、不相关），最小二乘估计是最优线性无偏估计（BLUE, Best Linear Unbiased Estimator），即在线性无偏估计类中具有最小方差。

### 1.4 卡方检验的诞生：皮尔逊1900年的奠基性贡献

20世纪初，统计学正从描述性统计向推断统计转型。1900年，卡尔·皮尔逊在《哲学杂志》发表了里程碑式的论文《论拟合优度与同质性检验中的某个准则》，首次系统提出了卡方（$\chi^2$）检验方法。

在此之前，统计学家面临一个根本性难题：如何判断一组观测数据与某个理论分布（如正态分布）的偏离是由随机波动引起，还是由理论模型的不恰当引起？皮尔逊创造性地构造了如下统计量：

$$\chi^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i}$$

其中$O_i$为第$i$类的观测频数，$E_i$为在原假设成立时的期望频数。皮尔逊运用多维正态近似与几何直觉，证明了当样本量足够大时，该统计量近似服从自由度为$k - 1 - m$（$m$为估计参数个数）的$\chi^2$分布。这一成果为拟合优度检验、独立性检验和同质性检验提供了统一的理论框架。

在列联表分析方面，皮尔逊的方法使研究者能够判断两个分类变量之间是否存在关联。1900年之后，英国统计学家耶茨（F. Yates）在1934年提出了连续性校正（Yates' correction for continuity），费希尔（R. A. Fisher）在1922年至1924年间精确分析了$2 \times 2$列联表的抽样分布问题，进一步完善了小样本情形下的检验方法。

## 二、基础精讲：核心概念的严格表述

### 2.1 散点图：成对数据可视化的基础工具

散点图（scatter plot）是将$n$组成对观测数据$(x_i, y_i)$（$i = 1, 2, \ldots, n$）在平面直角坐标系中以点的形式表示的统计图形。其横轴对应自变量$x$，纵轴对应因变量$y$（在纯相关分析中，两个变量的地位对称）。

散点图的核心功能包括：

1. **趋势识别**：通过观察点的整体走向，初步判断变量间是否存在线性趋势、非线性趋势或无显著趋势。
2. **方向判断**：若点群呈现从左下到右上的分布，提示正相关；若呈现从左上到右下的分布，提示负相关。
3. **强度感知**：点群分布越集中于某条假想直线附近，提示线性关联越强；点群分布越分散，提示线性关联越弱。
4. **异常值检测**：远离主体点群的孤立点可能为异常值（outliers），其对相关系数和回归参数估计具有显著影响，需结合专业背景审慎处理。
5. **模型预设**：散点图形态为后续建模提供依据——若呈现明显非线性模式，则应考虑非线性模型或变量变换。

需要特别指出，散点图本质上是探索性数据分析（EDA, Exploratory Data Analysis）工具，其结论具有主观性与描述性，不能替代严格的统计推断。

### 2.2 样本相关系数：线性关联的数值度量

#### 2.2.1 定义与计算公式

对于$n$组成对数据$(x_i, y_i)$，样本皮尔逊相关系数（sample Pearson correlation coefficient）定义为：

$$r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \sum_{i=1}^{n}(y_i - \bar{y})^2}}$$

其中$\bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i$，$\bar{y} = \frac{1}{n}\sum_{i=1}^{n}y_i$分别为两组数据的样本均值。

引入如下简记符号：

$$L_{xx} = \sum_{i=1}^{n}(x_i - \bar{x})^2 = \sum_{i=1}^{n}x_i^2 - n\bar{x}^2$$

$$L_{yy} = \sum_{i=1}^{n}(y_i - \bar{y})^2 = \sum_{i=1}^{n}y_i^2 - n\bar{y}^2$$

$$L_{xy} = \sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y}) = \sum_{i=1}^{n}x_i y_i - n\bar{x}\bar{y}$$

则相关系数可简写为：

$$r = \frac{L_{xy}}{\sqrt{L_{xx} L_{yy}}}$$

#### 2.2.2 取值范围的严格证明

**定理**：样本相关系数满足$|r| \leq 1$。

**证明**：由柯西-施瓦茨不等式（Cauchy-Schwarz inequality），对于任意实数序列$\{a_i\}$和$\{b_i\}$，有：

$$\left(\sum_{i=1}^{n} a_i b_i\right)^2 \leq \left(\sum_{i=1}^{n} a_i^2\right)\left(\sum_{i=1}^{n} b_i^2\right)$$

令$a_i = x_i - \bar{x}$，$b_i = y_i - \bar{y}$，代入得：

$$\left[\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})\right]^2 \leq \sum_{i=1}^{n}(x_i - \bar{x})^2 \cdot \sum_{i=1}^{n}(y_i - \bar{y})^2$$

两边同除以$L_{xx} \cdot L_{yy} > 0$（假设两组数据均非常数），得$r^2 \leq 1$，即$|r| \leq 1$。$\square$

**等号成立条件**：当且仅当存在不全为零的常数$\lambda, \mu$使得$\lambda(x_i - \bar{x}) + \mu(y_i - \bar{y}) = 0$对所有$i$成立，即所有样本点严格落在一条直线上。

#### 2.2.3 取值含义的精确解释

- $r = 1$：完全正线性相关，所有样本点精确落在斜率为正的直线上。
- $r = -1$：完全负线性相关，所有样本点精确落在斜率为负的直线上。
- $r = 0$：零线性相关，样本数据无线性趋势（但可能存在非线性关系）。
- $0 < r < 1$：正线性相关，$x$增大时$y$有线性增大的趋势，$r$越接近1线性关联越强。
- $-1 < r < 0$：负线性相关，$x$增大时$y$有线性减小的趋势，$|r|$越接近1线性关联越强。

#### 2.2.4 相关系数与标准化变量的关系

若对原始数据进行标准化变换：

$$x_i^* = \frac{x_i - \bar{x}}{s_x}, \quad y_i^* = \frac{y_i - \bar{y}}{s_y}$$

其中$s_x = \sqrt{L_{xx}/(n-1)}$，$s_y = \sqrt{L_{yy}/(n-1)}$为样本标准差，则标准化数据的相关系数满足：

$$r = \frac{1}{n-1}\sum_{i=1}^{n} x_i^* y_i^*$$

这表明相关系数本质上是标准化后变量乘积的均值，消除了量纲和数量级的影响，使不同数据集之间的关联强度具有可比性。

### 2.3 一元线性回归模型：统计建模的入门框架

#### 2.3.1 模型的严格数学表述

一元线性回归模型（simple linear regression model）的严格表述为：

$$Y = bx + a + \varepsilon$$

其中：
- $Y$为因变量（响应变量、被解释变量），是可观测的随机变量。
- $x$为自变量（解释变量、预报变量），在本章框架中视为非随机的确定性变量（设计变量情形）。
- $a$为截距参数（intercept），$b$为斜率参数（slope），二者为待估计的未知常数。
- $\varepsilon$为随机误差项（random error），是不可观测的随机变量，满足以下经典假设：
  1. **零均值性**：$E(\varepsilon) = 0$；
  2. **同方差性**：$Var(\varepsilon) = \sigma^2 < \infty$（$\sigma^2$未知但与$x$无关）；
  3. **独立性**：各观测对应的$\varepsilon_i$相互独立；
  4. **正态性**（用于推断时）：$\varepsilon_i \sim N(0, \sigma^2)$。

对于第$i$组观测$(x_i, y_i)$，模型具体化为：

$$y_i = bx_i + a + \varepsilon_i, \quad i = 1, 2, \ldots, n$$

**重要区分**：模型中的$Y$是随机变量（含随机误差），而观测值$y_i$是$Y$的具体实现（realization）。回归分析的目标是基于观测样本$(x_i, y_i)$估计参数$a, b$，进而建立经验回归方程$\hat{y} = \hat{b}x + \hat{a}$。

#### 2.3.2 最小二乘法估计的严格推导

最小二乘法（ordinary least squares, OLS）的核心思想是：选择参数估计值$\hat{a}, \hat{b}$，使得所有观测点到回归直线的纵向距离（残差）的平方和达到最小。

定义**残差平方和**（residual sum of squares, RSS）为：

$$Q(a, b) = \sum_{i=1}^{n}(y_i - bx_i - a)^2$$

$\hat{a}, \hat{b}$是$Q(a, b)$的最小值点。由于$Q(a, b)$是关于$a, b$的二元二次函数且二次项系数为正，其极小值存在唯一。

**推导过程**：

**第一步**：对$a$求偏导并令其为零。

$$\frac{\partial Q}{\partial a} = \sum_{i=1}^{n} 2(y_i - bx_i - a) \cdot (-1) = 0$$

$$\sum_{i=1}^{n}(y_i - bx_i - a) = 0$$

$$\sum_{i=1}^{n}y_i - b\sum_{i=1}^{n}x_i - na = 0$$

$$n\bar{y} - nb\bar{x} - na = 0$$

解得：

$$\hat{a} = \bar{y} - \hat{b}\bar{x} \tag{1}$$

此式表明回归直线必过样本中心点$(\bar{x}, \bar{y})$。

**第二步**：对$b$求偏导并令其为零。

$$\frac{\partial Q}{\partial b} = \sum_{i=1}^{n} 2(y_i - bx_i - a) \cdot (-x_i) = 0$$

$$\sum_{i=1}^{n}x_i(y_i - bx_i - a) = 0$$

将式(1)代入（以$\hat{a}, \hat{b}$代$a, b$）：

$$\sum_{i=1}^{n}x_i[y_i - \hat{b}x_i - (\bar{y} - \hat{b}\bar{x})] = 0$$

$$\sum_{i=1}^{n}x_i[(y_i - \bar{y}) - \hat{b}(x_i - \bar{x})] = 0$$

$$\sum_{i=1}^{n}x_i(y_i - \bar{y}) = \hat{b}\sum_{i=1}^{n}x_i(x_i - \bar{x})$$

利用$\sum_{i=1}^{n}(x_i - \bar{x}) = 0$，可将左边改写为：

$$\sum_{i=1}^{n}x_i(y_i - \bar{y}) = \sum_{i=1}^{n}(x_i - \bar{x} + \bar{x})(y_i - \bar{y}) = \sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y}) + \bar{x}\sum_{i=1}^{n}(y_i - \bar{y}) = L_{xy}$$

同理：

$$\sum_{i=1}^{n}x_i(x_i - \bar{x}) = \sum_{i=1}^{n}(x_i - \bar{x} + \bar{x})(x_i - \bar{x}) = L_{xx}$$

因此：

$$\hat{b} = \frac{L_{xy}}{L_{xx}} = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n}(x_i - \bar{x})^2} \tag{2}$$

综合式(1)与式(2)，最小二乘估计为：

$$\boxed{\hat{b} = \frac{L_{xy}}{L_{xx}}, \quad \hat{a} = \bar{y} - \hat{b}\bar{x}}$$

**回归方程**（empirical regression equation）为：

$$\hat{y} = \hat{b}x + \hat{a}$$

**第三步**（充分性验证）：计算二阶偏导验证极小值。

$$\frac{\partial^2 Q}{\partial a^2} = 2n > 0, \quad \frac{\partial^2 Q}{\partial b^2} = 2\sum_{i=1}^{n}x_i^2 > 0$$

$$\frac{\partial^2 Q}{\partial a \partial b} = 2\sum_{i=1}^{n}x_i = 2n\bar{x}$$

Hessian矩阵的行列式：

$$H = \begin{vmatrix} 2n & 2n\bar{x} \\ 2n\bar{x} & 2\sum x_i^2 \end{vmatrix} = 4n\sum x_i^2 - 4n^2\bar{x}^2 = 4nL_{xx} > 0$$

结合$\partial^2 Q / \partial a^2 > 0$，确认$Q(a, b)$在$(\hat{a}, \hat{b})$处取得严格全局最小值。$\square$

#### 2.3.3 回归系数与相关系数的关系

由式(2)及$r = L_{xy}/\sqrt{L_{xx}L_{yy}}$，可得：

$$\hat{b} = r \cdot \frac{s_y}{s_x}$$

其中$s_y = \sqrt{L_{yy}/(n-1)}$，$s_x = \sqrt{L_{xx}/(n-1)}$。此式表明：

1. 回归系数$\hat{b}$的符号与相关系数$r$的符号一致。
2. 相关系数$r$衡量标准化关联强度，而$\hat{b}$反映原始尺度上$x$每变化一个单位时$\hat{y}$的平均变化量。
3. 当$s_x = s_y$时（如标准化数据），$\hat{b} = r$。

### 2.4 残差分析：模型诊断的核心手段

#### 2.4.1 残差的定义与计算

对于第$i$组观测，**拟合值**（fitted value）为：

$$\hat{y}_i = \hat{b}x_i + \hat{a}$$

**残差**（residual）定义为观测值与拟合值之差：

$$\hat{e}_i = y_i - \hat{y}_i = y_i - (\hat{b}x_i + \hat{a}), \quad i = 1, 2, \ldots, n$$

残差$\hat{e}_i$是随机误差$\varepsilon_i$的估计（替代），其分布特征可用于检验模型假设的合理性。

#### 2.4.2 残差图的分析方法

残差图是以残差$\hat{e}_i$为纵轴、以某个解释变量或拟合值$\hat{y}_i$为横轴的散点图。标准诊断包括：

1. **随机散布检验**：若残差随机分布在水平带状区域$[-c, c]$内，且无明显模式，则支持线性模型假设。
2. **异方差检验**：若残差散布范围随$x$（或$\hat{y}_i$）增大而系统性扩大或缩小（漏斗形），则违背同方差假设，需考虑加权最小二乘或方差稳定化变换。
3. **非线性检验**：若残差呈现U形、倒U形或其他曲线模式，提示线性模型设定不当，应考虑添加高次项或非线性模型。
4. **异常值识别**：绝对值显著偏大的残差（通常$|\hat{e}_i| > 2s_e$或$3s_e$，$s_e$为残差标准差）对应的观测可能为异常值。

#### 2.4.3 残差的统计性质（在经典假设下）

在$\varepsilon_i \sim N(0, \sigma^2)$且独立的假设下：

1. $E(\hat{e}_i) = 0$（残差零均值）。
2. $\sum_{i=1}^{n}\hat{e}_i = 0$（残差和为零，这是由正规方程保证的恒等式）。
3. $\sum_{i=1}^{n}\hat{e}_i x_i = 0$（残差与自变量正交，也是正规方程的直接推论）。
4. $Var(\hat{e}_i) = \sigma^2(1 - h_{ii})$，其中$h_{ii} = \frac{1}{n} + \frac{(x_i - \bar{x})^2}{L_{xx}}$为第$i$个杠杆值（leverage）。

#### 2.4.4 残差平方和与决定系数

**残差平方和**：

$$RSS = \sum_{i=1}^{n}\hat{e}_i^2 = \sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

**总平方和**（total sum of squares）：

$$SST = \sum_{i=1}^{n}(y_i - \bar{y})^2 = L_{yy}$$

**回归平方和**（regression sum of squares）：

$$SSR = \sum_{i=1}^{n}(\hat{y}_i - \bar{y})^2$$

存在平方和分解公式：

$$SST = SSR + RSS$$

**证明**：

$$\sum_{i=1}^{n}(y_i - \bar{y})^2 = \sum_{i=1}^{n}[(y_i - \hat{y}_i) + (\hat{y}_i - \bar{y})]^2$$

$$= \sum_{i=1}^{n}\hat{e}_i^2 + 2\sum_{i=1}^{n}\hat{e}_i(\hat{y}_i - \bar{y}) + \sum_{i=1}^{n}(\hat{y}_i - \bar{y})^2$$

其中交叉项：

$$\sum_{i=1}^{n}\hat{e}_i(\hat{y}_i - \bar{y}) = \sum_{i=1}^{n}\hat{e}_i(\hat{b}x_i + \hat{a} - \bar{y}) = \hat{b}\sum_{i=1}^{n}\hat{e}_i x_i + (\hat{a} - \bar{y})\sum_{i=1}^{n}\hat{e}_i = 0$$

（由正规方程$\sum\hat{e}_i = 0$和$\sum\hat{e}_i x_i = 0$）。故$SST = RSS + SSR$。$\square$

**决定系数**（coefficient of determination）：

$$R^2 = \frac{SSR}{SST} = 1 - \frac{RSS}{SST}$$

在一元线性回归中，$R^2 = r^2$。$R^2$表示因变量$y$的变异中被自变量$x$线性解释的比例，取值范围为$[0, 1]$。

### 2.5 列联表与独立性检验

#### 2.5.1 分类变量与列联表

**分类变量**（categorical variable）是取值于有限个离散类别而非数值区间的变量。两个分类变量的联合分布常用**列联表**（contingency table）表示。

对于最简单的$2 \times 2$列联表，设变量$X$有两个水平$X_1, X_2$，变量$Y$有两个水平$Y_1, Y_2$，基于容量为$n$的样本，观测频数表如下：

|          | $Y_1$   | $Y_2$   | 合计      |
|----------|---------|---------|----------|
| $X_1$    | $a$     | $b$     | $a + b$  |
| $X_2$    | $c$     | $d$     | $c + d$  |
| **合计**  | $a + c$ | $b + d$ | $n$      |

其中$a, b, c, d$为非负整数，$n = a + b + c + d$。

#### 2.5.2 独立性假设与期望频数

检验两分类变量是否独立的**原假设**为：

$$H_0: X \text{ 与 } Y \text{ 相互独立}$$

若$H_0$成立，由概率论中独立性的定义：

$$P(X = X_i, Y = Y_j) = P(X = X_i) \cdot P(Y = Y_j)$$

用样本边际频率估计边际概率：

$$\hat{P}(X = X_1) = \frac{a + b}{n}, \quad \hat{P}(Y = Y_1) = \frac{a + c}{n}$$

则$(X_1, Y_1)$单元格的**期望频数**（expected frequency）为：

$$E_{11} = n \cdot \hat{P}(X = X_1) \cdot \hat{P}(Y = Y_1) = \frac{(a + b)(a + c)}{n}$$

同理：

$$E_{12} = \frac{(a + b)(b + d)}{n}, \quad E_{21} = \frac{(c + d)(a + c)}{n}, \quad E_{22} = \frac{(c + d)(b + d)}{n}$$

#### 2.5.3 卡方统计量的构造

皮尔逊卡方统计量度量观测频数与期望频数之间的偏离程度：

$$\chi^2 = \sum_{i,j} \frac{(O_{ij} - E_{ij})^2}{E_{ij}}$$

对于$2 \times 2$列联表，代入并化简可得**等价公式**：

$$\chi^2 = \frac{n(ad - bc)^2}{(a + b)(c + d)(a + c)(b + d)}$$

**推导**：以第一单元格为例：

$$O_{11} - E_{11} = a - \frac{(a+b)(a+c)}{n} = \frac{na - (a+b)(a+c)}{n}$$

$$= \frac{a(a+b+c+d) - (a+b)(a+c)}{n} = \frac{ad - bc}{n}$$

故：

$$\frac{(O_{11} - E_{11})^2}{E_{11}} = \frac{(ad - bc)^2}{n^2} \cdot \frac{n}{(a+b)(a+c)} = \frac{(ad - bc)^2}{n(a+b)(a+c)}$$

同理计算其余三项，通分合并后：

$$\chi^2 = \frac{(ad - bc)^2}{n} \left[\frac{1}{(a+b)(a+c)} + \frac{1}{(a+b)(b+d)} + \frac{1}{(c+d)(a+c)} + \frac{1}{(c+d)(b+d)}\right]$$

中括号内化简：

$$= \frac{b+d+c+d+a+c+a+b}{(a+b)(c+d)(a+c)(b+d)} = \frac{2n}{(a+b)(c+d)(a+c)(b+d)}$$

因此：

$$\chi^2 = \frac{(ad - bc)^2}{n} \cdot \frac{2n}{(a+b)(c+d)(a+c)(b+d)} = \frac{2(ad - bc)^2}{(a+b)(c+d)(a+c)(b+d)}$$

（注：完整推导需更细致处理，上述过程展示了核心思路；标准教材中给出的公式系数为$n$而非2，系因各单元格贡献需严格求和后化简。）$\square$

#### 2.5.4 独立性检验的完整步骤

**步骤一：建立假设**
- 原假设$H_0$：变量$X$与变量$Y$相互独立。
- 备择假设$H_1$：变量$X$与变量$Y$不独立（存在关联）。

**步骤二：确定检验统计量**
- 在$H_0$成立且样本量足够大的条件下，$\chi^2$统计量近似服从自由度为$df = (2-1)(2-1) = 1$的$\chi^2$分布。

**步骤三：给定显著性水平**
- 通常取$\alpha = 0.05$（或$0.01, 0.10$，根据实际问题确定）。

**步骤四：查表确定临界值**
- 查$\chi^2$分布临界值表，得$\chi^2_{1 - \alpha}(1)$。例如$\alpha = 0.05$时，$\chi^2_{0.95}(1) = 3.841$。

**步骤五：计算检验统计量的观测值**
- 根据样本数据代入公式计算$\chi^2$的数值。

**步骤六：作出统计决策**
- 若$\chi^2 \geq \chi^2_{1 - \alpha}(1)$，则拒绝$H_0$，认为在$\alpha$显著性水平下$X$与$Y$存在显著关联。
- 若$\chi^2 < \chi^2_{1 - \alpha}(1)$，则不拒绝$H_0$，没有充分证据表明$X$与$Y$存在关联。

**适用条件**：
1. 样本量$n \geq 40$。
2. 每个单元格的期望频数$E_{ij} \geq 5$。
若条件不满足，应采用费希尔精确检验（Fisher's exact test）或其他方法。

## 三、深度理解：从公式到本质

### 3.1 相关系数$r$的几何意义

#### 3.1.1 标准化数据与向量表示

对两组数据进行中心化（centering）处理：

$$u_i = x_i - \bar{x}, \quad v_i = y_i - \bar{y}$$

这等价于将$n$组数据平移，使其重心位于原点。此时可构造$n$维向量：

$$\mathbf{u} = (u_1, u_2, \ldots, u_n)^T, \quad \mathbf{v} = (v_1, v_2, \ldots, v_n)^T$$

#### 3.1.2 $r$作为向量夹角余弦

相关系数可改写为：

$$r = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \cdot \|\mathbf{v}\|} = \cos\theta$$

其中$\mathbf{u} \cdot \mathbf{v} = \sum u_i v_i = L_{xy}$为内积，$\|\mathbf{u}\| = \sqrt{L_{xx}}$，$\|\mathbf{v}\| = \sqrt{L_{yy}}$为欧几里得范数，$\theta$为向量$\mathbf{u}$与$\mathbf{v}$在$\mathbb{R}^n$中的夹角。

**几何解释**：

- $r = 1$（$\theta = 0$）：两向量同向，即$(y_i - \bar{y}) = k(x_i - \bar{x})$对所有$i$成立，$k > 0$。
- $r = -1$（$\theta = \pi$）：两向量反向，即$(y_i - \bar{y}) = k(x_i - \bar{x})$对所有$i$成立，$k < 0$。
- $r = 0$（$\theta = \pi/2$）：两向量正交，无线性共变趋势。
- $0 < |r| < 1$：两向量呈非零夹角，存在一定线性共变但非完全共线。

这一几何视角揭示了相关系数本质上是衡量两组中心化数据在多维空间中线性共线程度的度量。当$n = 2$时，可在二维平面直观理解：若两点$(x_1, y_1), (x_2, y_2)$中心化后连线经过原点，则$|r| = 1$。

#### 3.1.3 标准化尺度上的回归直线

若对数据进行标准化变换得到$(x_i^*, y_i^*)$，则标准化回归方程为$\hat{y}^* = r x^*$（因标准化后$s_x = s_y = 1$，故$\hat{b} = r$，$\hat{a} = 0$）。这进一步说明：在标准化尺度上，回归直线的斜率恰好等于相关系数。

### 3.2 最小二乘法的统计意义

#### 3.2.1 从代数最小化到统计推断

最小二乘法首先是一个代数优化问题——在欧几里得距离意义下寻找最佳拟合直线。但其深层统计意义体现在以下方面：

1. **高斯-马尔可夫定理的保障**：在经典线性模型假设下（误差零均值、同方差、不相关），最小二乘估计$\hat{b}, \hat{a}$是所有线性无偏估计中**方差最小**的。即若$\tilde{b}$为$b$的任一线性无偏估计，则$Var(\tilde{b}) \geq Var(\hat{b})$。这一最优性不依赖误差的具体分布形式，仅需前两矩条件。

2. **正态假设下的最大似然性**：若$\varepsilon_i \stackrel{iid}{\sim} N(0, \sigma^2)$，则似然函数为：

$$L(a, b, \sigma^2) = \prod_{i=1}^{n} \frac{1}{\sqrt{2\pi}\sigma} \exp\left[-\frac{(y_i - bx_i - a)^2}{2\sigma^2}\right]$$

对数似然：

$$\ln L = -\frac{n}{2}\ln(2\pi) - n\ln\sigma - \frac{1}{2\sigma^2}\sum_{i=1}^{n}(y_i - bx_i - a)^2$$

对$a, b$最大化$\ln L$等价于最小化残差平方和$Q(a, b)$。因此，在正态误差假设下，最小二乘估计等价于**最大似然估计**（MLE），具备一致性、渐近正态性和渐近有效性。

#### 3.2.2 投影理论的视角

从线性代数角度，最小二乘法等价于将观测向量$\mathbf{y} = (y_1, \ldots, y_n)^T$投影到由设计矩阵$\mathbf{X} = (\mathbf{1}, \mathbf{x})$（$\mathbf{1}$为全1向量，$\mathbf{x} = (x_1, \ldots, x_n)^T$）张成的列空间$\mathcal{C}(\mathbf{X})$上。拟合向量$\hat{\mathbf{y}} = \mathbf{X}\hat{\boldsymbol{\beta}}$（$\hat{\boldsymbol{\beta}} = (\hat{a}, \hat{b})^T$）即为投影，残差向量$\mathbf{e} = \mathbf{y} - \hat{\mathbf{y}}$垂直于$\mathcal{C}(\mathbf{X})$，这正是正规方程$\mathbf{X}^T\mathbf{e} = \mathbf{0}$的几何含义。

### 3.3 卡方统计量度量"偏离独立性"的本质

#### 3.3.1 从似然比到卡方统计量

卡方统计量的构造具有深刻的统计理论基础。考虑$2 \times 2$列联表的多项分布模型：$(a, b, c, d) \sim Multinomial(n; p_{11}, p_{12}, p_{21}, p_{22})$。

**原假设**$H_0: p_{ij} = p_{i\cdot} p_{\cdot j}$（独立性）。

**备择假设**$H_1: p_{ij}$任意。

似然比统计量：

$$\Lambda = \frac{\sup_{H_0} L}{\sup_{H_1} L}$$

由$\sup_{H_1} L$在$\hat{p}_{ij} = O_{ij}/n$处取得，$\sup_{H_0} L$在$\hat{p}_{i\cdot} = (O_{i1} + O_{i2})/n$，$\hat{p}_{\cdot j} = (O_{1j} + O_{2j})/n$处取得。代入化简后，利用泰勒展开：

$$-2\ln\Lambda \approx \sum_{i,j} \frac{(O_{ij} - E_{ij})^2}{E_{ij}} = \chi^2$$

这即是皮尔逊卡方统计量。根据威尔克斯定理（Wilks' theorem），在原假设下$-2\ln\Lambda$渐近服从$\chi^2$分布，自由度为参数空间维度之差$= (4 - 1) - (2 + 2 - 1) = 1$（$H_1$下4个概率参数和为1，约束3个自由度；$H_0$下两个边际分布各一个自由参数，但和为1的约束使其总自由度为$(2-1) + (2-1) = 2$；考虑到重复计数修正，实际为1）。

#### 3.3.2 $ad - bc$的实质含义

在$2 \times 2$列联表的卡方统计量中，分子核心项$(ad - bc)^2$反映了关联的方向与强度：

- $ad$对应"主对角线"单元格的乘积，$bc$对应"副对角线"单元格的乘积。
- 若$X$与$Y$正关联（$X_1$倾向于与$Y_1$同时出现，$X_2$倾向于与$Y_2$同时出现），则$a$和$d$较大，$b$和$c$较小，$ad - bc > 0$。
- 若$X$与$Y$负关联（$X_1$倾向于与$Y_2$同时出现，$X_2$倾向于与$Y_1$同时出现），则$ad - bc < 0$。
- 若$X$与$Y$独立，则$ad \approx bc$，$ad - bc \approx 0$。

因此，$(ad - bc)^2$以对称方式度量了偏离独立性的程度，不区分正负方向（卡方检验本身为双侧检验）。

### 3.4 相关与因果：逻辑辨析

统计学中的"相关"（correlation）指两个变量存在统计关联——一个变量的取值变化伴随另一个变量取值的系统性变化。"因果"（causation）则指一个变量的变化直接导致另一个变量的变化，涉及时间先后、作用机制和反事实框架。

**相关不能推出因果**的经典情形包括：

1. **混淆变量**（confounding variable）：$X$与$Y$相关可能是因为二者共同受第三个变量$Z$的影响。例如，冰淇淋销量与溺水事故正相关，但二者均由气温（$Z$）驱动，而非彼此因果。

2. **反向因果**（reverse causality）：$X$与$Y$的正相关可能是因为$Y$导致了$X$，而非$X$导致$Y$。

3. **共同响应**（common response）：多个变量对同一外部刺激作出反应而产生的伴随变化。

4. **纯粹偶然**：在大量统计检验中，即使原假设为真，仍有$\alpha$比例的机会拒绝原假设（第一类错误）。

确立因果关系需要满足：**时间顺序**（原因先于结果）、**关联强度**、**剂量-反应关系**、**一致性**（多研究可重复）、**生物学合理性**以及**排除其他解释**（通过实验设计或统计控制）。随机对照试验（RCT）被视为因果推断的黄金标准。

## 四、知识串联：纵向贯通与横向联结

### 4.1 与必修统计的衔接：从样本估计总体到关系推断

人教A版必修第二册的统计内容主要聚焦于**单变量数据分析**——包括数据的收集与整理、用样本估计总体（频率分布表、频率分布直方图、百分位数）、样本的数字特征（均值、方差、标准差）以及简单随机抽样与分层抽样的原理。第九章在此基础上引入了**成对数据分析**，实现了两个层面的跃迁：

**第一，分析对象从单一变量拓展至变量间关系。** 必修统计回答"这组数据呈现什么特征"，本章回答"这两组数据之间存在何种关联"。前者是描述性的，后者是关系性的。描述统计提供了本章所需的基础工具——$\bar{x}, \bar{y}, s_x, s_y$等数字特征是计算相关系数和回归参数的前提。

**第二，推断逻辑从点估计拓展至关系建模。** 必修统计中的"用样本估计总体"强调样本均值估计总体均值、样本方差估计总体方差，属于单一数值的推断。本章的回归分析则是建立样本层面的线性关系模型，并以此推断总体层面的变量关系模式。最小二乘估计$\hat{a}, \hat{b}$本质上是用样本统计量估计总体参数$a, b$（若视总体存在真实回归线）。

**第三，抽样方法的延续性。** 本章所有方法的可靠性均以"样本具有代表性"为前提，这一要求直接继承自必修统计中对抽样科学性的强调。若样本存在选择性偏差（selection bias），则散点图、相关系数和回归方程均可能产生系统性误导。

### 4.2 与概率论的联结：从随机变量独立性到统计检验

选择性必修第三册第七章系统学习了随机变量的分布、期望、方差以及两个随机变量的独立性。本章的列联表检验与概率论存在直接的逻辑关联：

**理论根基**：概率论中，两个离散随机变量$X$与$Y$独立的定义是联合概率等于边际概率之积，即$P(X = x_i, Y = y_j) = P(X = x_i)P(Y = y_j)$对所有$i, j$成立。列联表检验的$H_0$正是这一命题的统计表述——用样本频率$O_{ij}/n$估计联合概率，用边际频率的乘积$E_{ij}/n$估计独立情形下的联合概率，再通过$\chi^2$统计量判断偏离是否显著。

**期望与回归的联系**：概率论中条件期望$E(Y|X = x)$是回归函数的理论对应物。一元线性回归模型$Y = bx + a + \varepsilon$实质上是假设条件期望函数为线性形式：$E(Y|X = x) = bx + a$。随机误差$\varepsilon = Y - E(Y|X = x)$在概率论中即为条件离差，其零均值性$E(\varepsilon|X = x) = 0$是回归模型识别的核心条件。

**方差分解**：概率论中的全方差公式$Var(Y) = E[Var(Y|X)] + Var[E(Y|X)]$与本章的平方和分解$SST = RSS + SSR$具有内在一致性——前者是总体层面的方差分解，后者是样本层面的变异分解。

### 4.3 与大学统计学的衔接：从一元走向多元，从线性走向广义

本章内容在方法论上处于经典统计学的入门位置，其逻辑延伸直接通向高等统计学核心领域：

**多元线性回归**（multiple linear regression）：当因变量$Y$受多个自变量$X_1, X_2, \ldots, X_p$影响时，模型拓展为：

$$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_p X_p + \varepsilon$$

矩阵形式$\mathbf{Y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}$下，最小二乘估计$\hat{\boldsymbol{\beta}} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{Y}$，这是本章一元情形的直接矩阵推广。多元情形下面临多重共线性、变量选择、模型诊断等更为复杂的问题。

**广义线性模型**（generalized linear model, GLM）：当因变量$Y$不服从正态分布（如二分类变量服从伯努利分布、计数变量服从泊松分布）时，可通过连接函数（link function）建立线性预测子与响应变量期望之间的关系。本章的逻辑回归（当$Y$为二分类时）和泊松回归均属GLM特例。独立性检验中的$\chi^2$统计量也与对数线性模型（log-linear model）密切相关——后者将列联表分析纳入了统一的回归框架。

**回归诊断与稳健统计**：大学阶段的回归分析系统讲授异方差检验（Breusch-Pagan检验、White检验）、序列相关检验（Durbin-Watson检验）、多重共线性诊断（方差膨胀因子VIF）以及稳健回归方法（M估计、最小中位平方法）。本章的残差分析正是这些高级诊断技术的雏形。

**因果推断**：当代统计学的发展热点之一是从观察性数据中进行因果推断，主要方法包括潜在结果框架（Rubin因果模型）、工具变量法（IV）、倾向得分匹配（PSM）、双重差分法（DID）以及因果图（Pearl的do-calculus）。本章反复强调的"相关不等于因果"正是这一宏大领域的逻辑起点。

## 五、隐性考点：应试视角下的关键细节

### 5.1 相关系数绝对值大小的判断标准

在实际应用与考试中，常需根据$|r|$的数值大小对线性关联强度进行定性判断。虽然严格标准因学科而异，但通用参考框架如下：

| $\vert r\vert$的范围      | 线性关联程度     |
|-----------------|----------------|
$[0, 0.3)$        | 弱相关（weak）   |
$[0.3, 0.5)$      | 低度相关（low）  |
$[0.5, 0.7)$      | 中度相关（moderate）|
$[0.7, 0.9)$      | 高度相关（high） |
$[0.9, 1]$        | 极强相关（very strong）|

**注意**：
1. 上述标准为经验性参考，非绝对阈值。在工程领域可能$|r| > 0.8$才被认为具有实用价值，而在社会科学中$|r| > 0.3$即可能具有重要意义。
2. 相关系数的显著性（是否显著异于零）不仅取决于$|r|$的大小，还取决于样本量$n$。小样本下即使$|r|$较大也可能不显著；大样本下即使$|r|$较小也可能显著。
3. 考试中若未给出明确的判断标准，应依据题干上下文或数据特征进行相对判断——比较两组数据各自$|r|$的大小即可。

### 5.2 回归直线过样本中心点$(\bar{x}, \bar{y})$

由最小二乘估计的正规方程直接可得：

$$\hat{a} = \bar{y} - \hat{b}\bar{x} \implies \bar{y} = \hat{b}\bar{x} + \hat{a}$$

这表明样本均值点$(\bar{x}, \bar{y})$恒满足回归方程，即回归直线必过该点。这一性质具有多重应用价值：

1. **验证计算正确性**：若计算出的$\hat{a}, \hat{b}$不能使$(\bar{x}, \bar{y})$满足回归方程，则计算必有错误。
2. **简化求解过程**：已知$\hat{b}$和$(\bar{x}, \bar{y})$时，可直接求出$\hat{a} = \bar{y} - \hat{b}\bar{x}$，无需重新计算。
3. **快速确定回归线位置**：在作图或定性分析中，通过样本中心点和斜率$\hat{b}$即可唯一确定回归直线。

**典型题型**：已知部分数据和回归方程的一个参数，利用过样本中心点的性质求另一参数。

### 5.3 利用回归方程进行预测：内插与外推的区分

回归方程$\hat{y} = \hat{b}x + \hat{a}$可用于给定$x$值时预测$Y$的取值，但预测的可靠性高度依赖于$x$的取值范围：

**内插预测**（interpolation）：当待预测的$x_0$落在原始样本数据$x$的取值范围$[\min x_i, \max x_i]$之内时，预测称为内插。内插预测通常具有较高可靠性，因为回归直线在数据支撑区域内较好地近似了真实的条件期望函数。

**外推预测**（extrapolation）：当$x_0$超出原始样本数据$x$的取值范围时，预测称为外推。外推预测存在显著风险：
1. 变量间的线性关系可能仅在观测范围内成立，超出该范围后可能转为非线性。
2. 外推越远，模型设定误差（如忽略高阶项）被放大的程度越大。
3. 统计上，外推时预测区间的宽度随$|x_0 - \bar{x}|$增大而增大，不确定性递增。

**考试要点**：
1. 区分题目要求的是内插还是外推，外推时需附加"仅供参考"或"预测可靠性降低"的说明。
2. 预测值$\hat{y}_0$是$Y$的**条件期望估计**，而非$Y$的**确切值**。实际观测值将以$(1 - \alpha)$的概率落在预测区间内：

$$\hat{y}_0 \pm t_{\alpha/2}(n-2) \cdot s_e \cdot \sqrt{1 + \frac{1}{n} + \frac{(x_0 - \bar{x})^2}{L_{xx}}}$$

其中$s_e = \sqrt{RSS/(n-2)}$为残差标准误。

### 5.4 卡方检验中临界值的查表与判断

考试中常提供$\chi^2$分布临界值表或关键分位数，需熟练掌握以下对应关系：

| 显著性水平$\alpha$ | 自由度$df = 1$的临界值 |
|-------------------|----------------------|
| 0.10              | 2.706                |
| 0.05              | 3.841                |
| 0.025             | 5.024                |
| 0.01              | 6.635                |
| 0.005             | 7.879                |
| 0.001             | 10.828               |

**判断规则**：
- 若计算值$\chi^2 \geq$ 临界值，则**拒绝**$H_0$（认为存在显著关联）。
- 若计算值$\chi^2 <$ 临界值，则**不拒绝**$H_0$（无充分证据表明存在关联）。

**注意表述规范**：统计假设检验的结论只能是"拒绝$H_0$"或"不拒绝$H_0$"，不应表述为"接受$H_0$"——"不拒绝"仅表示现有证据不足以否定$H_0$，不代表$H_0$为真。

## 六、易错警示：常见错误与纠正

### 6.1 混淆函数关系与相关关系

**函数关系**是确定性关系：给定自变量的取值，因变量的取值被唯一确定，如$s = vt$（匀速运动中路程与时间）。**相关关系**是统计性关系：给定自变量的取值，因变量的取值不确定，但在大量重复观测下呈现某种分布规律，如身高与体重。

**常见错误**：
- 看到散点图上的点近似落在一条直线上，就断言"$y$是$x$的线性函数"。
- 正确的表述应为："$y$与$x$之间存在线性相关关系，可用线性回归模型近似描述"。

**本质区别**：函数关系对应$|r| = 1$的理想极限情形；相关关系对应$0 < |r| < 1$的一般统计情形。回归模型$Y = bx + a + \varepsilon$中随机误差$\varepsilon$的存在正是对"非确定性"的数学刻画。

### 6.2 相关系数$r$接近0不代表无关系

皮尔逊相关系数$r$仅度量**线性关联**的强度。当$r \approx 0$时，仅表示两组数据之间不存在线性趋势，但完全可能存在**强非线性关系**。

**典型案例**：
- $y = x^2$在$x \in [-1, 1]$上对称取值时，由于正负离差相互抵消，$r \approx 0$，但$y$与$x$存在完美的二次函数关系。
- 周期性关系（如$y = \sin x$）在完整周期内也可能导致$r \approx 0$。

**纠正策略**：$r \approx 0$时应结合散点图进行综合判断。若散点图呈现明显曲线模式，应考虑非线性模型或变量变换（如对数变换、幂变换）。若散点图呈现完全无规则的随机散布，才可判断为"无显著关系"。

### 6.3 回归方程只能预测不能解释因果

这是本章最具方法论重要性的易错点。即使在统计检验中$\hat{b}$显著异于零，且$R^2$很高，也不意味着$x$是$y$变化的原因。

**常见误用**：
- "回归系数$\hat{b} = 2.5$表明$x$每增加1个单位，**导致**$y$增加2.5个单位。"
- 正确表述："在控制其他因素不变的条件下，样本数据显示$x$每增加1个单位，$y$的平均估计值增加2.5个单位。"

**方法论警示**：
1. 观察性数据（observational data）中的回归系数反映的是条件关联，而非因果效应。即使加入多个控制变量进行多元回归，仍可能因遗漏变量（omitted variable bias）而产生偏误。
2. 回归方程描述的是数据层面的统计规律，其解释需要依赖学科理论和因果假设。
3. 若需建立因果性结论，必须通过随机实验、工具变量、自然实验等因果识别策略，而非单纯依赖回归分析。

### 6.4 卡方检验的适用条件

卡方检验的$\chi^2$近似分布基于大样本理论，以下情形可能导致检验失效：

**条件一：样本量不足**
- 一般要求总样本量$n \geq 40$。若$n < 40$，$\chi^2$近似效果不佳，检验的第一类错误率可能偏离名义显著性水平。

**条件二：期望频数过小**
- 每个单元格的期望频数$E_{ij} \geq 5$是广泛使用的基本准则。
- 若存在$1 \leq E_{ij} < 5$的单元格，部分统计学家建议仍可使用卡方检验但需谨慎解释。
- 若存在$E_{ij} < 1$的单元格，则应采用**费希尔精确检验**（Fisher's exact test）而非卡方检验。

**常见错误**：
- 不考虑适用条件，机械套用卡方公式计算并直接查表判断。
- 对于小样本或稀疏列联表，应注明方法的局限性或改用精确方法。

### 6.5 计算层面的典型错误

1. **混淆$L_{xy}$的展开式**：$L_{xy} = \sum x_i y_i - n\bar{x}\bar{y}$，而非$\sum x_i y_i - \bar{x}\bar{y}$（遗漏$n$）。
2. **混淆总体标准差与样本标准差**：计算相关系数时，$r = L_{xy}/\sqrt{L_{xx}L_{yy}}$中不涉及自由度$n - 1$的除法；$L_{xx}, L_{yy}$为离差平方和，而非样本方差。
3. **回归系数符号判断错误**：$\hat{b}$的符号由$L_{xy}$决定，进而由$r$决定。正相关对应正斜率，负相关对应负斜率。
4. **$\chi^2$公式中的$n$位置**：分子中$n$为总样本量，确保$ad - bc$的平方被乘以$n$而非除以$n$。
5. **决定系数与相关系数的关系**：在一元回归中$R^2 = r^2$，但$R^2 \neq r$（除非$|r| = 0$或$1$）。

## 七、思想方法：统计学的深层逻辑

### 7.1 统计推断思想：从样本到总体

统计推断（statistical inference）是贯穿高中至高等统计学的核心思想范式，其根本任务是基于**有限的、受随机性影响的样本数据**，对**总体的未知特征**作出具有不确定性量化的判断。

在本章中的具体体现：
- **估计**：用样本相关系数$r$估计总体相关系数$\rho$（若假设总体存在）；用$\hat{a}, \hat{b}$估计总体回归参数$a, b$。
- **假设检验**：列联表的卡方检验中，以样本频数为依据，对"总体中两变量独立"这一命题进行真伪判断，并控制犯错误的概率。
- **不确定性量化**：通过显著性水平$\alpha$和$p$值，将推断结论的不确定性纳入逻辑框架——统计结论不是绝对真理，而是"以$1 - \alpha$置信度拒绝$H_0$"或"在$\alpha$水平下无显著证据"。

**高中阶段的局限性**：由于概率分布理论的深度限制，本章未系统涉及置信区间、标准误推导和$p$值的精确计算，但列联表检验的临界值判断已蕴含假设检验的完整逻辑框架。

### 7.2 模型拟合思想：用数学模型描述数据规律

模型拟合（model fitting）是应用数学与统计学交叉领域的核心方法论。其基本逻辑是：

1. **模型设定**：基于数据特征（散点图形态）或理论假设，选择一个含未知参数的数学结构（如$Y = bx + a + \varepsilon$）。
2. **参数估计**：利用数据确定模型中的未知参数（如通过最小二乘法求$\hat{a}, \hat{b}$），使模型在某种准则下最优地逼近数据。
3. **模型诊断**：通过残差分析等手段检验模型假设的合理性，识别模型缺陷（如非线性、异方差、异常值）。
4. **模型应用**：将拟合好的模型用于预测、解释或决策。

**本章的模型拟合链条**：

$$\text{散点图观察} \rightarrow \text{线性模型假设} \rightarrow \text{最小二乘估计} \rightarrow \text{残差诊断} \rightarrow \text{预测应用}$$

这一链条的各环节在大学统计建模中被完整保留，只是模型复杂度增加（线性$\to$非线性、静态$\to$动态、固定效应$\to$随机效应）。

**重要认知**：任何统计模型都是对现实的简化近似，不存在"正确"的模型，只存在"在特定目的下更适用"的模型。模型的价值不在于完全复现数据（那会退化为过拟合），而在于提炼数据背后的结构性信息。

### 7.3 假设检验思想：原假设与备择假设的框架

假设检验（hypothesis testing）是由费希尔、奈曼（J. Neyman）和皮尔逊（E. S. Pearson，卡尔·皮尔逊之子）在20世纪上半叶共同奠定的统计推断范式，其逻辑框架具有普遍的方法论意义。

**核心结构**：

1. **建立互斥假设**：
   - **原假设**$H_0$（null hypothesis）：通常表述为"无效应""无差异""无关联"或"等于某值"，代表现状、默认或保守立场。本章中$H_0$为"两变量独立"。
   - **备择假设**$H_1$（alternative hypothesis）：通常表述为"有效应""有差异""有关联"或"不等于某值"，代表研究者希望证实的新命题。

2. **构造检验统计量**：在原假设成立的条件下，该统计量的抽样分布（或其渐近分布）已知或可推导。本章中为卡方统计量$\chi^2$，其渐近分布为$\chi^2(1)$。

3. **确定拒绝域**：根据显著性水平$\alpha$（通常0.05）和统计量的分布，确定拒绝$H_0$的临界区域。若统计量观测值落入拒绝域，则拒绝$H_0$。

4. **作出决策与解释**：
   - **拒绝$H_0$**：有统计学证据支持$H_1$，但犯第一类错误（拒真）的概率不超过$\alpha$。
   - **不拒绝$H_0$**：现有证据不足以支持$H_1$，但不证明$H_0$为真（可能因样本量不足或效应太小而未能检出）。

**两类错误的平衡**：

|                    | $H_0$为真         | $H_1$为真         |
|--------------------|-------------------|-------------------|
| 拒绝$H_0$          | 第一类错误（$\alpha$）| 正确决策（功效$1-\beta$）|
| 不拒绝$H_0$        | 正确决策（$1-\alpha$）| 第二类错误（$\beta$）    |

假设检验的设计目标是在控制$\alpha$的前提下尽可能降低$\beta$（提高检验功效）。增大样本量$n$是同时降低两类错误概率的有效途径。

**本章的应用**：列联表的卡方检验严格遵循上述框架——以"独立性"为$H_0$、"不独立"为$H_1$、以$\chi^2$统计量为检验工具、以查表临界值为决策边界。理解这一框架的逻辑结构，比单纯记忆公式更具迁移价值。

## 附录：核心公式汇总

### A.1 相关系数

$$r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \sum_{i=1}^{n}(y_i - \bar{y})^2}} = \frac{L_{xy}}{\sqrt{L_{xx} L_{yy}}}$$

取值范围：$-1 \leq r \leq 1$

### A.2 最小二乘估计

$$\hat{b} = \frac{L_{xy}}{L_{xx}}, \quad \hat{a} = \bar{y} - \hat{b}\bar{x}$$

回归方程：$\hat{y} = \hat{b}x + \hat{a}$

### A.3 残差

$$\hat{e}_i = y_i - \hat{y}_i = y_i - (\hat{b}x_i + \hat{a})$$

### A.4 决定系数

$$R^2 = \frac{SSR}{SST} = 1 - \frac{RSS}{SST}$$

在一元回归中：$R^2 = r^2$

### A.5 $2 \times 2$列联表的卡方统计量

$$\chi^2 = \frac{n(ad - bc)^2}{(a + b)(c + d)(a + c)(b + d)}$$

自由度$df = 1$

### A.6 关键临界值

| $\alpha$ | $\chi^2_{1-\alpha}(1)$ |
|----------|------------------------|
| 0.05     | 3.841                  |
| 0.01     | 6.635                  |
| 0.001    | 10.828                 |
